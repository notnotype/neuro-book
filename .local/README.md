# 本地资产目录

`.local/` 是用户管理的本地资产根。除本文件外，目录内容全部被 Git 忽略，不属于产品源码、Task 正式证据或发布输入。

## 约定

- Agent 通常不得读取、写入、移动或删除 `.local/` 内的内容；只有用户明确要求时才执行一次性迁移或检查。`.local/artifacts/` 是例外，见下文。
- 用户负责本地资产的来源、更新、备份、授权和清理。仓库治理不替用户管理这些内容。
- 本地资产不得作为 CI、发布、测试默认输入；需要进入仓库的脱敏结果应放入对应 Task 的 `evidences/`。

## 目录

- `.local/github/`：外部第三方调研仓库。默认只作为人工调研参考，不自动拉取、更新或改写。
- `.local/datasets/`：本地数据集和评测语料，不进入 Git。
- `.local/artifacts/`：Agent 为用户生成、只在本地查看的产物，例如可视化回顾网页。用户说“本地看”“不发布”的这类产物，Agent 直接写入这里，文件名带日期前缀（例如 `2026-09-30-platform-review.html`），不放在会重启丢失的会话临时目录。已有文件只在用户要求时读取或改写。
- `.local/drafts/`：从仓库 `docs/drafts/` 移出的用户草案、原始提示词和个人 TODO。它们不是当前规范、Proposal 或 Task；需要恢复开发时先提炼为仓库内的规范、Proposal 或 Issue。
- 其他目录：用户自行管理的本地素材，例如书籍资料和角色草稿。
