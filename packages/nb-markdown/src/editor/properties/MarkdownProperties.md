# MarkdownProperties

Markdown 文件开头 frontmatter 的属性面板（[`workbench/markdown-editing.md`](../../../../../docs/specs/workbench/markdown-editing.md) 输出 39–51）：正文上方一张淡底、没有边线的卡片，按属性显示与编辑，也能就地改两条 `---` 之间的 YAML。它只认 frontmatter 的原文：读成一行行属性、编辑后交出新的原文，改一项只替换这一项的那段原文（属性模型 `model.ts`），别的属性、注释与写法字节不变。放进哪个编辑器、怎样进撤销历史、展开状态记在哪里都归宿主（neuro-book 的 `MarkdownControl`）。

## 布局

- **顶上一行**：折叠箭头、“属性”、收起时的摘要（每个属性“名字 值”，以“·”隔开，一行放不下在末尾省略），右端是源码切换按钮（按下态表示正在看源码）。整行（切换按钮之外）是一个按钮，点了展开或收起。YAML 读不成属性时摘要换成一句出错提示，切换按钮不可用（展开时是按下的）。收起时点切换按钮：展开并看源码。
- **属性行**（展开、按属性显示时）：四列网格：类型图标（16px）、属性名（6em，单行截断）、值（伸缩）、行尾按钮（固定宽度，没有按钮时照样留着）。悬停的一行与焦点在里面的一行有底色；行尾按钮是“移除”（悬停或焦点在这一行时显现，位置一直留着）或表示不了的属性的“在源码里改”（常显）。值按类型：文字、数字是无框的单行输入，勾选是复选框，日期是 nb-ui `DateInput`（无框），列表是 nb-ui `TagInput`（无框，项会折行，行随之变高；每项的 × 只在焦点在这个列表里时显现，位置一直留着），表示不了的是一行等宽的源码（省略号截断）。
- **宿主给的图标、显示名与类型**（`describe`，输出 60）：声明的图标换掉这一行的类型图标（仍是改类型的按钮；表示不了的“{ }”不换），声明的显示名换掉属性名一列、收起时的摘要与各输入的可访问名称，名称的提示带真名（“显示名（真名）”）；有显示名的行里名字是一个按钮，点了才变成输入框、输入框里是真名，写回改的是真键，离开后回到显示名。声明的类型只管值为空（`名字:`）的行：这一行按它输入（日期、数字、勾选——空值显示成不勾选、点了才写回——或列表），不改文件；优先级是这次挂载里在类型菜单选过的 > 声明的 > 文字。有值的行仍按值推断，值与声明的类型不符时照值显示，不报错。
- **添加属性**：最后一行的按钮，与属性名一列对齐；点了在末尾多出一行，名字处是输入框。
- **源码**：按属性显示的那一块换成等宽、随内容长高的文字框（YAML 末尾的那个换行不显示，写回时补上）（无框，压在一块实心的面板底上）；读不成属性时下面一行写出错的行号与原因，出错的那一行在文字框里带波浪线。
- `390×844`：名字列仍是 6em，值列收窄，列表的项折行；行尾按钮不让位。

## 交互

- 文字、数字、名字的输入在回车或焦点离开时写回；勾选、日期（填满三段或在日历里选了一天）、列表（每加、删一项）立即写回。日期的年份不到 1000 时当作还没打完、不写回（在年份那一段从头打 `2026`，中途会先出 `0002`、`0202`）：所以面板里改不出 1000 年以前的日期，要在源码里写。数字的输入不是一个数时不写回，输入框回到原值。清空写回空值。
- 一个属性都没有时，新属性的名字空着按退格：这一行消失，发 `leave("backspace")`。
- 改名与已有的名字相同、或为空时不写回，回到原名。新加的名字为空时这一行消失；与已有的同名时这一行留着、值的位置写“已有同名属性”，焦点离开时这一行消失。新名字写回后焦点移到它的值。
- 类型图标是按钮，点了出类型菜单（文字、数字、勾选、日期、列表，当前的打勾，换不了的置灰；见 Spec 输出 46）。空值换成文字、数字或日期不写回，这一行在组件的这一次挂载期间按选的类型输入。
- 源码：焦点离开或 Ctrl+Enter（⌘Enter）写回；文字里有只写着 `---` 的一行时不写回，下面写出原因，字留在文字框里；这时点切换按钮回到按属性显示，这次的修改放弃。
- 键盘：上下方向键在顶上一行、各属性的值（表示不了的属性是它的“在源码里改”）与“添加属性”之间走（日期的分段输入自己用上下键）；在最后一个（展开时是“添加属性”，收起时是顶上一行）按下方向键，或在任何地方按 Esc（浮层没有先处理它时），发 `leave`，正在改的输入照常写回（失焦）。输入法组字时的回车与 Esc 归输入法。
- 宿主把焦点交进来用 `focusLast`、`focusNewName`（下面“数据”）。

## 数据

```ts
type MarkdownPropertiesProps = {
    /** 受控：frontmatter 的原文（开栏到闭栏，`isWholeFrontmatter` 认可的）。组件不改它，只发 `commit`。 */
    raw: string;
    /** 受控：展开。 */
    open: boolean;
    /** 只读：值不能改，没有“添加属性”、“移除”与类型菜单，源码只能看。缺省 false。 */
    readonly?: boolean;
    /** 按属性名给图标、显示名与类型（`PropertyDescription`，输出 60）；不传、或返回 null 的行照旧。在渲染里调用：它读的响应式状态（界面语言）变了面板跟着变。 */
    describe?: (name: string) => PropertyDescription | null;
};

type MarkdownPropertiesEmits = {
    /** 一次写回：新的 frontmatter 原文（与 `raw` 不同才发）。宿主把它作为一次编辑提交（撤销一步）。 */
    (event: "commit", raw: string): void;
    /** 点了顶上一行。 */
    (event: "update:open", open: boolean): void;
    /**
     * 焦点要交回正文（最后一个输入上按下方向键、Esc）。组件不自己移动焦点。`backspace`：一个属性都没有、新属性的名字空着时
     * 按了退格（刚新建的 frontmatter），宿主可以撤回那次新建。
     */
    (event: "leave", reason?: "backspace"): void;
};

type MarkdownPropertiesExpose = {
    /** 把还没写回的输入（文字、数字、名字、源码）同步写回：有就同步发一次 `commit`。宿主在结算、换文档之前调用。 */
    flush(): void;
    /** 手里有没有还没写回的输入（响应式读）。 */
    readonly pending: boolean;
    /** 焦点放到最后一个输入：展开时“添加属性”，收起时顶上一行。 */
    focusLast(): void;
    /** 展开（不看 `open`，同写错时）、在末尾开一行新属性并把焦点放到它的名字上。只读、读不成属性时不做。组件不发 `update:open`：记不记这次展开由宿主定。 */
    focusNewName(): void;
};
```

没有插槽。透传属性落在根元素（`section`）上。

`state:local`：还没写回的输入（同一时间只有焦点所在的那一个）、按属性显示还是看源码、正在新加的那一行、空值选过的类型（按属性名记，改名时跟着走）、不看 `open` 的展开（挂载时 YAML 读不成属性，或 `focusNewName`；收起一次后不再强制）。`state:inject`：经翻译端口取本包目录里的文字（`properties.*`）。类型菜单与日期的日历是 nb-ui 的 `DropdownMenu`、`DateInput` 自己的浮层，渲染到 `body`。

## 状态

- 只读：值的输入只读，勾选、日期、列表只读；没有“添加属性”、行尾的“移除”，类型图标不是按钮；源码文字框只读，切换照常。
- 变成只读时：还没写回的输入与正在新加的那一行放弃。
- 读不成属性：打开时强制展开（`open` 为 false 也展开，收起一次后按 `open`），显示源码与原因，不能切回；没有“添加属性”。
- 没有属性：展开时只有“添加属性”；收起时只有“属性”二字。
- `raw` 被宿主换掉（撤销、外部修改）：按新原文重画；还没写回的输入放弃。

## 不支持

全书统一的属性类型、日期时间、嵌套字段的表单编辑、属性名与值的补全、拖动排序、`tags` 这类键的特殊处理；改 frontmatter 之外的东西；新建或去掉整段 frontmatter（宿主做）。

## 注意事项

- 宿主要在 `raw` 变成 null（文档没有 frontmatter）时不挂这个组件，并在换文档时换一个实例（`key`）：空值选过的类型、强制展开都按一次挂载算。
- `commit` 是同步发的：`flush` 返回时宿主已经收到，宿主可以紧接着读编辑器的文档。
