# LowCodeResourcePresetField

低代码表单里带管理能力的资源预设字段：一个「资源」选择器加上可就地增删改的管理面板。每个资源有 key、名称、来源（全局 / 项目）与一段正文，用户能在面板里新建、重命名、删除、改正文，也能在项目视野下把全局资源复制成项目资源。它与同目录其它字段的差别有两条：一是协商两样东西——「选中了哪个 key」和「改了哪些资源」；二是**所有改动都不落盘**，组件只把结果发出去，保存时机与存储都归宿主。能力（能不能建、能不能改、能不能删）来自字段自带的描述，组件不猜。

## 数据

```ts
type LowCodeResourcePresetScope = "global" | "project";

type LowCodeResourcePresetFieldProps = {
    /** 字段定义。本组件用到 `path`（给改动打标）与 `resource`（选项、正文、模板、key 前后缀、能力）；`field.resource` 缺失时整块降级为一行提示。必填。 */
    field: LowCodeFieldDto;
    /** 当前选中的资源 key。受控；默认 `undefined`；非字符串一律按未选中处理。 */
    modelValue?: LowCodeJsonValue;
    /** 视野。默认 `"global"`；`"project"` 时来源为 `global` 的选项只读，并提供「复制到项目」。 */
    scope?: LowCodeResourcePresetScope;
    /** 是否禁用。默认 `false`；禁用后所有写入口（选择、增删改）都不生效。 */
    disabled?: boolean;
    /** 已暂存、尚未保存的资源改动。默认 `[]`；只认 `fieldPath` 等于本字段 `path` 的项。 */
    mutations?: LowCodeResourceMutationDto[];
};

type LowCodeResourcePresetFieldEmits = {
    /** 选中项变化（下拉选择、点列表行、新建/重命名/复制后自动选中）时触发，携带完整资源 key。 */
    (e: "update:modelValue", value: LowCodeJsonValue): void;
    /** 资源增删改后触发，携带本字段去重后的完整改动列表（同一 key 的同类改动被覆盖）；宿主用它整体替换自己保存的那一份。 */
    (e: "update:mutations", value: LowCodeResourceMutationDto[]): void;
};
```

无 slot，不暴露 `expose`。未声明的 attribute、`class` 与 `style` 落到本组件最外层容器上。它不读 store、不发请求、不写浏览器存储：这两条事件就是它全部的对外结果。

## 数据的语义约束

- **值就是资源 key**，形如 `field.resource.createKeyPrefix + slug + createKeySuffix`。历史值可能只存了裸 slug，组件在选择与高亮时会尝试补全前后缀来匹配现有选项（值里含 `/`、或资源没配前后缀时不补），匹配不到就按原值显示，也不清空它。
- **正文初值来自 `field.resource.contents`** 中 key 相同的项，缺失就是空串（资源在、正文不在）。**新建资源的初值取 `field.resource.template`**（没有则为空串）。`field.resource.content`（单数那个字段）不被本组件读取。
- **slug 由名称生成**：转小写、把 `a-z0-9._-` 以外的字符换成 `-`、去掉首尾 `-`；整段名称都被换掉时退回 `resource`。与现有可写选项重名时依次尝试 `resource-2`、`resource-3`……在 `scope="project"` 下「可写」指来源不是 `global` 的项，所以项目资源可以与全局资源同名。
- **能力门槛全部来自数据**：改正文要求该项 `editable` 且 `capabilities.update`；新建要求 `capabilities.create`；重命名要求当前项 `editable` 且 `capabilities.rename`；删除要求该项 `deletable` 且 `capabilities.remove`。缺哪条能力就少哪个入口，组件不猜、也不降级成别的动作。
- `scope="project"` 且当前项 `origin === "global"` 时正文只读，并给出「这个资源来自全局库，在项目配置中只读」的说明与「复制到项目」入口。
- `mutations` 是叠加在 `field.resource` 之上的未保存改动：回显的选项列表与正文都按 `create` / `rename` / `remove` / `update` 依次折算过，因此用户能看见自己还没保存的操作结果。

## 交互

- **选资源**：顶部下拉与面板里的资源行等价；行上有来源徽标（该选项带 `origin` 时显示「全局 / 项目」）和「当前」标记。点行即选中并上报 key。
- **展开管理面板**：右上「管理 / 收起」按钮切换；既没有选中项又没有任何管理能力时这个按钮不出现。面板左边是资源列表、右边是当前资源的正文编辑区。
- **改正文**：每次输入产生一条 `update` 改动并即时上报；禁用、未选中或没有 `update` 能力时正文区只读。
- **新建**：只填名称，slug 自动生成，初值为模板；确认后自动选中新资源并展开管理面板。名称全为空白时确认按钮不可用。
- **重命名当前**：改名称与 slug，正文跟着 key 迁移；确认后自动选中新 key。
- **复制到项目并选中**：只在 `scope="project"`、当前项来源为 `global` 且具备新建能力时出现；把当前正文复制成一个项目资源，名称与 slug 沿用原项，并自动选中新 key。这是绕过「全局项只读」的唯一途径。
- **删除**：行内删除按钮需要二次确认，确认框里显示待删项名称；删除只上报一条 `remove` 改动，不改当前选中的 key。
- 两个确认框由 nb-ui `Dialog` 承载：模态、焦点陷阱、打开期间页面滚动被锁、Escape 或点遮罩即关闭（关闭＝放弃本次输入），关闭后焦点归还触发它的按钮；打开新建/重命名框时焦点落在名称输入框，打开删除框时落在「取消」按钮（都由 `Dialog` 的焦点管理决定）。
- 管理面板本身不是浮层，是就地展开的一块区域；窄屏下资源列表与正文编辑区上下堆叠，宽屏下左右两栏。

## 状态

- `field.resource` 缺失：整块降级为一行英文提示「Resource preset is unavailable.」，没有任何入口。
- 没有可用资源且已禁用：一行「没有可用资源。」；没有可用资源但未禁用：照常渲染空的下拉与空面板（面板里提示「请选择一个资源。」）。
- 未选中：正文区提示「请选择一个资源。」，各写入口按能力门槛隐藏或禁用。
- 当前项是项目视野下的全局资源：正文只读并带说明，删除与重命名入口不可用。
- 出错：组件自身没有错误态，也没有加载态；正文合法性、保存结果都由宿主负责，组件不校验正文。

## 不支持

- 不落盘、不发请求：不保存就不存在。宿主不应用 `update:mutations` 的话，界面上的改动只活在本组件实例内。
- 不支持删除当前选中的资源：删除入口对选中项恒为禁用，必须先选中另一个资源。
- 不支持键盘操作管理面板：资源行是不可聚焦的元素，行内删除按钮虽然会进入 Tab 顺序，但默认透明、只在鼠标悬停该行时显形，键盘用户看不到它。
- 不支持搜索、排序、分组、多选与拖拽。
- 不渲染 Markdown：正文区是纯文本，写什么就显示什么字符。
- 不支持在组件内切换 `scope`、`disabled`、`mutations`：它们是 props，只能由宿主重传。
- 不支持批量导入，也不支持把项目资源反向复制回全局。

## 隐藏通道理由

`env:portal`：两个确认框（新建/重命名、删除）用 nb-ui `Dialog` 渲染，落点由本组件自己决定——它从自身根节点向上找最近的主题宿主（`.novel-ide-theme`），找到就把浮层放进宿主内，好让浮层继承页面的层叠上下文与主题；找不到时（例如 Lab 里没有宿主）退回 `body`。不把落点一路当 prop 从视图 → 详情面板 → 区段 → 低代码表单传下来，是因为那是通用表单零件不该背的视图层知识，而没有落进宿主会直接表现为主题错色。**目标缺失时的表现是明确的**：找不到宿主就用 `body`，不会因为目标不存在而整个对话框不出现（`Dialog` 自身也有「目标选择器查不到就回落 `body`」的兜底）。

`state:local` 不计入耦合：名称草稿、面板展开与否、两个确认框的开合与待删目标都是本组件自己的临时状态，不向外报告。

## 上游边界

本组件承诺的只有上面这些：两条事件的含义、能力门槛、slug 规则、正文与 key 的对应关系，以及「不落盘」。选择器、输入框、正文框、按钮与两个确认框都是 nb-ui 控件，它们的键盘与无障碍语义、浮层材质、层级与过渡归那些控件；本组件只传了 `title`、`width`、`show-cancel` 与 `teleport-target`，其余用它们自己的默认值，升级 nb-ui 可能改变这些表现。`Dialog` 的模态行为（焦点陷阱、滚动锁、Escape 与遮罩关闭、关闭后焦点归还）同样属于它，不属于本组件。
