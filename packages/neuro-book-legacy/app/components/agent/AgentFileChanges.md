# Agent 改动文件条

一轮里改动过的文件，放在轮末的一行文件条里：开头是 diff 图标和“改了 N 个文件”，后面每个文件一枚小标签，写文件名和增删行数。标签按内容宽度排开、放不下时换行，所以宽屏下只占一行、不拉满整行，窄屏下自然折成几行。点击标签请求打开该文件的 diff。轮次折叠或展开时都显示，所以折叠后仍能看到这一轮改了什么。

注意力低于回复气泡：没有外框、底色与阴影，标签只有一圈细分隔线，文字用次级色。

## 布局

- 开头：diff 图标、“改了 N 个文件”，11px 淡色。
- 文件标签：只写文件名，完整路径在悬停提示里；同一轮里有同名文件时改写成“上级目录/文件名”以便区分。增删行数跟在文件名后面；一侧为 0 而另一侧有改动时，0 那一侧不显示；增删未知时不显示数字。
- 文件多于 `limit` 时只显示前 `limit` 个，末尾一枚“+N”标签，点开后显示全部并变为“收起”。
- 根节点是行内伸缩容器，宽度随内容；宿主可以把它和用量行放在同一行。

## 数据

```ts
type AgentFileChangesProps = {
    /** 改动过的文件，必填，按显示顺序；added、removed 为 null 表示未知。 */
    files: Array<{path: string; added: number | null; removed: number | null}>;
    /** 收起时最多显示的文件数；默认 5。 */
    limit?: number;
};

type AgentFileChangesEmits = {
    /** 点击某个文件时发出，携带路径。 */
    (e: "open", path: string): void;
};
```

没有插槽和 expose。未声明的 attribute、`class` 与 `style` 落到根节点。

## 隐藏通道理由

`state:local`：是否展开了超出 `limit` 的文件。纯界面状态，重新挂载时回到收起。
