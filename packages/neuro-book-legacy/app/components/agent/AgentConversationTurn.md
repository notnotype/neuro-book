# Agent 对话轮次

分轮视图里的一轮：一条用户消息，加上 Agent 一侧按时间顺序排列的内容，版式沿用旧侧栏 `AgentSidebarView` 的对话气泡。它用 `buildTurn` 把消息分成三层：常显层（Agent 说出的 content、人机交互控件、信息条目）、默认折叠的思维链、轮末汇总（改动文件与用量）。已结束的轮次再整轮收起：翻看历史时只看到最终回复和改动文件，过程收成一行。

## 布局

两个说话者版式相同：上面一行角色行，下面缩进 24px 的内容。角色行依次是小头像、大写角色名、附加信息，右端是常显的消息操作条（有多个分支时分支切换在最前）；头像与名称取自注册表的“角色”扩展点。

- 用户：附加信息为时间，还在发送时加转圈和“发送中”；下面是带淡强调色的气泡，内容由 `AgentUserContent` 画（文字、附件与“仅显示预览”）。投递状态未知时气泡下面是 `AgentDeliveryNotice`。
- Agent：
  - 角色行附加信息为模型、时间，运行中加转圈和状态标签（等待回答、出错、已停止也在这里）。操作条作用于最终回复，没有最终回复时不显示。
  - 内容分“过程”和“结果”。结果是末尾连续的最终回复与错误，其余都是过程。每个块由 `AgentTurnBlock` 画出。
  - 运行中与等待回答时，过程按时间顺序全部显示：思维链摘要行、运行中的中间 content、人机交互控件、信息条目、steer 等。
  - 已结束（完成、出错、被停止）时，过程收成一行整轮摘要“过程 · 14 次操作 · 读了 7 个文件，改了 2 个”（失败时末尾加危险色“1 次失败”），下面只有结果。点击展开后，过程挂在从摘要图标垂下的竖线上，缩进一级。文案由 `process-summary.ts` 生成。最新一轮出错或被停止时默认展开，其余默认收起。
  - 被停止时末尾显示“已停止”。
  - 轮末汇总一行：左边是改动文件条 `AgentFileChanges`（一排文件小标签，没改文件不显示），右边是用量（用时、tokens、输入、输出、缓存读取与费用，悬停显示明细）；同一行放不下时用量折到下一行靠右。
- 最终回复之后的分隔线放在轮末汇总下方。
- 开头不完整的轮次（用户消息在尚未加载的历史里）直接从 Agent 一侧开始；“更早的内容”由对话视图顶部的历史行表示。

## 交互

- 点击整轮摘要展开或收起过程；手动操作过的轮次不再跟随自动规则。
- 运行结束、整轮自动收起时，键盘焦点若在被收起的过程里，移到整轮摘要行。
- 投递状态未知的用户消息与 steer：“重新发送”发出 `message.resend`，“移除”发出 `message.dismiss`。

## 数据

```ts
type AgentConversationTurnProps = {
    /** 这一轮的消息，必填；由 splitIntoTurnGroups 切出，第一条是普通用户消息或开场内容。 */
    messages: MessageView[];
    /** 对话视图的 ctx，必填；读取运行状态、历史、Workflow、分支、会话与交互许可，node 组件也会拿到它。 */
    ctx: AgentConversationContext;
    /** 必填；用 sanitizeHtml 渲染回复，用 resolveAttachmentUrl 显示附件。 */
    services: AgentConversationServices;
    /** 必填；角色、工具渲染器与消息操作从这里取。 */
    registry: AgentViewRegistry;
    /** 是否最新一轮，必填；最新一轮跟随运行状态。 */
    latest: boolean;
    /** 是否第一轮，必填；历史未加载完时第一轮可能开头不完整，此时不计算用时。 */
    first: boolean;
};

type AgentConversationTurnEmits = {
    /** 用户意图，原样转交宿主。 */
    (e: "action", action: AgentViewAction): void;
};
```

没有插槽和 expose。未声明的 attribute、`class` 与 `style` 落到根节点。

## 隐藏通道理由

`state:local`：整轮是否被手动展开或收起（未操作时跟随默认规则，所以运行结束时自动收起）。块内的展开状态由 `AgentTurnBlock` 自持。父组件用含会话 id 的 key 挂载每一轮，切换会话时这些状态随组件一起重建；开头不完整的轮次补上用户消息后沿用原来的 key，状态不丢。
