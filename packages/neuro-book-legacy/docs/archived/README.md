# 历史归档

`packages/neuro-book/docs/archived/` 保存已失效、被替代或只供考古的材料，不作为当前行为、操作或验收依据。归档文件应在文件头说明历史状态、失效原因和当前入口；原始历史内容可保留。

- `drafts/`、`plan/`：旧草案与实现计划。
- `reference/`：已退出的旧规范版本。
- `practices/`：一次实践和已失效设计记录。
- `proposals/`：已完成沉淀、rejected 或 superseded 的提案。
- `tutorials/`、`skills/`：不再发布的教程和产品 Skill。
- `workflows/`：历史执行脚本。其中 `implement-world-engine-zod-refactor.js` 属于 Task 67/69 的历史工作流，不是当前可运行入口。

当前规范从 [`../specs/README.md`](../../../../docs/specs/README.md) 查找，当前操作从 [`../runbooks/`](../runbooks/) 查找。
