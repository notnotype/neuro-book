# PaperSheet

官方站登录、注册、同意条款、授权确认几页共用的版面（t10 计划 3.6）。整页是一张稿纸：产品名与一行说明一格一字写在格子里，旁边盖一枚印章；页面的表单放在一张卡片里，卡片的四条边都落在格线上；页脚是隐私政策与服务条款两个链接。别的版面没有的地方是格线与内容对齐：格子的原点就是稿纸本身的左上角，页面怎么居中、怎么滚动，卡片与字格都压在格线上，不靠脚本算位置。

## 布局

- 格子：一格宽 40px、高 40px，行与行之间空 12px，所以横向周期 40、纵向周期 52。格线与印章的颜色取站点变量 `--site-paper-line`、`--site-paper-seal`（`styles/site.css`），纸的底色是主题的 `--bg-panel`；有稿纸的页面把页面底色也换成纸色，右缘预留的滚动条槽位不露出另一种颜色。
- 宽屏（1200px 起）：稿纸 28 格宽、水平居中，上方空 5 行；左边 13 格写字，右边 9 格放卡片，中间留空。页脚在稿纸底部。
- 中等宽度（561px 到 1199px）：稿纸 13 格宽，上方空 2 行；字在上，空一行后是卡片，卡片 9 格宽、从第 2 格起。
- 窄屏（560px 及以下，含 `390×844`）：稿纸 9 格宽（360px），上方空 1 行；卡片占满稿纸宽，内边距收小，页脚居中。
- 更窄（稿纸的根宽度在 371px 及以下，含 `360×800`）：格子缩成宽 36px、高 36px，行间 12px（纵向周期 48），仍是 9 格（324px），产品名一行写下，字号与印章跟着缩。按根元素的宽度判断（容器查询），不按视口：桌面浏览器的视口宽度含着预留的滚动条槽位。
- 已知限制：根宽度不到 336px（例如 `320` 宽）时稿纸宽度跟着视口缩，格线与卡片右边、产品名的折行不再对齐；不出现横向滚动。
- 卡片比视口高时整页滚动；格子伸出稿纸的部分被裁掉，不产生横向滚动。
- 一行说明写不下时按格换行，每个字仍在格子里。

## 交互

- 产品名与说明对读屏是一句话（一个 `sr-only` 的段落），逐格的字对读屏隐藏；不另造地标。
- 卡片是页面的 `main`。
- 由外壳按路由的 `meta.layout` 套在页面外面（`App.vue`）：几张稿纸页之间切换时稿纸是同一个元素，只换卡片里的页面。
- 页脚两个链接跳到 `/privacy`、`/terms`。

## 数据

```ts
// props：没有。

// slots
defineSlots<{
    /** 卡片里的内容：外壳放的 `RouterView`，页面自己的标题（`h1`）与表单。卡片给 `h1` 统一的样式。 */
    default(): unknown;
}>();

// emits：没有。expose：没有。attrs：透传到根元素（`[data-site-paper]`）。
```

文字取站点的文字目录：`paper.title`、`paper.about`、`paper.label`，页脚取 `legal.privacy.title`、`legal.terms.title`。

## 状态

只有一种状态；明暗随主题变量变化。

## 不支持

- 不支持自定义产品名、说明或页脚链接：它们是站点固定的文字。
- 不支持把卡片放到别的列，也不支持没有卡片的稿纸。

## 隐藏通道理由

- `state:inject`：文字从站点的文字端口取（`useSiteText`），与站点其它页面一致。
- `env:route`：页脚的两个链接是 `RouterLink`，几页共用同一份页脚，不必让每页传一遍。

## 验证

浏览器场景 `e2e/login.e2e.ts` 在 1440、390 与 360 三种宽度、亮暗两种明暗下量：不能横向滚动、卡片与字格落在格线上、产品名在一行、页面底色等于纸色、格线与印章的对比度；从登录页去注册页时稿纸是同一个元素。
