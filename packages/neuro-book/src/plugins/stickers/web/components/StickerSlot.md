# StickerSlot

表情图的框（[`agent/stickers.md`](../../../../../../../docs/specs/agent/stickers.md) 输出 26 的网格格子与输出 27 的属性栏大图共用）：框的大小由使用方定（宽高与内边距），图按比例缩进去、居中，不因图片大小改变框；底色很淡，让不透明的矩形图与透明底的小表情落在同一个框里。

## 数据

```ts
type StickerSlotProps = {
    /** 图的地址；缺省时用默认插槽放别的内容（上传中的转圈） */
    url?: string;
    /** 图的替代文字；装饰性的（格子下面另写了名字）传空串 */
    alt?: string;
    /** 把图调淡：认不出的、没加进来的 */
    faded?: boolean;
    /** 图片懒加载（网格里很多格） */
    lazy?: boolean;
};
```

一个默认插槽（没有 `url` 时的内容）；没有 `expose`，`class` 透传到根元素（使用方在上面写尺寸）。

## 不支持

- 自己决定尺寸与选中样式：由使用方的类写（格子选中时的描边在网格里）。
