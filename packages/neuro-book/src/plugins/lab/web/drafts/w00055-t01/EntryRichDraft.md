# EntryRichDraft

w00055 t01 的富文本 spike：条目主文字用标签写法（`<V of>`、`<If test>`、`<Ref id>`），在章节那套富文本编辑器里编辑，可以和源文字来回切。样本世界写死（星瑕、星瑾），不连内核；做法与限制写在 `entry-tags.ts` 开头。

- 取值是行内小块，显示此刻的值；别的条目的值前面带条目名；长的文字退成淡底加下划线；字段没了、还没填各有样子。点了弹浮层：看是哪个字段、去设定组里改（这里直接改样本世界的值，看小块与条件跟着变）、换一个、删掉。
- 条件默认只画生效的一支（下面一条虚线）；“显示全部分支”打开后画成条件加各支，没生效的变淡划掉。点了弹浮层改条件与各支的文字，可以加一支、删掉。没有一支生效时画一个淡的占位。
- 输入 `{` 弹字段列表、`@` 弹条目列表；Esc 或在空的搜索框里按空格退回成普通的字。工具栏也有“插入值”“条件”“提到条目”。
- 源文字是一个等宽的输入框。切回富文本前查标签：写坏了不让切，说明哪里。

```ts
type Props = {
    /** 一开始在哪个模式；默认 "rich"。 */
    mode?: "rich" | "source";
    /** 一开始是否把条件的各支都画出来；默认 false。 */
    showBranches?: boolean;
    /** 一开始的源文字；默认样本。 */
    source?: string;
};
```

没有 emits、slots、expose；attrs 落在根元素上。
