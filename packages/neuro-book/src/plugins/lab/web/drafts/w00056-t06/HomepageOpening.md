# HomepageOpening

首页原型的开场动画（w00056 t06）：叠在工作台下面的一层替身，三种演法都在真工作台排好版之后开始，照它量到的卡片摆位置，演完把舞台交给真工作台。替身的底色、圆角与投影取自真卡片，换过去时只看到内容出现。

- `unfold` 书展开成工作台（约 2.8 秒）：光起，赤红的书立在光里；书扣弹开、封面翻开，书展平、放大；书页一张张飞到各块面板的位置；内容出现。
- `gild` 金线勾出工作台（约 2.2 秒）：一根哑光金线从编辑区起笔，描出各块面板的边；象牙色从中间铺开，线退成面板的边；小猫印落在右上角。
- `assemble` 工作台自己搭起来（约 1.8 秒）：编辑区先浮上来，两侧与底部的面板从外面贴进来，落位时接缝一闪金光；小猫印落下。

访客往下滚、或要求少动效时，直接到终态。

## Props

| 属性 | 说明 |
|---|---|
| `variant` | `unfold`、`gild` 或 `assemble`。 |
| `plates` | 真工作台此刻的卡片（`DeskPlate`）：位置相对工作台的根。 |
| `ground` | 卡片之间露出来的桌面底色。 |
| `width`、`height` | 工作台的外框尺寸。 |

## 事件

| 事件 | 说明 |
|---|---|
| `light` | 舞台的光该亮起来了（`unfold` 先暗后亮，另外两种一开始就亮）。 |
| `reveal` | 真工作台该淡入了：替身已经在位，内容从这一刻出现。 |
| `seal` | 小猫印该落下了（`gild`、`assemble`）。 |
| `done` | 演完，这一层可以拿掉。 |

## 对外的方法

| 方法 | 说明 |
|---|---|
| `finish()` | 直接到终态：依次发出还没发的 `light`、`reveal`、`seal`、`done`。 |

没有 slots；attrs 落在根元素上。
