# GildedMarks

首页第一幕的鎏金标记（w00056 t06 第 9 轮）：开发者看第 8 轮时说“金色高亮矩形有点丑”，第 8 轮的标记是贴着目标描一圈 1px 金线框，文字两行时框住整块外接矩形，没高亮的字也框进去；侧轨上的落点格是一个空框。这一轮按 @designer 的一套视觉语法换成三种标记，遮罩（`DeskSpotlight`）与第一幕的几处点题都用它：

- **四角**（`corners`）：去掉四边，只在外扩 5px 的四个角各画一只 L 形的鎏金角，臂长 12px（`small` 时 8px，给标签这类小东西）、线宽 1.5px，角尖最亮、往臂端淡下去，带一团暖金的晕。出现时四只角从外面 8px 往里扣合（280ms，缓出），之后轻轻呼吸；收起时往外散开、淡掉（180ms）。和首屏书角的包金、按钮的角花是一家。
- **下划线**（`underline`）：贴着一行字的下沿画一道 1.5px 的金线，两头淡出；出现时从左往右铺开（320ms），铺满以后一道亮光从左掠到右（500ms，只一次）。同一批出现的几道一起掠过，所以两句对照的话会同时亮一下。文字一律按行给，不套跨行的大框。
- **落点槽**（`slot`）：一个圆角 6px 的短虚线槽，里面一层很淡的暖金，正中一颗 6px 的菱星：标“落在这里”，空着也看得懂。

`ripple` 的四角出现时再漾开两圈涟漪（各 1.6 秒）；`nudge` 的四角隔一会儿往右挪一下，示意能拖（交给访客时第一章的标签）。白天（`day`）换成深古铜金，晕淡一些。访客要求少动效时没有扣合、铺开、掠光、呼吸、涟漪与挪动，标记直接出现、直接消失。

## Props

| 属性 | 说明 |
|---|---|
| `marks` | 要画的几处（`GildedMark`）：`id`（同一个 `id` 在前后两次之间保持挂着，只挪位置；换了 `id` 就是收起旧的、出现新的）、`kind`（`corners`、`underline`、`slot`）、`rect`（在外面那个定位容器里的矩形，像素）、`small`、`ripple`、`nudge`。 |
| `day` | 白天的配色。 |

没有事件与 slots。根元素铺满外面的定位容器、不接指针，attrs 落在根元素上。
