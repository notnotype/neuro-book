# GiltButton

首页的按钮（w00056 t06）：第 6 轮出了四版（`HeroButtons`），第 8 轮开发者选定 B“皮面烫金”，首屏与第一幕交给访客那一行都用它。

- **主按钮**：哑光的深红皮面，里面一圈烫金细框，四角各一枚小角花，字是金的。
- **次按钮**：只留一道细金框与四角（@designer 第 6 轮：次按钮不用深皮面，白天太重、夜里沉底）；白天垫一层浅羊皮纸色的底、字换深墨（@designer 第 8 轮：浅底上透明的次按钮框融进石墙）。
- 白天的金换成古铜金：浅底上亮金看不出来。主按钮昼夜一样。

悬停不扫光，是受光的微变：皮面微微提温、烫金框往外展一像素、亮半档，带一圈淡暖晕；按下时下沉 1px。键盘聚焦有一道金色的焦点环。`glint` 时烫金框上多一团柔和的反光，位置读外面写的 `--sx-glint-x`、`--sx-glint-y`（-1 到 1，首屏场景跟着指针写）。访客要求少动效时没有这些过渡。

## Props

| 属性 | 说明 |
|---|---|
| `href` | 链接地址，缺省 `#`。 |
| `primary` | 主按钮（皮面）；缺省是次按钮（细金框）。 |
| `size` | `regular`（缺省，48 高）或 `small`（38 高，第一幕那一行与窄屏）。 |
| `day` | 放在白天的亮底上。 |
| `glint` | 烫金框上加跟着指针走的反光。 |

## Slots

| 插槽 | 说明 |
|---|---|
| 缺省 | 按钮上的字。 |

## 事件

| 事件 | 说明 |
|---|---|
| `click` | 点了（参数是那一下的 `MouseEvent`）。不拦它就照链接跳到 `href`；页内跳转的按钮由页面调 `preventDefault` 拦下，自己滚过去。 |

attrs 落在根元素（`<a>`）上。
