# HeroButtons

首页按钮的样张（w00056 t06）。第 6 轮开发者要“按钮的样式优化一下，出几版”，这里出了四版（双线金边、皮面烫金、书脊签、封蜡）；第 8 轮开发者选定 B“皮面烫金”，按钮本身成了 `GiltButton`，首页换成它，没选的三版删掉。

现在只摆选定的那一版：左边放在夜里（暗夜圣殿的底），右边放在白天（午后藏书阁窗光照着的暖象牙墙，首屏的按钮压在它上面），每格两对：首屏那一对（主：下载 NeuroBook；次：在 GitHub 上看看），与第一幕交给访客时那一对小号的（次：接着看世界引擎）。悬停、按下与聚焦的样子见 `GiltButton.md`。

## Props

没有 props、事件与 slots；attrs 落在根元素上。
