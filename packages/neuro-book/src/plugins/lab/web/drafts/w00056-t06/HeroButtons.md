# HeroButtons

首页按钮的几版样式（w00056 t06 第 6 轮，开发者要“按钮的样式优化一下，出几版”）：每一版一行，左边放在夜里（暗夜圣殿的底），右边放在白天（午后抄经室的石墙底），每格是一对按钮（主：下载 NeuroBook；次：在 GitHub 上看看）。开发者挑定以后，首页（`HomepageSanctum`）换成那一版，这个稿就退役。

- **A 双线金边（现版精修）**：主按钮赤红底，外一道鎏金边、里一道细金线，两端各一粒金菱形压在边线上；次按钮同样的双线，底是透的。
- **B 皮面烫金**：主按钮是哑光的深红皮面，里面一圈烫金细框，四角各一枚小角花，字是金的；次按钮只留一道细金框与四角（@designer 第 6 轮：次按钮不用深皮面，白天太重、夜里沉底）。
- **C 书脊签**：修长的赤红签条，里面一道极细的单金框，字两侧各一小段金线，像书脊上的书名签；次按钮只有细金框。
- **D 封蜡**：羊皮纸色的签条，主按钮左端压一枚红色火漆印（印着品牌小猫）；次按钮是素签条。

悬停不扫光（@designer：扫光像页游），只是受光的微变：赤红微微提温、金线亮半档、内框或菱形往外展一两像素、带一圈淡暖晕；按下时下沉 1px、高光收一点。键盘聚焦有一道金色的焦点环。访客要求少动效时没有这些过渡。

## Props

没有 props、事件与 slots；attrs 落在根元素上。
