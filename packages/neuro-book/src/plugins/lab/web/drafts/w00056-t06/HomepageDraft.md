# HomepageDraft

NeuroBook 文档站首页的原型（w00056 t06 第 3 轮）：首屏与第一幕“一张随你摆的桌子”。自己是滚动容器，画布按一屏的大小给。

## 版式

- 首屏：深色舞台，顶上一束暖光。上面三成是标志、第一句、说明与两个按钮，下面七成是一台真工作台（`HomepageDesk`），底边伸出屏幕一截，桌面底下透出一线光，提示往下还有。开场动画（`HomepageOpening`）先演，第一句与按钮 0.3 秒内就在。
- 往下滚，第一句淡出，工作台上移、右移，钉在舞台右侧；左边一窄列是这一幕的几步，像书页的旁注，当前这一步亮、别的淡。每一步进入时，一支金色的笔尖在工作台上演一遍这个动作：瞄准、按下、拖着走、松手；落下后的布局变化是产品自己的布局动画。
- 往回滚，工作台回到那一步的样子。访客自己按下或拖动工作台时，笔尖让开，工作台下面出现“接着看”“摆回去”；接着往下滚也会收起它们、接着演。
- 窄屏（宽不到 900）不演笔尖，工作台钉在上面，几步在下面滚过。

## Props

| 属性 | 说明 |
|---|---|
| `opening` | 开场：`unfold` 书展开、`gild` 金线勾出、`assemble` 自己搭起来。 |
| `start` | `top` 从首屏开始、放开场；`act-one` 不放开场，直接滚到第一幕的开头。 |
| `headline` | 首屏第一句的候选 id（`copy.ts` 的 `HEADLINES`）。 |

没有 emits、slots、expose；attrs 落在根元素上。
