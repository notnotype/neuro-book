# HomepageDesk

首页原型里那台能上手的工作台（w00056 t06）：产品里同一张工作台表面、同一个编辑器区与 Markdown 编辑器、同一个资源管理器和对话视图，文件与布局文档放在内存里。示例作品是《灰塔制图师》：左边作品树，中间是正文（第 3 轮第一章、第 4 轮第五章），右栏是和星璃的一段对话，底部面板收着。拖标签分栏、拖缝、换视图位置、浮窗、最大化都是产品的手势与布局动画；首页的开场动画与第一幕的演示经下面的方法驱动它。

配色用产品的“昼”，强调色换成品牌的赤红，落点高亮换成金色。

## Props

| 属性 | 说明 |
|---|---|
| `restore` | 上一次关掉时记下的布局、标签与最大化（`DeskSnapshot`）。缺省是首屏的样子，由 `setup` 定。 |
| `setup` | 首屏摆什么：`tour`（缺省，第 3 轮）打开第一章、第二章与艾莉丝的设定，第一章在前；`knock`（第 4 轮）打开第五章、第一章与艾莉丝，第五章在前，第五章停在半句上，第一幕接着写。 |

## 事件

| 事件 | 说明 |
|---|---|
| `touch` | 访客自己按下了指针或按了键（演示发的不算）：第一幕的自动演示据此让开。 |
| `ready` | 第一次排好版、卡片量得到了。 |

## 对外的方法

| 方法 | 说明 |
|---|---|
| `plates()` | 此刻各张卡片的位置与种类（相对根），开场动画照它摆。 |
| `target(name)` | 演示要瞄的地方（视口坐标）：第一章、第二章、艾莉丝的标签，编辑组，右栏，星璃那一栏，作品的活动栏入口，浮窗的落点。 |
| `splitRight(file)` | 把一份（缺省第二章）移到第一组右边，成为新的一组。 |
| `moveExplorer(region)` | 作品这个视图容器整个搬到右栏或搬回侧栏。 |
| `setMaximized(panel)` | 最大化某一块，`null` 还原。 |
| `floatAlice()` | 把艾莉丝的设定拖成浮窗：`tour` 落在编辑区偏右下，`knock` 落在侧栏作品树下面的空处。 |
| `showDrag(drag)` | 画演示用的拖影与落点预览（产品的拖动反馈组件），`null` 收起。 |
| `revealEnd(file)` | 让这份文件到前面，光标放到末尾并聚焦（编辑器的“继续写作”）；控件还没挂上时返回 `false`。 |
| `type(text)` | 在光标处打字：走浏览器的输入路径，编辑器照常收到输入、记脏；焦点不在这台工作台的编辑器里时不打。 |
| `typing()` | 焦点在不在这台工作台的编辑器里（放完光标后确认真的落下了）。 |
| `shows(text)` | 桌上的正文里有没有这句。 |
| `textRects(text)` | 这句话在编辑器正文里占的几块矩形（视口坐标，折行时是几块）。 |
| `lyraPost(message)`、`lyraHas(id)` | 往星璃的对话里加一条消息（同 `id` 的换掉，边打边出的回复每次给新文字）；对话里有没有这一条。`knock` 的对话开头聊第八层的线索，`tour` 是第 3 轮那段敲门的问答。 |
| `snapshot()`、`applyDoc(doc)` | 记下此刻的布局；把布局换回记下的某一份（布局动画照常）。 |

没有 slots；attrs 落在根元素上。
