# HomepageDesk

首页原型里那台能上手的工作台（w00056 t06）：产品里同一张工作台表面、同一个编辑器区与 Markdown 编辑器、同一个资源管理器和对话视图，文件与布局文档放在内存里。示例作品是《灰塔制图师》：左边作品树，中间第一章，右栏是和星璃的一段对话，底部面板收着。拖标签分栏、拖缝、换视图位置、浮窗、最大化都是产品的手势与布局动画；首页的开场动画与第一幕的演示经下面的方法驱动它。

配色用产品的“昼”，强调色换成品牌的赤红，落点高亮换成金色。

## Props

| 属性 | 说明 |
|---|---|
| `restore` | 上一次关掉时记下的布局、标签与最大化（`DeskSnapshot`）。缺省是首屏的样子：打开第一章、第二章与艾莉丝的设定，第一章在前。 |

## 事件

| 事件 | 说明 |
|---|---|
| `touch` | 访客自己按下了指针或按了键（演示发的不算）：第一幕的自动演示据此让开。 |
| `ready` | 第一次排好版、卡片量得到了。 |

## 对外的方法

| 方法 | 说明 |
|---|---|
| `plates()` | 此刻各张卡片的位置与种类（相对根），开场动画照它摆。 |
| `target(name)` | 演示指针要瞄的地方（视口坐标）：第二章的标签、编辑组、右栏、作品的活动栏入口、艾莉丝的标签。 |
| `splitRight()` | 把第二章移到第一章右边，成为新的一组。 |
| `moveExplorer(region)` | 作品这个视图容器整个搬到右栏或搬回侧栏。 |
| `setMaximized(panel)` | 最大化某一块，`null` 还原。 |
| `floatAlice()` | 把艾莉丝的设定拖成浮窗。 |
| `showDrag(drag)` | 画演示用的拖影与落点预览（产品的拖动反馈组件），`null` 收起。 |
| `snapshot()`、`applyDoc(doc)` | 记下此刻的布局；把布局换回记下的某一份（布局动画照常）。 |

没有 slots；attrs 落在根元素上。
