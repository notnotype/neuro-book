# HomepageDesk

首页原型里那台能上手的工作台（w00056 t06）：产品里同一张工作台表面、同一个编辑器区与 Markdown 编辑器、同一个资源管理器和对话视图，文件与布局文档放在内存里。示例作品是《灰塔制图师》：左边作品树，中间是正文（第 3 轮第一章、第 4 轮起第五章），右栏是和星璃的一段对话，底部面板收着。拖标签分栏、拖缝、换视图位置、浮窗与窗角缩放、最大化都是产品的手势与布局动画；首页的开场动画与第一幕的演示经下面的方法驱动它。

- **实时布局**（第 6 轮）：拖动用产品缺省的手感，接线照产品的外壳：拖着走时布局按预览一路排开（只给渲染用的一份文档，判定与提交仍看已提交的那份），内容拿起来成一张跟手的卡片，卡片头写着拿起的是什么和落点的文字，松手时落进空位；拖视图容器仍是落点指示。不画落点分区（上下左右中那一盘，第 7 轮开发者不要）：实时布局本来不画，走落点指示时也只留落点的框。
- **浮窗**：浮着的窗有产品的四边四角缩放手柄与键盘移动把手。
- **右栏的侧轨**（第 8 轮，跟上 w00043 t19）：右栏外侧和产品一样有一条侧轨，入口按区域摆（活动栏是左边那条，侧轨是右边这条）。把作品的入口拖到侧轨上，右栏显示作品树，星璃的入口留在侧轨上；侧轨上入口以外的地方拒收。
- **演示的指针**：第一幕的演示不另画拖影，而是往这台工作台上发合成的指针事件（`demo-pointer.ts`），走上面这些真手势；合成事件不算访客动手。

配色用产品的“昼”，强调色换成品牌的赤红；`night` 时强调色换成金。夜间配色下高亮里的字压成深墨：高亮的颜色是写进 Markdown 的浅色字面量，字却跟着正文用浅色，涂上看不清（产品本身的问题，第 6 轮发现）。

## Props

| 属性 | 说明 |
|---|---|
| `restore` | 上一次关掉时记下的布局、标签与最大化（`DeskSnapshot`）。缺省是首屏的样子，由 `setup` 定。 |
| `night` | 夜间配色时强调色换成金（配色本身由页面写在根上）。 |
| `setup` | 首屏摆什么：`tour`（缺省，第 3 轮）打开第一章、第二章与艾莉丝的设定，第一章在前；`knock`（第 4 轮起）打开第五章、第一章与艾莉丝，第五章在前，第五章停在半句上，第一幕接着写。 |

## 事件

| 事件 | 说明 |
|---|---|
| `touch` | 访客自己按下了指针或按了键（演示发的合成事件不算）：第一幕的自动演示据此让开。 |
| `ready` | 第一次排好版、卡片量得到了。 |

## 对外的方法

| 方法 | 说明 |
|---|---|
| `plates()`、`ground()` | 此刻各张卡片的位置与种类（相对根）与桌面底色，开场动画照它摆。 |
| `target(name)` | 演示要瞄的地方（视口坐标）：几份文件的标签、编辑组与它的正文和标签条（`first-editor-head`）、标签条的空白处、作品的活动栏入口、右栏、右栏侧轨上入口下面能接住入口的那一段（`auxiliary-rail`）、星璃那一栏、状态栏（标签在那里松手就浮出来）、浮窗的落点、艾莉丝那扇浮窗（`alice-float`）与它右上角的缩放手柄。 |
| `pointer()` | 演示用的合成指针（按下、移动、松开、撤下、点、双击），挂上以后才有。 |
| `splitRight(file)`、`moveExplorer(region)`、`setMaximized(panel)`、`isMaximized()`、`floatAlice()` | 不经手势直接摆：把一份移到第一组右边成新的一组；作品容器整个搬到右栏或搬回侧栏；最大化某一块（`null` 还原）；艾莉丝的设定浮出来（`knock` 落在侧栏作品树下面的空处）。第一幕快进与少动效时用。 |
| `revealEnd(file)` | 让这份文件到前面，光标放到末尾并聚焦（编辑器的“继续写作”）；控件还没挂上时返回 `false`。 |
| `type(text, where)` | 在焦点处打字：走浏览器的输入路径，编辑器照常收到输入、记脏；`where` 缺省是正文（焦点不在这台工作台的编辑器里时不打），`field` 是批注卡片里的输入框。 |
| `typing()`、`shows(text)`、`textRects(text)` | 焦点在不在这台工作台的编辑器里；桌上的正文里有没有这句；这句话在正文里占的几块矩形（视口坐标）。 |
| `selectText(text, share)`、`finishSelection()`、`collapseSelection()` | 选中这句的前一部分（演示的指针扫过去时逐帧加长），返回选区末端那一行的矩形；补一个指针松开，选区菜单据此出现；收起选区。 |
| `menuButton(kind)`、`commentSave()`、`focusCommentField()`、`commentMarker()` | 选区菜单上的高亮或批注按钮、写着的批注卡片的保存按钮、卡片的输入框、批注末尾的小符号（都不在时返回 `null` 或 `false`）。 |
| `marked(text, kind)`、`markNow(file, text, mark)` | 这句在不在高亮或批注里；不经菜单直接执行同一个编辑动作，返回是否真的加上了。 |
| `lyraPost(message)`、`lyraHas(id)` | 往星璃的对话里加一条消息（同 `id` 的换掉，边打边出的回复每次给新文字）；对话里有没有这一条。 |
| `snapshot()`、`snapshotSaved()` | 记下此刻的布局；先存盘，再连同正文与星璃的对话一起记下。 |
| `applyDoc(snapshot)`、`restoreTo(snapshot)` | 把布局换回记下的那一份（产品的布局动画）；`restoreTo` 先核对标签与存盘后的正文都对得上才就地换，返回是否换成了（对不上时页面重新挂一台）。 |

没有 slots；attrs 落在根元素上。根元素上的 `data-hp-preview`（实时布局此刻按哪个落点预览，没在拖是 `none`）给探针读：演示的拖动不该在半路换几次预览。
