# ActSeal

首页原型（w00056 t06）从一幕滚到下一幕时的开场（第 13 轮，开发者问“从第一幕滚动到第二幕的时候，没有演示开场动画吗”；编排照 @designer 第 12 轮的“沉幕落印”）。页面先把工作台压暗，再让这一枚印在正中描出来，最后收进工作台上面的眉题。它只管自己怎么画、怎么动；什么时候描、什么时候收、工作台怎么压暗与收栏，归页面（`HomepageSanctum.vue`）。

- **描出来**（`drawing`）：罗马数字的每一笔用金线依次描出，一笔约 0.36 秒，后一笔比前一笔晚 50 毫秒（两画的 II 共八笔，约 0.7 秒描完）；描到一半时副题从字距放宽淡入，下面一道花饰从中间往两边展开。
- **收进眉题**（`docked`）：副题与花饰先在 0.22 秒里散掉（缩小以后压在工作台的标签条上很乱），罗马数字挪 `dockX`、`dockY`、缩到 `dockScale`、淡掉，0.65 秒，缓动是先快后稳的那一条；缩放绕着罗马数字的中心。页面把它对到眉题里这一幕的名字上，眉题在它快到时显出来。
- **不画**（`off`）：直接消失，不放动画（往回滚时页面不落印）。
- 访客要求少动效时不描线、不挪：描出来是整枚淡入，收进眉题是淡出。

罗马数字只画 I 与 V 两种笔画（前五幕够用）：I 是上下两道衬线夹一对细竖，V 是两道斜笔加上沿的衬线，都是线不是面，像刻在金上的线。

## Props

| prop | 说明 |
|---|---|
| `numeral` | 罗马数字（`II`）。只认 I 与 V，别的字符跳过。 |
| `title` | 副题（这一幕的名字）。 |
| `state` | `off`、`drawing`、`docked`，缺省 `off`。从 `off` 换到 `drawing` 时从头描。 |
| `dockX`、`dockY` | 收进眉题时罗马数字的中心挪多少（px，负数往左、往上），缺省 0 与 -240。页面量眉题里这一幕名字的中心与罗马数字的中心算。 |
| `dockScale` | 收进眉题时缩到多大，缺省 0.34。页面按名字与罗马数字的高之比算。 |
| `day` | 白天：金换成深一些的古金，副题是暖象牙。缺省 `false`。 |

## 事件

无。

## Slots

无；attrs 落在根元素上。根元素盖满它的定位父元素、不接指针，印在中间。
