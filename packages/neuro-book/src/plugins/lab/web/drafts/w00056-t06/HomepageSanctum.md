# HomepageSanctum

NeuroBook 文档站首页的第 4 轮原型（w00056 t06）：方向一《入殿·俯案成界》的首屏与俯冲，接着是改过的第一幕。自己是滚动容器，一屏的大小就是自己的大小。

- **首屏**：暗夜圣案前的一幕（`SanctumScene`）。开场约 2.1 秒：暗处先起顶光，书角、丝带与羊皮页浮上来，远处桌布上那张桌子被光点亮，最后首句、说明与“下载”随光显出来。远处的工作台压到四成亮，首屏的主角是标题。首句缺省用 m2“写一部长篇，先摆好一张书桌。”，说明那一行把产品讲清楚。
- **俯冲**：往下滚一屏，镜头沿进深方向推进，书角与丝带先退出画面，羊皮页从身边掠过，桌子放平、推近、变亮，1:1 落在第一幕的位置（约九成宽），四周是铺到画外、淡进暗里的暗红桌布。
- **第一幕**：跟着第五章的一场戏走三拍（@designer 第 4 轮看过关键帧后收成三拍）。字幕在工作台下面，始终两行（幕名一行、字幕一行）；星璃的话在她自己的对话栏里：
  1. 第五章停在“她正要吹灯，”，接着打出“门外有人敲门，三下。她屏住气，等那第四下。”；作者在对话栏里问会不会太刻意，星璃读了第一章再边打边答，请作者把第一章摊开对照；第一章的标签先亮一圈金（其余地方压暗一点），再拖着金色尾迹落到右半边，两章并排，第一章翻到末尾，两声敲门同时描一道金。
  2. 双击标签栏，正文铺满桌面；再双击还原。
  3. 交给访客：第一章的标签上一圈金环，隔一会儿往右挪一下示意能拖；字幕那一行换成星璃的小贴纸、“换你来：拖一个标签，摆到顺手的地方。”与“下载 NeuroBook”“接着看世界引擎”。
- 演示走产品真的布局动作、拖动反馈与对话视图；访客一按工作台，演示让开，字幕后面出现“接着看”“摆回去”（第三拍里只熄掉金环）。往回滚时换回那一拍的终态，不重演。
- 窄屏（不到 900 宽）不俯冲、不演示：工作台平放在首屏文字下面，往下滚只换字幕，工作台保持首屏的样子给访客自己上手。访客要求少动效时没有开场与俯冲，首屏与落地的工作台淡入淡出，每一拍直接摆到终态。

## Props

| 属性 | 说明 |
|---|---|
| `start` | `top`（缺省）从首屏起，演开场；`act-one` 直接落在第一幕开头。 |
| `headline` | 首句的候选 id（`copy.ts` 的 `HEADLINES`），缺省 `m2`。 |

没有事件与 slots；attrs 落在根元素上。根元素上的 `data-hs-beat`（当前拍，-1 是首屏与俯冲）、`data-hs-phase`（第一幕在做什么）、`data-hs-landed` 给探针读。
