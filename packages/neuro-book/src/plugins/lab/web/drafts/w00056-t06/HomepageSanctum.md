# HomepageSanctum

NeuroBook 文档站首页的原型（w00056 t06 第 7 轮，在第 6 轮上改）：方向一《入殿·俯案成界》的首屏与俯冲，接着是跟着一场戏走、自己连播的第一幕。自己是滚动容器，一屏的大小就是自己的大小。

- **首屏**：暗夜圣案前的一幕（`SanctumScene`）。开场约 2.1 秒：暗处先起顶光，书角、丝带与羊皮页浮上来，远处桌布上那张桌子被光点亮，最后题辞 From words to world.、首句、一道金色花饰、说明与按钮依次随光显出来。停着时的动静由 `effects` 选（缺省全开，见 `SanctumScene.md`）：从字到世界一圈约 30 秒、五秒一步（落墨写出敲门那一行，金尘飞到地图上显出海岸与灰塔，红笔圈出伏笔，金尘飞到人物卡、抽出星璃的便笺，金尘沿航线走进剧情时间线，墨沉回纸里）；指针动时纸、书角与丝带带惯性地视差，花饰、按钮金边与书角上一团鎏金反光跟着走，停在哪张纸上那张就凑近一点。首句缺省用 e3“每一个世界，都从一行字开始。”。按钮是双线金边、两端各一粒金菱形的牌子，几版候选在 `HeroButtons`。
- **昼与夜**：缺省夜；导航最右端与落地后字幕那一条的左端各有一个开关（同一个；右端是章节条的条尾）。夜是暗夜圣殿，昼是午后的抄经室（石墙底、高窗斜进来的日光、深墨的字），工作台跟着换产品的夜间与日间配色，夜里强调色换成金。配色写在页面根上（主题有一批变量在根上从配色派生，只改工作台那一棵子树跟不上），卸载时放回原来的。
- **俯冲**：往下滚一屏，镜头沿进深方向推进，书角与丝带先退出画面，羊皮页从身边掠过，桌子放平、推近、变亮，1:1 落在第一幕的位置（约九成宽），四周是铺到画外的丝绒桌布。
- **第一幕**：跟着第五章的一场戏走六拍，最后交给访客。落地以后自己从第一拍连播到最后（第 7 轮，开发者：这一幕不用访客滚动，愿意就停在这里慢慢看），演完一拍留 0.7 秒静止再换下一拍。每一拍先在字幕里说要做什么、再做，做完说得到了什么；字幕上一行是章节条（`ChapterRail`，`rail` 选三版之一）：六段短标题，演到哪一段、这一段走了多少（按每一拍的标称时长估，说出结论那一刻补满），条尾是暂停与从头再看；点哪一段就从那一段的开头演。动作由一支金色指针做，按下、拖动、双击、点菜单都是真的发给工作台的指针事件，拖动走实时布局，不画上下左右中的落点分区。
  1. 两章并排：第五章打出“门外有人敲门，三下。她屏住气，等那第四下。”；作者问，星璃读了第一章边打边答；第一章的标签拖到第一组的右缘，布局一路排开，两章并排，第一章翻到末尾。
  2. 高亮批注：拖选两处敲门，点选区菜单上的高亮；再选第五章那半句，点“批注”，在卡片里写“第四下不会响：门外的人不是师傅。”，保存后点批注的小符号把卡片打开。
  3. 人物浮窗：艾莉丝的标签拖到状态栏上松手，浮出一扇窗；拉右上角的手柄，收到作品树下面，不盖正文。
  4. 视图换位：作品的活动栏入口拖到右栏的入口条上，作品树整块搬到右栏（和星璃上下两段），左边换成设定。
  5. 专心写：双击标签栏，正文铺满桌面；再双击还原。
  6. 下次还在：关灯，存盘并按此刻的样子重新挂一台工作台，再开灯：分栏、浮窗、高亮与批注、打到一半的那句、对话都还在。
  7. 交给访客：第一章的标签上一圈金环，隔一会儿往右挪一下示意能拖；字幕那一行换成星璃的小贴纸、邀请与两个按钮。
- **连播与停下**（导演在 `act-one.ts`）：舞台过半在视口里且已落地才演；滚走一半或往回滚让镜头拉回去时停下（演到一半的那一拍断开，没松开的拖动撤下），回来从那一拍的开头接着演。从不锁滚动：落地以后舞台再钉 0.8 屏，再往下滚就是下一节。点后面的段时，路过的拍一拍一拍快速摆上；点前面的段、从头再看时按记下的终态一步摆回去。同一时间只有一段在走。
- **访客动手**：一按工作台，演示让开，章节条的光丝定格、压暗，条尾换成“继续演示”；访客摆的样子留着（滚走再回来也不动它），按了“继续演示”才从访客摆的样子摆回这一拍的开头再演。摆回时能就地摆就走产品的布局动画；正文对不上（打过字、演到一半）时压一层薄暮，按记下的重新挂一台再揭开。交给访客那一段只熄掉金环。
- 窄屏（不到 900 宽）不俯冲、不演示：工作台平放在首屏文字下面，首屏的字退开以后，字幕与章节条在上面自己一段一段换（每段先说开头一句，再说结论），导航收起“更新日志”。访客要求少动效时没有开场、俯冲与首屏的动静，首屏与落地的工作台淡入淡出，每一拍直接摆到终态、停 3.2 秒再换下一拍。

## Props

| 属性 | 说明 |
|---|---|
| `start` | `top`（缺省）从首屏起，演开场；`act-one` 直接落在第一幕开头。 |
| `headline` | 首句的候选 id（`copy.ts` 的 `HEADLINES`），缺省 `e3`。 |
| `appearance` | 一开始是 `night`（缺省）还是 `day`，之后访客可以切换。 |
| `rail` | 章节条的画法：`ruler`（缺省，古籍标尺）、`diamonds`（菱形与进度环）、`ribbon`（赤红书签），见 `ChapterRail.md`。 |
| `effects` | 首屏停着时的动静，传给 `SanctumScene`；不给就是它的缺省（全开）。 |

没有事件与 slots；attrs 落在根元素上。根元素上的 `data-hs-beat`（字幕上是哪一拍，-1 是还没开演）、`data-hs-phase`（导演在做什么：`play 2`、`settle 1`、`restore 0`、`rest 3`、`paused`、`interrupted`）、`data-hs-landed`、`data-hs-night`，字幕那一条上的 `data-hs-rail-done`（章节条看过了几段）与 `data-hs-hold`（停着的原因：`none`、`user`、`touch`、`away`）给探针读。
