# HomepageSanctum

NeuroBook 文档站首页的原型（w00056 t06 第 5 轮，在第 4 轮上改）：方向一《入殿·俯案成界》的首屏与俯冲，接着是跟着一场戏走的第一幕。自己是滚动容器，一屏的大小就是自己的大小。

- **首屏**：暗夜圣案前的一幕（`SanctumScene`）。开场约 2.1 秒：暗处先起顶光，书角、丝带与羊皮页浮上来，远处桌布上那张桌子被光点亮，最后题辞 From words to world.、首句、一道金色花饰、说明与按钮依次随光显出来。首句缺省用 e3“每一个世界，都从一行字开始。”，和那句英文呼应；说明那一行把产品讲清楚。按钮是双线金边、两端各一粒金菱形的牌子（往皇室奢华感走）。
- **夜间工作台**：挂着时在根上换成产品的夜间配色（缺省），强调色换成金；落地后字幕那一条右端有昼夜切换。卸载时把根上原来的配色放回去。主题有一批变量在根上从配色派生，只改工作台那一棵子树跟不上，所以写在根上。
- **俯冲**：往下滚一屏，镜头沿进深方向推进，书角与丝带先退出画面，羊皮页从身边掠过，桌子放平、推近、变亮，1:1 落在第一幕的位置（约九成宽），四周是铺到画外、淡进暗里的暗红丝绒桌布。
- **第一幕**：跟着第五章的一场戏走五拍，最后交给访客。每一拍先在字幕里说要做什么、再做，做完说得到了什么；字幕上一行是进度（五粒金菱形）与这一拍的短标题，下一行是一句字幕。动作由一支金色指针做（滑到、停一下、按下漾一圈、拖着走身后一道金色尾迹、落点一起步就亮、停一下再松手）。星璃的话在她自己的对话栏里，她开口时那一栏亮一圈金。
  1. 两章并排：第五章打出“门外有人敲门，三下。她屏住气，等那第四下。”；作者问，星璃读了第一章边打边答；第一章的标签先亮一圈金，再拖到右半边，两章并排，第一章翻到末尾，两声敲门同时描金。
  2. 人物浮在手边：艾莉丝的设定拖成浮窗，落在作品树下面，不盖正文。
  3. 视图换个位置：作品树整块拖到右栏（右栏切到作品，星璃收在右栏的入口里），左边换成设定。
  4. 专心：双击标签栏，正文铺满桌面；再双击还原。
  5. 下次还是这样：关灯（工作台上压一层夜色），存盘并按此刻的样子重新挂一台工作台，再开灯：分栏、浮窗、打到一半的那句、对话都还在。
  6. 交给访客：第一章的标签上一圈金环，隔一会儿往右挪一下示意能拖；字幕那一行换成星璃的小贴纸、“换你来：拖一个标签，摆到顺手的地方。”与“下载 NeuroBook”“接着看世界引擎”。
- 演示走产品真的布局动作、拖动反馈与对话视图；访客一按工作台，演示让开，字幕后面出现“接着看”“摆回去”（交给访客那一段只熄掉金环）。往回滚时换回那一拍的终态，不重演。
- 窄屏（不到 900 宽）不俯冲、不演示：工作台平放在首屏文字下面，往下滚只换字幕，工作台保持首屏的样子给访客自己上手。访客要求少动效时没有开场与俯冲，首屏与落地的工作台淡入淡出，每一拍直接摆到终态。

## Props

| 属性 | 说明 |
|---|---|
| `start` | `top`（缺省）从首屏起，演开场；`act-one` 直接落在第一幕开头。 |
| `headline` | 首句的候选 id（`copy.ts` 的 `HEADLINES`），缺省 `e3`。 |

没有事件与 slots；attrs 落在根元素上。根元素上的 `data-hs-beat`（当前拍，-1 是首屏与俯冲）、`data-hs-phase`（第一幕在做什么）、`data-hs-landed`、`data-hs-night` 给探针读。
