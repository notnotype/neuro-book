# DeskSpotlight

首页第一幕的“案头聚光”（w00056 t06 第 8 轮）：开发者看第 7 轮时说高亮不显眼，一个改法是加遮罩。舞台上压一层幕，要看的那几块留亮，边缘是很宽的羽化，像灯只照着案头的那一处，不是挖出硬边的方框（@designer 第 8 轮：硬框加满屏滑窗像新手引导）。

- **压多暗**：夜里约四成（再暗就是死黑）；白天是一层暖褐，约两成（再重会把白天打脏）。
- **亮处**：比要看的东西大一圈，边缘约 28px 的羽化；核心对象（`rims` 点名的几块）内沿再描一道 1px 的暖金细线。
- **怎么换**：从无到有，幕淡入、亮处就在落点上（挂上时就带着亮处的，第一帧就是落好的样子）；同一时刻要看的几块换了位置但块数不变，亮处平滑地挪过去、变形过去；块数变了（换了一件事），幕先淡开、回亮一下，再在新的地方落光，不做探照灯式的横扫。收起时幕淡出。
- 访客要求少动效时没有淡入淡出与挪动，直接换。

幕不接指针，压在工作台上、眉题与章节条下面（宿主按 DOM 顺序放）；什么时候亮哪几块由第一幕的导演定（`HomepageSanctum.vue`）。

## Props

| 属性 | 说明 |
|---|---|
| `spots` | 要留亮的几块（舞台坐标的矩形）；空的时候幕收起。 |
| `rims` | 其中哪几块（下标）的内沿描一道细金线。 |
| `width`、`height` | 舞台的大小（幕铺满它）。 |
| `night` | 缺省 `true`；`false` 时用白天的暖褐与古铜线。 |

没有事件与 slots；attrs 落在根元素上。根上的 `data-ds-on`（幕亮着没有）与 `data-ds-count`（此刻留亮的块数）给探针读。
