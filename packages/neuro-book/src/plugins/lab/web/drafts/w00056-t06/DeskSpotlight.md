# DeskSpotlight

首页第一幕的“案头聚光”（w00056 t06 第 8 轮，第 9 轮改了标记与幕的深浅）：开发者看第 7 轮时说高亮不显眼，一个改法是加遮罩。舞台上压一层幕，要看的那几块留亮，边缘是很宽的羽化，像灯只照着案头的那一处，不是挖出硬边的方框（@designer 第 8 轮：硬框加满屏滑窗像新手引导）。

- **压多暗**：夜里约六成（第 8 轮的四成压在本来就暗的界面上差别太小，开发者看着像没压；@designer 第 9 轮给 0.64）；白天是一层暖褐，约三成。
- **亮处**：比要看的东西大 10px，边缘约 16px 的羽化（第 8 轮外扩 14px、羽化 28px，太糊，两块亮处之间连成一片）。每一块可以再标一处鎏金标记（`GildedMarks`）：元素标四角，文字按行标下划线，空的落点标落点槽，或者不标。
- **怎么换**：从无到有，幕淡入、亮处就在落点上（挂上时就带着亮处的，第一帧就是落好的样子）；同一时刻要看的几块换了位置但块数不变，亮处平滑地挪过去、变形过去；块数变了（换了一件事），幕先淡开、回亮一下，再在新的地方落光，不做探照灯式的横扫。收起时幕淡出。
- 访客要求少动效时没有淡入淡出与挪动，直接换。

幕与标记一起淡入淡出；换一件事时旧的标记收起（四角往外散）、新的出现（四角往里扣合）。幕不接指针，压在工作台上、眉题与章节条下面（宿主按 DOM 顺序放）；什么时候亮哪几块由第一幕的导演定（`HomepageSanctum.vue`）。

## Props

| 属性 | 说明 |
|---|---|
| `spots` | 要留亮的几块（舞台坐标的矩形）；空的时候幕收起。 |
| `marks` | 每一块标什么（与 `spots` 按下标对齐）：`corners`、`underline`、`slot` 或 `none`（缺省不标）。 |
| `width`、`height` | 舞台的大小（幕铺满它）。 |
| `night` | 缺省 `true`；`false` 时用白天的暖褐与古铜色的标记。 |

没有事件与 slots；attrs 落在根元素上。根上的 `data-ds-on`（幕亮着没有）与 `data-ds-count`（此刻留亮的块数）给探针读。
