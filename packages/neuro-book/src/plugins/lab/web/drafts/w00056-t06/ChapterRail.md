# ChapterRail

首页第一幕的章节条（w00056 t06 第 7 轮出了三版，第 8 轮定为古籍标尺，另两版删了）：第一幕改成落地以后自己连播（开发者：访客不用滚动，愿意就停在这里慢慢看），访客要能一眼看出演到哪了、这一段看完没有，也能跳着看。压在工作台下面的暗绒桌布上，一行六个短标题，下面是进度；条尾是暂停（或继续）与从头再看。纯显示：演到哪、这一段走了多少由页面给（页面按每一段的标称时长估，这一段说出结论时补满）。

每一段三种样子：看过的（金）、正在演的（标题提亮）、还没到的（暗）。画法是古籍标尺：一条极细的暗金底线分六格，每格右端一粒小金菱形。看过的格是实金线与实心菱形；正在演的那一格，底线上一道亮金光丝从左往右推进，前端一粒细微光点；还没到的是暗金虚线与空心菱形。

停下时（暂停、访客动了工作台）光丝定格、压暗，光点熄掉；访客动过工作台时，条尾的暂停键换成亮一些的“继续演示”。演完以后只留“从头再看”。

条尾挂在标题那一行的右边，不占它的宽（换成更宽的“继续演示”时六段不挪）。外面定条宽时两边各留出一个 `--cr-tail`（根上的变量：条尾连同它和条之间的空隙最宽要多少，缺省 156px），留不出来就把条收到 360 以下：条不超过 360 时条尾自己挪到下面一行，所以条尾总在外面的框里。写法：`width: max(min(<上限>, 100% - 2 * var(--cr-tail)), min(100%, 360px))`。条窄于 560 时标题收紧。

## Props

| 属性 | 说明 |
|---|---|
| `chapters` | 每一段的短标题（2 到 4 个字）。 |
| `current` | 正在演（或刚演完、正停着）的是第几段，从 0 起；-1 是还没开始。 |
| `done` | 从头起看过了几段：这几段画成看过的。 |
| `progress` | 正在演的那一段走了多少，0 到 1；`current` 已经算在 `done` 里时不看它。 |
| `status` | `playing`（在演：条尾是暂停）、`paused`（访客按了暂停：条尾是继续）、`yielded`（访客动了工作台：条尾是“继续演示”）、`finished`（演完了：只留从头再看）。`paused` 与 `yielded` 时光丝定格、压暗。 |

## 事件

| 事件 | 说明 |
|---|---|
| `jump` | 点了某一段的标题（参数是第几段）：页面从那一段的开头演起。 |
| `pause` | 按了暂停。 |
| `resume` | 按了继续或“继续演示”。 |
| `replay` | 按了从头再看。 |

没有 slots；attrs 落在根元素上。颜色可以由外面覆盖：根上的 `--cr-gold`（看过的标题、线与菱形）、`--cr-gold-light`（正在演的标题、光丝，条尾的边、字与图标也由它调出来）、`--cr-ink`（还没到的标题）、`--cr-dim`（还没到的虚线与空心菱形）、`--cr-glow`（光丝与光点的辉光）、`--cr-plate`（条尾按钮的底）、`--cr-tip-core`（光点的芯），缺省是压在暗绒上的夜色（白天压在浅色的旧橡木上，页面换成深墨与铜金）。访客要求少动效时，光丝不滑动，光点不呼吸。
