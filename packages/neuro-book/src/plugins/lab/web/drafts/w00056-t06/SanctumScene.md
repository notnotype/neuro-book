# SanctumScene

首页第 4 轮起首屏《入殿·俯案成界》的场景（w00056 t06）：暗夜的圣案前，顶上一束光，三张羊皮页悬在半空（一页手稿、一张人物卡、一幅霜港的地图），前景是一本赤红精装书的书角与一条丝带书签，浮尘在光里慢慢飘；远处的暗红桌布上平放着一张桌子，桌上是真工作台，首屏时压暗，只有顶光落着的那一块亮。

首屏停着时三张纸轮流演进（第 6 轮，开发者要首屏静中有动；@designer 建议不翻牌，改成纸上的东西自己演进、叠着的纸换上来）：约每 6.5 秒轮到一张，一次只动一张。手稿上敲门那一行涂上一道高亮，红笔圈出来、牵一条线写“伏笔：第五章再响”，下一轮再淡掉；人物卡下面压着星璃的便笺（她的头像与一句话），轮到时便笺斜着抽出来换到上面，人物卡往另一边让开、落到下面，下一轮再换回来；地图下面压着剧情的时间线（四章四件事，第一章与第五章那两声敲门连着一道红线），换法同人物卡。镜头推走了、页面在后台时不动。

昼（`night` 为 false，第 6 轮）是午后的抄经室：偏暖的灰石墙（比羊皮纸暗半阶，纸才不糊在底上），左上高窗斜进来一道日光，浮尘是极淡的暖白反光点，纸面提亮、投影换成柔和的棕，桌布压成枣红的暗调；书角与丝带照旧。

往下滚时镜头沿进深方向俯冲：书角与丝带先退出画面，羊皮页从身边掠过、淡掉，桌子放平、推近、变亮，最后 1:1 停在第一幕的位置，四周是铺到画外的暗红桌布。镜头的算法在 `sanctum.ts`；各层不共用一个 3D 场景，按同一台相机各自投影，落地时工作台的变换正好是恒等、换成 `none`，所以真工作台在第一幕里字是清楚的、拖动照常。

材质：书角（皮面、鎏金包角、刷金的书口）、羊皮纸、丝绒桌布是生成的照片（`assets/`，第 5 轮换上，提示词与模型记在 t06 的 Task 记录里），书角的黑底抠成了透明；手稿、人物卡、地图上的字与线、鎏金的线条用 SVG 画，浮尘用 Canvas 2D。不借契约仪式页的素材。

## Props

| 属性 | 说明 |
|---|---|
| `progress` | 镜头的目标进度，0 是首屏，1 是落地（页面按滚动给）。场景自己平滑地追上它，滚轮一格一格跳时镜头也是连贯的。 |
| `intro` | 挂上时演开场：暗处先起光，羊皮页与书角浮上来，桌子亮起，最后字随光显出来（约 2.1 秒，字的先后由 `hero` 插槽里的内容自己排）。`false` 时一挂上就是亮的。 |
| `deskReady` | 工作台第一次排好版了。开场里桌子等它再亮，免得亮出一张还没排好的桌子。 |
| `night` | 缺省 `true`，暗夜圣殿（工作台是夜间配色，首屏压暗得少一些）；`false` 是昼，见上。 |

## 事件

| 事件 | 说明 |
|---|---|
| `landed` | 落地与否变了（参数是布尔值）：落地后工作台才接指针。 |

## Slots

| 插槽 | 说明 |
|---|---|
| `desk` | 真工作台。放在桌布上，大小是落地时的大小（`sanctum.ts` 的 `landingBox`），俯冲中只变换不重排。 |
| `hero` | 首屏的字与导航：在最上层，往下滚时最先退场（只淡出、上移，不模糊）。插槽参数 `lit`：开场的光亮起了，插槽里的字据此依次显出来。 |

attrs 落在根元素上。访客要求少动效时不演开场、不俯冲、纸不轮播：首屏的样子静着，滚动时首屏淡出、落地的工作台淡入。
