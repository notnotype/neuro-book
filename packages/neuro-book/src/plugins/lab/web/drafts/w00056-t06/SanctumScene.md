# SanctumScene

首页第 4 轮起首屏《入殿·俯案成界》的场景（w00056 t06；第 7 轮改了停着时的动静，第 8 轮加了点纸细看、跟着指针速度的浮尘与丝带，重做了白天）：暗夜的圣案前，顶上一束光，三张羊皮页悬在半空（一页手稿、一张人物卡、一幅霜港的地图），前景是一本赤红精装书的书角与一条丝带书签，浮尘在光里慢慢飘；远处的暗红桌布上平放着一张桌子，桌上是真工作台，首屏时压暗，只有顶光落着的那一块亮。

首屏停着时的动静（第 7 轮，开发者：第 6 轮的轮播换得慢、动静小；@designer：串成一条单线接力的叙事，指针只做克制的响应，不做 3D 翻牌与扫光），由 `effects` 选，缺省全开（首页总是全开，只在 Lab 里关掉几样单独看）：

- **从字到世界**（`relay`）：一圈约 30 秒，五秒一步、演一半停一半，同一时刻只有一处在动；开灯后 0.9 秒起笔。一，手稿上敲门那一行落墨写出来（笔尖前一团湿墨，刚写的墨更黑，慢慢干）；二，一粒金尘从那一行飞到地图上，海岸线描出来、陆地染上、灰塔升起，红色航线从霜港流向灰塔；三，高亮涂过那一行，红笔圈出“三下”、牵一条线写“伏笔：第五章再响”；四，金尘从批注飞到人物卡，压在下面的星璃便笺往左下斜着抽出一截，露出她那几行字与小头像；五，金尘沿航线从霜港走到灰塔，剧情时间线换到地图上面，红线把第一章与第五章那两声敲门连起来；六，墨沉回纸里（字与线先褪成纸色再隐掉），便笺收回，时间线换回下面，下一圈再写。镜头推走了、页面在后台时停着。不演时停在都显出来的样子。
- **指针视差**（`parallax`）：几张纸、书角与丝带按远近跟着指针挪几个像素（近的多），纸倾不过两度，带阻尼的惯性（约 0.8 秒追上、不回弹）；顶光不动。镜头一推就收掉。
- **鎏金反光**（`glint`）：书角的鎏金上一团柔和的暖光跟着指针走（遮罩用书角那张照片，只亮在书上）；插槽里的字也读得到同一份指针位置，首页用它给花饰与按钮金边加反光。
- **悬停细看**（`peek`）：指针停在哪张纸上，那张稳住（漂浮停在半路），朝指针所在的那一边微倾、凑近；压在下面的那张多探出一点。
- **丝带尾巴**（`ribbon`）：指针一动，前景丝带的末端比书角慢半拍摆过去，再轻轻多摆一下停住；指针横扫得快时像被风带着，多摆一截。

浮尘、纸的漂浮与顶光的呼吸是底噪，周期在 8 到 12 秒。

能动手的几处（第 8 轮，开发者：首页旁边的东西要能点、点了稍微放大，要有跟鼠标位置、速度互动的动画）：

- **点纸细看**：点一张纸，它转正（倾角只留一成半）、放大约 1.2 倍、往首屏中间凑，别的纸、书角、丝带与桌子压暗（夜里暗得多，白天只淡一层）；再点它、点纸以外的地方、按 Esc 或往下滚都放回去。转过去的快慢由一个不回弹的弹簧按真实时间追，约半秒到位；访客要求少动效时直接到位。细看时从字到世界停着；指针在纸上是放大镜。
- **浮尘随指针**：指针划过时，划过的那一段两侧约 190 像素里的浮尘被带着走、打个旋，按速度亮一下（越快越亮、越大），一秒左右慢下来、暗回去。速度按指针事件自己的时间戳算：帧率低时事件成批到，按处理的时刻算会算出离谱的速度。
- **停留唤醒**：指针在一张纸上停 0.4 秒，纸上已经显出来的几处细节亮起来、慢慢呼吸（手稿上敲门那一行与红圈，人物卡的头像框与印，地图的海岸与航线）；离开就熄。只认真的鼠标，触屏没有悬停。

昼（`night` 为 false，第 8 轮重做，开发者：白天明显不对）是午后抄经室的一张桌子：桌布是本色亚麻（看得见经纬的织纹），左上高窗斜进来的日光在桌布上铺开一片暖白，越往右下越暗；纸、书角、丝带与桌子都往右下投柔和的暖棕影；浮尘是极淡的暖白反光点，纸面提亮。日光那一束要斜着照，旋转写在光束里层的元素上（外层的变换每帧由镜头写，写在外层会被盖掉）。

往下滚时镜头沿进深方向俯冲：书角与丝带先退出画面，羊皮页从身边掠过、淡掉，桌子放平、推近、变亮，最后 1:1 停在第一幕的位置，四周是铺到画外的桌布（夜里暗红丝绒，白天亚麻）。镜头的算法在 `sanctum.ts`；各层不共用一个 3D 场景，按同一台相机各自投影，落地时工作台的变换正好是恒等、换成 `none`，所以真工作台在第一幕里字是清楚的、拖动照常。

材质：书角（皮面、鎏金包角、刷金的书口）、羊皮纸、丝绒桌布是生成的照片（`assets/`，第 5 轮换上，提示词与模型记在 t06 的 Task 记录里），书角的黑底抠成了透明；手稿、人物卡、地图上的字与线、鎏金的线条用 SVG 画，浮尘用 Canvas 2D。不借契约仪式页的素材。

## Props

| 属性 | 说明 |
|---|---|
| `progress` | 镜头的目标进度，0 是首屏，1 是落地（页面按滚动给）。场景自己平滑地追上它，滚轮一格一格跳时镜头也是连贯的。 |
| `intro` | 挂上时演开场：暗处先起光，羊皮页与书角浮上来，桌子亮起，最后字随光显出来（约 2.1 秒，字的先后由 `hero` 插槽里的内容自己排）。`false` 时一挂上就是亮的。 |
| `deskReady` | 工作台第一次排好版了。开场里桌子等它再亮，免得亮出一张还没排好的桌子。 |
| `night` | 缺省 `true`，暗夜圣殿（工作台是夜间配色，首屏压暗得少一些）；`false` 是昼，见上。 |
| `effects` | 首屏停着时的动静（`sanctum.ts` 的 `SceneEffect`）：`relay`、`parallax`、`glint`、`peek`、`ribbon` 里选几样，缺省全开。 |

## 事件

| 事件 | 说明 |
|---|---|
| `landed` | 落地与否变了（参数是布尔值）：落地后工作台才接指针。 |

## Slots

| 插槽 | 说明 |
|---|---|
| `desk` | 真工作台。放在桌布上，大小是落地时的大小（`sanctum.ts` 的 `landingBox`），俯冲中只变换不重排。 |
| `hero` | 首屏的字与导航：在最上层，往下滚时最先退场（只淡出、上移，不模糊）。插槽参数 `lit`：开场的光亮起了，插槽里的字据此依次显出来；`glint`：开着鎏金反光，这时插槽外面写着 `--sx-glint-x`、`--sx-glint-y`（带惯性的指针位置，-1 到 1），插槽里的金线可以据此放反光。 |

attrs 落在根元素上。根元素上的 `data-sx-relay`（从字到世界此刻显出来的几样，空格隔开）、`data-sx-focus`（正在细看哪张纸：`manuscript`、`character`、`map`，没有是 `none`）、`data-sx-stirred`（此刻被指针带着的浮尘有几粒，约每 0.2 秒写一次）给探针读。访客要求少动效时不演开场、不俯冲、首屏没有动静：首屏的样子静着（停在都显出来的样子），滚动时首屏淡出、落地的工作台淡入；点纸细看照样能用，直接到位。

全局监听：在 document 上听按下与 Esc（细看时点在纸外、按 Esc 放回去）、页面可见性（后台时停帧循环）；开着指针的动静时在 window 上听指针移动、在 document 上听指针离开窗口。卸载时全部撤掉。
