# SanctumScene

首页第 4 轮首屏《入殿·俯案成界》的场景（w00056 t06）：暗夜的圣案前，顶上一束光，三张羊皮页悬在半空（一页手稿、一张人物卡、一幅霜港的地图），前景是一本赤红精装书的书角与一条丝带书签，浮尘在光里慢慢飘；远处的暗红桌布上平放着一张桌子，桌上是真工作台，首屏时压暗，只有顶光落着的那一块亮。

往下滚时镜头沿进深方向俯冲：书角与丝带先退出画面，羊皮页从身边掠过、淡掉，桌子放平、推近、变亮，最后 1:1 停在第一幕的位置，四周是铺到画外的暗红桌布。镜头的算法在 `sanctum.ts`；各层不共用一个 3D 场景，按同一台相机各自投影，落地时工作台的变换正好是恒等、换成 `none`，所以真工作台在第一幕里字是清楚的、拖动照常。

材质全是程序画的：皮面的纹理、纸的纤维用 SVG 的噪声滤镜，鎏金用多段的金属渐变，浮尘用 Canvas 2D；不用位图，也不借契约仪式页的素材。

## Props

| 属性 | 说明 |
|---|---|
| `progress` | 镜头的目标进度，0 是首屏，1 是落地（页面按滚动给）。场景自己平滑地追上它，滚轮一格一格跳时镜头也是连贯的。 |
| `intro` | 挂上时演开场：暗处先起光，羊皮页与书角浮上来，桌子亮起，最后字随光显出来（约 2.1 秒，字的先后由 `hero` 插槽里的内容自己排）。`false` 时一挂上就是亮的。 |
| `deskReady` | 工作台第一次排好版了。开场里桌子等它再亮，免得亮出一张还没排好的桌子。 |

## 事件

| 事件 | 说明 |
|---|---|
| `landed` | 落地与否变了（参数是布尔值）：落地后工作台才接指针。 |

## Slots

| 插槽 | 说明 |
|---|---|
| `desk` | 真工作台。放在桌布上，大小是落地时的大小（`sanctum.ts` 的 `landingBox`），俯冲中只变换不重排。 |
| `hero` | 首屏的字与导航：在最上层，往下滚时最先退场（只淡出、上移，不模糊）。插槽参数 `lit`：开场的光亮起了，插槽里的字据此依次显出来。 |

attrs 落在根元素上。访客要求少动效时不演开场、不俯冲：首屏的样子静着，滚动时首屏淡出、落地的工作台淡入。
