# SecretsMatrix

“谁知道什么”的表（[`plot/author-ui.md`](../../../../../../../docs/specs/plot/author-ui.md) 输出 7、8）：一行一个秘密、按主体分组，列是秘密、选中的人、别的人、读者、打算怎么揭。宽时是表格，窄时（页面按容器宽度给 `compact`）是一行一条的列表，同一时间只渲染一种，读屏不会读两遍。

## 布局与交互

- 表格：`<table>` 带可读名“谁知道什么”；表头是 `th scope="col"`，每组第一行是跨全行的组名（`scope="rowgroup"`，“关于某某”，没有主体的写“别的”），每行的秘密是 `th scope="row"`。秘密一列与组名在横向滚动时固定在左边，表头一行在纵向滚动时固定在上面。表格自己不做滚动容器，表宽于容器时由外面的编辑区横向滚动（自己滚动会把这两样固定关在它里面）。
- 选中的人的格子写程度（文字，不只靠图标）；信错了的下面一行写他以为的那句。
- 别的人：写“名字（程度）”，以顿号隔开；多了写“等 N 人”；没有时写“没有人知道”。
- 读者：程度，到怀疑以上时写“第 N 章第 M 段起”。
- 打算怎么揭：揭示计划一行一个（“第 N 章明说”“第 N 章暗示”，兑现了的后面写“已写”，没排章的写“还没排章”）；决策一行一个（已定写结论，待定写“还没定”与“第 N 章到期”，到期章不晚于所选位置的用警告色）；都没有时写“没有打算”。决策不可点。
- 列表版式：每个秘密一张卡：名字与保密档、选中的人各自的程度、别的人、读者、打算怎么揭，各一行。
- 秘密、人的名字是按钮，点了发 `open`（页面打开它的条目页）。

## 数据

```ts
type SecretsMatrixProps = {
    /** 这一页的行（服务已按主体在条目树里的顺序与名字排好）；必填。 */
    rows: readonly SecretRow[];
    /** 选中的人（表的列），按显示的先后；必填。 */
    people: readonly string[];
    /** 名字表：条目 id 到名字；必填。 */
    names: Readonly<Record<string, {readonly name: string; readonly type: string}>>;
    /** 章 id 到序号（从 1 起）；必填。 */
    chapters: ReadonlyMap<string, number>;
    /** 所选位置所在章的序号（初值是 0）；默认 0。 */
    now?: number;
    /** 窄的版式；默认 false。 */
    compact?: boolean;
};

type SecretsMatrixEmits = {
    /** 点了一个秘密或人的名字。 */
    (event: "open", id: string): void;
};
```

没有插槽、没有 expose；`attrs` 落在根上。

## 状态

空行时只有表头（页面另写“还没有秘密”）。
