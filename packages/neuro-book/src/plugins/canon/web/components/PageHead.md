# PageHead

别的浏览器入口的页面用的页头（[`canon/author-ui.md`](../../../../../../../docs/specs/canon/author-ui.md) 输出 35）：剧情侧的表格页经 `canonReadsKey` 拿到它（服务把窗口的读取层与线绑好，页面只给标题与受控的值）。与条目页的页头同一套控件、文字与出现的条件。

## 布局与交互

- 最上面是世界横幅（`WorldBanners`）：断开时“世界已断开”与“重试”，世界只读时写原因。
- 左边是标题，下面是默认插槽（一行说明）；右边是“在看”（`ViewPointPicker`：故事线、“最初”与各章的开头末尾、作品里有计划或这一页正算着计划时的“算上计划中的情节”；没有章、没有计划又只有主线时不出）。宽度不够时换到下一行。
- 内容列封顶 760 像素，`wide` 时 1100 像素。
- 位置的值空串是缺省位置（最新一章末尾）；选着的那一章不在章表里时按缺省位置显示，时间点左边的标记写“原来选的那一章已经不在了”（同条目页）。页面状态里的旧值不改，作者另选一个位置时这一句就没了。

事件：选位置发 `update:position`（值的写法同条目页），点“算上计划中的情节”或标记里的“算上计划 ×”发 `update:planned`；线选择直接改窗口在看的线，不发事件。

## 数据

```ts
type PageHeadProps = {
    title: string;
    /** 位置选择的值；空串是缺省位置。 */
    position?: string;
    planned?: boolean;
    wide?: boolean;
};
```

经服务拿到的组件已经绑好读取层与窗口的线；组件文件本身另收 `world` 与 `windowLine` 两个属性（canon 内部用）。

## 隐藏通道理由

- `io:read`：页头自己经传入的读取层读章表（位置选项与“选过的章不在了”都要它）与作品里有没有计划（勾选项要它），所以 Lab 不给它造替代场景；它的样子由用它的页面的组件测试与 e2e 看（`plot-author.e2e.ts`）。
- `state:inject`：界面文字经注入的文字端口取（canon 的目录）。
