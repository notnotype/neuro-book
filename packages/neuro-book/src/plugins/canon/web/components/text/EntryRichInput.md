# EntryRichInput

条目主文字的富文本输入框（[`canon/author-ui.md`](../../../../../../../../docs/specs/canon/author-ui.md) 输出 48）：作者看到的是排好版的文字，标签是不能打字进去的小块。它是 `EntryTextEditor` 的一种输入框，和源文字的输入框（`PlainSourceInput`、编辑器插件的 `CodeInput`）**同一个合同**：受控的整篇源文、`update:modelValue`、`focus(caret?)`、`cursorOffset()`、`insert(text)`、`readonly`。所以条目页的状态行、暂存、提交、冲突都不用知道它是富文本还是源文字。

和别的富文本输入不同的地方：读写都经章节编辑器同一套编解码器（nb-markdown），加条目语法模块（`../entry-syntax.ts`）。作者没动过的块原样写回，改过的块按规范写法重写并读回校验；条件 `<If>…</If>` 整段是一个小块，作者拆不坏。

## 合同逐项对照

| 合同 | 在富文本里 |
|---|---|
| `modelValue` → 显示 | 第一次挂上时整篇读入。之后 `modelValue` 变了：与最近一次交出的相同是回声，不动；不同（“换成那边的”、冲突里选“现在的”、重连后读到的暂存）就只把不同的那一段换掉，撤销历史保留，这次替换不进撤销。 |
| `update:modelValue` | 每次文档变化后整篇写出，写得出就交出（与上一次交出的相同不交）。写不出（不应发生：小块的改动都先过写入前的检查）时不交出，输入框下面写一句“这一处写不出”，暂存留着最后一次交出的文字；作者撤销那一步就恢复。 |
| `focus(caret?)` | 焦点进编辑区，`"start"`、`"end"` 把光标放到文首、文末；给整篇源文里的偏移时，先按顶层块在整篇里的起点二分找到块，再在块里按位置二分，找偏移不超过它的最后一个位置（切换模式与拒收后指到某一行用；偏移落在小块原文中间时停在小块前面）。给偏移时页面不滚动。 |
| `cursorOffset()` | 把光标之前那一截文档写出来的长度：小块按它的原文、强调按记号算，与整篇源文逐字对应（截断处的行尾空格写成字符引用，按一个字算）；光标在一块开头时是这一块在整篇里的起点，在列表项、引用里一段的开头时是这一段第一个字的位置。顶层代码块里按围栏下一行起的字数算；表格里按单元格的纯文字估（截出的半张表写不出或按规范写法重写，长度对不上）。随位置不减，不超出这一块在整篇里的范围。 |
| `insert(text)` | `text` 是一段源文（“插入”菜单给的写法），读成节点插在光标处，有选区时换掉选区；插入后的整篇过写入前的检查才落，否则不插、返回 false。只读、光标在行内代码或代码块里时返回 false。 |
| `readonly` | 不能编辑，不交出；能选、能复制。 |

## 数据

```ts
type Props = {
    /** 整篇源文，受控。 */
    modelValue: string;
    /** 编辑区的可访问名称。 */
    label: string;
    /** 合同里有的属性，富文本用不上（读法固定是条目语法）。 */
    language?: string;
    /** 默认 false。 */
    readonly?: boolean;
    /** 写入前检查用的没登记标签的基线（`../entry-check.ts` 的 `baselineOf`，开始编辑时读到的那一版）；默认空。 */
    baseline?: ReadonlySet<string>;
    /** 这个条目的 id：取值不写 `entry` 时指它自己。默认空串。 */
    self?: string;
    /** 本条目的字段与这一页位置上的值（`../entry-chip.ts` 的 `EntryField`）：刚插进来的取值马上显示它。默认空。 */
    fields?: readonly EntryField[];
    /** 本条目各字段的“改过”标记，按地址。默认空。 */
    marks?: Readonly<Record<string, string>>;
    /**
     * 世界服务按某一版整篇算的作者值表（canon.rendering 输出 16）。按标签名与起点对回那一版的活标签，再按标签原文对到此刻的小块：
     * 作者在别处打字、小块原文没变的照样换上；对不上那一版的整批不用。默认 null。
     */
    values?: {readonly source: string; readonly values: readonly EntryTextValue[]} | null;
    /** 值正在算；为假时（整篇太长不算）没有值的计算类小块是“没有算”。默认 true。 */
    computing?: boolean;
    /** 条件画成各支都在、没生效的变淡；默认 false（只画生效的那一支）。 */
    showBranches?: boolean;
    /** 找条目（`./entry-picker.ts`）：`@` 的列表与条目引用的“换一个”。默认 null：`@` 照普通的字打，条目引用没有“换一个”。 */
    find?: EntryFind | null;
};

type Emits = {
    "update:modelValue": [text: string];
    "focus": [];
    "blur": [];
    /** 浮层不是作者自己关的（开始提交变只读、外面换了整篇、撤销让小块不在了），而里面有没应用的字：宿主在状态行写“没应用的改动已丢弃”。 */
    "discarded": [];
};

type Exposed = {
    focus(caret?: "start" | "end" | number): void;
    cursorOffset(): number | null;
    insert(text: string): boolean;
    /** “插入”菜单里的计算、条件、条目：计算与条件在光标处开空的浮层，条目开条目列表（同 `{`、`@`）。只读、光标在代码里、条目却没有 `find` 时返回 false。 */
    openInsert(what: "calc" | "if" | "ref"): boolean;
    /** 此刻能不能在光标处插入：只读、光标在行内代码或代码块里时为 false（“插入”菜单据此把项写成不可用）。 */
    canInsert(): boolean;
};
```

没有 slots；attrs 落在根元素上。

## 布局

一个随内容增高的编辑区（不自己滚动，跟着条目页滚），正文的字号与行距同阅读视图；编辑区下面在写不出时多一行原因（危险色，`role="alert"`）。`390×844` 下照样占满内容列宽。

标签是不能打字进去的小块（浅底、圆角；计算前面一个“＝”；没登记的标签灰底等宽字写原文）；值很长时最多两行、末尾截掉。小块显示什么由 `../entry-chip.ts` 的 `chipOf` 决定（与阅读视图同一份判断）：有值表的项就照它；还没有时本条目的字段显示这一页的值，别的条目的字段、计算、条件是“计算中”（虚线框），整篇太长不算时是“没有算”；未知、不完整、读不到、条目已删除各有样子。条件是一个小块，只画生效的那一支（极淡的底色），没有一支成立时是淡的占位，`showBranches` 时各支都画、没生效的变淡划掉（翻开的那一次淡入；视口里光标所在段的位置交给浏览器自带的滚动锚定，不另外补滚动）。小块的壳带 `data-entry-chip`（种类）、`data-chip-state`、`data-chip-changed`（改过时）、条件的 `data-chip-branch`（生效的第几支）。浮层带 `data-chip-popover`（种类），输入框带 `data-chip-field`（`expr`、条件的 `test-N`、`branch-N`，N 从 0 起），按钮带 `data-chip-action`（`apply`、`replace`、`remove`、`add-branch`），检查不过的原因带 `data-chip-problem`；列表的搜索框在 `data-chip-menu` 里。输入法正在组字时不换值，组完再换。

## 改小块与插入

点小块（或选中它按 Enter；左右键越过小块时先选中它）在小块下面弹出浮层（nb-ui `Popover` 的锚点用法，传送到 body；顶层小块的壳是 `role="button"`，可读名字是“显示名：值”，打开过的带 `aria-haspopup`、`aria-expanded`；浮层的可读名字是它的标题）。新插的计算、条件还没有小块：浮层只按光标的位置定位，没有锚点，点到正文别处就收起。关上时内容留到退场动画走完。浮层里能做什么看种类，从小块的原文读出、改完拼回（`../entry-chip-edit.ts`）：

| 小块 | 浮层 |
|---|---|
| 取值 | 字段的“设定组 · 字段名”与值的全文；“换一个”（在小块上打开字段列表）、“删掉” |
| 计算 | 式子的输入框与此刻的结果；“应用”“删掉” |
| 条件 | 每支一行：“如果 / 否则如果 / 否则”、判断（“否则”没有）、这一支的源文字（一行）；生效的那支标出来；“加一个‘否则如果’”（加在“否则”之前，判断抄第一支）、“删掉”“应用” |
| 条目引用 | 条目名；“换一个”（条目列表，有 `find` 时）、“删掉” |
| 图片、没登记的标签 | 原文；“删掉” |

浮层里打的字只存在浮层里；按“应用”或回车时，先让按钮转圈画出来，再把拼出的原文读成节点（必须正好读成一个同种小块，否则写“这样写读不成一个小块”），整篇过写入前的检查（`../entry-check.ts`），通过才改、是一个撤销步，不通过写原因、字留着。属性里有双引号直接拦下（会把标签切坏）。Esc 关上、焦点回编辑器且小块仍选中（新插的按 Esc 取消时不选，光标留在原处：插入点后面紧挨着的小块不被选中）；应用后同样，只是新插的应用后光标在它后面（接着往下打不会把它换掉）。点外面关上，焦点留在点的地方。只读时浮层只给看：输入框只读、没有按钮。

`{` 在光标处弹字段列表（nb-ui `SuggestionMenu`，顶上一个搜索框）：最前面是“条件”“计算”，选了先弹空的浮层、应用了才插进去；后面是本条目的字段（`fields`），选了插入取值，马上显示这一页的值，光标在它后面。`@` 弹条目列表，按搜索词经 `find` 找（去抖同条目选择器），选了插入条目引用。列表里上下键选、回车插入，筛选不分大小写；Esc 关上并把 `{`、`@` 补回正文（作者就是要打这个字），搜索框空着时按空格同样关上、补回的是“{ ”；点到列表外只关上、不补字；输入法正在组字时这几个键不算。光标在行内代码或代码块里时 `{`、`@` 照普通的字打。

## 不支持
- 块级的条件、跨行的条件在富文本里改：跨行的条件各标签各一个小块，只能在源文字里改。
- 从外面粘进来的含标签的纯文字按写法读入：按文字处理（写成 `\<V`），在源文字里粘才是标签。

## 隐藏通道理由

- `state:local`：编辑器的实例、原文对照、最近一次交出的文字、写不出的那一句、开着的浮层与列表。
- `state:inject`：经 `useCanonText()` 取翻译端口写“这一处写不出”、浮层与列表的文字。
- `env:portal`：小块的浮层与 `{`、`@` 的列表渲染到 nb-ui `Popover`、`SuggestionMenu` 的 Teleport 目标（body）。
- `env:global`：列表开着时在 document 上按捕获阶段听 pointerdown，按在列表外就关上；卸载时解除。
