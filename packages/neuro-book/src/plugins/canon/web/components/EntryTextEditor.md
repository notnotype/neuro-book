# EntryTextEditor

条目页文字分页的编辑视图（[`canon/author-ui.md`](../../../../../../../docs/specs/canon/author-ui.md) 输出 39、44 到 46、48）：主文字当一整篇改，一个源文字输入框；上面一行是有没有未提交的修改、暂存的状态、“预览”、“插入”、“放弃”与“提交”；旁边可以开一栏预览，内容由宿主放进插槽。受控：整篇的文字、暂存与提交的状态都由宿主给，改动只发事件。整篇怎样写回各块（第一块放整篇、其余的块删掉）是宿主的事，这里不分块。

阅读视图是 `EntryText`；宿主在两者之间切换。

## 布局

纵向两部分，第二部分在预览开着时是两栏：

- **状态行**：在最上面，不吸顶（条目页的页头已经吸在滚动区顶上）。左边是“有未提交的修改”（有改动时才写，前面一个圆点）、暂存的状态（“已暂存”“没有暂存”等）与“提交”点不了的原因（`submitBlocked`，有改动时才写；整批的说明里正写着同一句时不重复）。右边依次是“预览”开关（宿主给了 `preview` 插槽、并且读得出块时才出）、“插入”（条目有字段可插时才出）、一个离开的按钮（有东西可丢时是“放弃”，否则是“取消”）与“提交”。另一个窗口也在改时多两个按钮“用这里的”“换成那边的”；上一次提交结果不明时写“正在确认上一次提交”与“再试”。整批的说明（提交被拒的原因、读不出最新的文字）另起一行，危险色；它出现时状态行滚进视野中间（在长条目的下半截用键盘提交的人要看得到）。
- **输入框**：整篇的源文字（Markdown 加 `{表达式}`），外面一个框，聚焦时框线用强调色；内核说写得不对时（`problem`）框线变危险色，输入框下面一行写原因（`role="alert"`）。
- **预览栏**（`preview` 为真、给了插槽、读得出块时）：宿主画的渲染结果；栏顶上可以有一句（`previewNote`，警告色），有这一句时栏里的内容变淡（它是上一次的样子）。这一句写在一个一直在的播报区域里（`role="status"`，没有那一句时是空的）：随文字一起插进页面的播报区域，读屏多半不报。本组件的宽度不小于 880 像素时输入框与预览栏左右各半，中间一条分隔线；预览栏吸在页头下面、自己滚动，高度不超过滚动区看得到的部分（吸顶的位置与最大高度取条目页根上的两个变量 `--entry-page-sticky-top`、`--entry-page-viewport`，没有时按视口）。窄于 880 像素时预览栏排在输入框下面、上面一条分隔线，跟着页面滚。

宽度由父容器封顶（宿主在左右分屏时把内容列放宽）。左右还是上下看的是本组件自己的宽度（容器查询），不是视口：编辑组被拆窄时也排成上下。`390×844` 下预览栏在输入框下面，状态行里按钮多到放不下时按钮换到下一行。

预览栏自己滚动是“页面只有一层滚动”的例外：预览的字号与行距比源文字大，同一段内容预览比源文字高一倍多，跟着同一条滚动条滚时两边对不上。内容不比栏高时它不滚。

## 交互

- 输入：发 `update`（整篇文字）。输入框失焦发 `blur`（宿主据此立刻暂存）。
- “预览”是一个开关按钮（`aria-pressed`）：点了发 `update:preview`（反过来的值），开没开由宿主记。
- 预览栏自己滚动时，作者每打一次字，栏里的内容跟着换了以后，把光标所在那一行对应的段落滚进栏里（已经看得到就不动）。只跟这一次：之后栏里的内容因为别的事变了（别处改了值），不把作者自己滚到的位置拽回去。段落在源文字里的行号由插槽里的内容写在元素上（`data-source-line`，`EntryText` 会写）；光标的位置问输入框（`cursorOffset()`）。还没打过字时不滚（刚打开从头看）。作者自己滚预览栏不影响输入框。
- “插入”是一个下拉菜单（nb-ui `DropdownMenu`），项是“设定组 · 字段”（`inserts`）。选了由输入框自己在光标处写入（它的 `insert`：进它的撤销历史、光标落在写法后面，照打字一样发 `update`），之后焦点回到输入框；菜单开着时焦点不在输入框里，光标的位置由输入框记着。输入框还没就绪时把写法接在整篇末尾发 `update`。
- “放弃”先问一句（`AlertDialog`），确认才发 `discard`；没有东西可丢（没有改动、读得出块、不在等上一次提交的结局）时是“取消”，直接发 `cancel`，Esc 同它（有改动时 Esc 不接，输入法正在组字时的 Esc 也不算）。
- 给焦点（`focus()`）时输入框还没就绪（按需加载的输入框）：记下来，就绪时再给。
- 动效：状态行里各项、整批的说明、输入框下面的原因与预览栏顶上的那一句出现与消失都有过渡，预览栏出现时淡入、栏里的内容变淡与恢复有过渡，时长与缓动取令牌；输入框里的文字不加。预览栏关掉时立刻让出位置（输入框马上变宽，不等它淡完）。
- 提交在途、等上一次提交的结局时输入框只读、“插入”不可用。
- `frozen`（读不出块）时输入框只读、不出“插入”、不出“预览”开关与预览栏，能选能复制，只能放弃。

## 数据

“插入”的项类型 `InsertItem` 在 `entry-text-editor.ts`（宿主逻辑也用它）。

```ts
interface InsertItem {
    label: string;
    /** 写进源文字的写法，例如 `<V of="panel.魔力" />`；同一个菜单里不重复。 */
    snippet: string;
}

type Props = {
    /** 整篇的源文字，受控。 */
    text: string;
    /** 输入框下面要写的原因（内核说写得不对）；空串没有。 */
    problem: string;
    /** 有没提交的内容。 */
    dirty: boolean;
    saved: "none" | "saved" | "unsaved" | "failed" | "too-large" | "diverged";
    phase: "idle" | "submitting" | "confirming";
    /** “提交”不能点的原因（只读、断开……）；空串是能点（还要有改动）。 */
    submitBlocked: string;
    /** 整批的说明；空串没有。 */
    message: string;
    /** 读不出块：只能看与放弃。默认 false。 */
    frozen?: boolean;
    /** “插入”里列的写法；空数组时不出“插入”。默认空。 */
    inserts?: readonly InsertItem[];
    /** 源文字的输入框组件，合同见 `PlainSourceInput.md`（外露 `focus(caret?)`、`insert(text)` 与 `cursorOffset()`）；不给时用 `PlainSourceInput`。 */
    input?: Component;
    /** 交给输入框的语言 id；默认 "markdown"。宿主给 `canon-entry`（`entry-language.ts`）。 */
    language?: string;
    /** 预览开着，受控。给了 `preview` 插槽、并且不是 `frozen` 才有预览栏与开关。默认 false。 */
    preview?: boolean;
    /** 预览栏顶上的一句（写得不对的行与原因、读不出来的原因）；非空时栏里的内容变淡。默认空。 */
    previewNote?: string;
};

type Emits = {
    (event: "update", text: string): void;
    (event: "blur"): void;
    (event: "submit"): void;
    (event: "discard"): void;
    (event: "cancel"): void;
    (event: "take-over"): void;
    (event: "adopt"): void;
    (event: "retry"): void;
    /** 点了“预览”开关：要换成的值。 */
    (event: "update:preview", value: boolean): void;
};

type Slots = {
    /** 预览栏的内容：输入框里此刻的整篇渲染出来的样子。不给时没有预览栏，也没有“预览”开关。 */
    preview?(): unknown;
};

type Exposed = {
    /** 把焦点放进输入框。 */
    focus(): void;
};
```

attrs 落在根上。

## 不支持

- 分块：块的增、拆、并、删、恢复、调换顺序都没有，提交时整篇写进第一块、其余的块删掉（宿主，见 `EntryPageHost.md`）。
- 自己渲染预览：渲染由宿主做（世界服务算），这里只给位置。
- 在预览里改、点预览跳到源文字、两栏同步滚动（只有打字后跟到光标那一段）。
- 插入条目引用：“插入”只列本条目各设定组的字段。

## 隐藏通道理由

- `state:local`：放弃的确认框开没开、输入框是不是在等按需加载、作者刚打过字而预览栏还没跟过去。
- `env:timer`：预览栏里的内容换了以后等一帧（`requestAnimationFrame`）再量位置、滚动。
- `state:inject`：经 `useCanonText()` 取翻译端口。
- `env:portal`：放弃的确认框与“插入”菜单渲染到 nb-ui `AlertDialog`、`DropdownMenu` 的 Teleport 目标。
