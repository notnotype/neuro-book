# NetworkPage

设置窗口“通用”分组下的“网络”页（[`network/egress.md`](../../../../../../../docs/specs/network/egress.md) 的“网络页”）：`nbook.network` 贡献的 column 页面，只在“用户”标签下可用。两组：“代理”（代理方式、自定义时的代理地址、测试代理）与“模型目录”（自动更新模型列表、现在更新）。它是页面，不是宿主：选路说明、测试与目录状态在数据模块（`web/network-store.ts`），三项设置经传入的配置服务读写，写失败交给窗口通知（`reportWriteFailure`）。改了就写，没有“未保存”状态。

## 布局

单列，内容列由设置窗口封顶。每组一个带分隔线的小组标题（同“搜索与网页”页），组里是 [`SettingsRow`](../../../../ui/settings/SettingsRow.md) 与 [`SettingsActionRow`](../../../../ui/settings/SettingsActionRow.md) 的行，控件右缘对齐。代理方式是三段的 `SegmentedControl`；代理地址是单行输入（随行宽收窄，最宽 280px）；两个动作是次级按钮。行下信息（现在用的代理、测试结果、更新失败的原因）小字号、任意处折行，390 宽与英文下不撑出页面。

## 交互

- **代理方式**：跟随系统、自定义、直连，点了就写。跟随系统时行下写现在用的代理与来源（“现在用的是 http://127.0.0.1:7890（来自环境变量 HTTPS_PROXY）”；带用户名密码的写“带用户名与密码”，不写出来；系统没设写“系统没有设代理，请求直连”）；读不到、代理不支持（SOCKS、自动配置脚本）时写原因（危险色）。说明来自 `describe()`，进入页面与改了代理设置之后各取一次；取的过程中写“正在读取现在用的代理…”。
- **代理地址**（只在自定义时出现）：失焦或回车时写；不是 http 或 https、带用户名密码的原位写原因（标题后状态图标，危险色），不写进设置。别处改了地址时，正在编辑的框不被打断，失焦后换成实际值。地址为空或不合规时行下写选路的错误。
- **测试代理**（直连时不出现）：点“测试”经现在的设置请求一次 Cloudflare 的 trace；进行中按钮变成“取消测试”，状态写“正在测试…”。框里没交的地址先交、等写完再测。结果：通了写出口 IP 与耗时（成功色）；测试目标在旁路清单里或本机时写“测试目标没有走代理”，不说“通了”；失败按原因写（危险色）。改了代理设置后旧结果清掉、在跑的取消；离开页面取消在跑的测试。
- **自动更新模型列表**：开关，点了就写。
- **现在更新**：说明写上次更新的时间与模型数（“…更新过，共 1,104 个模型”）、还没取过、这台机器关掉了在线目录、读不到目录状态几种；进行中按钮写“更新中”并停用。上次更新失败时状态写原因（危险色）。

## 数据

```ts
defineProps<{
    store: NetworkStore;                                            // 浏览器入口建的数据模块
    settings: SettingsService;                                      // 本插件的配置服务（三项设置都是本插件声明的）
    writable: boolean;                                              // 用户层能不能写（页面上下文的 writable）
    reportWriteFailure: SettingsPageContext["reportWriteFailure"];  // 写失败交给窗口通知
}>();
```

没有 emits、slots 与 expose；attrs 落在根元素上。根带 `data-network-page`；行下信息 `data-network-summary`（`data-tone`），测试按钮 `data-network-test`，更新按钮 `data-network-update`。

## 状态

- 只读：`writable` 为假时控件停用（设置文件坏了、读不到）。
- 说明：读取中、有（代理、直连、旁路、出错）、读不到。
- 测试：空闲、进行中（可取消）、通了、没走代理、失败、没测成（远程调用本身失败）。
- 目录：读不到状态（模型服务的合同不可用）、关掉了、没取过、有、更新中、上次失败。

## 不支持

- 本作品标签下编辑（三项都只有用户层）。
- SOCKS 代理与自动配置脚本（决定 21）；代理地址里的用户名密码。
- 按 `focus` 定位到某一行。

## 隐藏通道理由

- `state:local`：代理地址框的草稿与它有没有焦点（决定别处改了地址时换不换框里的字），卸载即丢。
- `state:inject`：文字经宿主注入的翻译端口取。

数据模块、配置服务、`writable` 与 `reportWriteFailure` 都经属性传入，读写走的是这条明面通道，所以页面没有 `io:*` 与 `state:shared-*` 标签，能在 Lab 里用内存里的替身摆出来。
