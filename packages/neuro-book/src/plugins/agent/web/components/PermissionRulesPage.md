# PermissionRulesPage

设置窗口的“权限规则”页（[`agent/permissions.md`](../../../../../../../docs/specs/agent/permissions.md)）。

## 什么时候用

只由 `nbook.agent` 的设置页包装用，包装读配置与项目规则文件，把改动写回用户设置。

## 行为

- “我的规则”可增删改、上移下移：顺序有意义，第一条命中算数。一条规则是工具、一个条件、动作、理由；嵌套条件用 JSON。
- 绑定了作品时列出这本书的规则，只读；放行规则标明不生效，文件坏了写明后果。
- 手写在设置文件里的规则照样显示：表单认不出的条件显示成“自定义条件”，编辑时是 JSON。
