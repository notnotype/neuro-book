# SubagentCard

父会话里一次 `agent_spawn`、`agent_send`、`agent_answer` 调用的卡片（对话视图的节点，[`conversation.md`](../../../../../../../docs/specs/agent/conversation.md) 输出 33–39）。每次派发一张，上下排着，不合成一组。

## 布局与交互

- 卡头：Profile 图标、子代理名、“后台”（调用先返回了）、工具次数与用时、状态（运行中转圈，否则状态图标）、打开子会话（`session.select`；派发失败、找不到子会话时不可用）。
- 下面一行：运行中写正在做什么：最近一步的动作名与对象（“读取 第二章.md”）。动作名取对话视图注册表里那个工具的名称，注册表里没有时写工具名；对象是地址时只写最后一段。等批准时同样写动作名。在问父 Agent 时写问题，结束后写结果第一句；调用被拒写“没有派出”，参数不对写“参数不对，没有派出”，不知道派没派出时照实写（找得到子会话就叫用户打开核对）。只占一行，放不下截断；进度更新只改这一行的文字，高度不随文字与状态变化。
- 有结果全文时这一行能点开，全文区有最高高度、区内滚动；运行中、结束时都不自动展开。
- 出错时边框用危险色。

## 数据

属性同工具节点（`ToolComponentProps`：`call`、`ctx`、`services`、`locale`）；事件 `action`。状态按 `web/subagent-card.ts` 的 `cardModel` 推导。

## 隐藏通道理由

`state:local`：结果全文的展开。`state:inject`：卡片的数据（`subagent-store.ts`，宿主按会话提供：后代的进度、任务、每秒走的 `now`）、工具名到动作名的查询（对话位置的组件按视图的注册表提供，卡片是工具节点、拿不到注册表），与界面文字。
