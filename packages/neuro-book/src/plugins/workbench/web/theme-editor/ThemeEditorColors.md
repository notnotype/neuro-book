# ThemeEditorColors

主题编辑器的“配色”分区（[`theme/editor.md`](../../../../../../../docs/specs/theme/editor.md) 输出 7、8、14）：主色与推导、33 个配色变量按用途分组、折叠的角色变量。所有修改都交给模型（`ThemeEditorModel`），它自己不存值。

## 布局

自上而下：主色（背景、文字、强调三行，下面是“推导整套”“从另一套派生”两个按钮和一句说明）；背景、文字、边框、强调、状态、其它六组，每组一个小标题加若干 `ColorField` 行（三个主色不在组里重复）；最后一个折叠的“高级：角色变量”，展开是 10 个角色变量各一行输入加“清除”。分区之间留 `--space-8`，组内行间留 `--space-2`。`--color-scheme` 由明暗决定，不在这里改。

## 交互

- 改主色：只是推导的输入，不算手改。点“推导整套”：只填没手改过的项（主色读不懂时显示一条提示，什么都不改）。“从另一套派生”按钮写着另一套的名字，把那一套的主色换算成当前明暗的主色再推导。
- 改其它项：记为手改过，行上出现小圆点和“还原为推导值”。
- 每个有对比度的项（文字类、状态色）在行末显示比值，见 `ColorField`。
- 角色变量：输入停手后写入；写空或点“清除”就删掉这一项。

## 数据

```ts
type Props = {model: ThemeEditorModel};
```
