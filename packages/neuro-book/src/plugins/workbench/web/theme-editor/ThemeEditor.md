# ThemeEditor

主题编辑器的主体（[`theme/editor.md`](../../../../../../../docs/specs/theme/editor.md)）：我的主题库的选择与增删，左边分区导航，右边一次一个分区。编辑区的页签与浮动窗口放的是同一个主体（经 `ThemeEditorHolder`），同一时刻只有一份模型。组件自己不存声明：所有读写都经 `ThemeEditorModel`，模型里的声明在 Storage 的“我的主题”记录里，改动立刻回显到真实工作台的预览。

## 布局

整体是一列：顶部操作条、（读取失败时一行错误）、主体。主体铺实心面（`--bg-panel`），不随被预览主题的半透明浮层面变：改色时要看清自己在改什么。

- **操作条**：我的主题下拉（没有主题时不画）、新建、复制、删除（点一次变成“确认删除”，失焦回去）、弹性空隙、亮/暗分段控件、关闭（只在浮动窗口里画）。放不下时换行。
- **没有我的主题**：居中的空状态，一个“新建”和一个“复制自…”下拉（从全部主题里选）。库还没读完时只显示“正在读取我的主题”（`aria-busy`）。
- **主体**：左边 180px 的分区导航（基本信息、配色、字体、活动栏与画框、场景与取景、对比度检查；对比度检查旁有不合格项的数量角标），右边是滚动的分区内容。当前分区在导航里用强调色底。
- **窄屏**：组件宽度不足 520px 时导航收成顶部一条（横向可滚），分区内容占满宽，内边距收小。

## 交互

- 切分区只换右边的内容，不丢各分区里没提交的输入。
- 亮/暗分段控件只决定正在编辑的是哪一套，同时决定真实工作台预览的明暗；它不改设置里的明暗。
- 基本信息：中英文标题、主题包两项（NeuroBook、macOS）。其它分区由各自的组件承担（`ThemeEditorColors`、`ThemeEditorTypography`、`ThemeEditorChrome`）；“场景与取景”分区在后续的 Task 里补全。
- 对比度检查分区：一句说明，下面列出两套明暗里全部不合格的项（明暗、变量、比值、落在哪个底上最差）；没有时写“没有不合格的项”。

## 数据

```ts
type Props = {
    model: ThemeEditorModel;
    themes: ReadonlyArray<ThemeEntry>;   // “复制自…”的候选，来自主题目录
    closable?: boolean;                  // 画“关闭”按钮；缺省画
};
type Emits = {close: []};
```

文字取自 `nbook.workbench` 的 `themeEditor.*`，经注入的翻译端口；主题标题是 `Text`，经 nb-ui 的文字端口解析。
