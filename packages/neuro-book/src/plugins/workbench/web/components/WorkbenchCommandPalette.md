# WorkbenchCommandPalette

命令面板：把宿主里的命令与面板状态渲染成 nb-ui `QuickInput` 浮层。`>` 按命令搜索，`:` 按行号跳转；命令发起的选择模式（`host.pick` 不为空时）列出请求给的候选。几种模式共用同一个输入框与同一次打开的浮层。行为合同见 [`workbench.quick-open`](../../../../../../../docs/specs/workbench/quick-open.md)。

它不能单独摆出来：宿主由 prop 传入（产品页上是工作台的命令宿主，Lab 里是命令场景的局部宿主，都随所在页面或场景建立与释放）。候选从哪来、查询的含义、执行时机都归宿主；组件自己不建命令表、不挂键盘监听、不碰存储。

## 数据

```ts
type Props = {
    /** 命令服务、面板状态、活动编辑器的接入口与会话 MRU（palette-host.ts 的 PaletteHost）；面板只通过它执行命令。 */
    host: PaletteHost;
};
```

无 emits：组件把 QuickInput 的请求翻译成对 `host` 的调用，宿主状态变化驱动回显。无 slots、无 expose；attrs 透传给 QuickInput（QuickInput 再绑到浮层面板根上），Lab 因此能用 `data-lab-subject` 把打开中的面板标成受检零件。

文案按显示语言取中英两份中的一份（设置插件加入前固定简体中文），命令标题来自命令声明。

## 命令契约

面板是命令系统的触发面本身，执行确实发生在组件内，但唯一入口是 prop 传入的 `host`，没有第二条通道。它引用两个命令 id，都属于面板合同：

- `:N` 合成 `nbook.editor.go-to-line` 的参数 `{target, line}`，accept 后执行；N 的合法性在这里求值（读活动编辑器的行数），非法输入不产生候选。
- `nbook.quick-open.open-line` 是同层模式切换：不关面板，执行后把查询原位改成 `:`，保留打开时捕获的目标。

其余命令按 id 交给命令服务执行；结果进入命令系统的审计，成功与否都在执行记录里。

选择模式不执行命令：提交时调用 `host.choosePick`（选中项，或允许提交文字时末尾那一项“提交输入的文字”），QuickInput 的 `closed` 到达后调用 `host.closed()`，由宿主把结果交回发起选择的命令；Escape 关闭时同样在 `closed` 后结算为取消。标题、占位与空态文案取自请求，选择模式不做前缀路由。

## 交互与状态

- 开合由 `host.open` 决定。accept 后先关面板，等 QuickInput 的 `closed`（焦点已归还）才执行；等待期间重复 accept 忽略；关闭期间活动文档换代（不再与打开时捕获的目标相同）则作废这次选择。
- Escape 由 QuickInput 关闭面板并把焦点还给打开前的元素。
- 候选是 `expose.human !== false` 且当前可用的 canonical 命令，在命令表增减或可用性依赖的上下文变化时重算，不轮询；行号模式在正文变化、活动编辑器变化与每次输入时重读行数。
- 行号非法、没有活动编辑器、编辑器不支持行号跳转或尚未就绪时，列表为空，原因显示在空态里，Enter 不提交。
- 成功执行的面板选中命令写进 `host` 的会话 MRU；行号动作与面板入口本身不记，失败与取消不记；选择模式不记。

## 不支持

- 文件与工作区实体的快速打开、`@` 符号导航、多步向导。
- 执行失败的提示：结果交给命令系统的审计，由宿主决定怎么呈现（Lab 命令场景在检视区显示，产品页记入诊断）。
