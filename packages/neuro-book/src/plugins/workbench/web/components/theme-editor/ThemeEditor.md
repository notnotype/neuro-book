# ThemeEditor

主题编辑器的主体（[`theme/editor.md`](../../../../../../../../docs/specs/theme/editor.md)）：我的主题库的选择与增删，左边分区导航，右边一次一个分区。编辑区的页签与浮动窗口放的是同一个主体（经 `ThemeEditorHolder`），同一时刻只有一份模型。组件自己不存声明：所有读写都经 `ThemeEditorModel`，模型里的声明在 Storage 的“我的主题”记录里，改动立刻回显到真实工作台的预览。

## 布局

整体是一列：顶部操作条、（读取失败时一行错误）、主体。主体铺实心面（`--bg-panel`），不随被预览主题的半透明浮层面变：改色时要看清自己在改什么。

- **操作条**：左边是库操作（我的主题下拉（没有主题时不画）、新建、复制自…、复制、删除（点一次变成“确认删除”，失焦回去）、导出、导入），放不下时它们自己换行；右上固定是亮/暗分段控件和关闭（只在浮动窗口里画），不跟着库操作换行。窄到库操作排不下 280px（手机宽度）时这一组才落到下一行。
- **没有我的主题**：居中的空状态，一个“新建”和一个“复制自…”下拉（从全部主题里选）。库还没读完时只显示“正在读取我的主题”（`aria-busy`）。
- **主体**：左边 180px 的分区导航（基本信息、配色、字体、活动栏与画框、场景与取景、图标、对比度检查；对比度检查旁有不合格项的数量角标），右边是滚动的分区内容。当前分区在导航里用强调色底。
- **窄屏**：组件宽度不足 520px 时导航收成顶部一条（横向可滚），分区内容占满宽，内边距收小；当前分区的导航项会被带进可视范围（分区变了、组件重新挂载、导航条宽度变了时都做，只改导航条自己的 `scrollLeft`，不滚动祖先）。

## 交互

- 切分区只换右边的内容，不丢各分区里没提交的输入：输入组件（`DraftInput`、`ColorField`）在卸载与失焦时立刻交出还在等的值。
- 操作条里有“复制自…”（从目录里任一主题起步，库里已有主题时也在）、新建、复制当前、删除、导出、导入。删除点一次变成“确认删除”，4 秒不再点、换了主题、失焦就回去，不到 400ms 的第二下不算（快速双击不会直接删）；防抖与超时用定时器（`env:timer`）。
- 修改写不进去时（取值引外部资源、标题两种语言都空、保存失败被撤回）在操作条下面显示一行原因（`role="alert"`），不静默。导出与导入的结果在常驻的提示区里（换主题或分区时清掉）；导出导入进行中按钮停用，意外（读不了的响应）也给一行原因，不留未处理的拒绝。
- 亮/暗分段控件只决定正在编辑的是哪一套，同时决定真实工作台预览的明暗；它不改设置里的明暗。
- 基本信息：中英文标题、主题包两项（NeuroBook、macOS）。其它分区由各自的组件承担（`ThemeEditorColors`、`ThemeEditorTypography`、`ThemeEditorChrome`、`ThemeEditorContrast`）；“场景与取景”由 `ThemeEditorScene` 承担（场景图、工作态场景、场景提供者、预览状态、取景），“图标”由 `ThemeEditorIcons` 承担。
- 导出与导入的请求不在这里发：主体只调 `transfer`（持有者给的实现）并显示结果。导出：把当前选中的主题打成 zip（`package.json` 加 `assets/`，同不写代码的主题插件）下载；有对比度不合格项时照样导出，提示里写有几项。导入：选一个 zip，包里每个主题都复制成一套新的“我的主题”（素材先传完再写主题，任何一步失败都不写主题；已传的素材不回滚）；包不合格（路径、大小、声明、图片）时整个拒绝并写出原因。结果在操作条下面一行提示。
- 窄屏：整个编辑器宽度不足 520px 时导航收成顶部一条，各导航项不换行、条上横向可滚；分区内部（配色行、取景编辑）的换排按分区内容自己的宽度（`.theme-editor__section` 是容器）。
- 对比度检查分区由 `ThemeEditorContrast` 承担：两套明暗里每个文字色各一行样张，标比值与等级，不合格的排前并可一键跳到那个色值（见同名 `.md`）。

## 数据

```ts
type Props = {
    model: ThemeEditorModel;
    themes: ReadonlyArray<ThemeEntry>;   // “复制自…”的候选，来自主题目录
    closable?: boolean;                  // 画“关闭”按钮；缺省画
    transfer: ThemeTransfer;             // 导出、导入、上传场景图与图标、复制插件主题素材的实现，请求由持有者发
};
type Emits = {close: []};
```

文字取自 `nbook.workbench` 的 `themeEditor.*`，经注入的翻译端口；主题标题是 `Text`，经 nb-ui 的文字端口解析。
