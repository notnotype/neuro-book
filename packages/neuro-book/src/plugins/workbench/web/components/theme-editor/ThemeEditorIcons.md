# ThemeEditorIcons

主题编辑器的“图标”分区（[`theme/editor.md`](../../../../../../../../docs/specs/theme/editor.md) 输出 21）：当前明暗下的图标覆盖，写进声明 `Look.icons`。图标是工作台自己用的 lucide 图标（`i-lucide-<名>` 的 <名>）；每一项把一个名字换成一个上传的 SVG。亮、暗各一份，顶部的明暗切换决定这里编的是哪一份。

## 布局

上方一句说明（写明“保存不等于产品里有这个图标”）。然后是“添加”行：图标名输入、“添加”按钮（输入框里的名字已有时写“更换”；点它打开系统的文件选择，只收 SVG）、“复制到另一套明暗”。添加行放在列表上方：列表可以很长（至多 64 个），放在底部要滚下去才找得到。下面是列表，每行：用该 SVG 画的预览（蒙版，随前景色变，装饰用，对读屏隐藏）、旁边调淡的“原图标”预览（产品里这个名字原来的样子，目录里没有这个名字时不画）、图标名、“更换”、“移除”（可访问名带图标名）。没有图标时一句引导。名字不合规则（输入时就提示）、名字为空（点添加时提示）与上传失败各一行错误（`role="alert"`）；名字合规但当前页面没有这个图标的样式时是一行非阻断的说明（`role="status"`，仍可添加）。窄屏（390px）下行内元素换行，不横向溢出。

## 交互

- 补全：名字输入框是 combobox，候选（至多 8 个，名字以输入开头的在前、含有输入的在后）经 nb-ui 的 `SuggestionMenu` 贴在输入框下（菜单传送到 `body`，目标不存在时不显示），焦点不离开输入框；上下键移动高亮（Escape 收起后，方向键把它重新打开），**回车只在用方向键或指针选过候选时填入它，否则就是添加**（与补全出现之前一样：输入完整的 `folder` 时候选里还有 `folder-plus`，不能让回车改掉用户输入的名字），Escape 收起，点候选选中。输入法组字中不处理回车与方向键。候选只显示名字，不画预览：`SuggestionMenu` 的图标只能给类名，而 `i-lucide-<名>` 会被正在编辑的主题覆盖。输入框已经等于唯一候选时不再弹。目录读不到（空）时不补全、不提示。
- 目录：`icon-scan.ts` 读页面里已加载的样式表，样式表里有 `.i-lucide-<名>` 且带 `--svg` 的规则，就是产品此刻能画这个图标（别名写成分组选择器，也收）；主题自己的覆盖表（`data-nb-skin-icons`）不算。每次打开分区、输入框获得焦点时重扫，不缓存（Vite 开发服务原地改 `<style>` 文本时缓存会漏）。开发服务、Lab 与 e2e 外壳的样式比产品多出只在 Lab 夹具里用到的图标，所以提示只说“当前页面没有”，不说产品没有。
- 原图标：行里的“原图标”预览直接把目录里取到的默认 `--svg` 写在元素的行内样式上，不挂 `i-lucide-<名>` 类（实时预览会注入不分层的同名规则去覆盖产品里的图标，挂了类画出来的就是正在编辑的那个 SVG）。

- 添加：图标名首尾空白去掉后要匹配小写字母、数字与连字符（`folder-open`），否则在输入框下给原因，不打开文件选择；通过后打开文件选择，只收 `.svg`。对已有的名字，添加就是替换：按钮此时写“更换”。
- 目标在选文件时就定下：主题、明暗、规范化后的图标名一起冻结，上传期间切了主题、明暗或改了输入框，图标仍落在发起时的那一项上；进度与失败原因也只在那个目标上显示（`use-upload-status.ts`）。有上传在进行时添加（含输入框里按回车）、更换、移除、复制到另一套都停用。写进声明才算成功：被拒绝或提交失败时原因在编辑器的提示行，输入框里的名字留着。
- 上传经 `transfer.uploadIcon`：浏览器先拦下超过 16 KiB 的，SVG 是否合格由路由检查，原因原样显示；失败时声明不变。
- 更换：同一个文件选择，名字取那一行的；移除：去掉这一项，素材文件不删。
- 复制到另一套明暗：整份覆盖另一套的图标（当前这套没有图标时清空另一套）。
