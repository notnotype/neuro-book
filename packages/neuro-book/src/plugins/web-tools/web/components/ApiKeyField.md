# ApiKeyField

“搜索与网页”页里一家服务的 API 密钥框（[`web/settings-page.md`](../../../../../../../docs/specs/web/settings-page.md) 输出 2 到 5、10）。只进不出：已存的密钥从不回到浏览器，框里永远是用户正在输入的新值；写入发出时清空。受控零件：写入、清除都只发事件，由页面经数据模块去写。插件内共用，以后每家服务一节都用它。

## 布局

上面一行是标签（左）与“清除”（右，已设置时才有），下面是密码框，框下可能有一行提示。宽度随父元素，不封顶（页面的表单封顶）。

## 交互

- 失焦或回车时交出：去掉首尾空白后为空不交；交出后清空框，所以回车之后紧接着失焦不会再交一次。已存的值不在浏览器里，没法比较“与写前相同”。
- 以 `env:` 开头的输入不交，框下原位写“这里不支持环境变量引用”（`role="alert"`），框标为无效，直到输入改掉。
- “清除”直接发 `clear`，不确认；它的可访问名称带服务名（“清除 DeepSeek 的密钥”）。
- 框里有失焦就会交出的输入（非空、不是 `env:` 写法、没停用）时发 `pending(true)`，没有了发 `pending(false)`。页面据此让“检测”在第一次填写时就能点。
- 停用时（`disabled`，或 `state` 为读取中）框与“清除”都不可用。

## 数据

```ts
defineProps<{
    state: "loading" | "set" | "unset";  // 读取中、已设置、还没有填写；决定占位文字与“清除”是否出现
    service: string;                     // 服务名，进“清除”的可访问名称
    disabled?: boolean;                  // 缺省 false
    describedBy?: string;                // 额外关联到框上的说明的元素 id
    tip?: string;                        // 标签旁说明图标（InfoTip）的提示；缺省没有图标
    notice?: string;                     // 没有密钥时标签行右边（有密钥时是“清除”的位置）写的状态字，警告色；缺省不写
}>();
defineEmits<{
    (e: "set", value: string): void;     // 交出一个新值（已去掉首尾空白，不是 env: 写法）
    (e: "clear"): void;
    (e: "pending", value: boolean): void; // 框里有没有失焦就会交出的输入；只在变化时发
}>();
defineExpose({focus});                   // 把焦点放进密码框（页面在“等着启用”时用）
```

没有 slots；expose 只有 `focus`；attrs 落在根元素上。

## 状态

- 读取中：占位写“读取中”，停用。
- 已设置：占位写“已设置”，标签行出现“清除”。
- 未设置：占位写“还没有填写”。
- 输入不合要求：`env:` 写法时框标为无效并在框下写原因。

## 不支持

- 显示或复制已存的密钥。
- 环境变量引用（模型设置页的 `env:` 写法）。

## 隐藏通道理由

- `state:local`：框里的草稿。
- `state:inject`：文字经宿主注入的翻译端口取。
