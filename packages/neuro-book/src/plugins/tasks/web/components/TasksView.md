# TasksView

底部面板里的“后台任务”视图（[`workbench/background-tasks.md`](../../../../../../../docs/specs/workbench/background-tasks.md) 输出 10、11、13、24–26、28）：按归属分组列出自己的任务（插件经 `start()` 登记的长任务）与提供方交出的行（例如 Agent 的后台命令、子代理与在跑的会话）。分组行来自 `RowsStore`（可见时才订阅），自己的任务的通知与“看过”来自 `TasksStore`；本组件在可见时把可见与否、此刻画成终态的自己的任务上报给它们。

## 布局

- 分组依次是会话、项目、应用。会话组是一块浅底的圆角块，块里任何一行在等你处理时是浅警示色底；块里第一行是组头：收起箭头、状态图标、会话标题（加粗）、“等你处理”徽标、此刻在做什么、开始时刻、“打开”“停止”。项目组与应用组的组头是一行小标题：收起箭头、图标、“项目「名字」”或“应用”、件数。
- 每组一个网格，各组用同一套列，所以组与组之间各列对齐：收起箭头或缩进（20px）、状态图标（16px）、标题（前面一个淡色的种类名）、进展、进度条（96px）、时间（4.5em）、按钮（10.5em）、移除（24px）。标题与进展按 2 比 3 分剩下的宽度，标题至少 8 个字宽；放不下时截断，悬停看全文。每行至少 28px 高。
- 组里的行缩进在组头下面（第一列画一条细竖线）。组的展开与收起用 nb-ui 的 `Collapsible` 的高度与透明度过渡；箭头随之旋转。
- 列表末尾：有没列出的行时写“另有 N 件没有列出”；当前项目范围下其他项目还有在跑的时写“其他项目还有 N 件在运行”。
- 列表在视图里纵向滚动（视图声明 `layout: "fill"`）；空的时候视图中间一句说明。范围里什么都没有、只有其他项目在跑时，视图中间写“其他项目还有 N 件在运行”，不写“没有后台任务”。

## 动效

- 组与行出现时淡入；离开时脱离排版、在原处淡出（`--motion-fast`）；其余的组与行从原位滑到新位置（`--motion-move`）。换范围时整份换内容也是这样：留下的组滑动，换掉的淡出淡入。
- 状态变了（在跑到失败、中断）图标与进展的颜色过渡过去；组头的“等你处理”徽标淡入淡出；会话块的浅警示底色随之过渡。
- “停止”与“取消”按钮有固定的最小宽度，变成“正在停止”“正在取消”时旁边的按钮不动。
- 系统减少动态效果时 token 是 0，转圈的图标停转。
- 视图不到 600px 宽（例如 `390×844`）：一行放不下，每件改排两行。第一行是缩进、图标、标题、时间、按钮、移除；第二行在标题下面写进展，进度条在它右边。标题与进展照样截断。

## 交互

- 收起箭头：切换这一组的展开与收起，按窗口记住；`aria-expanded` 跟着状态，可访问名称写“收起”或“展开”加组名。
- 自己的任务：“取消”（可取消的在跑任务；`cancelRequested` 时变成不可用的“正在取消”）、“重试”（可重试的）、“详情”（有详情的，取原文后打开 `DetailDialog`，标题“任务标题：详情”，取不到时不打开）、移除（结束的）。
- 提供方的行与会话组头：“停止”（声明了可停的；结果回来之前变成不可用的“正在停止”，结果写成提示由 `RowsStore` 负责）、“打开”（有 `open` 的；命令须是那家提供方贡献的：行看它的来源，会话组头看分组里写明的那家；打不开写成提示）。提供方的行没有移除。
- 按钮都是 nb-ui 的 `Button`、`IconButton`，焦点画内嵌焦点线；行里的按钮用 `aria-describedby` 指向这一行的标题，几行同名的“停止”“移除”读屏分得出是哪一件。
- 范围开关不在本组件里：它是视图的标题动作（命令 `nbook.tasks.toggle-all-projects`），由工作台画在面板头。

## 数据

```ts
type Props = {
    /** 工作台给视图的上下文；只读 `visible`。必填。 */
    context: ViewContext;
    /** 本窗口自己的任务（受控：通知与“看过”由它持有，本组件只调它的方法）。必填。 */
    store: TasksStore;
    /** 本窗口的分组行（受控：范围、收起、停止与打开由它持有）。必填。 */
    rows: RowsStore;
};
```

没有事件与插槽；没有 expose；attrs 落在根上。

## 状态

- 还没取到分组行：什么都不画（读得快的不闪一下占位）。
- 空：居中的一句说明。
- 进展一列：自己的任务在跑写进展，失败写原因，已取消写“已取消”或发起方给的文字，已中断写“已中断”，成功写发起方给的文字或“完成”；提供方的行写它给的进展，结束的没有进展时同上写结果。
- 时间：在跑的写开始时刻，结束的写结束时刻（当天“时:分”，前一天“昨天”，更早月日）；悬停写“开始于”或“结束于”加完整时刻。

## 隐藏通道理由

- `state:inject`：经 `useText()` 取窗口的翻译端口：翻任务与行的标题、进展（文字值，可能来自别的插件的目录）、本插件目录里的文字，并取当前语言格式化时间、排项目组的名字。
- `env:global`：经 `useForegroundVisibility`（`src/ui/foreground-visibility.ts`）监听 `document` 的 `visibilitychange`，页面转到后台时报“不可见”，卸载时摘掉监听并报“不可见”（输出 13 的“页面在前台”）。
- `env:portal`：“详情”经 `DetailDialog` 渲染到页面根上的浮层。
