# TasksView

底部面板里的“后台任务”视图（[`workbench/background-tasks.md`](../../../../../../../docs/specs/workbench/background-tasks.md) 输出 10、11、13）：列出插件发起的长任务，在跑的画进度，能取消、重试、看详情、移除结束的。清单来自 `TasksStore`（所有窗口同一份），“看过”按窗口记，由本组件在可见时上报。

## 布局

- 在跑的在上、结束的在下，各自新的在前。
- 每件一行，整个列表共用几列（子网格），名字长短不推动后面的列：状态图标（16px）、标题、进展、进度条（96px）、时间（至少 3.5em、按内容放宽，右对齐）、按钮（按内容宽）、移除（24px）。标题与进展按 2 比 3 分剩下的宽度，标题至少 8 个字宽；放不下时截断，悬停看全文。每行至少 28px 高。
- 状态图标：在跑的是转圈（系统设了减少动画时不转），成功、失败、已取消、已中断各一个图标，失败用危险色、已中断用警告色。
- 进度条只在在跑的行：数字是确定进度，`null` 是不确定进度。
- 列表在视图里纵向滚动（视图声明 `layout: "fill"`）；空的时候视图中间一句说明。
- 视图不到 600px 宽（例如 `390×844`）：一行放不下七列，每件改排两行。第一行是图标、标题、时间、按钮、移除；第二行在标题下面写进展，进度条在它右边。标题与进展照样截断。

## 交互

- “取消”：可取消的在跑任务有；点了交给仓库，`cancelRequested` 为真时变成不可用的“正在取消”。
- “重试”：可重试的（失败、发起方还在）有。
- “详情”：有详情的有；点了经仓库取原文，打开 `DetailDialog`，标题“任务标题：详情”，被截断时注明；取不到（任务已移出）时不打开。
- 移除：只结束的行有。
- 按钮都是 nb-ui 的 `Button`、`IconButton`，焦点画内嵌焦点线；行里的按钮用 `aria-describedby` 指向这一行的标题，几行同名的“重试”“移除”读屏分得出是哪一件。

## 数据

```ts
type Props = {
    /** 工作台给视图的上下文；只读 `visible`。必填。 */
    context: ViewContext;
    /** 本窗口的任务仓库（受控：清单与“看过”由它持有，本组件只调它的方法）。必填。 */
    store: TasksStore;
};
```

没有事件与插槽；没有 expose；attrs 落在根上。

## 状态

- 空：居中的一句说明。
- 进展一列：在跑写进展；失败写原因；已取消写“已取消”或发起方给的文字；已中断写“已中断”；成功写发起方给的文字或“完成”。
- 时间：在跑的写开始时刻，结束的写结束时刻（当天“时:分”，前一天“昨天”，更早月日）；悬停写“开始于”或“结束于”加完整时刻。

## 隐藏通道理由

- `state:inject`：经 `useText()` 取窗口的翻译端口：翻任务的标题与进展（文字值，可能来自别的插件的目录）、本插件目录里的文字，并取当前语言格式化时间。
- `env:global`：经 `useForegroundVisibility`（`src/ui/foreground-visibility.ts`）监听 `document` 的 `visibilitychange`，页面转到后台时报“不可见”，卸载时摘掉监听并报“不可见”（输出 13 的“页面在前台”）。
- `env:portal`：“详情”经 `DetailDialog` 渲染到页面根上的浮层。
