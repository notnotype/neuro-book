# CodeInput

页面里的一个源码输入框（[`workbench/editor.md`](../../../../../../../docs/specs/workbench/editor.md) 输出 69）：给别的插件在自己的页面或对话框里放一段可以编辑的源文字，外观、语法配色与字号同源码编辑器。它不对应文件：没有文档、标签、未保存状态与文件菜单，文字由使用方给、改动交回使用方。别的插件经编辑器插件的服务 `editorComponentsKey` 取它，不直接引这个文件。

与 `MonacoControl` 的区别：那一个按编辑器控件合同绑定一份文档，占满编辑组；这一个只认一段文字，高度随内容，一页里可以放很多个。

## 布局

一块，宽度随容器，高度随内容（一行起）。没有行号、缩略图与自己的纵向滚动条，长行折行；鼠标滚轮交给外面的页面。`390×844` 下结构不变。

## 交互

- 一页里可以有很多个：还没进入视野、也没拿到焦点时只画等宽的原文（能用 Tab 聚焦，读屏报成多行文本框），进入视野或拿到焦点时才建 Monaco；建好以后不再拆。因为聚焦才建的，建好后焦点进编辑器、光标在文末。原文的行高照 Monaco 的算法取，换成编辑器时高度不跳。
- 输入、撤销、查找照 Monaco；自带的右键菜单关掉。打字时不自己弹补全（按词的建议、触发字符的建议都关着），回车总是换行；Ctrl+Space 仍能手动叫出。
- Tab 与 Shift+Tab 离开输入框、走到页面上的下一个与上一个控件（Monaco 的 `tabFocusMode`），不在框里缩进。
- 不处理保存的快捷键：Ctrl+S 照常冒泡到工作台，由“保存”命令交给所在的页面（输出 68）。

## 数据

```ts
type Props = {
    /** 文字，受控：使用方换了它，输入框换内容（撤销历史清空，光标尽量留在原处）；与输入框里的相同时不动。 */
    modelValue: string;
    /** 可访问名称，必填。 */
    label: string;
    /** 语言 id；编辑器区没登记这门语言时按纯文本。默认 "plaintext"。 */
    language?: string;
    /** 只读。默认 false。 */
    readonly?: boolean;
};

type Emits = {
    /** 用户改了文字；每次改动发一次，带改后的整段文字。使用方换文字引起的变化不发。 */
    "update:modelValue": [text: string];
    /** 文字区拿到、失去焦点（焦点进它自己的查找框算失去）。 */
    focus: [];
    blur: [];
};

type Exposed = {
    /** 把焦点放进输入框；还没建 Monaco 时先建。`caret` 把光标放到文首、文末或整篇里的偏移（超出的按文末）；不给时已经建好的保持原来的光标，因为这一次聚焦才建的放在文末。 */
    focus(caret?: "start" | "end" | number): void;
    /** 光标在文字里的偏移（按 `modelValue` 的字符数）；还没建 Monaco 时为 null。失焦以后仍是最后的位置。加载失败时取文本框的。 */
    cursorOffset(): number | null;
    /**
     * 在光标处写入一段文字（有选区时换掉选区），光标落在它后面；照用户输入交出 `update:modelValue`，进撤销历史。只读、还没建
     * Monaco 时不做，返回 false。加载失败时写进文本框。使用方要在光标处加字时用它，不要把拼好的全文经 `modelValue` 给回来：那是
     * 整篇替换，撤销历史清空。
     */
    insert(text: string): boolean;
};
```

没有 slots；attrs 落在根元素上。

## 状态

- 没建 Monaco：等宽的原文，`data-code-input-stage="plain"`。
- 建好：`data-code-input-stage="ready"`。
- 只读：能选能复制，不能输入。
- Monaco 加载失败：换成普通文本框（nb-ui `Textarea`，高度随内容），照样能改、照样交回改动；下面一行写原因（`role="alert"`），`data-code-input-stage="failed"`。没有语法配色与查找。是因为要焦点才去加载的，焦点落进这个文本框。这个实例之后不再重试加载。

## 不支持

- 不绑定文档，不参与编辑区的保存、自动保存与关闭时的询问。
- 不保留换内容之前的撤销历史。
- 原文里混用两种换行符时，第一次输入后交回的文字统一成一种（Monaco 的模型如此）。

## 上游边界

输入、选区、查找、撤销与折行来自 Monaco，升级可能变化；本组件承诺的是上面“数据”一节。

## 隐藏通道理由

- `state:inject`：语言登记表与排版选项（字体、字号、行高）由编辑器区提供，与源码编辑器同一份；没有提供方时（Lab、对话框之外的场合）只有纯文本与 JSON、用缺省排版。
- `env:global`：Monaco 的主题整页一份，跟随文档根的主题变化重新生成（`code/theme-follow.ts`，各实例共用一个观察器，最后一个实例卸载时停止）。
