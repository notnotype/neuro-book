# CollapsibleSidePanel

可以塌成一条窄边的侧栏。Lab 的左栏（组件选择列表）和右栏（多功能面板）都是它。**它只解决一件事：让一整栏退到屏幕边上、把宽度全让给中间的画布，而且退下去之后还找得回来。**

仓库里有三个看着相近但都不做这件事的东西，选型时不要混：

- nb-ui 的 `Collapsible` 是上下方向的手风琴折叠（reka 提供），用来收起一段内容，不是收起一整栏。
- 主应用的 `SideDetailPanel` 是贴在底部的详情面板，沿高度方向收，还自带拖高和关闭按钮，职责比这里重。
- nb-ui 的 `Splitter` 负责相邻两栏之间怎么分宽度。**本零件与它配合而不是替代它**：Splitter 管拖宽，本零件管收起。

## 布局

两块，上下排：

- **标题栏**：高度固定，不随内容变化，因此切换内容不会引起布局位移。左边是标题文字，右边是收起按钮，收起按钮左侧留给使用方放额外按钮。
- **内容区**：占满标题栏之外的全部高度，内容超出时在自己内部纵向滚动，不把整栏撑高。

**宽度不归本零件管**，由父容器决定。展开态占多宽是 Splitter 或父级布局的事。

**形状也不归本零件管**：它不画任何外框，不设圆角，不投阴影。贴边三栏要的是一条竖直分割线，浮起三栏要的是圆角加抬起，同一个侧栏两种都可能对，所以这一层交给使用方在外面给类。Lab 走的是浮起那一路（见 `LabShell` 的 `.lab-panel`）。

收起态只剩一条固定宽度的窄边，宽度由 `collapsedWidth` 决定，里面只有一个展开按钮。标题文字在收起态不显示，但仍然是展开按钮的可访问名称。

内容变多时先让位的永远是内容区，标题栏不动。

**这一栏用什么材料由 `layer` 决定，不由 `side` 决定。**`nav` 是器械：取主题的侧栏面色，玻璃主题下它是半透明的并开模糊，背后的窗体底纹会透上来。`content` 是纸：实心面板色，与画布同一档材料。装导航、装工具用前者，装要读的正文与数据用后者——底纹从字后面浮上来不是材料感是脏。Lab 的左栏是 `nav`，右栏是 `content`。

`390×844` 下本零件的结构不变，宽度依然由父容器给。窄屏下三栏能不能并排是使用它的那个布局要回答的问题，不是本零件的问题。

## 交互

- 点收起按钮，栏塌成窄边；再点窄边上的展开按钮，栏恢复。**组件自己不改变收起状态**，只发事件，实际收不收由父组件决定。
- 标题栏本身**不可点击**。`SideDetailPanel` 把整条标题栏做成了可点区域，本零件有意不这么做：一大块可点区域要做到键盘可达就得给它按钮语义，而它里面还可能放别的按钮，嵌套按钮是无效 HTML。只让按钮可点，这个问题就不存在。
- 收起按钮的箭头朝向随 `side` 变化，指向它会缩过去的方向。

键盘：

- 收起按钮与展开按钮都是普通按钮，Tab 可达，回车或空格触发，有可见的聚焦环。
- 收起态整栏只有一个 Tab 停靠点，就是展开按钮。内容区的所有可聚焦元素随内容区一起移出 Tab 顺序。
- **收起时如果焦点正在内容区里，焦点移到展开按钮上**，不允许掉回页面顶部。展开时不抢焦点——展开可能由父组件在别处触发，抢焦点会打断用户当时在做的事。

## 数据

```ts
type CollapsibleSidePanelSide = "left" | "right";
type CollapsibleSidePanelLayer = "nav" | "content";

interface CollapsibleSidePanelProps {
    /**
     * 标题。展开态显示在标题栏，收起态不显示文字，
     * 但两种状态下都是收起/展开按钮的可访问名称。必填。
     */
    title: string;

    /**
     * 是否收起。**受控值，组件自身不修改。**
     * 父组件不响应 update:collapsed 的话按钮点了不会有任何反应。
     */
    collapsed: boolean;

    /**
     * 这一栏在哪一侧。**只影响收起按钮的箭头朝向**，不影响其它任何行为。
     * 不画边框也不管圆角——形状归使用方，见「布局」。
     */
    side?: CollapsibleSidePanelSide;   // 默认 "left"

    /**
     * 这一栏在材料语言里属于哪一层。
     * nav = 器械（侧栏面色 + 玻璃），content = 纸（实心面板色）。
     * 只影响这一栏的面，不影响布局、尺寸或任何交互。
     */
    layer?: CollapsibleSidePanelLayer; // 默认 "nav"

    /** 收起态的宽度，单位像素。 */
    collapsedWidth?: number;           // 默认 40
}

interface CollapsibleSidePanelEmits {
    /**
     * 用户点收起或展开按钮时发出，携带的是**期望的下一个状态**，
     * 不是当前状态。组件不会自己去改 collapsed。
     */
    (e: "update:collapsed", value: boolean): void;
}
```

两个 slot：`default` 是内容区，`actions` 放在标题栏收起按钮的左边，用于挂使用方自己的按钮。收起态两个 slot 都不渲染。

不 expose 任何方法或属性。未声明的 attribute、`class` 与 `style` 按 Vue 默认行为落到根节点上。

## 状态

- **默认（展开）**：标题栏加内容区，内容区可滚动。
- **收起**：只剩窄边与展开按钮，内容区不渲染（不是隐藏——里面的组件会被销毁，有自己状态的内容重新展开后是新的）。
- **内容为空**：正常渲染标题栏与一个空的内容区，本零件不提供空状态提示，那是内容自己的事。

禁用、只读、加载中、出错四种状态本零件都没有，见「不支持」。

## 不支持

- **不支持拖动改宽度。**展开态的宽度由父容器决定，Lab 里由 Splitter 负责。
- **不支持记住收起状态。**`collapsed` 是受控的，要不要存进设置或 URL 由使用方决定。
- **不支持禁用、只读、加载中、出错四种状态。**本零件只是个壳，这些状态属于它装的内容，由内容自己表达。
- **不支持收起态显示竖排标题。**竖排文字在中英混排下换行规则复杂，收益不足以换取这份复杂度。收起态的标题通过可访问名称与鼠标悬停提示提供。
- 不支持横向收起以外的方向。要上下收用 nb-ui 的 `Collapsible`。

## 注意事项

- **`collapsed` 是受控的，不接 `update:collapsed` 收起按钮就是个死按钮。**点了没反应，也没有任何报错。这是使用中最容易踩的一处。
- **不要在插进内容区的内容外面再套一层滚动容器。**内容区自己已经是滚动容器，套两层会出现双滚动条，而且外层滚不动。
- **收起会销毁内容，不是隐藏。**内容区里如果有编辑器、有未提交的输入、有滚动位置，收起再展开全部丢失。需要保留就把状态提到父组件。

## 隐藏通道理由

无隐藏通道，标签为空。这是一次确认结果，不是尚未处理：本零件不读写 store、不访问浏览器存储、不发请求、不注册全局监听，也不把内容渲染到自身组件树之外。收起时移动焦点是对自己 DOM 内元素的操作，不构成对外通道。
