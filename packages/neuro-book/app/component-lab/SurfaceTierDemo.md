# SurfaceTierDemo

5 档表面角色对照板。把库里登记的 5 档表面并排摆出来，用于**挑选哪一档适合大面积 chrome**。

## 用途

这不是产品组件，是 Lab 内部的演示工具。它解决一个具体问题：库里有 5 档表面角色（工具栏、侧栏、浮层、窄条、面板），每一档在 nbook 下的不透明度、模糊强度都不同，而 FormSelect 的下拉菜单实际用了内联覆盖（65% 面板底）、不走那 5 档里的任何一档。

**要给侧栏、工具条这类大面 chrome 定一个标准盒子，得先看这 5 档哪一档在复杂背景下读得清。** 这个组件就是干这个的。

## 交互

无交互。5 个并排的卡片，每张卡片是一档表面，上面有：

- 档位名称（工具栏 / 侧栏 / 浮层 / 窄条 / 面板）
- 一段示例文本，用来判断可读性
- 这一档在 nbook·昼 的实际取值（不透明度 + 模糊配方）

**判据写在明处：背景复杂时，文字能不能读。** 如果底纹从字后面浮上来、得盯着看才能认出字，这一档就不适合铺在整栏那么大的面上。

## 验证方法

1. 切换顶栏的「桌面」到「自定义图片」，选一张色彩复杂的照片（例如动漫场景、城市夜景）
2. 或者切到「极光」，那是大面积、低频、高饱和的渐变，也能看出模糊之后会不会糊成一片
3. 看 5 张卡片哪一张的正文还能一眼认出来，不用盯着看

## 数据

无 props，无 emits，无 slots。5 档的配方写死在组件里，取的是主题变量（`--toolbar-surface` / `--sidebar-surface` / `--overlay-surface` / `--strip-surface` / `--panel-surface`）。

## 状态

只有一个：默认。无禁用、无加载、无出错、无空状态。

## 不支持

- 不响应任何用户输入
- 不消费 fixture 数据
- 在非 nbook 主题下可能看不出区别（aurora / editorial 把所有 chrome 都改成实心了）
- 不接 `state:shared-read` 或任何 `io:` / `persist:` 标签，所以它能在 Lab 里直接挂载
