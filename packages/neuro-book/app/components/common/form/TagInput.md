# TagInput

自由输入的多值输入框：敲一个词、回车或逗号把它变成一枚标签，退格在输入为空时删掉最后一枚，失焦时把还没提交的输入补交上去。值本身完全由 `modelValue` 决定，组件唯一自己持有的东西是"此刻正在输入、还没提交的那串文字"。

## 数据

```ts
interface TagInputProps {
    /** 已有标签；必填、受控——增删都通过事件交给父组件，组件不就地改数组 */
    modelValue: string[];
    /** 没有标签时输入框的占位提示；有标签时不再显示 */
    placeholder?: string;
    /** 是否用强调色渲染标签；默认 false（默认是描边样式） */
    accentStyle?: boolean;
}

interface TagInputEmits {
    /** 新增或删除标签后发出，携带完整的新数组（顺序即显示顺序） */
    (event: "update:modelValue", value: string[]): void;
}
```

没有 slot，没有 `expose`。未声明的 attribute 落到根容器上（`class` 与内置类名合并）；输入框与每枚标签上的删除按钮拿不到外部 attribute。

## 交互

- **回车**或**逗号**提交当前输入：去掉首尾空白后作为新标签；空白串被忽略；与已有标签重复的值被丢弃。无论是否真的新增，输入框都会被清空。
- **退格**在输入框为空且至少有一枚标签时删除最后一枚标签。
- **失焦**会执行一次与回车相同的提交动作，所以"打了字直接点别处"不会丢字。
- 每枚标签右侧有删除按钮，点击删除该枚标签。
- 键盘路径只有输入框与删除按钮两处焦点：删除按钮是原生按钮，可以被 Tab 到并用回车/空格触发（可访问名称见「已知偏差」）。

标签多于一行时容器换行增高（`flex-wrap`），输入框始终跟在最后一枚标签之后、至少占 20px 宽。容器最小高度 28px；获得焦点时整圈边框与聚焦环变化（焦点在内部输入框上时同样成立）。窄屏下结构与交互不变，只表现为更早换行。

## 状态

没有禁用、只读、加载中与错误态：这些条件不由本组件表达。数据为空时只显示输入框和占位提示；`placeholder` 在存在标签时不显示，因此"还能不能再加"靠输入框本身判断。

## 已知偏差

- 每枚标签的删除按钮当前没有可访问名称（图标按钮没有文字也没有 `aria-label`），屏幕阅读器只会读出"按钮"。文档要求它说出删的是哪一枚标签；实现待补。
