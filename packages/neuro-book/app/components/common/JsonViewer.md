# JsonViewer

只读为主的 JSON 查看器，用来在界面里展示结构化数据。基于 `json-editor-vue` 封装，外层提供自定义工具栏、高度约束和主题接入。

## 布局

由工具栏和编辑器主体两块组成。工具栏在上，分左右两组：左组是三个模式按钮，右组是复制、展开全部、折叠全部三个动作按钮。工具栏可以整体关闭。

编辑器主体占据剩余空间。容器有最大高度约束，内容超出后由编辑器自己在内部滚动，不把外层撑高，也不产生页面级滚动。最大高度设为 0 表示不限制。

工具栏高度固定，切换模式或数据变化都不改变它的尺寸，因此不会引起布局位移。

窄屏下结构不变。工具栏的六个按钮在一行内排布，均为紧凑尺寸。

## 交互

- 点击模式按钮切换文本、树形、表格三种查看方式。当前模式的按钮呈选中态。
- 点击复制把当前内容写入系统剪贴板。字符串原样复制，其它值格式化后复制。内容为空时不做任何事。复制失败只在控制台留一条警告，界面不提示。
- 点击展开全部或折叠全部作用于所有节点。这两个动作只在树形模式下可用，其它模式下按钮为禁用态。
- 六个按钮都有可访问名称，与鼠标悬停提示一致。
- 键盘可以逐个聚焦到按钮并用回车或空格触发，焦点有可见的聚焦环。组件不注册任何快捷键。

## 数据

进：

- `value`：要展示的 JSON 值，必填，可以是对象、数组或字符串。
- `mode`：初始模式，默认树形。
- `readOnly`：是否只读，默认是。
- `mainMenuBar`：是否显示自定义工具栏，默认是。
- `navigationBar`、`statusBar`：是否显示编辑器自带的导航栏与状态栏，默认都不显示。
- `maxHeight`：容器最大高度，单位像素，默认 300，为 0 表示不限制。

出：

- `update:value`：内容变化时发出。文本模式下保留用户当前输入，即使此刻的 JSON 还不完整。

## 状态

- 默认：按 `mode` 呈现内容，工具栏可用。
- 只读：编辑器不接受输入，工具栏仍可切换模式与复制。
- 空数据：正常渲染空结构，复制动作不做任何事。
- 非树形模式：展开与折叠按钮为禁用态，视觉变淡且不可点击。
- 出错：组件自身没有错误态。复制失败只写控制台警告，界面不变。

## 不支持

- 不支持校验 JSON 合法性，也不对外报告校验结果。
- 不支持搜索、跳转或按路径定位。
- 不支持持久化用户选择的模式或展开状态，每次挂载都回到 `mode` 指定的初始状态。
- 不支持读取剪贴板，只写不读。

## 隐藏通道理由

`env:clipboard`：复制按钮直接调用浏览器剪贴板接口。这个动作与被展示的内容强绑定，复制的文本需要按当前值的类型决定格式；交给宿主处理会让每个使用方都重复一遍同样的格式化逻辑。写入的是用户主动请求复制的展示内容，不涉及产品数据。

## 已知偏差

无。
