# 变更记录

NeuroBook 应用（`@notnotype/neuro-book`）、Windows 桌面版与插件 SDK（`@notnotype/nb-plugin-sdk`）每个版本里用户看得到的变化。三者同一个版本号。怎么写见 [发布手册的“写变更记录”](../../docs/standards/releasing.md#写变更记录)；0.13.0 之前的版本见 Git 历史。

## [Unreleased]

### 不兼容的改动

- 插件 SDK 的组件子路径 `Button`：不写 `variant` 时从实底主按钮改成次按钮（`secondary`）。要保持主按钮的写明 `variant="primary"`；一块区域（对话框、面板头、工具条、一张卡片）里只留一个主按钮。
- 插件 SDK 的 `NestedGrid`：树里节点的收起策略（`collapse`）去掉 `restoreSize` 与 `restoreToShare`，展开总是回到节点的尺寸意图：按钮、`setCollapsed` 与分隔线上的 Enter 结果相同，Enter 不再由隔着分隔线的那块独自让位，按比例分的兄弟按份额让出与吸收。已经构建的插件照常运行，树里多写的这两项被忽略；重新编译时写着它们的树字面量会报类型错误，删掉即可。独立 `Splitter` 的面板配置照旧要 `restoreSize`，类型改名为 `SplitterCollapseState`。

### 新增

- 插件 SDK 的 `NestedGrid`：树里保留像素的节点可以标 `rigid: true`：沿排列方向钉在自己的尺寸上，拖动推过它时由更远的兄弟让位，窗口窄到放不下时它最后才让。
- 插件 SDK 的 `NestedGrid`：树里节点的收起策略可以写 `locked: true`，锁住收起状态：拖动收不了也拉不开，分隔线上的 Enter 跳过它，只有插件自己改树时能翻；手势要翻它时提交被拒，码是 `collapse-locked`。
- 插件 SDK 的组件子路径加上 `Pagination`（分页条：页数多时固定 7 格，翻页时宽度与箭头位置不变）。
- 插件 SDK 的组件子路径加上 `DataTable`（带工具条与分页的数据表格：加载、空、出错时工具条与页脚不动，表头吸顶）；`Table` 多一个 `stickyHeader` 属性，表头吸顶。
- 网页工具可以用 Tavily 搜索与读网页。设置窗口的“搜索与网页”页改成左边列表、右边详情（同“服务商与模型”页），各家带 logo：在详情里“设为使用中”（还没填密钥的那家先填密钥、填好后自动切过去）；左栏顶上的“搜索规则”设默认结果条数与屏蔽网站；各家的“高级”里能改接口地址，Tavily 还能选搜索深度。
- `web_search` 一次可以搜几条查询（最多 10 条，同时搜、按条分组交回）：查一串候选名字这类事不再一个名字一次、来回几十次。

### 改动

- 界面的颜色按 WCAG AA 调过：次要文字、状态色文字与亮色主题的强调蓝都深了一点，对它们所在的底至少 4.5:1；没有边框的按钮与行聚焦时，焦点环的实线加粗到 2 像素，看得清。
- 系统设了“减少动态效果”时，界面不再全部硬切：滑动、缩放、从按钮处长出来都取消，出现与消失、换内容改成淡入淡出。
- 数据表格的加载遮罩一旦出现，至少停 0.4 秒再消失，几百毫秒的请求不再闪一下；停留期间新的一页已经能点。
- 插件与用户自己写的 Profile 要有 Agent 模式（普通、讨论、计划），在 Profile 声明里写 `referencedExtensions: ["nbook.agent.modes"]`；模式控件跟着它显示，与工具里有没有 `switch_mode` 无关（`switch_mode` 只决定 Agent 能不能主动申请切换）。原来只列了 `switch_mode` 的 Profile 不再显示模式控件，切换时也不再报“发送失败(unknown-extension)”。
- `web_search` 没给条数时每条查询回 5 条（原先一条查询 8 条），在“搜索规则”里改。
- 网页工具的插件 id 改为 `nbook.web`（0.15.0 到 0.17.0 里是 `nbook.web-tools`），工具 id 随之改为 `nbook.web.search`、`nbook.web.fetch`，旧 id 不再认。写着旧 id 的设置不再生效：权限规则里按 `nbook.web-tools.fetch` 拒绝或询问的主机会照常放行，Profile 工具绑定里去掉的这两个工具会回来，自己写的 Profile 把旧 id 列为必需工具时用它的会话发一次就报缺工具、之后只读（改 Profile 后重开恢复），改过的 DeepSeek 地址回到缺省。权限规则请改用给模型的名字 `web_fetch`、`web_search` 来写（以后改 id 也不受影响）；`web_search` 的参数 `query` 换成了 `queries`，按参数 `query` 写的规则要改。已填的密钥照常可用。

## [0.17.0] - 2026-11-24

### 新增

- 后台任务视图按归属分组：会话的任务排在各自的会话下（等你处理时浅色提示，组头带“打开”与“停止”），项目与应用的任务在各自的小标题下；分组可以收起，状态栏的数是各范围合起来的后台工作。子代理完成后，它的卡片写那次运行最后一条回复的首句。
- 世界的条目页：编辑主文字时右侧（窄处在输入框下面）多一个预览栏，停顿后按条目的渲染规则显示，写得不对时栏顶写出行与原因、留着上一次的样子；状态行的“预览”开关记在标签上。条目文字有自己的着色：花括号里的字段、标签与 Markdown 的记号各一种颜色。

### 改动

- 世界的条目页：主文字改成整篇编辑，一个代码输入框加“插入”；提交前核对别处有没有改过同一篇，改过时问一次，不再把别处加的块悄悄带进提交。
- 代码输入框打字时不自己弹补全（回车总是换行）：按词的建议会在写正文时弹出文档里别处的词。
- 语法着色里的关键字改成紫色（之前在亮色配色上几乎看不出颜色），标记语言的标题行加粗。

### 修复

- 模型请求的缓存键按会话固定：之前每次请求都生成新的 `prompt_cache_key`，服务端按它分片缓存的服务商（例如 Ollama Cloud）几乎每轮都不命中缓存，多轮对话的提示全部按未缓存计费、变慢。现在同一个会话里（含压缩）键不变。

## [0.16.0] - 2026-11-23

### 新增

- 插件 SDK：`NestedGrid` 的内容项多了 `leave`：标 `"retain"` 的内容被宿主去掉、它的叶又在缩回去时，库用它最后一次的渲染留到过渡结束才卸载，带 `data-content-leaving`。不给时与原来相同（当即卸载）。
- 插件 SDK：`NestedGrid` 多了 `paneLabel`，分隔线读屏时念出面板的名字，不再念节点 id；独立 `Splitter` 的面板配置多了 `label`，同样用于读屏名称。不给时与原来相同。
- 服务商都从模板添加：“添加服务商”按国际、国内、聚合与网关、其他、自定义分组多列排开，带图标、模型数与地区，可以搜索；同一个模板可以添加多份（名称自动区分）。中转站与本机端点用“OpenAI 兼容”“Anthropic 兼容”“Gemini 兼容”三个空白模板，第二步填名称、地址与接口格式；有地区的服务商（Moonshot、MiniMax）第二步选地区。
- 添加模板服务商就带上它的全部对话模型（OpenRouter 也是），以后打包目录里新出的模型自动出现；不想要的在“管理模型”里移出，移出的可以再加回来。“服务商新出的模型自动加入”可以关掉，关掉后列表保持当时的样子。
- 服务商详情的标题区：点图标换图标（内置的、上传一张图片、首字母块，可恢复模板的图标），点名称就地改名，“复制一份”连密钥一起复制。模型选择器、服务商列表与“全部模型”都显示各家自己的图标。
- 每家服务商都能改接口格式（多了 Google Gemini）与地址；改了以后按通用协议发送，页面上写明，选回模板的就恢复。
- 模型清单跟着服务商自己的模型列表走：设好密钥就去取一次，之后每天在后台更新；账号用不了的模型不再出现，服务商新上的模型自动出现。中转站与本机端点（空白模板）也一样，取到的模型缺上下文窗口时列出来、补上才能启用；服务商没说明类型的模型在“管理模型”里单独一组，确认是对话模型再加入。模型区写着列表是什么时候取到的、取失败的原因，可以“重新拉取”。
- 不升级也能用上新模型：OMP 的在线模型目录每天更新一次，补上打包目录里还没有的模型。设置里的“网络”页有“自动更新模型列表”，关掉后只在点“重新拉取”或“现在更新”时联网。
- 模型区有搜索，模型多时系列默认收起；编辑模板里的模型时显示目录的值，改过的标“已改”、可以恢复。“全部模型”按服务商分节，可以搜索。
- 接口格式旁边有“检测协议”：在同一个地址上把四种接口格式各试一次（每种一次请求），逐行写通过与否、耗时和服务商的原话，点“用这个”才改。不知道中转站说哪种协议时用它。
- 代理：设置里的“网络”页可以选跟随系统（读 `HTTPS_PROXY` 这类环境变量，再读 GNOME、KDE、macOS、Windows 的系统代理）、自定义 HTTP 代理地址或直连；“测试代理”经现在的设置请求一次，写出口 IP 与耗时；同一页有“自动更新模型列表”与在线模型目录的“现在更新”。每家服务商还可以在“高级”里单独设代理。对话、拉取模型列表、检测、在线目录与网页工具的请求都按它走；SOCKS 与自动配置脚本不支持，会提示原因、不发请求。

### 改动

- 插件 SDK：布局组件（`NestedGrid`、`Splitter`、`SortableList`、拖放反馈与浮动窗把手）与它们的类型在 nb-layout 里标 `@experimental`，编辑器悬停看得到：它们在 nb-layout 1.0 之前会变，变了照样按插件 API 的兼容起点处理，用到它们的插件预期比只用 nb-ui 组件的更常需要重新构建。
- 模型请求发出前核对完整的请求地址：环境变量（例如 `MOONSHOT_BASE_URL`）把地址改到别处时不再发出（错误码 `endpoint-mismatch`）；服务商回重定向时请求失败，不跟随，要把地址改成最终地址。
- 删了服务商再用同名、同址重建，同一地址换了密钥或认证头，或者同一服务商换了模型之后，旧对话里的思考签名不再原样送回（之前可能被服务商拒绝或串号）。
- “检测全部”改为逐个检测、同时 4 个，旁边写已检几个；要检的超过 20 个时先确认（每个模型都是一次真实请求，会计费）。取消时已经发出的标“结果未知”，没轮到的不再发。
- “管理模型”不再单独拉取 `/models`：空白模板的服务商和模板服务商一样，列的是服务商列表里的模型；“重新拉取”挪到了模型区。
- 设置文件里服务商这一项手改坏了（不合格式）时，界面里的改动会被拒绝并提示先修设置文件，不再把它当成空的整份盖掉。
- 服务商自己的模型列表里没有、但你启用过或绑在角色上的模型照常可用，行上标“列表里没有”（之前会标成“服务商已不再提供”，角色用不了）。

### 数据与升级

- 应用要求 Bun 1.4.4 或更新的版本，旧版本启动时会被拒绝。代理缺省“跟随系统”：设了 `HTTPS_PROXY` 这类环境代理或系统代理的，模型与网页工具的请求会走它。
- “自动更新模型列表”的设置键从 `nbook.models/catalogAutoUpdate` 换成 `nbook.network/catalogAutoUpdate`；在开发版里改过它的，回到缺省（开）。
- 服务商设置换成新的形状：旧设置照常读进来、行为不变，第一次改服务商设置时整份写成新形状。目录服务商的模型条目上写着、旧版本本来就不认的字段（上下文窗口、能看图等）这时丢掉。写入之后再装回旧版本，旧版本会把整个服务商设置当成无效丢弃（服务商列表变空，密钥仍在凭据库里）；不做保护。
- 升级后第一次启动会给每家有密钥的服务商取一次模型列表；列表里没有、但以前加过的模型标“服务商已不再提供”，可以移除。取到的列表存在状态根的 `agent/model-sources/`，在线目录的副本是 `agent/model-catalog.json`，删掉只是下次重新取。离线环境可以把启动环境变量 `NBOOK_MODELS_CATALOG_URL` 设成空串，不取在线目录。
- 以前加过的 Bedrock、Cursor、Codex 这类不经 HTTP 请求的模型保留在列表里，标“不能当对话模型用”，不能发送。设了 `PI_OPENROUTER_RESPONSES=0` 的 OpenRouter 照旧走 Chat Completions。

## [0.15.0] - 2026-11-20

### 不兼容的改动

- 插件 SDK 的 `NestedGrid`：`onGestureCommit` 拒绝一次调整时返回 `{ok: false, code, message, params?}`，原来的 `reason` 去掉了。`code` 给程序判断（网格没就绪是 `not-ready`，工作面、版本、容器尺寸过期是 `stale-context`、`stale-revision`、`stale-size`，落账时结构操作拒绝就是它的码），`message` 是英文、只给日志看；插件自己拒绝时可以用自己的码。按旧写法返回 `{ok: false, reason}` 的插件要改成新形状、重新构建：重新编译时类型检查会报错，没重新构建的插件被拒时诊断里的原因是 `undefined`。

- 插件 SDK 的 `NestedGrid`：`issues` 事件的元素从中文句子改成 `{code, message, params?}`，`gesture-update` 载荷的 `issues` 与 `layout.issues` 也是。`code` 给程序判断（例如 `over-constrained` 加 `params.cause` 说清是最小值合计超出、固定尺寸装不下还是交叉轴不够，`params.id` 是出问题的分支或面板），`message` 是英文、只给日志看；带 `ok` 的元素是被拒的提交。`issues` 事件改成只发新出现的：一场拖动里同一个诊断只发一次，要知道现在有哪些问题读 `gesture-update` 载荷的 `issues`。按字符串读诊断的插件不会报错，只是读到错的值（`join` 得到 `[object Object]`、`includes` 永远是假），要改成读 `code`；重新编译时类型检查会报错。

- 插件 SDK 的布局组件（`NestedGrid`、`Splitter`、`SortableList`、落点组件、浮动窗把手）读的 CSS 变量改成 `--nb-layout-*`。主题照旧生效（nb-ui 在根元素上把主题的名字接过去），换主题、换配色不受影响。受影响的是在自己的样式里改布局组件外观的插件：设旧名旋钮的（`--layout-sector-radius`、`--sortable-first-line`、`--sortable-held-shadow`、`--nb-splitter-seam`、`--nb-splitter-seam-inset`），或在自己的容器上设主题变量的（`--layout-card-radius`、`--sash-line-*` 这类，主题的名字只在根元素上传得过去），这些覆盖不再生效、外观回到缺省，要改设新名，例如 `--nb-layout-sector-radius`、`--nb-layout-card-radius`。落点组件的样式类 `nb-ui-drop-indicator*`、`nb-ui-drop-feedback*` 改名为 `nb-layout-drop-*`。已经构建的插件照常运行，只是这些覆盖不起作用。

### 新增

- 插件 SDK 导出 `GridIssue`、`GridIssueCode`、`GridHostIssueCode`，给 `@issues` 与 `gesture-update` 写类型用。
- 插件 SDK 导出 `GridGestureStart`、`GridGestureCancellation`（`NestedGrid` 的 `gesture-start`、`gesture-cancel` 的载荷）与 `SashGestureSource`、`SashGestureCancelReason`（手势来源与取消原因，`NestedGrid` 与 `Splitter` 共用）。
- 插件 SDK 的组件子路径加上 `ImagePreviewDialog`（看大图的对话框，能复制写法、下载原图）与 `SidePanel`（贴在右边、不挡住页面的面板）。
- 插件 SDK 导出 `GridLayoutCommitResult`、`GridFailure`、`GridCommitFailureCode`、`GridParamValue` 几个类型，给 `onGestureCommit` 写类型用。
- 应用自带两套星璃表情包：“星璃”（15 个）与“星璃 · 半身”（12 个），只读，在表情包页里可以“复制到我的”再改；内置的主创默认能用“星璃”，在对话里发 `:lyra/开心:` 这样的表情。我的表情包与内置的同名时，按包名写的表情显示我的那一份，内置的那份要写 `:builtin.lyra/…:`。
- 点表情看大图：对话里的回复与自己发的消息、Markdown 编辑器里单击表情，表情选择器底部点“查看大图”，打开和原图预览一样的对话框，能复制写法、下载原图，小图放大到 320 像素。
- 表情包可以设成“按贴纸显示”（表情包页的属性栏里，内置与插件的包也能设）：这个包的表情夹在文字里也显示成大图，切换立刻生效，各个窗口与客户端里都一样。
- Agent 能搜网页、读网页：新的内置工具 `web_search`、`web_fetch` 经 DeepSeek 的搜索与读取接口工作，Agent 缺省就能用（不想要时在 Profile 的工具里去掉，或用权限规则按网站拒绝）。密钥在设置窗口 AI 分组新的“搜索与网页”页填写，与模型设置里的 DeepSeek 密钥分开存放；页上可以检测密钥，每次检测按一次搜索计费。
- 模型角色可以设默认思考档（设置里“模型角色”页新增一列）：选“跟随模型”或模型能提供的档位；对话里没明确选档时用主力等角色设的档，选了就以对话里选的为准。角色也有了图标，自建的角色可以挑。
- 对话输入框的模型选择器重做：角色两列单行（宽度不够时单列）带角色与服务商图标；模型库按服务商分组，超过 30 个的组默认收起（当前模型所在的组只展开它附近几行）；思考档不再因为模型没写档位而藏起来——不支持思考的写原因，能调的用分段按钮，跟随角色默认时只画细框并写“跟随主力的默认”，选了就是你明确选的；只能降到最低档的模型不再叫“关闭”。

### 改动

- 插件 SDK 的 `SplitterGestureSource`、`SplitterGestureCancelReason` 改名为 `SashGestureSource`、`SashGestureCancelReason`，旧名留作弃用别名（编辑器里划线），以后的版本会去掉；已经构建的插件不受影响，重新编译也照常通过。
- 带阴影的卡片、气泡与浮层（浅色主题）的投影改轻，与菜单一档。

### 数据与升级

- 模型角色设置多了可选的思考档与图标（`effort`、`icon`）。写入之后再装回这一版之前的版本，旧版本会把整个“模型角色”设置当成无效丢弃，主力等绑定会显示成没设置；没改过角色的思考档与图标就不受影响，不需要迁移。

## [0.14.0] - 2026-11-18

### 新增

- Markdown 编辑器的属性面板：文件开头的 frontmatter 显示在正文上方，按属性看与改（文字、数字、勾选、日期、列表），能添加、改名、移除、改类型，也能就地改 YAML 源码；改一个属性只改文件里的那一行，注释与别的写法不变。没有 frontmatter 时在第一段开头打 `---`，或用“添加属性”（命令面板、斜杠菜单、工具栏的“⋯”）新建。面板缺省收起成一行摘要，展开过的文件下次打开仍展开。

- Markdown 编辑器能插入链接与图片：选中文字按 Ctrl+K（⌘K）或点工具栏、选区菜单的链接按钮，填一个地址就加上链接（作品里的文件写成相对当前文件的地址），光标在链接里时改整条的地址或去掉链接；按住 Ctrl（⌘）点链接才打开，单击选中整条链接。图片：工具栏的图片按钮与斜杠菜单里的“图片”打开插图卡片，列出存放目录里的图、按名字找整部作品里的图、粘贴网址，也能上传本机的图；直接在正文里粘贴截图或复制来的图，会存进作品并插入。图片存放位置在设置的“编辑器”里选：作品根下的指定目录（缺省 `插图/`）、作品根、与当前文件同目录、当前文件旁的子目录；重名的图不会覆盖，加序号。
- 插件可以按属性名给 Markdown 的 frontmatter 属性指定图标、显示名和类型：新贡献点 `markdown.properties`，声明 `{name, icon?, label?, kind?}` 写在插件描述的顶层 `contributions` 里。属性面板里这一行的类型图标换成声明的图标（点它仍是改类型的菜单），名字一列、摘要与各输入的名称显示声明的显示名（悬停与改名时是文件里的真名，显示名跟着界面语言变），值为空的行按声明的类型输入（日期、数字、勾选、列表）；有值的行仍按值判断，文件不会被改写。同名属性有多个声明时 id 最小的一条生效、其余记诊断 `markdown.properties.conflict`，不合格的声明被贡献点拒绝。
- 往作品里写图片的上传接口：`PUT /api/nbook.files/raw/project/<项目 id>/<代次>/<路径…>`，只收 PNG、JPEG、GIF、WebP（按文件头判定），上限 32 MiB，只新建不覆盖，可选重名加序号；文件服务的 `find` 加了按扩展名过滤。
- 桌面版首次启动向导：第一次打开桌面版时分四步选主题、明暗与界面语言，定桌面快捷方式、登录时打开、关窗后留在托盘，最后看设置与作品放在哪里；命令面板里的“打开桌面版欢迎向导”随时再打开。
- 桌面版的设置“在桌面放快捷方式”：关掉后删掉桌面上的 NeuroBook 快捷方式（更新后又出现的也会删），开始菜单里的不受影响。
- 桌面版自己画的标题栏：窗口按钮与工作台标题栏合成一条，可以拖动、双击最大化、贴边；新的应用图标；窗口最小 800×560，标题栏左上角的标志回到书架。
- 桌面版的“桌面窗口”设置：界面缩放（Ctrl 加减号、Ctrl+0）、登录 Windows 时打开、关掉最后一个窗口时留在系统托盘（托盘菜单里打开或退出）、实验性的磨砂窗口背景（Windows 11 22H2 以上）。
- 把插件的构建目录拖到插件页（或点“选择文件夹”）就能安装：先上传、预览，确认后安装。

### 改动

- 桌面版里界面框架（标题栏、标签、导航、按钮、菜单）的文字不再能被选中，正文、对话、路径、错误说明照常能选中复制。
- 桌面版的书架顶端改成欢迎页的样子，窗口缺省 1600×1000；改窗口大小时页面不再卡顿。
- 插件兼容按插件 API 的兼容起点判断：NeuroBook 提版而插件 API 没有不兼容的改动时，按旧版本构建的插件照样能装、能加载。这一版接受按 0.12.1 起的版本写的插件（例如要求 `^0.12.1` 的）。

## [0.13.0] - 2026-11-15

### 新增

- 第一个 Windows 桌面版：安装版装到当前用户下、不需要管理员权限；便携版解压即用，数据放在解压目录下。自带运行环境，不用另装 Bun；与命令行 `nbook` 共用同一个数据目录。
- 桌面版自动更新：有新版本时提示，同意后在后台下载，下次打开时换上；只升不降。便携版只提示并打开下载页。
- 关闭窗口前询问：有没保存的改动、Agent 或后台任务还在运行时先问，可以全部保存、不保存或取消。
- 后台任务：任务视图、状态栏上的进度与结束通知；通知中心与状态栏的铃铛。
- Skill：设置里的 Skill 页、Profile 页的 Skill 一节；输入框里用 `$` 选 Skill，还没初始化的在后台初始化，失败时能看输出、重试。
- 批注：给选中的文字加批注，页边卡片按段排列；按住 Ctrl 悬停或点批注末尾的小符号打开。
- 工作台：视图可以拖进别的容器、在活动栏上新建容器或换序；“移动到”菜单与命令面板用同一份目标。
