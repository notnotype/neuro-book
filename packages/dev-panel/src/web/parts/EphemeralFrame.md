# EphemeralFrame

装临时数据（会话、租约、谁在动、运行）的虚线框，角上一个“临时”小标。持久的数据画实线的面，临时的一律用它，开发者一眼分得清哪些会随会话结束而消失（t03 第三轮已定的画法）。读屏上是一个带名字的 `group`（“谁在动（临时）”），不是地标：首页每张卡片都有一个，做成地标会在地标列表里出现一串同名的（t22）。标签用 `--text-xs`，颜色是状态色往正文色混三成，对比度到 4.5 以上。标签的底色取所在的面：在 `.nbdev-surface` 里是卡片的底色（`--nbdev-surface-bg`），否则是页面底色；宿主没有内容要放时不画这个框（t22）。

## 数据

```ts
interface EphemeralFrameProps {
    /** 框的标题（例如“谁在动”）；必填 */
    title: string;
}
interface EphemeralFrameSlots {
    /** 框里的内容；必填 */
    default: () => any;
}
```

没有事件与 expose；attrs 落到根节点。框不给面色（不叠层级），只有信息色的虚线边。
