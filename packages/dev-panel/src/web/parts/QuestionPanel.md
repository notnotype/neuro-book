# QuestionPanel

产物页侧栏里只读的题（t03 第二轮产物页起，t15 阶段 4 第 1 批按“待答、已答、之前几版的题、已取代与撤回”重新分组）。分组用 `host/answers.ts` 的 `groupQuestions`，与答复表单同一份：

- **待答**：这一版里能答、还没答的题（含旧答复作废要重答的，题下写明原因），必答在前；标题写“待答 N”，有必答题时另数“必答 M”；逐题列出类型、选项（推荐的标出来）、是否必答，这一版新加的标“新”；
- **已答**：这一版里能答、已经答了的题，写答案、针对哪一版、什么时候答的与说明；默认折叠；
- **之前几版的题**：来自页面、已经答过、后来的页面里没有了（`origin` 为 `markup`、`page` 为 `null`）。它们留在题表里只为答案查得到，服务端不再收答复（`question_earlier`）；默认折叠，只读；
- **已取代与撤回**：默认折叠，写明在哪一版、被什么取代。

有答复表单时（`answering`），待答与已答由 `AnswerForm` 显示，这里只列后两组，放在表单的 `readonly` 插槽里。它只显示，不答题。

## 数据

```ts
interface QuestionPanelProps {
    /** 当前显示的那一版的题与状态（`/api/artifact` 的 `questions`）；必填 */
    questions: QuestionState[];
    /** 显示的是第几版；必填 */
    version: number;
    /** 最新一版；必填。不是最新时顶上写“看的是 vN 的题表”；标“新”也按它 */
    latestVersion: number;
    /** 有答复表单：只列“之前几版的题”与“已取代与撤回”，也不写版本提示（表单里有）；默认 false */
    answering?: boolean;
}
```

没有事件、插槽与 expose。`state:local` 是“已答”“之前几版的题”“已取代与撤回”三组的展开状态，组件销毁即丢。

## 布局

纵向一列，宽度随父容器；题多时由父容器滚动（本组件不另开滚动）。390 宽时它在 iframe 下面，占满一列。
