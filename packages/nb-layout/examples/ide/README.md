# 示例：IDE 式的工具窗

用 `@notnotype/nb-layout` 搭一个 IDE 的外框：左、右、下三个可以收起的工具窗区，各有一条按钮条；点按钮开关工具窗，按钮可以在条与条之间拖动；中间是编辑区，可以最大化；布局存在浏览器里，重新打开还在。

库不带按钮条、工具窗与“区里显示哪一个”这套规则：它管的是一棵布局树、按约束算尺寸、拖分隔线、收起与展开，以及拖动会话与落点几何。哪个按钮属于哪一条、点一下发生什么、哪些分隔线不让拖，都是这个示例自己写的，这正是它要演示的。

## 跑起来

```sh
npm install
npm run dev
```

这个目录可以单独拷走：它只依赖 `@notnotype/nb-layout` 与 `vue`，只经包的公开入口导入。它跟着仓库 master 上的 nb-layout，可能用到 npm 上还没发布的名字；照已发布的版本抄时，看仓库里那个版本的标签下的这个目录。

## 界面与快捷键

- 点按钮条上的按钮：区收着时展开并显示它；区显示别的工具窗时换成它；已经显示它时收起。
- 把按钮拖到别的条（或同一条的别的位置）：落点处出现插入线，松手后挪过去；工具窗里打的字跟着走。
- 工具窗标题条上的减号收起区并把焦点交给编辑区；编辑区标题条上的按钮最大化与恢复。
- Alt+Shift+1 到 6 开关六个工具窗，Alt+Shift+M 最大化编辑区，焦点在工具窗里时 Escape 回到编辑区。

## 读的顺序

1. `src/model.ts`：模型。一棵网格加三条按钮条上的次序与每个区显示哪一个；点按钮的三种结果、跨条移动、最大化、被分隔线展开后的补全；存档与读档。
2. `src/drop.ts`：落点规则。哪里算落点，原位不算；落点的完整动作。
3. `src/App.vue`：把模型接到 `NestedGrid`（`useGridHost`）、工具窗正文放在内容层、一场拖动会话（`useDragSession`）、落点反馈（`DropFeedbackOverlay`）、快捷键与焦点。
4. `src/ToolStripe.vue`、`src/ToolPanel.vue`：按钮条与工具窗正文。

## 绕过的库的空缺与已知限制

- 区被分隔线拖开时，里面显示什么库不管：示例在 `onApplied` 里补（`reconcile`），区展开而没有显示的工具窗时显示这条上的第一个。
- 库在展开时回到节点的尺寸意图，不看策略里的 `restoreSize`：读档时先用 `setSize` 放回尺寸，再 `setCollapsed`，收起着的区存的是收起前的尺寸。
- 条旁的分隔线和没有按钮的区的分隔线用 `sashDisabled` 禁掉，条本身不设尺寸上限与下限。
- 下条放在主区的外面：放进中列时，最大化编辑区的外接矩形会把它盖住。
- 最大化只在内存，不进存档。
- 拖动只能用指针：拖动会话支持键盘拖动，示例没接。按钮本身能用键盘点开关。
- 窗口缩小到放不下时照库的行为压缩。
