# DiffView

比较两段文字并显示改动：先按行比，改了的一对行再按字比，中文一段就是一行，只标整行看不出改了哪儿。用于审批写入前看改动，以后也用于收件箱。不做语法高亮，正文字体。算差异的函数在 `@notnotype/nb-ui/diff`，别的包要同一份结果时用它。

开发者面板的同名零件是另一件事：它显示 `git diff` 已经算好的统一差异文本，输入不同，不共用。

## 布局与交互

- **标题行**：标题（可选）、`+新增行数 −删除行数`、显示方式切换。贴着外面的滚动容器吸顶；组件自己不滚动、不限高，高度由放它的地方管。
- **行内**：一列，一对改动上下叠放。**两栏**：一行一对，左边改前、右边改后，少的一侧留空。
- **能不能两栏看自身宽度**：不到 700px 时切换隐藏，`mode` 选了两栏也按行内显示。同一个组件可能在右栏，也可能在编辑区，看视口判断不了。
- 新增与删除除了颜色还有 `+`、`−` 前缀和 `<ins>`、`<del>`，不只靠颜色区分。整行增删靠底色；一对改动行才标到字，删除的字带删除线。
- **折叠**：没变的连续行收起成“展开 N 行没变的内容”（改动上下各留 `foldContext` 行，只收一行时不收）。一行之内离任何标记超过 40 字的没变文字收成“…（812 字）…”，点开展开这一行。内容变了展开状态清掉。
- 窄屏同一结构，文字折行。

## 数据

```ts
type DiffViewProps = {
    /** 改前、改后的全文，必填。 */
    before: string;
    after: string;
    /** 标题行，例如文件路径；默认空串不显示。 */
    label?: string;
    /** 改动上下各留几行没变的内容；默认 2。 */
    foldContext?: number;
    /** `v-model:mode`，默认 "inline"。 */
    mode?: "inline" | "split";
};
```

插槽 `actions`：每块改动末尾的动作，参数 `{hunk, beforeText, afterText}`，分别是这块的行范围（从 0 数、右开）与改前改后的全文。没给时不占位置。

没有 expose。未声明的 attribute、`class` 与 `style` 落到根节点。

## 状态与边界

- **很大的改动只标到行**：一对行两侧长度和超过 2000 字、编辑距离超过较短一侧的 20%、或累计按字比超过 150 毫秒之后，这一对行整行标记。这是因为按字比在主线程上算，两段各 3000 字完全不同时要 7.5 秒。
- 行数很多又几乎全不一样时，按行比超过 300 毫秒就当作整段替换。
- 只差文件末尾有没有换行时不算改动。
- 一处改动都没有时不收起，标题行写“没有改动”。
- 中文按码位数字数，不把一个字劈成两半。

## 隐藏通道理由

`state:inject`（翻译端口）：读宿主注入的翻译端口（`useUiText()`）取切换与折叠的文案，同 `CodeBlock`。这些文字每个调用方都一样，逐处传属性不现实。
