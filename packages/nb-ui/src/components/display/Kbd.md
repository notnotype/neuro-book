# Kbd

`Kbd` 用语义化的 `<kbd>` 元素呈现一个或多个按键标记，适合在快捷键提示或操作说明中与正文并排使用。按键字符由插槽提供，组件不解析或执行快捷键。

## 布局与交互

内容保持单行，以等宽字体居中显示，具有控件描边、浅色表面和凸起阴影。尺寸可选 `sm`、`md`、`lg`，分别增加高度、最小宽度、内边距与字号；宽度可随按键文本增长。组件是展示内容，不接收焦点也不响应键盘输入。

## 数据

```ts
type KbdSize = "sm" | "md" | "lg";

type KbdProps = {
    /** 键帽尺寸；默认 "md"。 */
    size?: KbdSize;
};

type KbdEmits = Record<never, never>;

type KbdSlots = {
    /** 按键文字或符号；可省略。 */
    default?(): unknown;
};
```

无 expose API。未声明 attrs、`class` 与 `style` 按 Vue 默认行为透传至根 `<kbd>`。组件没有隐藏通道。

## 状态与边界

组件没有受控值、禁用、只读、加载、错误或空数据状态。空插槽会呈现空键帽；复合按键的分隔符和平台差异由调用方提供。

## 不支持

- 不负责快捷键注册、键盘事件监听、按键名称本地化或平台检测。
