# Separator

一条 1px 的分割线，横放或竖放，颜色取主题的 `--divider`。它是这条线在组件库里的唯一写法：需要在一处布局里分隔两块内容时用它，而不是就地写一条 `border` —— 换主题时线的颜色、以及「它是不是装饰」这件事都有统一的地方可改。

组件没有状态，也不渲染任何子内容。

## 数据

```ts
type SeparatorProps = {
    /**
     * 方向；默认 "horizontal"。
     * horizontal 画一条 1px 高的横线并横向铺满；vertical 画一条 1px 宽的竖线并纵向铺满。
     */
    orientation?: "horizontal" | "vertical";
    /**
     * 是否只是装饰；默认 true。
     * true 时对辅助技术隐藏（这条线不表达结构）；false 时向辅助技术暴露这是一条分隔。
     */
    decorative?: boolean;
};
```

没有 emits，没有 slots，没有 expose。未声明的 attribute 以及 `class` / `style` 落在唯一根节点上（Upstream 的分隔元素），与它自带的类合并；因此想改间距或颜色时可以用 `class` 覆盖，但正常用法不需要。

## 布局

横线是 `h-[1px] w-full`，宽度随父容器伸缩；竖线是 `h-full w-[1px]`，要求父容器有确定的高度，否则它塌成 1px。它是 `shrink-0` 的，父级是 flex 时不会被压缩。

横向的分隔线之间不产生外边距：间距由使用它的容器负责，组件不代替父级决定留白。

## 不支持

- 不支持虚线、渐变色或粗细可调；只有 1px 实线。
- 不支持在线上放内容（没有默认插槽）。带文字的分节标题不属于本组件。

## 上游边界

分隔元素与它的方向/装饰语义由底层的 Reka UI Separator 提供，本组件固定了尺寸（1px）与颜色（`--divider`）。可访问语义的具体属性以底层为准，不在本组件的合同内。
