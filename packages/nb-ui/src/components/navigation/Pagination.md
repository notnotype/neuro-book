# Pagination

分页条：一行“上一页、页码格、下一页”，当前页由使用方用 `v-model` 给，点页码或箭头时发出新页码。和自己拼一串页码按钮的差别是格数固定：页数多于 7 时总是 7 格（首页、末页、当前页与两侧、省略号），翻页时整条的宽度与两个箭头的位置不变，鼠标停在箭头上连点不会点空。

组件是受控的，不自带页码状态：页码进不进地址栏、什么时候取数，都由使用方决定。

## 数据

```ts
type PaginationProps = {
    /** 当前页，从 1 起；用 v-model 绑定。不在 [1, pageCount] 里时按夹到边界的值显示 */
    modelValue: number;
    /** 总页数；小于 1 时按 1。使用方按 ceil(total / pageSize) 算，没有数据时给 1 */
    pageCount: number;
    /** 整条不可用（例如还不知道总数）；默认 false */
    disabled?: boolean;
    /** 上一页按钮的读屏名字与悬停提示；缺省经翻译端口取（中文“上一页”） */
    prevLabel?: string;
    /** 下一页按钮的读屏名字与悬停提示；缺省经翻译端口取（中文“下一页”） */
    nextLabel?: string;
    /** 整条导航的读屏名字；同一页有多条分页时各给一个；缺省经翻译端口取（中文“分页”） */
    navLabel?: string;
};

type PaginationEmits = {
    /** 点了与当前不同的页码，或点了可用的箭头；参数是新页码，总在 [1, pageCount] 里 */
    "update:modelValue": [page: number];
};
```

没有插槽，没有 expose。未声明的 attribute 与 `class`、`style` 落在唯一根节点 `nav` 上。

## 布局

一行不换行的 `flex`：上一页箭头、页码格、下一页箭头，彼此留一个最小间距单位。

- **格子**：页数不超过 7 时列出全部页码。多于 7 时总是 7 格，按当前页 `p`、末页 `n` 排：`p` 不超过 4 时是 `1 2 3 4 5 … n`；`p` 不小于 `n - 3` 时是 `1 … n-4 n-3 n-2 n-1 n`；其余是 `1 … p-1 p p+1 … n`。
- **宽度**：每格至少 32px、高与小号图标按钮相同，数字用等宽数字（`tabular-nums`）。三位数以内的页码都放得进最小宽度，所以页数多于 7 时翻页不改变整条宽度与两个箭头的位置。页码到四位数时格子按内容变宽，翻到位数不同的页时整条会变宽一点。
- **当前页**：浅灰底、正文字色、加粗；其余页码是次要文字色。页码的悬停底色与按下底色、按下时的轻微缩小，都与同一条里的两个箭头（`IconButton` 的缺省档）相同，鼠标从箭头移到页码时深浅一致。底色、字色与缩放的变化用短时长过渡，减弱动效时没有过渡。
- **390 宽**：两个箭头加 7 格不到 320px，放得下；组件不缩格子，放不下时由使用方安排它的位置。

## 交互

- 点页码：与当前页不同时发出那一页；点当前页不发。
- 点箭头：在第 1 页时上一页不可用，在末页时下一页不可用；可用时发出当前页减一或加一。
- 键盘：页码与箭头都是原生按钮，Tab 依次可达，Enter、Space 触发；当前页带 `aria-current="page"`，仍可聚焦；省略号对读屏隐藏、不可聚焦。页码按钮的读屏名字是“第 N 页”。组件不注册方向键之类的快捷键。
- 焦点：翻页后格子会重排，刚点的那个按钮可能变成省略号或换了数字；箭头点到端点时自己会变成不可用。当前页、总页数或 `disabled` 变了以后，如果焦点原先在分页条里、现在没地方落（落到了条外，或落在变成不可用的按钮上），就把焦点移到当前页按钮上，不让焦点掉回 `body`：例如焦点在“下一页”上连按 Enter 到末页，焦点落到末页的格子上。焦点原本不在分页条里时不动焦点。整条变成不可用时当前页也不可用，没有能落的格子，组件不挪焦点，焦点交给使用方安排（例如移到它自己的某个容器上）。

## 状态与边界

- `disabled`：所有页码与箭头都不可用（原生 `disabled`），不发事件；焦点见“交互”。
- 越界的 `modelValue`（例如数据变少、页数跟着变少）：按夹到 `[1, pageCount]` 的值显示，箭头随之不可用；组件不自动发事件改值，改不改由使用方定。
- `pageCount` 为 1：只有一格“1”，两个箭头都不可用。

## 不支持

- 不支持跳到指定页的输入框、每页条数的选择、首页与末页的单独按钮。
- 不支持自定义格数或省略号的画法。
- 不认识路由，也不改地址栏。

## 隐藏通道理由

`state:inject`（翻译端口）：读宿主注入的翻译端口（`useUiText()`，`TEXT_PORT_KEY`）取两个箭头与整条导航的读屏名字、页码按钮的“第 N 页”，语言跟着端口走，换语言不重新挂载；没有宿主注入时用 nb-ui 的缺省端口（`zh-CN`，自带目录 `@notnotype/nb-ui/locales`）。调用方显式传 `prevLabel`、`nextLabel`、`navLabel` 时以属性为准；页码按钮的名字没有对应属性，固定走端口。这类读屏名字每个调用方都要有，逐处传属性不现实，所以由组件自己经端口取。
