# NavigationMenu

顶部导航菜单：一排一级入口，其中带多个链接的入口展开成一个面板（占整条宽度的目录式浮层），切换入口时面板在同一个视口里换内容并带尺寸过渡。与 `Dropdown` 的区别是它不是「一个按钮 + 一个列表」，而是共享一块视口的一排入口；与直接写一排链接的区别是展开、悬停意图、键盘导航与视口动画都不用自己实现。

它是纯展示组件：入口与链接由数据给出，点击某条链接后组件只发事件，是否跳转由浏览器照常处理。

## 数据

```ts
interface NavigationMenuLinkItem {
    title: string;
    /** 补充说明，渲染在标题下方 */
    description?: string;
    /** 链接目标；不传时退化为 "#" */
    href?: string;
    /** 图标类名（如 i-lucide-*）；不传就没有图标 */
    iconClass?: string;
}

interface NavigationMenuItemData {
    /** 入口身份；受控值用的就是它 */
    id: string;
    /** 入口文字 */
    label: string;
    /** 有非空的 links 时该入口变成可展开的触发器，面板里按两列排这些链接 */
    links?: NavigationMenuLinkItem[];
    /** 没有 links 时的链接目标；不传时退化为 "#" */
    href?: string;
}

type NavigationMenuProps = {
    /** 当前展开的入口 id；受控值，父组件不传就是非受控 */
    modelValue?: string;
    /** 非受控时的初始展开入口 */
    defaultValue?: string;
    /** 入口列表；默认空数组 */
    items?: NavigationMenuItemData[];
    /** 方向语义；默认 "horizontal"（见「注意事项」，它不改变排列方式） */
    orientation?: "horizontal" | "vertical";
};

type NavigationMenuEmits = {
    /** 展开的入口发生变化（含收起）时发出 */
    (e: "update:modelValue", value: string): void;
    /** 点击面板里的某条链接时发出；普通链接入口不触发 */
    (e: "select", link: NavigationMenuLinkItem): void;
};
```

没有 slots，没有 expose。未声明的 attribute 与 `class` / `style` 落在唯一根节点（底层的导航菜单根）上。

## 布局

根节点是一行居中的入口胶囊（带边框、半透明底与模糊），入口之间一个间距单位。带面板的入口是「文字 + 展开箭头」（展开时箭头翻转 180°），普通入口就是一个链接。面板挂在根节点下方、整条宽度居中，内部是**固定 380px 的两列网格**，每一项是图标加标题、可选描述；视口的高度与宽度由底层的测量值驱动并做过渡，因此在两个入口之间切换时不会跳变。指示器（触发器下方的小三角）跟随展开的入口。

## 交互

- 展开与收起：由底层负责（点击、悬停意图与延迟、`Escape`、外部点击的具体规则以底层为准）。展开状态变化会发 `update:modelValue`；受控时以传入的 `modelValue` 为准。
- 点击面板里的链接：发出 `select` 并照常导航（`href` 缺省为 `#`）。
- 点击没有 `links` 的普通入口：只是普通链接跳转，不发 `select`。
- 键盘：入口之间的方向键移动、触发与关闭由底层实现；本组件不追加任何键盘处理，也不注册全局快捷键。

## 状态与边界

- 空 `items`：渲染一个空的入口胶囊。
- 有 `links: []`：按普通入口渲染（空数组等同于没有下拉）。
- 除「当前展开哪个入口」之外没有别的状态：没有禁用、只读、加载与错误态；链接的可用性由 `href` 与调用方决定。

## 不支持

- 不支持多列以外自定义面板布局：面板结构写死在组件里（固定宽度、两列、图标 + 标题 + 描述），没有面板插槽。
- 不支持在面板里混入任意内容（表单、图片墙等）。
- 不支持嵌套层级：入口只有一层，面板里的链接不再有下一级。

## 上游边界

底层的 Reka UI 导航菜单原语负责：展开与收起的触发规则（指针悬停意图、点击、`Escape`、外部点击）、键盘导航与焦点处理、面板视口的测量与动画（通过 `--reka-*` 变量）、以及各元素的可访问语义与属性。本组件承诺的只有：入口与链接的数据形状、两层视觉结构（入口胶囊、380px 两列面板）、`orientation` 的转交以及上面两个事件。上游其余行为随升级可能变化，需要依赖时以底层文档与实测为准。

## 注意事项

- **`orientation` 不改变排列。** 它只把方向交给底层（方向键与键盘语义），组件的布局类始终是横向一行——竖着用不会得到竖向排布。
- 面板内部是固定宽度的两列网格，窄屏（`390×844`）下整块面板会被视口裁掉超出部分，而不是换成一列。
