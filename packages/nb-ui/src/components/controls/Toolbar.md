# Toolbar

`Toolbar` 是一组相关操作的语义容器，提供水平或垂直排列的工具栏外观，并通过默认插槽组合按钮及其它可聚焦工具。它只负责容器，不生成工具、不管理业务动作；与单纯的 `div` 不同，它委托 Reka Toolbar 提供工具栏角色和方向语义。

## 布局

根容器按方向排列默认插槽内容，带紧凑间距、面板底色、边框和内边距。水平模式宽度随内容伸缩且最多占满父级，超出时在容器内部横向滚动；垂直模式宽度随内容伸缩，不自动限制高度或添加滚动。

在 `390×844` 下，水平工具过多时工具栏内部滚动而非制造页面横向滚动；垂直工具项的高度由父级布局控制。

## 交互

- 工具栏的子项由默认插槽提供；子项是否可点击、如何执行及焦点外观由各自组件决定。
- `orientation` 传给上游原语，以表达水平方向或垂直方向的工具布局和导航语义；具体键盘方向键与焦点停靠由 Reka Toolbar 负责。
- 容器不处理业务点击、不主动移动焦点，也不注册全局快捷键。

## 数据

```ts
type ToolbarProps = {
    /** 工具栏方向；默认 "horizontal" */
    orientation?: "horizontal" | "vertical";
    /** 工具栏可访问名称；默认 "工具栏" */
    ariaLabel?: string;
};

type ToolbarEmits = {};

type ToolbarSlots = {
    /** 工具栏项目；可放入按钮及其它工具 */
    default?: () => unknown;
};
```

没有 `expose` API。未声明的 attribute、`class` 与 `style` 按 Vue 默认规则传给根 `ToolbarRoot`；DOM 角色及 attribute 透传细节由 Reka 决定。组件本身没有隐藏通道。

## 状态

- 默认：显示水平工具栏容器，可访问名称默认是“工具栏”。
- 垂直：子项纵向排列，容器宽度按内容决定。
- 禁用、只读、加载、错误、空数据：容器不提供这些状态；空插槽只显示空工具栏外壳，子项状态由各自组件负责。

## 不支持

- 不支持生成或管理工具项、分组、选择状态、快捷键命令或业务行为。
- 不支持垂直模式下的自动高度限制与滚动；需要时由父容器负责。

## 上游边界

Reka UI 的 Toolbar 原语负责工具栏语义、方向与焦点/键盘行为。本组件负责布局方向、可访问名称透传和默认插槽容器样式；未由本组件显式约束的上游焦点规则与 DOM 细节不属于稳定合同。
