# AgentSessionTree

分支树弹窗的内容，外框与开关在 `AgentConversationView`。行为合同见 [`ui/agent-conversation-view.md`](../../../../../docs/specs/ui/agent-conversation-view.md) 的“分支树”，算法在 `session-tree.ts`。

## 布局与交互

- 上面写节点数与分叉数，右边切换“列表”“单线”“图”；图模式还有方向（从上往下，缺省；从左往右）。下面是搜索与过滤（默认、不含工具、只看用户、全部）。
- 列表：竖着一行一个节点，分叉处缩进线；当前路径的字亮，别的暗，缩进线按分支着色；图标按说话的人着色；当前那行有底色，有分叉的行写几条分支；分支的开头能收起。上下键选，左右键收起展开，回车切换。
- 单线：不缩进，一条路径从头走到尾。有分叉的行上有“‹ 1/3 ›”，点一下或按左右键，后面的行换成那条分支；不在当前路径的行左边的竖线变色，底部按钮把它切过去。上下键选。
- 图：节点是小块，线连起来，当前路径强调色，别的分支各一种颜色。分叉节点上有“‹ 1/3 ›”，点一下把选中换到另一条分支，先看再切。方向键沿时间走到父节点或孩子，垂直于时间的方向换分支；回车切换。节点太多（超过 1,500 个）时说明并让用列表。
- 底部写选中的节点和 id（点了复制），“切换到这条分支”：已在当前路径或不能切换时不可点。双击也切换。
- 打开、换视图、换方向时滚到当前位置。

## 数据

`tree`（`SessionTreeView`）、`canActivate`。事件 `activate`（节点 id）、`copy`（节点 id）。

## 隐藏通道理由

- `state:local`：视图、方向、过滤、搜索词、收起的分支、选中的节点都是纯界面状态。
- `state:inject`：翻译端口，同视图里的其它零件。
