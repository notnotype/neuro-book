# AgentStatusBar

输入框下面一行小字。行为合同见 [`conversation.md`](../../../../../../docs/specs/agent/conversation.md) 输出 15–18。

## 布局与交互

左边：上下文圆环与百分比（不知道窗口时只有绝对数）；运行阶段与用时、等重发、等批准或回答、正在停止（超过 10 秒提示工具没有响应）；费用告警；“全部放行”的警告；断线。宿主登记的 `statusItems` 跟在后面。右边：累计 tokens、输入、输出、缓存命中，图标与轮末的用量相同，明细在悬停；费用单列，未知时不显示，0 写“免费”。窄的时候明细让出位置，只留累计与费用。

## 数据

属性 `ctx`、`registry`。视图不自己计时，用时按 `ctx.now` 算。

## 隐藏通道理由

`state:inject`：翻译端口，同视图里的其它零件。
