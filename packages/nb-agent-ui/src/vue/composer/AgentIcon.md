# AgentIcon

选择器里画服务商图标与角色图标的小零件。收一个图标引用（`ComposerIcon`），经宿主注入的图标解析端口换成能画的东西，画成固定大小的方块。

## 布局与交互

- 没有交互；整个零件是装饰，`aria-hidden`，名字由旁边的文字给。
- 单色图（`mask`）用文字色着色（CSS mask），暗色下跟着变；多色图（`image`）原样显示；`class` 是图标 class（角色图标）。
- 解析不出（端口没注入、表还没到、没登记）时画首字母块：中性底、次要色，取引用里的 `fallback` 首字。首字母块不按名字配色，避免和模型无关的颜色被当成含义。
- `url` 类（用户上传的服务商图标）不经解析端口，直接按地址画成多色图；图片加载失败时换成首字母块（取 `fallback`）。
- 引用为空时什么也不画，不占位。

## 数据

属性：`icon`（`ComposerIcon`，可空）、`size`（像素，缺省 14）。端口在渲染里调用：端口读的响应式状态被当前渲染追踪，图标表晚到之后这里自动换掉首字母块。

## 隐藏通道理由

- `state:inject`：图标解析端口由宿主经 `provideAgentView` 的 `renderers.icons` 注入。
