# AgentWizardFrame

审批与提问向导共用的外框：标题行（图标、标题、等宽小字、“第几个”、收起）、内部滚动的内容区、底部的按钮。表面和其它浮层相同（磨砂）。

## 布局与交互

最高占视图的 60%（`60cqh`，容器是 `.acv-body`；`large` 时 85%，放长计划），内容区内部滚动、最少 8 行高；放不下时整个框滚动。

停靠变体：放在 [`AgentDock`](AgentDock.md) 里时，外框从注入（`dock-frame.ts`）读停靠区的标题行——带来源的标题写“子代理「名字」：……”、图标换成子代理的、计数写停靠区的“第 n / m 个”，提问向导自己有“第 k / j 题”时接在后面（“第 n / m 个 · 第 k / j 题”），另有上一个、下一个与打开子会话；面换成停靠的轻阴影（`0 1px 2px`、10% 的 `--shadow-color`）与输入框的圆角（`--radius-panel`），限高交给停靠区。标题放不下时省略号截断，计数与按钮固定在右边（同步与停靠都一样）。

## 数据

属性 `icon`、`title`、`detail?`、`count?`；事件 `collapse`；插槽缺省（内容区）、`foot`（按钮）。文字经翻译端口取。

## 隐藏通道理由

`state:inject`：翻译端口，同视图里的其它零件；停靠区的标题行经注入（只有 `AgentDock` 提供，同步向导里读到的是 null）。
