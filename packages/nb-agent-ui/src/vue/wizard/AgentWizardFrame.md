# AgentWizardFrame

审批与提问向导共用的外框：标题行（图标、标题、等宽小字、“第几个”、收起）、内部滚动的内容区、底部的按钮。表面和其它浮层相同（磨砂）。

## 布局与交互

最高占视图的 60%（`60cqh`，容器是 `.acv-body`），内容区内部滚动、最少 8 行高；放不下时整个框滚动。

## 数据

属性 `icon`、`title`、`detail?`、`count?`；事件 `collapse`；插槽缺省（内容区）、`foot`（按钮）。文字经翻译端口取。

## 隐藏通道理由

`state:inject`：翻译端口，同视图里的其它零件。
