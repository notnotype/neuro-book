# AgentRequestDetail

查看器右边选中那次请求的详情：顶部常驻的概览，下面消息、系统提示词、工具、原始请求体、响应五页。只在 `AgentRequestTrace` 里用。

## 布局

- 概览：状态图标、“请求 #N”、用途、状态与时刻、重发标记，右端新一次、旧一次、打开会话、复制请求四个图标按钮；下面一行会话标题、轮与 Profile；失败时一行错误文字；再下面模型、输入、输出、缓存命中、第一块内容、总时长、费用、HTTP 状态与停止原因（自动换行的格子）；改过这次请求的扩展（有才显示）。
- 页签之下是各自滚动的正文。消息、系统提示词、工具三页每条一行（序号、角色或工具 id、一行预览、补充说明、token 数），点一行在原地展开全文；回复放在消息页最后。原始请求体与响应两页原样显示 JSON，带行号。

## 交互

- 页签是组件自己的状态：换一条记录时停在原来那一页；展开的行在换记录时收起。
- 展开一行时，`contents` 里还没有这段内容就发 `request.load-content`；打开原始请求体那一页、且这条存着请求体、`payload` 还是 `idle` 时发 `request.load-payload`。
- 详情加载中、没有记录、读不出（带重试，发 `request.retry-detail`）各占满详情区。
