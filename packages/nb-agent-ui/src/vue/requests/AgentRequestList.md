# AgentRequestList

查看器左边的请求列表：列表头写条数与输入、缓存命中、费用的合计，下面按会话的轮分组，每条请求两行。只在 `AgentRequestTrace` 里用，数据都来自它。

## 布局

- 列表头一行：左边条数，右边合计（等宽小字，放不下时截断）。选中的那条不在结果里时下面多一行说明；有没插进列表的新请求时再下面一条“有 N 条新请求”，点了刷新。
- 组头一行：会话标题（只看一个会话时不写）、“第 N 轮”（后台标题会话写“后台”，轮外写“轮外”）、那一轮用户的话（单行截断）、组里最早一条的开始时刻。按别的排序时不分组、没有组头。
- 每条固定两行、等高：第一行是状态图标、用途、模型（去掉服务商前缀）、重发次数与“工具声明变了”的标记、序号 `#N`、时刻，状态图标与序号、时刻各占固定的列；第二行按状态换内容：进行中写已经等了多久，失败写 HTTP 状态与错误类别、用时，其余写输入、输出、缓存命中（没命中时提醒色）、用时、费用。
- 列表自己纵向滚动，离底部不到 240px 时发 `request.more`。

## 交互

- 点一条发 `request.select`。列表是 `listbox`，焦点在列表上时上下键选中上一条、下一条。
- 空列表按情况写：加载中、读不出（带重试）、没有符合筛选的、还没有、记录关着（带“打开记录”，发 `request.open-settings`）。
