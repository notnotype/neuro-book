# Actor 材料包标签规范（RP v2）

actor 材料包是 rp.screenwriter 在事前判断（P2）中按角色组装、由 rp.cast 分发给各 rp.actor 的消息。核心约束：**只包含该角色在戏内合理能感知、知道或推断的信息**——不含任何 secret、他人内心或 god-view 内容。

> 本文是 RP v2 版本；legacy 版本在 `reference/agent/rp-tick/actor-facing-packet.md`。

## 标签总览

| 标签 | 用途 | 必须 |
|------|------|------|
| `<gm>` | 场景描述 + 环境事件 | 是 |
| `<character name="...">` | 其他角色的可观察行为和台词 | 有其他角色行为时 |
| `<knowledge>` | 该角色合理已知的世界知识 | 需要补充角色常识/专业知识时 |
| `<directive>` | 本轮特殊指示 | 可选 |

## `<gm>`

场景描述 + 环境事件。相当于 GM 给角色描述"你看到了什么、听到了什么、感受到了什么"。

**内容来源**：
- 当前场景环境（来自 rp.world 的 P1 状态分发摘要，已剥除 secret）
- LOD0 中该角色能感知到的事件（见 [lod-simulation.md](lod-simulation.md)）
- LOD1 中能传到当前场景的感知（远处的声音、气味等）

**规则**：
- 用第二人称"你"描述。
- 只写该角色能直接感知的（视觉、听觉、触觉、嗅觉）。
- 不写其他角色的内心；不写该角色不知道的设定原理。
- LOD 事件中的 lorebook 术语必须转换为该角色认知水平的描述。

## `<character name="...">`

其他角色的可观察行为和台词。"你看到/听到某某做了什么、说了什么"。

**规则**：
- `name` 填角色在该 actor 认知中的称呼：认识的人用名字，不认识的用描述性称呼（"白发女孩""穿红袍的老人"）。
- 只写可观察的外在行为：动作、表情、台词、声音。不写内心想法。

## `<knowledge>`

注入该角色合理已知的世界知识、背景信息、专业判断依据。

**解决的问题**：actor 通过 `rp_character_recall` 加载的是人设/心境/已知信息/记忆摘要，但角色还有**常识性知识**或**专业知识**不在档案里。

**规则**：
- 只注入该角色合理知道或能推断的知识，用角色自己的认知水平描述。
- 不注入该角色不应知道的隐藏设定。
- **与角色档案去重**：`<knowledge>` 是新信息注入通道，`rp/characters/{id}/已知信息` 是存储。只注入"本轮场景需要、且角色已知信息（K 条目）尚未覆盖"的知识；已覆盖的不重复注入——actor 回忆时会自己读到。角色经此第一次接触的知识是否沉淀为 K 条目，由终裁后的「信息变动」流程决定（screenwriter 执行 rp_character_update），不在 packet 里处理。

**示例——法师（魔法专家）**：

```xml
<knowledge>
你是受过正规训练的法师。你知道：
- 异界召唤术式成功时，被召唤者通常会立即展现某种形式的魔力外放。
- 完全没有外放的情况极为罕见，通常意味着召唤失败或能力处于封印/休眠状态。
</knowledge>
```

**示例——普通高中生**：

```xml
<knowledge>
你是一个普通的高中生。你不理解这个世界的任何规则。
你只知道：你和另外三个人被传送到了一个陌生的地方，一个穿红袍的老人说你们被"召唤"来了。
</knowledge>
```

## `<directive>`（可选）

给 actor 的本轮特殊指示。不是每轮都需要，用于微调角色行为、引导剧情方向。

**规则**：
- 用建议而不是命令（"你可能会……"而不是"你必须……"）。
- 不破坏角色自主性——actor 可以根据角色性格偏离指示。
- 不用来注入该角色不知道的信息。

## rp.actor 的 report_result

actor 的 report_result 使用**第一人称**三通道：

| 字段 | 含义 |
|------|------|
| `visible_response` | 其他人能看见的（动作、神态、沉默） |
| `spoken_dialogue` | 说出口的话 |
| `inner_response` | 没说出口的（情绪、意图、误解） |

```json
{
  "visible_response": "我微微一颤，下意识把背包抱得更紧了。然后慢慢转过头，眨了眨眼睛。",
  "spoken_dialogue": "我……我没事。你、你也是被召唤过来的吧？",
  "inner_response": "终于有人搭话了。这个白发女孩看起来好冷静……她怎么做到的？"
}
```
