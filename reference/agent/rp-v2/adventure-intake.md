# 开团引导（Adventure Intake）

rp.leader 在「小屋」接到开团意图时的引导协议。核心原则：**开团是用户的创作决策，你只提案、不代决**——绝不允许因为用户说了「开始跑团」就自己编一套剧本直接开跑。

## 铁律

- 每轮最多问 1-2 个问题，并给出可选项（A/B/C + 欢迎自由发挥），不要让用户写作文。
- 用户说「随便」「你来定」时：给出**一个具体提案**请用户确认，而不是继续追问，也不是不确认就开跑。
- 全程保持小屋（元场景）语气——这是炉火边的共创闲聊，不是填表。
- 引导产物先落盘（rp/manual/、rp/lorebook/），再进入 rp-v2-bootstrap 的技术初始化；没有用户确认的「冒险企划书」不落盘、不开场。

## 第 0 步：分流

接到「开始跑团」类意图时，先探明现状（read rp/manual/README.md、rp_tick_info）：

1. **rp/ 已有进行中的冒险**（manual 有内容且 ticks 有进度）→ 不进引导。介绍这个冒险是什么、进行到哪（可引用最新 prose 标题），问：继续 / 新开一个 / 调整化身。
2. **rp/ 无冒险材料** → 进入引导。第一问只有一个：

   > 这次冒险想怎么开始？
   > A. 用这本书已有的世界观开团（我去读你写作模式的设定，改编成跑团世界）
   > B. 完全新开一个故事（我们聊着把世界捏出来）

   根 lorebook/ 不存在或为空时跳过选项 A，直接走路线 B。

## 路线 A：从写作设定改编

1. **授权确认**：读写作模式的根 lorebook/、manual/ 需要用户点头（这是模式分离的唯一例外：一次性拷贝改编）。用户在第 0 步选了 A 即视为授权。
2. **读取与摘要**：read 根 lorebook/ 核心条目，给用户一页纸摘要——这个世界是什么、有哪些可用的角色/地点/规则/阵营。不要全文倾倒，捡最有戏的说。
3. **逐项补 RP 缺口**（每轮 1-2 问）：
   - **化身**：扮演原作已有角色，还是原创一个新角色？与原作角色是什么关系？
   - **时间线**：开局在正传剧情之前/之中/之后，还是平行世界？原作剧情允许被跑团改变吗？
   - **危险度**：会死人/重伤吗？判定偏宽松爽文还是严格拟真？
   - **禁区**：有没有不想让故事触碰的内容（角色死亡、某类剧情……）。
4. **改编落盘**：确认后把**用得上的部分**改编进 `rp/lorebook/`（改写为跑团视角，剔除纯写作素材），并写 rp/manual/ 三件套（见「收束」）。此后两份设定独立演化，运行时绝不回读根 lorebook/。

## 路线 B：从零共创（问答式）

按顺序聊完六个话题。每个话题先给选项/示例再等回答；用户答「你来定」就提案并确认。

1. **类型与基调**：奇幻冒险 / 都市异闻 / 科幻 / 武侠仙侠 / 现代日常 / 恐怖悬疑……？基调轻松欢乐还是严肃残酷？
2. **世界核心**：这个世界最特别的一条规则是什么（魔法体系 / 超能力 / 特殊科技 / 诡异怪谈……）？用一句话说世界现状（例：帝国衰落、旧神苏醒）。
3. **化身**：想扮演什么样的人？身份、性格关键词、开局起点（普通人卷入 / 自带金手指 / 落魄强者……）。名字与细节可以后面再定。
4. **其他角色**：想要什么样的同伴、对手、群像？有没有必须存在的关系（青梅竹马、宿敌、失散亲人……）？
5. **规则与危险度**：判定风格（2d6，偏宽松还是严格）、死亡/重伤风险开不开、主持的自由裁量边界、内容禁区。
6. **开局**：三选一——用户指定开局场景 / 你设计 2-3 个候选开局给用户挑 / 完全随机盲开（用户喜欢惊喜时）。

## 收束：冒险企划书 → 落盘 → 交接

1. 聊完输出**冒险企划书**（一屏内）：世界一句话 / 基调 / 核心规则 / 化身 / 关键 NPC / 危险度与禁区 / 开局方式。请用户确认或修改；确认前不落盘。
2. 确认后落盘：
   - `rp/manual/README.md`：世界一页纸 + 基调 + 禁区。
   - `rp/manual/player-guide/`：化身卡（身份/性格/能力/起点）。
   - `rp/manual/gm-guide.md`：难度基调、判定风格、裁量边界、禁区（给 screenwriter 看的主持手册）。
   - `rp/lorebook/`：世界规则、关键 NPC、开局地点等核心条目。
3. 交接 rp-v2-bootstrap 从 Step 2 继续：rp/world-engine/ 配置（抄 skill 里的 schema/calendar 模板）→ rp.world 初始化 → 角色建档（ensure 带 name/aliases）→ 开场白 Brief 交 rp.writer。
