# LOD 世界模拟（RP v2）

LOD（Level of Detail）模拟是 rp.screenwriter 在事前判断（P2）中执行的世界层模拟，在角色级演绎（P3）**之前**完成。它用于丰富世界真实感、为后续冒险埋线。

> 本文是 RP v2 版本；legacy simulation 体系的同名文档在 `reference/agent/rp-tick/lod-simulation.md`，其 current.md 机制在 v2 中已废除。

## 核心规则

### 先世界，再角色

LOD 模拟必须在角色级演绎之前完成。角色在世界里行动，不是世界围着角色转。LOD 产出的事件可能影响角色行为（如突然的声响、光线变化），所以必须先确定世界发生了什么。

### 全知精确

LOD 模拟是 rp.screenwriter 的全知视角产物。必须精确引用 `rp/lorebook/` 条目和真名：

- ✅ `一位女仆端着装有[治愈之泪](rp/lorebook/item/healing-tear.md)的华丽盒子进来`
- ❌ `一个仆人端着一个神秘的盒子进来`

**例外**：如果当时也没想好这个东西是什么，才允许用"神秘的""不明的"——这意味着该道具/事件的设定留待后续自由发挥。

## LOD 层级

| 层级 | 范围 | 数量 | 说明 |
|------|------|------|------|
| LOD0 | 当前场景附近 | 4–6 个 | 必须有。角色可能直接感知到的变化 |
| LOD1 | 区域级（城堡、集市） | 2–4 个 | 通常有。当前场景外但同一建筑/区域内 |
| LOD2 | 城镇级别 | 1–2 个，可以没有 | 可选 |
| LOD3 | 国家级别 | 通常没有 | 罕见 |
| LOD4 | 世界级别 | 通常没有 | 极罕见 |

数量是**基准值**，按剧情密度动态调整：剧情密集（冲突、重要判定多）→ LOD0 只给 2–3 个，避免噪声淹没主线；剧情松弛（赶路、休整、独处）→ 适当加量，用世界的自主运行感填充叙事空间。

## LOD 事件类型

- **纯装饰**：丰富真实感。蜡烛火焰跳动、鸽子被惊飞、光斑偏移。
- **伏笔**：为后续冒险留素材。公会发布讨伐委托、管家发现税收不达标。
- **即将进入场景的事件**：女仆端着热茶正在走向大厅（2 分钟后到达）。当前 Tick 不影响角色，但将在后续 Tick 自然进入场景。

## Pending Events = World Engine 未来切片（v2 机制）

「即将进入场景的事件」与未兑现伏笔**不再写 current.md**（legacy 机制已废除）。v2 做法：

- screenwriter 在事前判断/终裁报告的「pending」段列出这些事件（含预计兑现时间）。
- rp.world 在写回（P5）时把它们落为**未来时间、`kind: "pending"`** 的 World Engine 切片（见 [world-contract.md](world-contract.md)）。
- 每 Tick 开始的状态分发（P1）会列出已到期的 pending 切片，screenwriter 把到期事件纳入本轮 LOD0/场景事件；已失效的由 rp.world 删除。

跨 Tick 记忆由 World Engine 承载，screenwriter 不需要也不应该维护任何单独的状态文件。

## LOD → actor 的信息过滤

LOD 产出后，screenwriter 按角色感知范围过滤，融入 actor 材料包的 `<gm>` 标签（见 [actor-packet.md](actor-packet.md)）：

- 角色能**直接感知**的 LOD0 事件：融入该角色的 `<gm>`。
- 角色能**间接感知**的 LOD1 事件（远处的声音、气味）：可选融入。
- 角色**不在场**的事件：不融入。
- LOD 事件中引用的 lorebook 术语：必须转换为角色认知水平的描述。
  - 给法师："召唤术式的残余魔力出现了元素亲和力共鸣" → 可以，法师知道这些概念。
  - 给普通高中生："脚下的发光文字好像变色了" → 只能这样。

## LOD → Writer Brief 的信息过滤

rp.leader 从 LOD 中挑选用户化身能感知的事件，用**用户视角的感官语言**描述（不使用 lorebook 术语），织入 Writer Brief（见 [writer-brief.md](writer-brief.md)）。

用户化身不在场的 LOD 事件不进 Brief。Brief 里没有的，writer 永远不知道。

## 示例

```markdown
## LOD 世界模拟

### LOD0 — 仪式大厅

1. 西侧一扇彩色玻璃窗没有完全关紧，风灌进来让最近的三根蜡烛同时晃了一下。
2. 地面上的召唤纹路持续熄灭中，但洛丽塔女孩附近的一段出现了微弱的共鸣反应。
3. 台阶右侧的一名卫兵膝盖旧伤发作，悄悄换了一下重心。
4. 大厅顶部横梁上的灰鸽子被越来越大的声音惊到，扑棱着飞到另一根横梁。

### LOD1 — 子爵城堡

1. 女仆莉丝正往仪式大厅方向走，手里端着热茶，大约两分钟后到达大厅侧门。
2. 东塔书房里管家正在翻账本，上个月的税收又没有达标。

### pending（交 rp.world 写为未来切片）

- [约 2 分钟后] 女仆莉丝端着热茶到达仪式大厅侧门（来源：本 Tick LOD1）
- [未定] 冒险者公会的虫群委托可能与召唤魔力波动有关（伏笔）
```
