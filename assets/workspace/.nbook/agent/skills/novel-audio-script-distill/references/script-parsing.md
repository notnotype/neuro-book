# 台本输入解析

novel-audio-script-distill 阶段 A 第 2、3 步的解析规则：格式探测、文件名与音轨标记、时间戳利用、A/B/C 噪音分级、长轨采样。

---

## 1. 文件名与音轨标记解析

多音轨作品的**文件名本身就是重要的结构信息**，先于内容解析：

```
09EX. 不想听到的女友娇喘声.txt
│ │   └─ 音轨标题：常直接概括本轨场景/事件
│ └─ EX 标记：外传/特典轨，可能是 if 线或纯服务轨，时间线归属需单独判定
└─ 序号：默认播放顺序（≠ 一定是故事顺序）

02.（※滥交男学长的视点）被滥交男学长弄到高潮了….txt
     └─ 视点标记：括号 + ※ 是最常见写法，指「本轨听者角色是谁」
```

需要识别的标记（中日文都要认）：

| 标记 | 语义 |
|------|------|
| `（※XX的视点）` / `（XX視点）` | 听者角色切换为 XX。注意：出声角色通常**不变**，变的是听者 |
| `序章` / `プロローグ` | 开场轨，常承担世界观与关系交代 |
| `EX` / `おまけ` / `特典` / `After` / `番外` | 附加轨；判定属于正传延长线、if 线还是无剧情服务轨 |
| 纯编号无标题 | 标题无信息，依赖内容判断场景 |

音轨清单异常处理：

- 序号缺口（01、02、04…）→ 问用户是否缺文件。
- 同序号多文件（04a/04b）→ 按字母序视为连续轨。
- 目录里混入非台本文件（图片、商品说明）→ 列出并确认剔除；商品说明文案转存 `reference/audio-script/{作品名}/_官方信息.md`。

## 2. 格式探测

读文件前 20 行即可判定：

| 格式 | 特征 | 解析要点 |
|------|------|----------|
| WEBVTT | 首行 `WEBVTT`；cue 结构 `序号 / HH:MM:SS.mmm --> HH:MM:SS.mmm / 文本` | 每 cue 一句台词；记录起始时间戳供节奏分析 |
| SRT | cue 结构同上但时间戳用逗号 `00:00:07,000`，无 WEBVTT 头 | 同 WEBVTT |
| LRC | 每行 `[mm:ss.xx]文本` | 时间戳在行首；无 cue 序号，按行序编号 |
| 剧本体 | `角色名：台词` 或 `角色名「台词」` | **多侧有声**——罕见但存在（ドラマCD 完整台本）；不需要单侧反推，按普通对话拆，推断等级整体上调（更多【实证】） |
| 纯文本 | 无时间戳无角色名，逐行台词 | 无节奏信息；行序即台词序 |

编码：优先 UTF-8；乱码时换 GBK / Shift-JIS 重试。无法恢复的行标 `[乱码]` 跳过，不猜内容。

## 3. 时间戳的节奏利用

时间戳不是噪音，是**免费的场景节奏标注**：

- **cue 间隔 > 30 秒**：大概率是 SFX 段或场景转换。逐轨笔记记为「静默段」，配合前后台词推断发生了什么（例：告白后 40 秒静默 → 亲吻/拥抱段【弱推断~强推断】）。
- **cue 密集段**（间隔 < 3 秒连续多句）：情绪高点或信息密集段，精读优先级高。
- **轨总时长 vs 有效台词行数**悬殊（长轨少台词）：本轨以音效/氛围为主，剧情权重低。

时间戳只保留在逐轨笔记的定位引用里；卡片层面用 `tracks` 字段定位到轨。

## 4. A/B/C 噪音分级（信息密度过滤）

音声台本的台词行大量是喘息、拟声与重复句。逐行分析既浪费又会把笔记变成露骨内容复述。逐轨精读按信息密度分三级：

| 级别 | 定义 | 处理方式 |
|------|------|----------|
| A 信息行 | 含设定/称呼/事件/关系/底线/心理转折的行 | 逐行登记进逐轨笔记「A 类新信息」表 |
| B 情绪行 | 无新事实，但反映情绪状态或态度变化（拒绝→默许→主动的措辞渐变） | 按段落摘要，标注情绪走向 |
| C 拟声行 | 纯喘息、拟声词、同义重复 | **只计数不逐行分析**。每轨统计 C 类占比——占比本身是节奏信息（服务段 vs 剧情段） |

判定原则：**一行同时含 A 和 C 成分时按 A 处理**——露骨句里嵌着称呼变化或关系信息是音声台本的常态，信息要提取，原句不进笔记/卡片，改为转述 + 行号定位。

## 5. 长轨采样策略

单轨行数 > 300 时不要一次读全文：

1. 先读前 60 行 + 后 40 行，确定场景与结局状态。
2. 中段按 100 行一批扫 A 类信息行；C 类密集区跳读（每批抽头尾确认无 A 类混入）。
3. 逐轨笔记注明采样方式（「中段 L120-L260 为 C 类密集区，抽样确认无新信息」），保证溯源诚实。
