# 音声台本信息提取方法论

novel-audio-script-distill 阶段 A 第 3、4 步的核心方法：单侧对话重建、听者角色与视点解析、称呼口癖提取、时间线重建、世界观线索收集、推断分级细则、音声题材标签、角色弧线模式。

---

## 1. 单侧对话重建（核心技术）

台本里只有出声角色的台词，听者角色（主人公）说了什么、做了什么，全靠反推。三种基本手法，可靠度从高到低：

### 1.1 复述法（→ 多为【实证】）

出声角色**复述**了对方的话：

> 「是你想做的事情嘛…如果你说你想在教室做的话…是可以啦…」

→ 听者说过「想在教室做」【实证：被复述】。复述内容按原话登记；复述语气（无奈/撒娇/嘲讽）另记为出声角色的态度信息。

### 1.2 回应反推法（→ 多为【强推断】）

从回应形态反推对方刚才的言行：

| 回应形态 | 反推 |
|----------|------|
| 答疑式（「欸？没事，没什么～」） | 对方发问了；问题内容从上下文补 |
| 制止式（「不可以摸胸啦」） | 对方做了被制止的动作 |
| 允诺式（「那就来做吧…可是要戴上套子唷」） | 对方提出了请求；附加条件是出声角色的底线设定 |
| 感知式（描述正在发生的对方状态） | 场景事实 |

### 1.3 空隙补完法（→ 一律【弱推断】）

台词之间、静默段里发生了什么，只能按合理性脑补。允许补，但必须打【弱推断】并写明依据（「40 秒静默 + 后句语气变化，推测为亲吻段」）。

### 1.4 听者言行还原表

逐轨笔记每轨建一张表：

```
| 位置(行/时间) | 出声侧台词(转述) | 还原的听者言行 | 手法 | 等级 |
```

这张表是给**听者角色立卡**的唯一数据源——听者角色往往是全作性格信息最隐蔽的角色，但对写作恰恰最重要（他就是改写后小说的第一视角骨架候选）。

## 2. 出声角色 / 听者角色 / 视点

三个概念必须分开，混掉会把整条时间线拆错：

- **出声角色**：台词的说话人。单 CV 作品全程只有一个（最常见）；多 CV 作品按语气、称呼、自称区分说话人。
- **听者角色**：出声角色正在对谁说话——即「主人公」。
- **视点标记**（文件名里的 `※XX的视点`）：指**本轨听者是谁**，不是出声者换人。例：「※学长视点」轨里出声的仍是女主，但她面对的是学长——听者临时切换，用于让听众旁观「自己不在场的场景」。

**双听者结构**（NTR / 三角类作品的标准结构）：主人公视点轨 + 第三者视点轨交替。拆解要点：

1. 每轨先定听者是谁（文件名标记 > 台词内称呼 > 内容排除法）。
2. 出声角色对**不同听者**的说话风格差异，本身就是人设核心素材（对 A 收敛、对 B 放纵 → 表/里人格拆分依据）。
3. 注意「窃听轨」：听者 A 在场但不被知晓（隔窗帘、门外、电话），台词是说给 B 的——场景关系三方，逐轨笔记单独注明。

## 3. 称呼与口癖提取（说话风格 = 音声台本最值钱的写作素材）

### 3.1 称呼表

登记**谁称呼谁为什么**，以及**称呼随剧情的变化**——称呼变化是关系变化最硬的信号：

```
| 称呼者 | 被称者 | 称呼 | 出现区间(轨) | 变化说明 |
```

两条称呼线并置（对 A 的称呼降温、对 B 的称呼升温）就是关系弧线的骨架。

### 3.2 口癖与语气特征

每个出声角色提取：口癖（高频语尾、感叹词、独特用词）、语气基线（敬语程度、句长、省略号密度——犹豫型 vs 直球型）、**语气随剧情的漂移**（初期撒娇抗拒句尾 → 后期祈使句变多）、例句 ≥3（选非露骨高信息句；露骨句用转述替代）。

日文台本：口癖、称呼保留原文（假名/汉字写法差异也是信息），附中文说明。

## 4. 时间线重建（storyline 卡的方法）

**轨序 ≠ 故事序**。重建步骤：

1. **锚点排序**：找绝对时间线索（季节、事件因果、关系状态不可逆变化）给各轨排故事序。
2. **并行轨判定**：两轨场景/事件重叠、听者不同 → 同一时刻的双视点。时间线上并列编号（4a/4b），标注「并行」。
3. **EX / 特典轨归位**：三种判定——正传延长线（承接结局状态）/ if 线（与正传事实冲突）/ 无剧情服务轨（不进时间线）。
4. **关系阶段划分**：按关系状态不可逆点切阶段，每阶段一句状态描述 + 起止轨。
5. **转折点**：每个转折点记「转折前状态 → 触发事件 → 转折后状态 → 落点轨」。

产出双表：`轨序表`（听众体验顺序）+ `故事序表`（时间顺序）。两者的**差值本身是叙事技法**（先让听众看到结果再补过程 = 悬念倒叙；同时刻双视点 = 信息差张力），提炼进 technique 卡。

## 5. 世界观线索收集（setting 卡的方法）

音声台本的世界观是「碎渣式」的，靠物证归纳：

| 线索类型 | 例 | 归纳方向 |
|----------|-----|----------|
| 地点 | 教室、厕所、自宅 | 场景清单 + 各场景的功能（安全区/禁忌区/日常区） |
| 时代物证 | 手机、通讯软件、校规 | 现代/近未来/架空判定 |
| 社会关系 | 学长-学妹、情侣、社团 | 关系网 + 信息差：谁不知道什么 |
| 规则设定 | 催眠、魔法、契约（如有超自然） | 规则的边界、代价、触发条件——写作最需要 |
| 道具 | 反复出现的物品 | 象征物候选 |

**空白区清单**（写进 `INDEX.md` 末尾）：台本从未交代、改写成小说必须补的设定（角色姓名、外貌、恋爱起点、家庭背景…）。列出来 = 告诉写作者哪里可以自由发挥、不会与原型冲突。

## 6. 推断分级细则

| 等级 | 判定标准 | 采纳时的处理 |
|------|----------|--------------|
| 【实证】 | 台词原文直接陈述 / 官方信息写明 / 复述法还原 | 可作为节点主体（仍需变形确认） |
| 【强推断】 | 回应反推且合理解释基本唯一；或多轨互证 | 可作为节点主体，默认沿用 |
| 【弱推断】 | 空隙补完、单一线索、经验补齐 | 舍弃，或与用户确认后作为本作自有设定重写 |

规则：

- 每条结论**一个**等级，取该结论内可靠度最低的成分（木桶原则）。
- 多轨互证可升级：单轨【弱推断】被另一轨印证 → 升【强推断】，注明互证轨。
- 与官方信息冲突时官方优先，台本证据记为「演出偏差」。
- 不确定就降级，宁可【弱推断】——虚高等级会污染新作设定。

## 7. 音声题材标签速查

给作品定位、写 INDEX 摘要时用。主标签 1 个 + 副标签 ≤3 个：

| 类别 | 标签 |
|------|------|
| 关系向 | 纯爱/甘々、青梅竹马、年上（姐姐系/人妻）、年下（妹系/后辈）、师生、偶像 |
| 冲突向 | NTR（寝取られ：被夺 / 寝取り：主动夺 / 寝取らせ：自愿献出）、三角、复仇、堕落、净化 |
| 玩法向 | 催眠/洗脑、调教、痴女（女方主导）、关系权力逆转、秘密关系 |
| 氛围向 | 耳语系、治愈/安眠、日常系、猎奇/致郁 |
| 结构向 | 单人独白、双听者交替、多结局、报告体（事后转述） |

定位时附一句「本作对该标签的执行偏差」——哪里按类型套路走、哪里反套路；反套路处即卖点，值得单独出 technique 卡。

## 8. 角色弧线常见模式（character 卡对照用）

归型参照，不是硬套模板：

- **纯爱升温**：拘谨 → 信赖 → 主动（无对抗力，靠细节浓度）。
- **堕落三段**：抗拒（底线声明）→ 动摇（底线松动的自我合理化）→ 沉溺（主动化 + 称呼/语气翻转）。拆解重点：每段之间的**不可逆点**在哪一轨哪句台词。
- **双面维持**：对 A 一套人格、对 B 一套人格，张力在两套话术的差值与穿帮风险。
- **净化/救赎**：初始防御姿态 → 裂缝 → 卸防。与堕落同构反向。
- **听者弧线**：主人公也有弧线（察觉 → 怀疑 → 确认/崩溃，或无知 → 幸福假象），全部来自还原表。
