# NeuroBook 基础品牌标识 · 设计简报

状态：**已确认（2026-09-28）**。受众、主气质、看板娘关系、交付范围、视觉尺度与色彩方向由用户逐项回答；核心承诺与评审标准由设计师归纳，经用户整体确认。

本稿取代上一轮猫耳书探索的方向要求。上一轮草稿已归档到本地 `.local/brand/logo-archive/archive/round-1/`，仅作参考，不代表本轮已选定猫耳、书本、星星、字体或具体造型。

## 1. 核心受众与创作范围

用户原话：**「无文笔、有故事的人。不论是自娱自乐还是商业写作。当然二者得兼是最好的。」**

- 核心受众：有故事与想法，但未必擅长文字表达的人；同时兼容文笔成熟的创作者。
- 创作范围：文学创作，包含小说、剧本、短篇等，不限定长篇或世界观构建。
- 创作目的：自娱自乐与商业写作均在范围内。

核心承诺（设计师归纳，已确认）：**NeuroBook 帮助有故事的人跨越文字表达的门槛，把脑中的人物、情节与想象变成作品。**

## 2. 品牌气质

用户已确认：

- 第一印象：**亲近、鼓励**。
- 视觉尺度：**轻巧、有趣**。
- 希望传达的感受：用户选择了「我的想法值得被写出来，在这里可以开始」这一方向。

设计解释：以清晰、轻快的整体形态容纳一个容易发现的小巧思；亲近感不预设为卡通、表情或明显萌化。文学与想象力可作为内涵，但不压过鼓励开始创作的第一印象。

修订（2026-09-28，第一轮草图后用户反馈）：上一句中「不预设萌化」是设计师解释，与用户期望不符。用户要求标志有**可爱感**，并且概念要能直接引起联想，不依赖文字游戏或冷门典故。可爱程度（不画脸、简笔表情或角色化）在第二轮草图中比较后确定。

## 3. 与看板娘的关系

用户已确认：**有含蓄的联系。** 可以提取看板娘的一项代表性特征，让熟悉角色的人发现关联。

设计解释：标志应能独立识别，不要求观众先了解角色设定。具体提取色彩、形态还是某项意象，留到概念阶段比较；不预先指定猫耳或星星。

## 4. 色彩方向

用户已确认：**延续赤红、金色、象牙色系，允许调整。**

- 可调整明暗、饱和度与使用比例，使整体符合轻巧、亲近的气质。
- 不要求三色全部出现在主标志中。
- 上一轮色值仅供参考，不作为本轮固定标准色；最终色值在方案精修时确定。
- 单色与反白版本应能独立成立，识别不能只依赖配色。

## 5. 交付范围

用户已选择：**一套基础品牌标识，以 SVG 为主。**

1. 独立图形标志。
2. `NeuroBook` 字标。
3. 图形与名称的组合；组合方向及比例按使用场景确定。
4. 彩色、单色、反白及小尺寸版本。
5. 简短使用规范：标准色、安全留白、最小尺寸、背景使用方式与常见误用。

字体、大小写的视觉处理、组合排布均未选定。本轮未约定新增中文品牌名、独立口号标志、动态标识或完整品牌手册。

## 6. 使用场景与制作约束

沿用前期已记录的使用需求；以下不是本轮重新检查产品代码所得的现状声明：

| 场景 | 设计约束 |
| --- | --- |
| 桌面标题栏 | 约 14px 单色；提供可跟随 UI 颜色的 `currentColor` SVG |
| favicon、托盘及任务栏 | 重点检查 16px 等小尺寸；必要时提供专用简化版 |
| 应用图标 | 在方形画布中有清楚的主体、合适的视觉占比 |
| 官网及宣传 | 图形与字标组合清楚，兼容明暗背景 |
| 导出文件及书印等延伸场景 | 验证单色标识的可用性，不自动扩大为独立辅助标识交付 |

可按尺寸调整细节，但各版本必须保持同一身份。具体尺寸、背景表现与字标可读性，在后续实际渲染中验证；本稿不声明已通过验收。

## 7. 品牌资料与概念空间

- 品牌母题库（本地 `.local/brand/lore/NeuroBookBrandLora.md`）：`From words to world.`、Word → World、叙事之线、记忆、创造与世界等。
- 品牌状态文案（本地 `.local/brand/lore/AgentThinkingStatusMessages.md`）：文学、想象力、温柔、幽默与角色化表达的参考。

这些资料提供概念来源，不要求将全部意象放进一个图形。`From words to world.` 可作为品牌叙事参考，本轮尚未确认把它固定加入标志组合。

下一阶段应比较不同的概念思路，而不是只为旧图形替换表情。任何具体符号都需要同时接受亲近感、辨识度与小尺寸表现的检验。

## 8. 建议的评审标准

以下由设计师依据访谈归纳，已确认：

1. **亲近与鼓励**：目标用户愿意接近、尝试创作，不因视觉表达产生距离感。
2. **轻巧与趣味**：整体简练，小巧思自然，不依赖大量装饰或长篇解释。
6. **一秒可懂**（2026-09-28 增补）：先认出一个熟悉的事物、感到一种情绪，巧思留给第二眼；需要解释才成立的概念不合格。
3. **独立辨识**：离开看板娘和品牌故事后，仍具有可记住的形态。
4. **一致性**：图形、字标、配色与角色之间协调；含蓄联系不妨碍独立使用。
5. **实际可用**：单色、反白、明暗背景和 14–16px 重点场景均需实际检查。

情绪与联想属于视觉判断；尺寸与渲染属于技术验证。两者分别记录，不把 SVG 可解析等同于设计成功。
