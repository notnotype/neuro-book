# 按需协调

主 Agent 对结果负责，可以亲自调查、实现和验证；本技能不是正式角色，不要求转交 Tasker。范围和授权来自当前请求与 [Work/Task](../../works/README.md)，不是技能名称。

1. 从当前目标与 Task 快照明确可观察结果、范围、授权和真正阻塞；仅补充缺失合同，不重读完整历史。
2. 先判断是否有独立且值得委派的工作。短任务直接完成；只有真实依赖才串行，不按文件数量拆分或预建依赖未知结果的链。
3. 派发前约定切片输入、输出、共享接口、文件 owner 和验收边界；共享文件由一个集成 owner 修改。主 Agent 负责最终集成与统一验证，避免每个子代理重复跑完整门禁。
4. 派发后继续自己的独立工作；只在结果缺失阻断下一步时等待。子代理建议不扩大产品范围或受限动作授权。
5. 对安全、隐私、数据生命周期、迁移、公开接口、安装发布及跨模块高风险变更安排独立审查；审查结论仍需主 Agent 核实，不代替用户批准。
6. 按 [最小充分验证](../../../docs/testing/README.md#验证门禁) 收口，更新唯一 Task 当前快照；只有需要恢复的历程才存 walkthrough，报告使用 [report](../report/SKILL.md)。

完成条件：各切片组成已批准结果，验证与未解决边界明确；没有等待形式化角色交接或为追加检查延迟交付。
