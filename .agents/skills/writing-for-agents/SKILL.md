# Agent 指令写作

修改 Skill 时参考 [调用机制](SKILL-MECHANICS.md)。规则服务当前任务，不覆盖更高优先级系统或宿主要求。

- 只持久化廉价环境查询得不到的知识：约定、决策原因、易错点与边界；命令和目录从实际配置查明。
- 入口写职责、触发条件和链接；按任务分支披露参考资料，不要求每次编辑读完整文档堆栈。
- description 简短且区分用途，不罗列同义触发词抢占其它 Skill。
- 明确范围、可观察成功条件和真正停止条件；常规细节由执行者判断，不把固定步骤或更强烈措辞当成可靠性保证。
- 同一规则维护单一来源；相关定义与边界放在一起，删除过时重复，不为隐藏后续步骤额外委派。
- 按需披露相关片段；调查完成后用结论替代失效草稿与日志，同时保留当前目标、授权边界、当前错误和修改中源码。恢复先读最新 Task 快照，不从历史叙事推测当前授权。
- 保留真实安全、权限、数据和失败边界；精简不能把未验证改写成成功。
- 用代表场景核对删减：只读、授权修改、验证完成、受限动作和交付恢复。检查是否能完成目标且不扩大范围，不宣称未经实验的性能提升。

完成时确认链接、适用机器合同与场景语义；不为文本改动增加产品测试或新的通用流程。
