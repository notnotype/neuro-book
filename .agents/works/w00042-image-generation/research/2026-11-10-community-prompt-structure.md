# 社区提示词的结构：法典图鉴数据统计

2026-11-10，w00042。开发者要求在设计工作台之前先积累经验：看社区写的提示词大概是什么结构。数据来自[法典图鉴](https://novelai.quicktagcloud.com/)公开发布的数据（2026-11-07 的版本）。这份数据的词条与汇编结构不许再分发，所以本文只写统计与结论；下面的示例都是按同样结构自己编的，不是原文。原始数据、统计脚本与完整输出只留在本地 `.local/agent/works/w00042-image-generation/research/qtc-2026-11-07/`。

## 结论

1. **一条完整的提示词分成几节，最常见的顺序是：主体数量、画风、质量、内容。**画风这一节由三部分组成：带权重的画师串、年份、负权重压制。多角色时，内容大多写进角色提示词。
2. **社区已经在自己造“节”。**一半的 V5 提示词用空行分节；有人写 `<style>…</style>` 这类标记，有人写 `//` 注释。原因是输入框里没有分节的办法。
3. **画风串是最主要的复用单位。**它被整段复制到很多张图里，法典图鉴的数据也把它存成“画师加权重”的列表。
4. **权重已经是“数值”的思路，不再数括号。**V5 的加权标签里，数值写法约占 94%。负权重很常见：73% 的 V5 提示词用了，主要用来在正面提示词里压掉某种画风。
5. **负面提示词是个人预设，各自改着用。**它们很长（V5 中位 74 个词）。3488 条里有 1460 种不同的负面；一半以上写了要避开的画师。
6. **法典里的是片段，不是整条提示词。**一个词条中位 16 到 18 个词，按用途分类；编者在备注里说明哪几个词是核心、哪些是陪衬。
7. **噪声很多。**常见的有：同一条里重复的词（V4.5 有 46% 的条目）、下划线写法、SD 的写法与习惯词、括号或权重没闭合、把界面设置当成标签写进去。

图包的分级以成人为主（V5 图包里成人与猎奇两级合计 73%）。这里只统计结构，不看内容。

统计方法：按 NovelAI 的强调规则切分标签（花括号与方括号每层乘或除 1.05，`数值::…::` 算数值权重，单独的 `::` 算结束），再用 tagcomplete 的 `danbooru.csv` 分类（画师、角色、作品、通用、元）。质量、美学、复杂度、年份与主体数量（`1girl`、`solo` 等）另列一类。“画师”包括 `artist:` 前缀与 Danbooru 的画师类标签，有误判，数字是近似值。

## 一条完整提示词的结构

两个图包的统计（V5 / V4.5）：

| 部分 | 出现的条目 | 在提示词里的位置（0 是开头，1 是结尾，中位） | 说明 |
|---|---|---|---|
| 主体数量 `1girl, solo` | 64% / 81% | 0.06 / 0.13 | 几乎总在最前 |
| 画师 | 94% / 91% | 0.20 / 0.21 | 中位 8 位画师，P90 16 到 17 位；每位带权重，V5 的画师权重中位 0.8，常见 1.0、0.5、0.8、0.7 |
| 年份 `year 2025` | 84% / 58% | | 常常写两三个年份 |
| 负权重压制 | 73% / 46% | | 例如 `-1::artist collaboration::`、`-2::multiple views::`、`-1::flat color::` |
| 质量、美学、复杂度 | 95% / 93% | 0.55 / 0.58 | 常在画风之后，也有放最后的 |
| 场景、构图、动作 | 绝大多数 | 0.6 以后 | |
| 自然语言句子 | 25% / 19% | 0.79 / 0.73 | 放在后面 |

按各部分第一次出现的顺序归类，最常见的几种是：

- 主体数量 → 内容 → 画师 → 质量 → 负权重
- 画师 → 质量 → 主体数量 → 内容 → 句子（V4.5 最多，533 条）
- 主体数量 → 画师 → 质量 → 内容 → 负权重

NovelAI 文档推荐的顺序是“`1boy, 1girl`、角色、作品，其余任意”。社区保留了主体数量在前，但几乎都把画风这一节放在内容前面。

**多角色的时候，内容进了角色提示词。**V5 图包里 78% 的条目带角色提示词，每条的角色数是：1 个 1254 条，2 个 873 条，3 个 347 条，最多 16 个。在带角色的条目里，15% 到 20% 的主提示词几乎只有画风与质量，人物、动作都写在角色里。角色提示词的写法：

- 第一个词多半是 `girl` 或 `boy`（V5 约 75%，V4.5 约 85%）；
- 接着是角色名（作品）。34% 到 46% 的角色提示词写了 Danbooru 的角色标签；
- 再往后是外貌、服装、动作，中位 10 到 11 个词；
- `source#`、`target#`、`mutual#` 只有 2% 到 3% 的角色用。

按结构自己编的一个例子（三行之间是空行）：

```text
1girl, 1boy, solo focus

0.8::artist:甲::, 0.5::artist:乙::, 1.2::artist:丙::, year 2025, year 2024
-1::artist collaboration::, -2::multiple views::, -1::flat color::

very aesthetic, masterpiece, high complexity, night, harbor, fog, from side

角色 1：girl, 某角色 (某作品), long hair, red scarf, holding envelope, target#giving
角色 2：boy, short hair, round eyewear, vest, source#giving
```

## 社区自己造的“节”

- **空行分节**：52% 的 V5 提示词（V4.5 是 31%）写了三行以上，每行一类。按行归类，最常见的是“画师 / 内容”“内容 / 画师 / 质量”“画师 / 质量 / 内容”。
- **分段标记**：6% 的 V5 提示词用 `<style>…</style>` 一类的标记包住画风。nai-atelier 的“一键整理”也认 `<artist>`、`</style>` 这类分段标记，说明这不是个别人的习惯。
- **注释**：少数人用 `//` 写注释，例如在画风后面写一句中文说明。NovelAI 不认注释，这些字会原样进入提示词。
- **伪结构标签**：漫画分格的提示词里出现 `top panel: …, middle panel: …, bottom panel: …` 这种写法，用文字给每一格分节。

## 权重怎么写

| | V5 图包 | V4.5 图包 | 所长 N4.5 法典 |
|---|---|---|---|
| 数值写法 `1.2::…::`（按标签计） | 60,493 | 85,634 | 5,486 |
| 花括号 | 3,514 | 16,799 | 10,476 |
| 方括号 | 720 | 14,383 | 385 |

- 写法在随时代变化：较早的法典以花括号为主，V5 图包几乎全用数值写法。V4.5 时期的常见倍率里还有 1.05、1.1、1.16、0.95、0.91，说明当时还在数括号层数；V5 的常见倍率是 2、-1、0.5、1.5、0.8、-2、-3，都是整齐的数字。
- 负权重在 V5 图包里出现在 73% 的条目，最常见的是 -1、-2、-3。
- 单独的 `::` 用来提前结束权重，V5 图包里出现 2,435 次。
- 数值权重没闭合的：V5 2%，V4.5 6%。NovelAI 允许这样写（权重延续到结尾），但多数看起来是漏写。
- 用了 SD 写法 `(tag:1.2)` 的约 2%。NovelAI 把圆括号当普通字符，这种写法不起作用。

## 负面提示词

- 几乎每条都有。长度中位 74 个词（V5）、48 个词（V4.5）。
- 不同的负面很多：V5 的 3488 条里有 1460 种，最常见的一种只用了 53 次。大家从几份流传的“标准负面”出发，各自增删。
- 56%（V5）、22%（V4.5）的负面写了画师名，用来避开某些画风。
- 最常见的词：`lowres`、`worst quality`、`jpeg artifacts`、`very displeasing`、`bad quality`、`artistic error`、`logo`、`scan artifacts`、`chromatic aberration`、`dithering`、`halftone`、`film grain`、`blank page`、`multiple views`、`negative space`。

## 复用：画风串

把每条提示词里第一个主体数量或角色名之前的部分当作“风格前缀”。在 V4.5 图包里，1638 种前缀中有 310 种被两条以上复用，共覆盖 2139 条；同一种前缀最多复用了 1024 次（都在图包里同一个合集“AI 杂图”里）。V5 图包有 237 种被复用，共覆盖 773 条。

法典图鉴自己的画师串数据，存的也不是文字，而是“画师序号加权重”的列表。V4.5 的数据里有 2428 位画师、1610 串。

## 法典里的片段

- **片段不是整条提示词**：所长 N4.5 法典的词条中位 16 个词，N5 中位 18 个词，几乎不含画风与质量词（只有 2% 到 9% 的词条写了）。
- **按用途分类**：一级分类是场景（3141 条）、服装（1593 条）、人外种族（392 条）、自然语言（340 条）、群友处收录、原创角色杂项、风格。
- **核心词与陪衬词**：编者在备注里写哪几个词是核心，例如“这两个动作词是本法的核心，搭配其他词可以实现更多构图”。核心词常加权重。
- **单标签图鉴**：渡鸦的构图鉴一条只有一个标签，配中文解释与难度星级，例如“及膝袜：长度到膝盖附近，更高一些用另一个词”。
- **自然语言片段**：V5 时期的写法是一整段英文。顺序大致是：整体画风，谁在哪里做什么，镜头角度，每个人物的位置（左、右）、外貌、服装与手势。

## 噪声

| 现象 | V5 图包 | V4.5 图包 | 共创广场 |
|---|---|---|---|
| 同一条里有重复的词 | 34% | 46% | 66% |
| 下划线写法（`looking_at_viewer`） | 43% | 59% | 74% |
| 含中文 | 5% | 1% | 24% |

其它常见的：

- SD 时代的习惯词：`8k`、`4k`、`highly detailed`、`detailed eyes`。
- 不在 Danbooru 里的描述词当风格词用：`simple illustration`、`cel shading`、`clean lineart`、`soft shading`。
- 把界面设置当标签写进去：`Variety+`。
- 连续逗号、全角逗号、多余的引号。

## 对工作台的启发（待讨论，不是决定）

1. **节可以是一等公民**：画风、质量、主体、场景、每个角色、负面各是一节，可以单独收起、换掉、存成片段，生成时拼成一串。社区现在靠空行和 `<style>` 标记模拟这件事。
2. **画风串单独成一类对象**：它包括画师加权重、年份、负权重压制，配一张样图。可以试“内容不动、只换画风”的抽卡：同一个种子，换几套画风并排比。
3. **权重按数值编辑**：用倍率加滑块，负权重要一眼看得出。花括号只作为读进来的旧写法保留。
4. **负面是带版本的个人预设**：界面显示与预设相比改了什么（第 1 轮静态稿里的“预设 Heavy · 另加 3 个词”就是这个意思）。
5. **角色提示词可以从设定生成**：固定开头 `girl`/`boy`，接角色名与外貌。这正是 t11 角色视觉档案可以自动填的部分。
6. **提示词体检**：检查没闭合的权重、SD 写法、下划线、重复的词、中文、未收录的词、界面设置混进提示词。这些都能在本地查出来，不用调模型。
7. **片段区分核心词与陪衬词**：片段带备注与样图；用途分类与文件夹分开（nai-atelier 也是这样做的）。
8. **自然语言一节按固定顺序写**：整体、人物与动作、镜头、每个人物的位置与外貌。可以交给生图管线（t10），从章节内容生成。
