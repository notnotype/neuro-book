## 怎么改的

第 5、7、8 条根因相同：词与句子的文字里，能混进在 NovelAI 里另有含义的写法。所以不逐处补，收成一道数据规则：
- **词：**不许有分隔符、括号、`||`、`::`、`Text:`，也不以 `@{` 开头。
- **句子：**不许有 `||`、`::`、`@{`、`Text:`，括号要配对。
- **句子在哪里结束：**遇到数值权重的开始或结束、随机项、片段引用、`Text:`，句子在它前面结束。
- **原文段：**不自成一段时，展开失败。

按 SD 读法读出的词里有这些写法时，整段按原文保存，新诊断 `reserved-text`。
