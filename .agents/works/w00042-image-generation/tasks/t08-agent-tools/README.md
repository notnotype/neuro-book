# Agent 工具

## 目标与范围

让 Agent 能检索与校验标签、读写预设、发起生成、检索图片资产；检索条件与界面共用一套结构。

优先做校验：Agent 写出候选标签，工具判断是否存在、归一化别名、给出热度与相近标签。LLM 本身认识多少标签是推断，要实测。合同：待补充。

## 当前状态

2026-11-06 经 nbdev 新建，尚未开工。

2026-11-18 范围加了两样（[Work 决定](../../README.md#决定)）：

- 标签效果记忆表：固定种子、只换一个词，记下这个词影响画面的哪一部分，例如 `collar` 几乎只改衣领。
