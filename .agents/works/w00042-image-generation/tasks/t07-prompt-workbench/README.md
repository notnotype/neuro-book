# 提示词工作台

## 目标与范围

用户搭提示词加抽卡的界面：词库、片段组装、原文与标签块切换、结果与种子；先按 design-review 出静态稿，开发者看过再实现。

可借鉴的交互见[调研的法典图鉴一节](../../research/2026-11-06-tag-sources-and-novelai.md#法典图鉴)、NovelAI 的 Prompt Chunks，以及开发者 2026-11-09 推荐的 [nai-atelier](https://github.com/HelloQun54321/nai-atelier)（MIT）：原文加中文对照、同一层括号的几个词合成一个组框、生成前显示费用、片段按固定用途分类。合同：待补充（t03）。

## 已定

2026-11-09 会话里定（开发者“其他都先同意”）：

1. 注意力排序：提示词在左、结果在右，各占一半；结果默认显示最近一批的大图。
2. 词库常驻、做成窄栏；打字时的标签联想在提示词框里弹出，不依赖词库栏。
3. 参数只露一行摘要，点开才展开；负面提示词收成一行（预设名与另加的词）；历史是结果区底部的一条缩略图带，点一批恢复当时的配方。
4. 窄屏时词库变成抽屉；看大图时进灯箱。
5. 工作台是编辑区里的一个标签页，一个标签页一份配方，不做独立页面。
6. Agent 不嵌进工作台，留在对话视图里经工具读写。
7. 静态稿按 NovelAI 的形态画；SD 或 ComfyUI 缺的部分在稿上标出。

2026-11-10 评审板答复（第 2 版）：

8. 标签显示为标签块：一词一块，下面一行中文，权重写成倍率，同一层括号的几个词合成组框；每个提示词框可以切回原文（问题 1）。
9. 词库放在外壳的侧栏，和资源管理器换着用（问题 2）。
10. 提示词区按节组织：主体、画风、质量、场景与构图、自然语言、角色、负面，生成时按节的顺序拼成一串；套了预设的节默认收起成一行（问题 3）。
11. 套用预设以后是引用加差异（问题 4，开发者 11-10 在会话里说“按推荐来”，主会话代录）：配方记用了哪个预设、在上面改了什么；预设更新后，没改过那几项的配方跟着变；可以还原、另存为新预设或把改动写回预设。历史批次存拼好的整串，不受以后预设改动的影响。
12. 下一步出第 3 轮静态稿：参数展开、片段页、窄屏，加上“内容不动、只换画风”的对比抽卡（同日“按推荐来”）。

2026-11-10 评审板答复（第 3 版）：

13. 窄屏（390 宽）用分段切换：“提示词”与“结果”各占整屏，生成后自动切到结果；词库是底部抽屉（问题 5）。
14. “只换画风”的对比抽卡第一版不做（问题 6）。开发者的批注：绝大部分情况下用不上对比抽卡。要比画风时，固定种子、换一个画风预设再生成一次。
15. 开发者同一次答复的附言：最关键的是预设和标签系统。后面的设计与 Spec 把这两块放在最前面。

- 第 3 轮：窄屏用分段切换还是上下叠放；“只换画风”的对比抽卡第一版做不做。
