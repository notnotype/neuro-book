# 提示词工作台

## 目标与范围

用户搭提示词加抽卡的界面：词库、片段组装、原文与标签块切换、结果与种子；先按 design-review 出静态稿，开发者看过再实现。

可借鉴的交互见[调研的法典图鉴一节](../../research/2026-11-06-tag-sources-and-novelai.md#法典图鉴)、NovelAI 的 Prompt Chunks，以及开发者 2026-11-09 推荐的 [nai-atelier](https://github.com/HelloQun54321/nai-atelier)（MIT）：原文加中文对照、同一层括号的几个词合成一个组框、生成前显示费用、片段按固定用途分类。合同：待补充（t03）。

## 已定

2026-11-09 会话里定（开发者“其他都先同意”）：

1. 注意力排序：提示词在左、结果在右，各占一半；结果默认显示最近一批的大图。
2. 词库常驻、做成窄栏；打字时的标签联想在提示词框里弹出，不依赖词库栏。
3. 参数只露一行摘要，点开才展开；负面提示词收成一行（预设名与另加的词）；历史是结果区底部的一条缩略图带，点一批恢复当时的配方。
4. 窄屏时词库变成抽屉；看大图时进灯箱。
5. 工作台是编辑区里的一个标签页，一个标签页一份配方，不做独立页面。
6. Agent 不嵌进工作台，留在对话视图里经工具读写。
7. 静态稿按 NovelAI 的形态画；SD 或 ComfyUI 缺的部分在稿上标出。

2026-11-10 评审板答复（第 2 版）：

8. 标签显示为标签块：一词一块，下面一行中文，权重写成倍率，同一层括号的几个词合成组框；每个提示词框可以切回原文（问题 1）。
9. 词库放在外壳的侧栏，和资源管理器换着用（问题 2）。
10. 提示词区按节组织：主体、画风、质量、场景与构图、自然语言、角色、负面，生成时按节的顺序拼成一串；套了预设的节默认收起成一行（问题 3）。
11. 套用预设以后是引用加差异（问题 4，开发者 11-10 在会话里说“按推荐来”，主会话代录）：配方记用了哪个预设、在上面改了什么；预设更新后，没改过那几项的配方跟着变；可以还原、另存为新预设或把改动写回预设。历史批次存拼好的整串，不受以后预设改动的影响。
12. 下一步出第 3 轮静态稿：参数展开、片段页、窄屏，加上“内容不动、只换画风”的对比抽卡（同日“按推荐来”）。

2026-11-10 评审板答复（第 3 版）：

13. 窄屏（390 宽）用分段切换：“提示词”与“结果”各占整屏，生成后自动切到结果；词库是底部抽屉（问题 5）。
14. “只换画风”的对比抽卡第一版不做（问题 6）。开发者的批注：绝大部分情况下用不上对比抽卡。要比画风时，固定种子、换一个画风预设再生成一次。
15. 开发者同一次答复的附言：最关键的是预设和标签系统。后面的设计与 Spec 把这两块放在最前面。

2026-11-10 评审板答复（第 4 版）：

16. 标签系统第一版做五样：打字联想、标签块上的操作，加上体检、粘贴拆到各节、相近的词（问题 7，开发者三样全选；主会话原先只推荐体检与粘贴拆分）。相近的词要词库带“哪些词常一起出现、哪些词是一组”的数据，t05 要把它放进第一版，并先解决来源与授权。
17. 预设和片段跟书走，另有跨书的“我的书架”：配方只引用本书里的；从书架拿一个到书里用，是复制一份进来；官方的预设每本书直接可用，只读（问题 8）。
18. 第 4 轮里照推荐画、没有单独问的几条，开发者答题时没有提出异议，按已定处理：
    - 打字联想里中文、英文、别名都能搜，片段在同一个列表里；选到属于别的节的词（例如画师），放进它该去的节。
    - 标签块的权重按数值改，可以是负数。
    - 预设的内容在配方里改，点“更新预设”才写回，不另做预设编辑器；侧栏的预设页只做管理（改名、复制、放到书架、删除、看用在哪）。
    - 更新预设前列出受影响的配方：没改过那一项的跟着变，自己改过的保持自己的值。
    - 新配方从“本书默认”开始（四个预设各指定一个）；第一版只有一组，封面、立绘要另一套起点时再扩成几个模板。
    - 预设记着它是在哪个模型上调的；配方换了模型，对不上的节上提示一句，不拦。
    - 画风预设的样图从结果里挑一张，不单独生成。
    - 从历史恢复配方时仍然引用原来的预设，差异按当时的内容重新算。

2026-11-10 产物管理与模型灵活度的讨论（开发者“都按推荐”，全文记在 [t03](../t03-core-contracts/README.md#产物管理与模型灵活度2026-11-10-开发者都按推荐)）改了上面几条：

19. 改 3：点历史里的一批只看那批图，恢复配方另按一个按钮，先显示差异。
20. 改 10：节是有序列表，同一种节可以有几个、可以起名，另加“通用”节；“场景与构图”改名“内容”；负面分官方段、我的负面、要避开的画师三节。粘贴默认按原文段落分节、保住词序。
21. 改 17：“我的书架”改名“我的预设库”。
22. 补 18：风格组合进第一版，“本书默认”就是默认的那一组；画风预设的样图在预设里存缩小副本。

2026-11-18 开发者选“组”就是节（[Work 决定](../../README.md#决定)）：

23. 界面上把节叫“组”，预设叫“存进库的组”，数据不改。服装这类内容组要在几份配方里复用，用片段。角色框有位置；氛围迁移可以放进画风组。精确参考里有角色参考，不一定归画风组，放在哪里等 t02 测出参数再定，界面也等那时再画。

各轮问了什么：

- 第 3 轮：窄屏用分段切换还是上下叠放；“只换画风”的对比抽卡第一版做不做。
- 第 4 轮：体检、粘贴拆到各节、相近的词哪几样进第一版；预设和片段存在哪里。

草稿在 `.worktree/w00042-t07-drafts`（分支 `w00042-t07/drafts`，不合并、不推送），组件在 `packages/neuro-book/src/plugins/drafts/web/components/prompt-workbench/`，Lab 里是 `PromptWorkbenchDraft` 的各轮场景（场景 id 以 `q1-`、`q2-`、`r2-`、`r3-`、`r4-` 开头）。

搭稿时发现、记给 t03 与 t05 的：

- Token 计数要按模型的分词器算；片段在原文里的写法未定；角色提示词只有 NovelAI 有；NovelAI 专用写法（`girl`、`source#`）要进词库基础层。
- 第 4 轮：词库的中文名不能只是可选包（t05 写的是“中文层作可选包”，而标签块下面那行中文与中文联想都靠它）；打字联想可以直接用 nb-ui 的 SuggestionMenu，它的次要文字是纯文字，高亮命中的字要加参数；体检与粘贴拆分要提示词的语法切分（t03）、词库的类别与特殊词表（t05）；历史要按节存拼好的内容才能恢复到各节（“已定”11 写的是整串，写 Spec 时改成按节）；NovelAI 图片里的元数据可以走同一张拆分预览，进不进第一版写 Spec 时再看。
