# 标签库

## 目标与范围

建本地标签库：Danbooru 基础数据并入 NovelAI 官方特殊标签与改名表，支持别名、中文名检索与校验；suggest-tags 作在线增强；语义搜索与中文层作可选包。

来源见[调研](../../research/2026-11-06-tag-sources-and-novelai.md#标签来源)。合同：待补充。

- **中文名不能只是可选包。**标签显示为标签块、下面一行中文（8），打字联想可以用中文搜（18），都靠中文名。“目标与范围”里写的“中文层作可选包”要改成第一版必带；语义搜索仍然可选。
- **“相近的词”进第一版（16）。**选中一个标签，要列出能换上去的近义词或同组词，词库得带“哪些词常一起出现、哪些词是一组”的数据。调研里看到的共现数据（DanbooruSearch 的 NPMI）授权没有确认，要先定来源：Danbooru 自己的标签组与相关标签、自己从公开数据算，或另找有授权的。
- 体检与粘贴拆到各节（16）要每个词的类别（画师、角色、作品、通用、元）和特殊词表（质量、年份、主体数量），这些本来就在基础层的范围里。
