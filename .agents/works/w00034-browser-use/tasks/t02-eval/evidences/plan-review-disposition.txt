审查者：Claude Sonnet 子代理（reviewer），2026-11-26，只读，带本机实验（脚本留在本地 reports/plan-review/scratch/），报告见 plan-review.txt。
发现 23 条：阻断 2（2、5）、重要 14、建议 7。全部成立；计划第二稿按下表改。主会话没有逐条重跑审查者的实验，以它附的实验脚本与源码行号为据（第 22 条是推断，靠试飞验证）。

1. 隔离可绕过（用户总线、Chrome 的 file://）：成立。沙箱加 --tmpfs /run；Chrome 也进沙箱（--tmpfs $HOME，只绑它的临时配置）；起不来时先试 --no-sandbox，仍不行就把“执行者能经 CDP 读本机文件”写进未验证边界。测试补“连不上用户总线”“经 CDP 打不开 .env”。
2. 取消通道缺失，terminate 几十毫秒杀掉沙箱（阻断）：成立。改由 browser-use 自己的 run(timeout=时限) 到点收尾，调度器在时限加 90 秒才兜底 terminate；计时起点改为执行者连上浏览器后发出的 ready 事件；每个步骤事件到达就追加写 progress.jsonl。
3. 两个端口同在 127.0.0.1 不跨站，iframe 不是独立目标：成立。编辑器源写成 http://localhost:<端口>，测试断言有 iframe 目标。
4. Bun.serve 缺省监听所有网卡、假密钥没写拒绝：成立。网关与假站都绑 127.0.0.1；假密钥用 randomUUID，未登记的回 401 不转发。
5. 网关 10 秒空闲期限掐断非流式请求（阻断）：成立（仓库 TypeScript 规范也写了这条）。每个请求 server.timeout(req, 0)，上游 fetch 带 AbortSignal.timeout；测试加“上游延迟 11 秒仍交回”。是否改成对上游流式：先不改，524 多了再说（写进风险）。
6. 每题次数公式只保证半宽、5 次估方差偏低、T 不是将来的题数：成立。报两个数：半宽法与 80% 功效法（推荐后者）；各给 T=8 与 T=24；全同分的题单列，并给记 0 与保守下界两种结果。
7. 流程凭据的消耗时机：成立。凭据绑定弹窗或组件实例，只在写入生效时消耗，4xx 不消耗；条目证据写明测的是“按页面协议取过凭据”。
8. 回答解析、富文本比对、forum-verify 的条目没定义清、只有一题对过真实输出：成立。定义 parseAnswer 与每题的比对规则；富文本在服务端按 innerText 语义转纯文本；forum-verify 改成“打开过精华区（20）、以‘无法完成：’开头（40）、没有‘答案：’行（40）”；正式运行前加试飞（8 题 × 3 模型 × 1 次）人工核分。
9. 真 Chrome、真 bwrap 的用例会进默认测试与 CI，fixed-wait、llm-credential 规则会拦：成立。这类用例命名 *.live.test.ts，NBOOK_EVAL_LIVE=1 才跑，包脚本 eval:live；测试规范的“测试分类与运行”登记这一类；网关路由由参数注入，测试不读环境变量；要等被测程序自己时限的用例写 test-lint-allow 说明。
10. worktree 里没有 .env、.env 是 CRLF：成立。--env-file，缺省按 git common dir 找主工作区的 .env，去回车与引号，缺文件与缺键分别报错。EXTREMELYCAT_API_KEY 已由主会话写入（前置条件）。
11. CDP 调用没有逐次时限、对话框让截图不返回：成立。cdp.send 带 timeoutMs；截图超时记为丢帧，不算评测部件出错；收尾每步各有时限。
12. --lang 不固定页面语言、env 整体替换：成立。改用 --accept-lang=zh-CN；Chrome 的环境只给 PATH、HOME（临时目录）、TZ。
13. Gemini 与 browser-use 的真实请求形状要到正式运行才相遇：成立。probe 改用 browser-use 自己的路径跑最小题，挪到第 5 片；推理档的 medium 改 high 规则写清；试飞在正式运行前。
14. 上游 429、5xx、524、重置被计成执行者的失败：成立，收窄。网关记上游结果；运行以出错或超时结束且网关记到上游失败（5xx、524、重置、超时、连不上）时记 infra-error，不计分、重跑（每格最多 3 回）。这在设计稿“网关连不上上游才重跑”的意思之内，主会话自己定，交付时告诉开发者。没采纳：网关对上游重试（会改变两边执行者看到的失败）；429 不算上游失败，只计数。
15. 代理写法矛盾（Bun fetch 默认读环境代理，proxy: "" 关不掉）：成立。每条上游显式写 proxy：luna 为 false，extremelycat 取环境代理，缺了起手报错；测试用非回环网卡上的假上游与假代理，并做变异。
16. 原样转发 content-encoding 会让下游解压出错：成立。请求只带白名单头并设 accept-encoding: identity；回给执行者时去掉编码、长度、连接与 set-cookie 头；测试加 gzip 用例。
17. 运行记录的几处合同没写：成立。写进计划：结局表、步骤用事件顺序号、种子进任务定义与任务集哈希、try-<n> 目录与续跑、job/workspace/executor 三个绑定目录、标准输出只认带 schema 的 JSON 行。
18. 正式运行没有时长、费用与止损：成立。网关加单次运行预算；run 加整批止损；试飞量出单次用量后估算，超过 50 美元先问开发者。
19. 工作目录真实路径进系统提示：成立。沙箱里固定绑到 /work。
20. Chrome 退出一律算评测部件出错：成立。退出码 0 归执行者（browser-lost）；被信号结束且调度器没发终止才归 harness-error。
21. 与设计稿对照漏了五处：成立。补允许的写入清单、安全计数、两类自检样本、步骤的页面目标、收尾时限与计时起点。
22. Gemini 多轮工具调用的思考签名（推断）：成立为风险。probe 的最小题走到第二次请求；不兼容的先报开发者，不换接法。
23. 下载目录的设置随连接消失、第一阶段不下载：成立。第一阶段不做下载，运行记录只留字段。
