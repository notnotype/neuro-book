5. NestedGrid.md 里写了、Spec 没有、我留在 NestedGrid.md 的行为句子
========================================================================

这些是行为，不只是用法。按“Spec 没有的留在组件文档”处理，没有加进 Spec（不加输出条目）。要不要升进 Spec 作者定：

- 交换：交换开始之后才挂上来的内容项按它的叶属于哪一组裁，但从终点出现（已知限制）。
- 交换：滑出去的分隔线不再问宿主的 `sashKind`、`sashStyle`，沿用离开前最后一次的结果。
- 交换：裁切窗应当等于两组静止时的外观，过渡结束那一帧摘掉裁切。
- 交换：组里的分隔线两侧尺寸冻结在离开前。
- 过渡：不给 `leafShape` 时按外框的矩形裁，卡片在不动的那边被直着切掉。
- 过渡：内容外层在过渡中按叶的矩形摆（`data-by-leaf`），面板头那一条用 `clip-path` 裁掉且不挡面板头的指针；宿主在过渡中量内容外层量到的是叶的矩形。
- 内容层：拿起的内容落进已有的叶时，那块叶上一帧显示着的内容留在卡片下面（`inert`、不接指针），过渡结束才停放；落进这次才出现的叶时，外框和手柄也从卡片的矩形一起长到终点。
- 浮动窗：摘掉 `data-float` 的那一刻外框还带着 `data-moving`。
- 手势：接纳后宿主应发布与提交匹配的新 `layout`，否则下一 tick 回到已发布布局并报告问题。这一句是交互合同，按 README 应在 Spec“时序与寿命”；我没有搬，因为现行 Spec 没有，搬就是新增合同。建议你定。
