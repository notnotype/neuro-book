# nb-story 并排看卡片

## 目标与范围

开发者 2026-11-22 定（问“nb-story 改造做到哪一步”时选“加并排看卡片”）：nb-story 右侧详情可以再开一张卡片并排对照，卡片能拖到左右两半，nb-story 自己检验 nb-layout 的拖动公开面（ADR 0054 第 8 条：第一个外部使用方）。这是 nb-story 的新功能，按 [design-review](../../../../skills/design-review/SKILL.md) 先出静态稿、在评审板上定外观与交互，再写 Spec 与计划。

合同：会改 [`story/viewer`](../../../../../docs/specs/story/viewer.md)（右侧详情的输出条目），定稿后写。

## 决定

评审板第 1 轮（v1），开发者 2026-11-22 在面板上答复，四题都按推荐：

1. **并排时右侧详情多宽**：两张卡各保持原宽，右侧详情加宽（1440 宽的窗口里正文从 850 缩到 450）；关掉一张回到一张卡的宽度。
2. **第二张卡从哪里打开**：Ctrl（Mac 上 ⌘）点名字，开在另一半，已经并排时换掉另一半那张；名字与关系图的点上右键“在旁边打开”（名字现在没有右键菜单，新加）。拖名字进来不做。
3. **两张都开着时普通点名字换哪一张**：最近点过的那一张（点过、滚过或在里面点过名字的算最近）；卡片里的名字换它自己那张。
4. **拖卡片换边的样子**：同意。按住卡片头拖，被拖的卡缩成名字跟着指针，要放的那一半盖一层落点指示，松手两张对调。

评审板上“直接做，不用答”的八条一并定下：最多两张；拖到另一半对调、放回自己那一半不动、Esc 取消；两张中间有能拖的分隔条；关掉一张剩下的占满；窄窗口（详情浮起、手机）不并排，只显示最近点过的那一张，放宽后两张回来；人物卡、原文、段落、图节点四种详情都能放进任一半；地址栏记两张；拖动先做落点指示，实时让位等 t49。
