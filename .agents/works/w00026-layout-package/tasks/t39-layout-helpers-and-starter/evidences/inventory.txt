## 2. `createDragSession` 的生命周期

4 个调用方，两种写法。

- **工作台**：`createLayoutDrag`（`workbench/web/layout-drag.ts`）在 `:980` 调 `createDragSession`，`:1123-1132` 包装 `dispose`。`WorkbenchShell.vue` 用 `shallowRef` 持有（:738），`onMounted` 里用 `hostEl.value!` 创建（:739-770），`onBeforeUnmount` 里销毁（:771）。不处理换根。
- **Explorer** `explorer/web/components/ExplorerTree.vue`：`gesture` 是 `shallowRef`（:256）。`onMounted` 里 root 为空就返回，否则创建（:301-326）；同一个 `onMounted` 里还有一个 `watch(gesture.value.state, …, {flush: "sync"})`，没有显式停止。`onBeforeUnmount(() => gesture.value?.dispose())`（:327）。
- **Lab** `lab/web/fixtures/nb-layout/DragSessionScene.vue`：`session` 是 `shallowRef`（:45），`onMounted` 创建（:46-50），`computed` 读 `state`（:85），`onBeforeUnmount(dispose)`（:83）。
- **nb-layout** `src/vue/useSortable.ts`：`watch(options.root, (root, _prev, onCleanup) => …, {immediate: true})`（:214），创建（:221），`onCleanup` 里 dispose、移除 pointerdown、清空 session（:316-321）。这是唯一处理换根的调用方。

重复的样板：前三处同形，都是“ref 持有、挂载时建、卸载时 dispose、root 为空守卫”，每处 4 到 5 行；有两处再包一层 `state`（computed 或 watch）。`onScopeDispose` 没有在这里用过。`createDragSession` 要求 `root` 在建的时候就给（`src/vue/drag-session.ts:89`，`options` 是只读的一次性输入）。

推断（未核实）：`useSortable` 在组件卸载时靠 `watch` 的 `onCleanup` 销毁，这依赖 Vue 在卸载时停止 watcher 并执行清理。我没有在运行时验证。
