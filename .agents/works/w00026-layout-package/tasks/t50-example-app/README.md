## 结果

- 三个示例在 `packages/nb-layout/examples/`：`tabbed-panels`（标签编组）、`desktop`（浮动窗口的桌面）、`ide`（IDE 式的工具窗），各自独立、MIT、只经公开入口；nb-layout README 的“示例应用”一节与“我要做 X”表指过去。截图与摩擦记录汇总在[报告](artifacts/examples/index.html)（`nbdev artifact publish` 第 1 版）。
- 守着它们的：`typecheck` 检查每个示例（CI 的 `test:affected --typecheck` 会跑到）；`src/examples.test.ts` 核对导入只经公开入口、依赖、许可证、不引 Spec 编号；三个示例的模型单元测试；`test:e2e`（本机，48 条）；发布冒烟照第三方的装法装、类型检查、构建每个示例。
- 不好用之处：[摩擦记录](friction.md) 58 条，开头按根归成六组、排序并给了后续 Task 的候选，交开发者定做不做、先后。
- [行数](evidences/line-counts.txt)：标签编组去掉注释约 666 行，比体验审查的玩具（约 480）多，多出的是玩具没做的读档判据、试拆、读屏与键盘、焦点、样式；应用层与拖动适配与玩具相当。示例没有让第三方少写，它是一份能照抄、有测试守着的答案；少写要靠改库。
- 未验证：Vite 以外的打包器；触摸与笔的拖动；TS 6 下示例的类型检查（仓库与冒烟都装 5.9，只核过 `vite/client` 那一处）；动画只在 e2e 里断言了飞入的起点，其余靠截图与探针。
