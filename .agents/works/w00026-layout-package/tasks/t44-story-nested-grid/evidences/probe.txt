## 不同的（都已解释）
1. 主区与抽屉之间那条线的 aria-valuemin、aria-valuemax：改前是粗算的 360、1440，改后是网格算出的真实可达范围（例如宽屏 498、1008，收起时 1138、1288）。读屏取值更准；宽度本身相同。
2. 导航收起再展开：改前回到配置里的 188，改后回到收起之前的宽度（探针里先按 End 到 300 再收起，展开回到 300）。网格在收起那一刻记下要恢复的宽度（ui/nested-grid 输出 148）；导航宽度不进偏好，刷新后照旧 188。列为有意的差别 5。
3. 平板档：导航那条线改为停用（有意的差别 3）；多一条 0 宽、停用、Tab 落不上的“调整 main 与 drawer 的宽度”分隔线（审查第 6 条预料之内，库没有“叶隐藏但保留”的状态，记进接入记录）。主区宽度 979 与改前相同。
4. 关抽屉的第一帧（s12a）：改后抽屉里仍是刚关掉的人物卡、正跟着外框往右滑出（有意的差别 1）；改前那一张截到时抽屉已经收完。
5. 抽屉元素（aside）在收起后的宽度：改前 1，改后保持原宽、被宽 0 的叶外框裁掉，看不见、里面没有内容。
