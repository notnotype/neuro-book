# t25 计划：视图容器试用反馈

## Context

开发者 2026-11-12 在开发服务上试用 t24（视图容器第一步）后报了三个问题、要四处动画（一个一个来）。复现在 worktree `.worktree/w00026-t25-container-feedback`（分支 `fix/w00026-t25-container-feedback`），用临时 e2e 探针在真实浏览器里量：

| 反馈 | 复现结果 | 原因 |
|---|---|---|
| 1 拖走第一节再移回原处，不让位；松手回原处 | 回到原处判为“原位”，会话仍占满 842 高 | 照 [workbench-layout](../../../../../docs/specs/ui/workbench-layout.md) 输出 38“这一场不再展开”（Trellis）实现：收起后判定用收起后的几何，回到原处是原位，预览保持收起 |
| 1 松手后马上再拖，拖不起来 | 松手后约 150ms 内按标题落空，180ms 后正常 | 落回原位的过渡里外框还在飞，按下时指针下是别的元素，`sourceAt` 拿到的不是标题 |
| 2 动画时内容先于外框出来 | 切回容器时外框高 0→421 约 400ms，内容第一帧就是 340×389、可见 | 内容层与外框是兄弟元素；`enteringRects` 只给新出现的内容起点，停放过的内容算“已有”，一取消停放就在终点 |
| 3 右栏拖空后打不开 | 开关点了不写入 | t24 定的“空区域点显示零写入”；右栏、底部面板的入口条在第二步，拖空后没有别的入口 |

开发者 2026-11-12 的决定（会话里答复）：

- 回到原处要有预览：来源展开回原位、邻居让位（“松手后没问题，但是就没有预览了”）。
- 空区域能打开：开关照样打开，里面写“把视图拖到这里”，整块是落点，放下新建一个只含它的容器；拖空时照旧自动隐藏。
- 第二次拖不起来的情形是“松手后马上又拖”。
- 动画四处，一个一个来：设置窗口的关闭、侧栏展开、视图浮动、标签与容器切换（后一条是开发者同日追加的）。

## 关键设计

### 回到原处展开：`web/live-drag.ts`、`web/layout-drag.ts`

- `live-drag.ts`：来源已收起时，稳定下来的候选是原位（`offered.inPlace`）就展开：调宿主新加的 `expandSource(from)`，`collapsed` 清回假，预览换回已提交的文档（`show(null)`）。离开原处再停稳，按原来的规则再收起。标签条里的原位（`sorting`）现在已经显示已提交的样子，并进同一条规则。
- `layout-drag.ts`：收起时记下收起前的判定几何；`expandSource` 换回它，`sourceCollapsed` 清回假，清预览缓存，和收起一样记下展开那一刻的落点（`held`），指针再动才按展开后的几何重判。
- 影响：活动栏“自己的空位”、标签条“回到自己那条”与这条同一个判定，待确认清单里“收起后回到空位”的已知限制随之消失。

### 过渡中按下：nb-layout `src/vue/drag-session.ts`、`NestedGrid.vue`

- `createDragSession` 的选项加 `settleMotion?(): boolean`：按下时先调它，返回真（有过渡被走到终点）就按坐标重新取指针下的元素（`elementFromPoint`），再交给 `sourceAt`。
- `NestedGrid` 的 `settleMotion` 返回这次有没有停下进行中的过渡；工作台把它接进拖动会话。

### 内容跟着外框长出来：nb-layout `src/grid-motion.ts`

- `enteringRects`：内容项上一帧是停放的（不活动或没有矩形）、它的叶这一帧是新长出来的，和新内容项一样从叶的起点长出来。内容体保持终点尺寸，由内容项自己的裁切逐帧露出来，和外框同一个过渡。

### 空区域能打开

- 新 ADR（部分取代 [ADR 0046](../../../../../docs/adr/0046-workbench-view-containers.md) 决策 1 的“锚永远不进呈现树”）：区域显示着、里面一个分节都没有时，锚进呈现树，画成一块空面板；有分节时照旧不进。
- nb-layout：`isPanelShown` 对锚改成“没隐藏且区域里没有分节”；投影、落点枚举认这块空面板：整块是一个落点，放下是“在这个区域新建一个只含它的容器”（`sectionLanding` 挂在锚后面）。
- 工作台：`settleContainers` 只在这次提交让区域变空时隐藏锚（比较提交前后），不再每次都把空区域藏起来；`setPartHidden` 去掉 t24 的“空区域零写入”。空面板写“把视图拖到这里”，键盘落点同样有它。
- Spec：`ui/workbench-layout` 输出 11、22、43 与验收 8（原排在第二步，这里提前做空区域本身；底部面板与右栏的入口条仍在第二步）。

### 动画（每个做完给开发者看，确认后再做下一个）

1. 设置窗口（活动栏底部齿轮打开的覆盖窗）的关闭。
2. 侧栏从隐藏到展开（点活动栏入口）。
3. 视图变成浮动窗。
4. 标签切换：活动栏切换容器、标题头里切换标签。

每个动画开工前先看现状、定方案（时长与曲线用主题的动效令牌），减少动效时不播。

## 不做与风险

- 不做：右栏、底部面板的入口条（第二步）。
- 风险：回到原处展开后，判定几何在“收起后”和“拿起时”两份之间切换，指针在两份几何的交界处可能来回切；靠“停稳 150ms 才换”兜底，e2e 里慢速走过交界。
- 风险：锚进呈现树影响 F6 顺序、焦点落点、卡片相连等按“锚不显示”写的规则；片 3 前用 grep 列出读 `isPanelShown` 与锚的地方逐个过。
