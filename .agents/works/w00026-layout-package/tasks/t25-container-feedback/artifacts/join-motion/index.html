活动栏与侧栏分开、合上时接缝怎么动

侧栏收起、展开时，活动栏和侧栏相接的地方选哪种？

推荐丙（你提的）：角始终是同一对 12px 的圆角，只是跟着侧栏的右沿走，没有变形这一步；不用滤镜，开销和现在一样。

现在

角跟着变圆，缝和中间那条短线等侧栏缩到零才一下子出来；展开时一开始就没了。

甲 同步分开

角、缝、短线一起渐变，和侧栏同时走完。每帧开销：活动栏那一格的内边距在变，重排它这一小块（几个图标）并重绘；短线淡出只在合成层。

乙 水滴

甲加上接缝那一条画成液体：连着时是圆滑的凹角，侧栏缩成细条后从上下两头往中间收，像一滴水被吸回去；展开反过来鼓出一滴再拉开。每帧开销：甲的，加上接缝一条（约 30px 宽、整列高）的模糊滤镜重绘，静止时没有这一层。

丙 侧栏的角接过去

活动栏和侧栏一直是一张卡片在缩：侧栏右边那两个圆角跟着右沿往左走，收到底正好落在活动栏右边，成了活动栏的两个角；展开时活动栏的角被拉出去成为侧栏的右角。短线随着淡出、淡入。每帧开销：和现在一样，侧栏外框本来就每帧按卡片形状裁；只是收起时它往左多盖住活动栏右边 14px。
