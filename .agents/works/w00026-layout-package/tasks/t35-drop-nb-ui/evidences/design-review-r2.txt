### 1. 桥接写进 tokens.css，会被 SDK 的 docs/tokens.md 当成主题变量列给插件作者
**严重程度**：重要　**类别**：被破坏的既有约定
**位置**：计划“桥接：nb-ui 的 src/tokens.css”；`packages/neuro-book/plugin-sdk/pack.ts:311-323`、`:294-302`（cssTokens）、`:282-292`（DESIGN_GROUPS）

**现象**：
- SDK 构建的 `docs/tokens.md` 是“主题变量”清单，对插件作者说“用 var(--名字) 取这些变量”“主题可以覆盖”。
- 它由 `cssTokens` 读 nb-ui 的 `tokens.css` 与 `theme.css` 里所有 `--x: 值;` 生成。
- 桥接约 40 行进了 `tokens.css`，就全进这份清单。
  - `--nb-layout-panel-surface`、`--nb-layout-focus-outline` 这类落进“面与线的角色”。
  - 其余落进“其它”，缺省值栏写 `var(--sash-line-color)` 之类。

**为什么是问题**：
- 公开的作者文档被内部桥接名污染。
- 插件作者会照文档依赖 `--nb-layout-*`，而计划把它们定位成“一小批以外都标内部”。
- `pack.test.ts:214` 只断言 `--space-2`、`--accent-main`，不会报。
- 计划与 Task README 都没提这条通道。

**如何核实**：读 `pack.ts` 上面几处；桥接加完后跑 plugin-sdk 的构建，看生成的 `tokens.md`。

**建议改法**：
- 桥接放 nb-ui 里单独的样式文件（例如 `src/layout-bridge.css`），在 `tailwind.css` 里同样 `layer(base)` 引入。
  - `./tokens.css` 也是单独的导出子路径，要决定直接 `@import` 它的宿主要不要也拿到桥接。
- 或者让 `cssTokens` 跳过 `--nb-layout-`。
- 无论哪种，在 `pack.test.ts` 加一条“tokens.md 里没有 `--nb-layout-`”。
- “桥接放 `tokens.css`”写在已接受的提案与 ADR 0054 里，改位置要回写那两处。

### 5. 一致性与回退测试按字面写不出来，范围也没定

**位置**：计划“桥接”一致性测试、“变量改名”回退比对、“机检”；`packages/neuro-book-test-support/src/style-tokens.ts`；`nb-ui/src/components/token-consumption.test.ts`

  - 回退里有嵌套 `var`、`color-mix`、逗号（`--layout-card-shadow`）。

### 6. reduced-motion.css 不带 !important：第一轮第 8 条只处理了一半
**严重程度**：建议　**类别**：边界
**位置**：计划“减少动效”；`packages/nb-ui/src/tokens.css:262-289` 的注释

**现象**：
- 装了 nb-ui 时，桥接经旧名的归零（`!important`，在 `layer(base)`）已经让 `--nb-layout-motion-*` 为 0ms。`reduced-motion.css` 对这类宿主多余，只对不装 nb-ui 的宿主起作用。
- 那里宿主按 README 的变量表，在 `:root[data-theme=…]`（0,2,0）上声明 `--nb-layout-motion-layout`，就压过 `:root`（0,1,0）的归零，减少动效的人仍然看到 470ms。
- nb-ui 的注释明说“系统级无障碍偏好压过任意主题”，所以带 `!important`。

**建议改法**：
- 四个声明加 `!important`。不分层的重要声明只输给分层的重要声明，装 nb-ui 时两边同为 0ms。
- 与 e2e 里子树行内设值不冲突，因为重要性只在同一元素上比。

### 7. 类名清单漏了 nb-ui-drop-feedback*；变量扫描照字面会误报
**严重程度**：建议　**类别**：遗漏
**位置**：计划“自己的样式类”“变量扫描”；`DropFeedbackOverlay.vue:313-362,374-431`；`e2e/editor-area.e2e.ts:908`；`DropFeedbackOverlay.dom.test.ts:66`

**现象**：
- **类名**：计划只写改名 `nb-ui-drop-indicator*`。DropFeedbackOverlay 的根与子元素还有 12 处 `nb-ui-drop-feedback*`。样式类扫描要到第 4 片才发现，e2e 选择器 `.nb-ui-drop-feedback__line`（`editor-area.e2e.ts:908`）要同改。
- **BEM 误报**：变量扫描写“所有 `--[a-z]` 开头的名字”。
  - BEM 的 `nb-float-handle--bottom-right`、`nb-ui-drop-feedback__area--standby` 里的 `--bottom-right` 会命中。
  - nb-layout 的 5 个 `.vue` 里有 36 行含“字符--小写”的写法。

- **内部前缀**：`--nb-grid-inset`、`--nb-sash-core-*` 是 JS 行内写、自己读的内部变量，改前缀没有外部影响。“白名单为空最好”会逼出这些改名；可以允许 `--nb-` 内部前缀并写进扫描规则，省一轮改动。

### 8. 焦点环：外观与今天一样；放哪里、!important 保不保留没写
