# 视图容器第二步：右栏、底部面板的入口条与切换容器的动画

## 目标与范围

开发者 2026-11-16 试用 t25 后的两条原话：

- “左侧 ActivityBar 容器的切换动画，点击图片后怎么切换，我觉得可以做成上下滚动切换，具体也是可以先在评审版上做出来给我看看”；
- “底部的面板应该也是类似 ActivityBar 的那种容器（类似 vscode），切换应该是左右滚动切换。右栏也应该是和 ActivityBar 一样能切换容器的”。

所以有两件：右栏、底部面板的入口条（视图容器第二步，ADR 0046 留下的“入口条怎么进几何”）；三个区域切换容器时的滚动动画（从 t25 的动画 4 移过来，标签切换不在内）。先出评审板，定了再写计划。

合同：[`ui/workbench-layout`](../../../../../docs/specs/ui/workbench-layout.md) 输出 22（活动栏）、40 到 47（容器、入口、切换、入口条，47 是右栏与底部面板的入口条，现写“几何另行设计”）、输出 1 的默认树；[ADR 0046](../../../../../docs/adr/0046-workbench-view-containers.md)。动画按 [`ui/nested-grid`](../../../../../docs/specs/ui/nested-grid.md) 的“过渡”。

  - `switch-1` 切换时内容怎么滚：现在（按代码推的、没录屏）、甲 整块滚过去（推荐，470ms 布局曲线）、乙 推一小段加淡、丙 整块滚但 300ms 两头慢。
  - `indicator-1` 入口的选中标记跟不跟着滑：滑过去（推荐）、原地换。
  - `strip-1` 右栏、底部面板的入口条放在哪：甲 区域多一行头（VS Code 的做法，底部面板几节并排时这一行横跨几张卡片，要在布局里给整排留高度）、乙 放进第一节的头（推荐，不加新的一行、不进布局树）、丙 右栏右边一条活动栏（照“和 ActivityBar 一样”另画的，和 11-10 定的“放在各自的头上”不同，作为树上的条有提案里查出的六处冲突）。
