一个容器一张卡片，里面用线分开

活动栏 底部面板

“一个容器一张卡片、里面用线分开”用在哪些区域？

推荐侧栏、底部面板、右栏都这样，编辑组照旧一组一张卡片：工具区域里一个容器是一个整体，切换、隐藏都按容器；编辑组各自独立，拖、拆、关都按组。

侧栏、底部面板、右栏

三个工具区域都是一个容器一张卡片，几节之间一条两端缩进 10px 的线（侧栏、右栏横线，底部面板竖线）。编辑组照旧一组一张卡片、组与组之间是缝。侧栏这张卡片和活动栏一直连着，就是上面舞台的样子。

只侧栏和底部面板

右栏照现在一节一张卡片、节与节之间是缝。

编辑区也这样

几个编辑组共用一张卡片，组与组之间画竖线、横线。11-16 你说编辑组之间的竖线可以删掉，这一项等于把它画回来。

右栏、底部面板的入口条放在卡片顶上一行，还是第一节的头里？

推荐甲：入口条是卡片顶上一行，切换时它不动、只有下面的内容滚；当前容器只有一节时，那一节的标题和动作并进这一行，不多占高度。第 1 版你先同意的乙放在第一节的头里，现在一个容器一张卡片，乙的入口条会跟着内容一起滚走。

甲 卡片顶上一行

右栏：图标一行在卡片顶上，下面“对话”“引用”两节各有自己的头，中间一条横线。底部面板：标题一行横跨整张卡片，下面“问题”“修改建议”两节左右并排、各有自己的头，中间一条竖线。上面舞台里的底部面板就是这样，点“校对”看切换。

乙 第一节的头里

入口条画在第一节（右栏最上面一节、底部面板最左边一节）的头里，后面跟着这一节的标题；别的节的头只写标题。少一行，但切换容器时入口条在滚动的内容里。

卡片里的线旧外壳的开放式分割线（ui/workbench-shell 输出 38）：1px，沿长轴两端各缩进 10px，不碰卡片边；拖它照旧改两节的大小
侧栏和活动栏侧栏一张卡片，和活动栏一直连着（中间那条短线），几节也一样；隐藏、显示时卡片右边的两个角接到活动栏上，同 t25 的丙
切换时怎么滚照第 1 版选的甲：侧栏整张卡片上下滚，两个容器之间隔一条缝；底部面板、右栏的卡片和入口条不动，里面的内容左右滚
方向跟着入口条：活动栏点下面的入口内容往上走；底部面板、右栏点右边的往左走
点当前容器的入口区域可见就隐藏
