切换容器：怎么滚、入口条放在哪

活动栏 底部面板

点入口切换容器时，内容怎么滚？

推荐甲：整个容器像翻页一样滚过去，时长和曲线与侧栏显隐相同；滚动只动合成层，不每帧排版。

现在

旧容器一下子没了，新容器从侧栏上边往下露出来（按代码推的，没录屏）。底部面板现在没有入口条，只能用命令切换。每帧开销：外框的高在变，每帧重排这一列。

甲 整块滚过去

新旧两个容器上下（底部面板左右）挨着，中间隔一条缝，一起滚，470ms，先快后慢。点下面的入口内容往上走，点右边的往左走。每帧开销：两块各自平移，只在合成层。

乙 推一小段加淡

旧的往前推 32px 同时淡出，新的从后面 32px 处推上来同时淡入，前三分之一只有旧的在淡。方向同甲，走的距离短。每帧开销：平移加不透明度，只在合成层。

丙 整块滚、短而匀

同甲，但 300ms、两头慢中间快（cubic-bezier(0.4, 0, 0.2, 1)），收尾没有长尾巴，常切换时不拖沓。和侧栏显隐的时长、曲线不一样。每帧开销同甲。

入口的选中标记跟着滑过去吗？

推荐滑过去：活动栏的按下底色、底部面板标题的下划线和内容同时走、同一条曲线，眼睛能跟着从旧入口到新入口。

滑过去

上面几种候选（除了“现在”）用的都是这种。每帧开销：一个色块平移，只在合成层。

原地换

点下去旧的马上灭、新的马上亮，只有内容在滚（现在和 VS Code 都是这样）。

右栏、底部面板的入口条放在哪？

推荐乙：放进区域第一个分节的头里，不加新的一行、不进布局树；当前容器只有一节时（最常见）和甲长得一样。

甲 区域多一行头

VS Code 的做法：区域顶上一行写入口；当前容器只有一节时那一节的头并进这一行（右栏），有几节时下面每节再各有自己的头（底部面板的“项目”是两节，头叠成两行）。底部面板几节左右并排时，这一行横跨几张卡片，要在布局里给整排留出这一行的高度。

乙 放进第一节的头

入口条画在第一个分节（右栏是最上面一节，底部面板是最左边一节）的头里，后面跟着这一节自己的标题；别的分节的头照旧只写标题。区域只有一个容器时不画入口条，头和现在一样。

丙 右栏右边一条活动栏

照你这次说的“和 ActivityBar 一样”另画的：右栏右边贴一条和活动栏一样的图标条，切换上下滚；底部面板同乙。11-10 定的是“放在各自的头上”；这一条常驻占 48px 宽，作为布局树上的条有提案里查出的六处冲突要先解决。

例子样子
右栏两个容器：对话、通知（从底部面板移过来的），当前是对话，只有一节
底部面板两个容器：后台任务、项目（从侧栏移过来的，会话与资源管理器两节左右并排），当前是项目

直接做，不用答

哪里怎么样
方向跟着入口条：活动栏上下，点下面的入口内容往上走；底部面板、右栏左右，点右边的往左走。“更多”里的入口按入口顺序算
什么在滚只滚区域里的内容：侧栏的分节连同它们的头一起滚；入口条本身不动（活动栏、底部面板与右栏的头）
点当前容器的入口和活动栏一样：区域可见就隐藏（侧栏的角接到活动栏上，t25 的丙）；右栏、底部面板同样
区域隐藏或拖到零时点别的入口按显示的过渡长出来，里面已经是新容器，不滚
滚到一半又点从这一刻的位置接着滚到新的目标，不跳（上面按钮快速连点就是）
减少动态效果直接换，不滚
平铺主题同样滚，只是没有缝和圆角
底部面板默认的两个容器后台任务、通知现在就是两个容器（各自的隐式容器），有了入口条就是头上两个标题，像 VS Code 的“问题、输出、终端”

  2. 活动栏切换容器上下滚，底部面板左右滚（2026-11-16）
