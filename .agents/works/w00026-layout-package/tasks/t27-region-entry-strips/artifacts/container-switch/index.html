几节的容器和活动栏连在一起

活动栏（点亮着的那个是隐藏、显示） 底部面板

几节的容器这样连在活动栏上，可以吗？

推荐照这样做：每一节靠活动栏的一边都是直的、不留缝；切换时活动栏一直连着，只有右边一列在滚；隐藏、显示时最外面两个角落到活动栏上，节与节之间的角跟着压平。

什么时候怎么画每帧开销
静止项目两节、设定三节，每一节靠活动栏的一边是直的、不留缝；节与节之间的缝一直通到活动栏边上；每一节和活动栏之间各有一条两端不碰顶底的短线无
切换容器活动栏前后都连着、不换画法，只有右边一列滚；节与节之间的缝、两个容器之间的缝跟着滚过活动栏的边每块平移，只在合成层
隐藏每一节往左伸过活动栏的一个圆角加半缝，伸过去的那截是活动栏的底色、压在活动栏下面；最上面一节的右上角、最下面一节的右下角跟着右沿走，缩到零正好成了活动栏的两个角（同 t25 的丙）；节与节之间的两个角随着变窄压扁，缩到零时是直的；缝里露出来的活动栏右边跟着往左让出半缝；短线淡出同侧栏现在的隐藏：外框每帧排版、按形状裁；另加活动栏这一张卡片的右边每帧挪一点（最多 2px）
显示倒过来：从活动栏的两个角里长出来，长完换回相连的画法，画面不变同隐藏

哪里怎么样
方向跟着入口条：活动栏上下，点下面的入口内容往上走；底部面板、右栏左右，点右边的往左走。“更多”里的入口按入口顺序算
什么在滚只滚区域里的内容：侧栏的分节连同它们的头一起滚；入口条本身不动（活动栏、底部面板与右栏的头）
点当前容器的入口区域可见就隐藏（侧栏如上）；右栏、底部面板照它们现在的过渡收起
区域隐藏或拖到零时点别的入口按显示的过渡长出来，里面已经是新容器，不滚
滚到一半又点从这一刻的位置接着滚到新的目标，不跳
减少动态效果直接换，不滚
平铺主题同样滚，只是没有缝和圆角
底部面板默认的两个容器后台任务、通知现在就是两个容器（各自的隐式容器），有了入口条就是头上两个标题，像 VS Code 的“问题、输出、终端”
