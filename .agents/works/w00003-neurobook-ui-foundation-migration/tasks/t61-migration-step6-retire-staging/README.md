## 实现要求

1. **核验先行**：退役前必须核验「新记录 / 完成标记 / data 原件（逐块回读 + 摘要）/ 当前可持久恢复身份」四项，并给出可观察结论；任一缺失即停在可重试状态，不退役。
2. **重建入口**：清单/分块被回收时，能从浏览器暂存重建并回读核验；重建失败不得伪装成功（沿用既有失败分类口径，不新增静默分支）。
3. **标记独立**：进度与完成标记不随目标记录删除/墓碑回收而失效；不重新导入。
4. **幂等**：重复执行、多标签并发与中断续跑都不得重复退役或损坏原件。
5. **可观察**：状态与失败分类进快照（`StorageMigrationSnapshot` 一类），UI 侧沿用既有反馈范式（本 Task 不改 UI，只保证可观察）。
