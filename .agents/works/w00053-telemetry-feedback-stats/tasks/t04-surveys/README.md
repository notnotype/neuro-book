# 调查问卷

## 目标与范围

应用里的调查问卷：官方站后台出题与看结果，应用取到问卷后按本机条件决定是否邀请，用户作答并确认后匿名提交。开发者 2026-11-24 提出，未开工；与主动反馈共用收件与条款。

合同：待定，随 w00053 的提案与 Spec 定。

## 当前状态

2026-11-24 记下，未开工（开发者：还有调查问卷这个功能）。

主会话的初步设想（未经开发者确认）：

- 官方站后台出题、发布与关闭、看汇总结果与文字回答。
- 应用不为问卷单独联网：问卷清单随每天那一份匿名上报的回应带回；匿名档关着时不取，用户自己打开问卷页时才取。
- 邀请谁由应用按本机条件判断（版本范围、平台、语言、里程碑），服务端不知道是谁。
- 邀请是右下角的非阻塞通知；同一份问卷只邀请一次，两次邀请之间隔若干天；设置里有“不再邀请我”。
- 作答是用户主动的动作，归“含内容的反馈”一级：提交前看得到将要发送的全部内容，点确认才发；匿名提交，可附匿名档的版本与环境。
- 服务端与主动反馈共用收件。
