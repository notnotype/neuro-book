# 插件市场：Obsidian、VS Code、Claude Code 与其它（2026-10-30）

- 问题：[t25](../tasks/t25-plugin-marketplace/README.md) 要定插件市场的索引、来源、审核、版本与更新、信任与下架。Skill 侧的调研见[各家的 Skill](2026-10-30-skill-survey.md)第 4 节。
- 做法：一个 Haiku 子代理读官方文档与 obsidian-releases 仓库的索引文件；没有读客户端源码。证据等级：**文档**为官方文档（经抓取工具摘要）；**仓库文件**为原文；**检索**为搜索摘要。

| 项 | Obsidian | VS Code（含 Open VSX） | Claude Code |
|---|---|---|---|
| 索引 | `obsidian-releases` 仓库的 `community-plugins.json`，每条只有 id、名称、作者、说明、代码仓库，版本与下载不在索引里（仓库文件） | 官方市场单一托管；Open VSX 是独立注册表（文档、检索） | 没有中心目录：市场是带 `.claude-plugin/marketplace.json` 的 Git 仓库、URL 或目录，用户自己添加（文档） |
| 上架与审核 | 提交后自动扫描，热门、精选与被标记的才人工审（文档，旧资料口径不一） | 每个版本经多个杀毒引擎扫描、沙箱运行检测、密钥扫描，通过前不公开；发布者可经域名验证拿蓝勾（文档） | 自有市场推到 Git 即发布；Anthropic 目录另有提交流程（文档） |
| 发布物与完整性 | GitHub Release 的 `main.js`、`manifest.json`、`styles.css`；官方模板生成构建溯源证明；客户端校验未查到（文档） | 市场给每个扩展签名，安装时校验完整性与来源（文档） | 来源可为 GitHub、URL（可固定提交）、git 子目录、npm、压缩包（配 sha256，不符拒装）；没有签名字段（文档） |
| 兼容 | `minAppVersion`，按 `versions.json` 找兼容的最新版（文档） | `engines.vscode`；预发布版另发（文档） | 未见兼容字段（文档） |
| 更新 | 不自动更新，手动（文档） | 自动更新，缺省延迟 12 小时；VSIX 手装的不自动更新；可装其它版本、不能锁定（文档） | 第三方市场缺省不自动更新，官方市场缺省自动（文档） |
| 信任 | 缺省开“受限模式”不跑第三方代码；插件权限无法细分（文档） | 与 VS Code 同权限；首次装某发布者的扩展时确认；企业白名单（文档） | 安装前警告；插件的钩子、MCP 等都以用户权限运行；企业可限制市场（文档） |
| 下架 | 恶意可立即下架；已安装副本怎么处理未查到（文档） | 恶意扩展从市场删除并进黑名单，已安装的自动卸载（文档） | 维护者可让已从市场删除的插件在下次启动时卸载，记进 `flagged-plugins.json`（文档） |

- SillyTavern 扩展粘贴 git 地址安装，要本机有 git，没有索引、审核与下架（文档）。Logseq 市场经 PR 提交（检索）。JetBrains 每个新插件与更新都人工审核，目标两个工作日（检索）。
