# t06 后端实现审查的处理（omp，6 条，都标重要）

报告原文：同目录 `impl-review-backend.txt`。

| 条目 | 处理 |
|---|---|
| `env BASH_ENV=...` 判成只读 | 成立，改。`env` 与外层 `bash -c` 上的变量算进每条内层命令 |
| 不生效的放行规则挡住后面的拒绝 | 成立，改。这是实际的判定错误：`[shell 放行, git push 拒绝]` 对 `eval git push` 没拦住 |
| `sed` 的 `ep` 标志 | 成立，改。脚本改成白名单，不再猜写法 |
| 展开出来的选项（`find . "$(printf -- -delete)"`） | 成立，改。要看选项的命令有展开时不算只读；`cat "$f"` 这类没有写选项的不受影响 |
| 项目规则文件跟随符号链接 | 不改：项目规则放行不生效，链到外面也只能多加拒绝与询问，作品本来就能直接写这些规则。理由文字只回到本机界面 |
| 未绑定窗口按 id 读作品规则 | 不改：浏览器是用户自己的界面，同一远程服务的 `list`、`create` 同样接受任意作品 id，这里不是隔离边界；规则也不比会话更敏感 |
