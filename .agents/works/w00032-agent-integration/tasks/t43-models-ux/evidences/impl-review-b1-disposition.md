# 段 B1 实现审查的处理

审查对象：分支 `feat/w00032-t43-b1` 的 `56a4d61c0..e3ecdbba4`。后端一个 omp 会话（默认模型），报告 [`impl-review-b1-backend-omp.txt`](impl-review-b1-backend-omp.txt)：22 条（阻断 0、重要 16、建议 6）；前端一个 Claude Sonnet，报告 [`impl-review-b1-frontend-sonnet.txt`](impl-review-b1-frontend-sonnet.txt)：20 条（阻断 0、重要 8、建议 12）。两份都逐条核实；改了的都补了用例，主要的几条做了变异检查（删掉修正后用例变红）。

## 后端（omp）

| 条 | 结论 | 处理 |
|---|---|---|
| 1 模型请求没有按决定 29 直连 | 成立 | `OmpTarget.direct`，最内层 `fetch` 带 `proxy: false`；`buildResolution` 建的都直连。用例：设了 `HTTP_PROXY` 等变量与空 `NO_PROXY` 时请求直达端点、代理收到 0 次（变异：去掉后用例失败） |
| 2 同实例换模型仍送回旧签名 | 成立 | `restorable` 比较 `origin.model`；旧日志把历史里真正作答的模型 id 交给 OMP。用例：真实 JSONL 关会话重开后换模型，不送回（变异通过） |
| 3 认证头换号时身份与“解析后变过”看不出来 | 成立 | 凭据身份与 `stillCurrent` 的指纹都含生效的服务商与模型请求头。用例：换认证头后旧解析得 `endpoint-mismatch`、新凭据身份不同（变异通过） |
| 4 设置层拒收的键被整份覆盖 | 成立 | 设置服务的 `inspect` 加可选的 `problem`；模型服务的适配器见到时按 `invalid` 处理（`settings-unavailable`）。用例：真实设置文件写坏这一项后添加被拒、原文还在（变异通过） |
| 5 768 KiB 量的是值，不是写盘时的帧 | 成立，收窄 | 改为两层编码后的字节（设置全文作为文本再进一帧）；其它设置项不计，留 256 KiB 余量。精确到整个设置文件要设置拥有者参与，接受这个近似。用例：一层没超、两层超的写入被拒（变异通过） |
| 6 服务入口没有 Bun 门槛 | 成立 | `server/bun-gate.ts` 是 `main.ts` 的第一个导入，版本不够时写明原因、退出码 2。本机只有 1.4.4，低版本路径没有实测 |
| 7 图标目录本身是链接时照读 | 成立 | 存、读、列都从状态根起逐段 `lstat`；读在打开的句柄上有界读。用例：`provider-icons` 是指向别处的链接时读 404、列空、存失败 |
| 8 复制到有遗留密钥的 id 接上别人的密钥 | 成立 | 添加与复制共用 `createProvider`：先清最终 id 的遗留密钥再写设置。用例：副本 id 预放的旧密钥不会生效 |
| 9 添加时接受模板没有的协议又不给地址 | 成立 | 添加前用与改协议同一条核对，`invalid-value`。用例（变异通过） |
| 10 不能发的目录行只报漂移 | 成立 | nb-harness 的 `BuildResult` 加 `transport-unsupported`（`not-chat`、`transport`）；行的状态加 `unsupported`，界面写“不能当对话模型用”；会话仍映射成 `unknown-model` |
| 11 模板服务商里手加的模型读行说能用、解析不了 | 成立 | `ProviderTarget.defaultApi`：没覆盖协议的手加模型用模板的缺省协议。用例：读行可用、解析成功 |
| 12 OpenRouter 不再认 `PI_OPENROUTER_RESPONSES=0` | 成立 | 按服务端进程环境选 Chat Completions 或 Responses，物化后不再漂移。用例 |
| 13 添加时清库失败交回合同外的码 | 成立 | `addProvider` 的失败表加 `credentials-unavailable`（没做故障注入用例：凭据库写失败的夹具要另做，收益小） |
| 14 免认证按子串剥头 | 成立 | 只剥值恰好是哨兵或 `Bearer <哨兵>` 的头。用例：用户配的 `Bearer team-N/A-token` 照发（变异通过） |
| 15 只按行数分页保证不了帧大小 | 成立 | 一页另按编码后 512 KiB 截，`nextOffset` 接着实际交出的最后一行；单行受第 5 条的设置预算约束。用例：12 行各约 60 KB 的手加模型分页读完、一页不超 1 MiB（变异通过） |
| 16 每页都重算整家成员与排序 | 成立，接受取舍 | 8 家 × 600 个读完 24 页在本机几十毫秒，用户触发的读取频率低；按配置代次缓存成员索引留到真的慢时再做 |
| 17 图片生成、裁判模型进了对话清单 | 成立 | 目录行带 `chat`（`kind` 缺省为对话），清单与解析只收对话类；不能发的给第 10 条的原因。用例（变异通过） |
| 18 手加条目被同 id 的目录行接管 | 成立 | 成员、写回、移出、物化都按条目的来历：手加的优先，不借目录的窗口与能力，移出时删掉。用例（变异通过） |
| 19 已有的 `identity.key` 不收紧权限 | 成立 | 已有的收紧到 0600；坏文件写新文件再改名换上。用例（Windows 跳过） |
| 20 `checkAll` 仍在合同里 | 不改 | 现行 Spec 与 B1 计划都保留它（“`check` 保持现状，B2 改探测”）；B2 换成逐个 `check` 时一起删 |
| 21 行没有来源值 | 已修 | 前端第 8 条的处理里加了 `source` |
| 22 新建冲突后换 id 没清新 id 的密钥 | 成立 | 同第 8 条的 `createProvider`。用例：写设置时 id 被别处占了，换成 `-2` 且其遗留密钥被清（变异通过） |

另：写第 3 条的用例时发现，Anthropic 协议对本地拦下的请求按退避重试十来次（几秒到十几秒才交回 `endpoint-mismatch`）；改为拦下即中止整次调用。

## 前端（Sonnet）

| 条 | 结论 | 处理 |
|---|---|---|
| 1 版本没变也换 rows、lookup 并多次通知 | 成立 | 内容没变不换引用、不通知；`attach` 交回要不要重读，agent 插件要重读时等行到齐再算模型列表，且只在快照或行换了时重算。用例（变异通过） |
| 2 并发登记引用把没取到的写成 null | 成立 | `lookup` 只放取到的（没有键是还在取）；在途的取引用不再换 `lookup`。用例（变异通过） |
| 3 快照比读取快时一直到不了 ready | 成立 | 读完的那家就进缓存；同一家同一版本的读共享。用例（变异通过） |
| 4 三轮换代后停在读取中 | 成立 | 交出 `revision-changed` 失败（界面写原因与“重试”）。没写用例：三轮换代的时序要注入，收益小 |
| 5 密钥没复制成用泛用文案 | 成立 | 用 `header.keyNotCopied` |
| 6 Profile 页把没取到当成不在 | 成立 | 与第 2 条一起：`undefined` 是还在取，不报“模型不在了” |
| 7 全部模型的 200 行预算跨节共用、缺状态 | 成立 | 不搜索时每节各自封顶；加读取中、失败、没有命中。新增 dom 测试 |
| 8 恢复来源值只做了两个字段 | 成立 | 行带 `source`；六个字段都能恢复，点了把来源值填回表单。新增 dom 测试 |
| 9 预算与选择器图标没有覆盖 | 部分 | 选择器的选项抽成纯函数 `model-options.ts` 并补用例（同模板两实例各自的图标、上传图标走读取路由）；“一份快照模型列表只算一次”由选用数据的用例与插件里的输入比较保证，插件层没有单独的计数用例 |
| 10 输入法组字时的回车 | 成立 | 搜索框、名称框、第二步的两个输入框都避开 `isComposing` 与 keyCode 229。用例（变异通过） |
| 11 展开阈值跨 30 时用户的选择翻转 | 成立 | 记绝对的展开状态 |
| 12 上传用透明 input 盖在按钮上 | 成立 | 藏起文件框、按钮打开，一个停靠点 |
| 13 地区用原生 radio；可访问名称盖掉可见文字 | 成立 | 用 nb-ui 的 `RadioGroup`；去掉 `aria-label`，名称取可见内容 |
| 14 Esc 抛 TypeError、焦点丢失 | 成立 | 按钩子找铅笔的元素；点名称也能改名。用例 |
| 15 添加对话框的初始焦点在关闭按钮 | 成立 | `initial-focus` 给搜索框。用例（变异通过） |
| 17 设置页的数据模块没开角色页也读全部服务商 | 成立 | 选用数据加 `lazy`，角色页订阅后才读 |
| 18 图标失败是页面级状态 | 成立 | 换服务商时清掉 |
| 19 一家读失败选择器一直空；重试时旧的选用数据不释放 | 成立 | 第一轮读完即就绪（失败的那家按没有行）；订阅失败时释放这一份 |
| 20 没用到的文案、`.md` 不一致 | 成立 | 删掉 8 个；`AllModelsView.md` 补 `state:local` 与钩子；`ProviderHeader.md` 跟上 |
| 21 小项 | 四项改、一项不改 | 管理模型的计算属性无副作用；角色页去掉多余的计数；图标地址只在 `models/shared/icons.ts` 拼；空白模板不显示“自动加入”。Profile 页的选项不封顶：8 家 × 600 个才到 4800 项，常见规模下不明显，接受取舍 |
