# 后台任务清单的提供方与分组视图

## 目标与范围

按已接受的[提案“统一后台任务”](../../../../../docs/proposals/unified-background-tasks.md)第四节第 2 小节与 [ADR 0056](../../../../../docs/adr/0056-background-work-providers-and-session-notices.md) 改 `nbook.tasks`：

- 提供方：服务端插件登记成提供方、交出行与变化、执行转来的操作；自己的任务（`start()`）规则不变。
- 行的字段（归属、种类、形态、操作、打开的去处）与按编码大小的上限；操作带注册代次，旧点击得“目标已不在”；按筛选分页、计数取汇总；一家出错只影响它自己；停止分已受理、没受理、未知；打开走拥有对象的插件的导航、如实报失败。
- 视图按归属分组（缺省当前项目、应用与全部会话，能切到全部项目），按形态与种类筛选；通知与看过只对自己的任务；远程合同升版本。
- Agent 作为提供方交出的行（后台任务、在跑或等你处理的根会话、没有任务覆盖的在跑子会话）放在 t22 还是本 Task，开工时按两边进度定。

合同：改 [`workbench/background-tasks.md`](../../../../../docs/specs/workbench/background-tasks.md)（先写 planned）。

依赖：无；可与 t41 并行。

两轮提案审查（证据在 [t22](../t22-background-work/README.md) 的 `evidences/`）里归本 Task 的：

- [第二轮](../t22-background-work/evidences/proposal-review-r2.txt)：11（注册代次）、12（大小与分页）、13（提供方隔离与撤回）、14（按归属的导航）、15（停止的结果）、17（没有任务覆盖的子会话）。
- t22 第 6 片推迟过来的：子代理卡片在任务移出之后，经远程新方法 `runOutcome({sessionId, runId})` 读有界的终态，不读整份 `runResult`（[t22 计划](../t22-background-work/plan.md)“前端”一节，设计审查第 15 条）；和清单里子代理行的终态一起做、一起在 e2e 里看。

## 决定

1. 第一批的行（开发者 2026-11-23，选推荐）：`nbook.tasks` 自己的任务；Agent 作为提供方交出三类：后台任务每件一行（后台命令、后台子代理、插件的工具登记的任务），在跑或等你处理的根会话每个一行（停止是以用户身份停它当前的运行、保留排队的话），没有任务覆盖、却在跑的子会话一行。t22 已完成、没有交清单的行，Agent 的行在本 Task 做。服务与定时形态还没有提供方，不出现。
2. 视图按归属分组、会话在前（开发者 2026-11-23，选推荐）：顶上一个范围开关（当前项目｜全部项目）；分组依次是会话（每个根会话一个组头，写标题与“运行中”“等你处理”，带停止与打开，它的后台任务缩进在下面）、当前项目、应用；组内在跑的在上、结束的在下；等你处理的会话组头用警示色。
3. 状态栏与通知（开发者 2026-11-23，选推荐）：状态栏只数在跑的插件任务与 Agent 后台任务，不数会话的运行（Agent 有自己的活动条目）；结束通知只给 `nbook.tasks` 自己的任务，Agent 的结果已作为回执送回会话，不弹。
4. 形态与种类（开发者 2026-11-23，选推荐）：行的数据带形态与种类，种类在行上显示；视图先不做形态与种类的筛选，等第一个服务或定时的提供方出现时再加。缩减了提案第四节第 2 小节第 8 条，记进提案的决策记录。
