# 方案 A+B 从文字到世界（脚本、分镜与关键一幕原型）

## 目标与范围

白天书房、夜里星海、天亮回到书架：一行字里的人名地名化成星，夜里连成世界，天亮落回成一本书；白天讲现在能用的，夜里讲正在长成的世界。先出分场脚本；开发者同意后出分镜与关键一幕的原型。整页的实现不在这里。

合同：行为合同未变（首页是对外的介绍页，不改产品行为）。

## 当前状态

2026-11-26 第 1 轮：分场脚本发在 [评审板](artifacts/review/index.html) v1。7 场、约 11 屏；招牌动作是字化成星（结尾倒过来，星光聚成书）。星璃只在夜里出现一次（第 5 场，书庭的一扇圆窗）；第 4 场第二步的伏笔标“在做”。三道题：这版往不往下做（推荐出分镜，并先拿第 3 场“字化成星”做原型）、首屏第一句（推荐 c1“从文字，到世界。”）、哪一场要改。
