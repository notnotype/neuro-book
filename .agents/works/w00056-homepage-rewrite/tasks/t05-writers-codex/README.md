# 新方向《执笔者之书》：整页一本书，史诗、神圣、西幻（脚本、分镜与关键一幕原型）

## 目标与范围

整页是一本书，从封面翻到跋：讲写作与编辑器、世界引擎、剧情（在做）、星璃与 Agent，以及本地与开源、模型自选、插件、桌面版。基调取 [w00050 t06 契约仪式](../../../w00050-lyra-persona-and-prompts/tasks/t06-contract-ceremony-onboarding/README.md) 的史诗、神圣、西幻气氛与书的做工，不复制它的书；不直接用现成的 NovelAI 场景图。先出分场脚本，开发者同意后出分镜与关键一幕的原型。整页的实现不在这里。

合同：行为合同未变（首页是对外的介绍页，不改产品行为）。

2026-11-26 第 1 轮：分场脚本发在 [评审板](artifacts/review/index.html) v1。8 场、约 12 屏：封面、启封、落笔、世界之卷、预言之卷（在做，用“尚未启封”的火漆封着）、守书人（星璃出现一次）、纸墨线匣（平台四项合成一幅器物图）、跋（书合上，桌上多一本空白的书）。招牌动作是一本书贯穿全页、滚动即翻页；示例小说是《灰塔制图师》。四道题：这版往不往下做（推荐出分镜，先做封面与启封的原型）、首屏第一句（推荐 d1“每一个世界，都从一行字开始。”）、星璃用什么画（推荐另画一张肖像插页）、哪一场要改。
