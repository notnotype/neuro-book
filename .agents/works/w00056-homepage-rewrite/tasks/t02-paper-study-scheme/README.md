# 方案 A 书房：一部长篇的一生（脚本、分镜与关键一幕原型）

## 目标与范围

只用书房的美术（象牙纸、墨色正文、赤红与金色点缀、Fraunces 与宋体标题、产品真截图），讲一本书从第一行写到最后一章。先出分场脚本；开发者同意后出分镜（动效语言、关键帧、滚动地图）与关键一幕的原型。整页的实现不在这里。

合同：行为合同未变（首页是对外的介绍页，不改产品行为）。

## 当前状态

2026-11-26 第 1 轮：分场脚本发在 [评审板](artifacts/review/index.html) v1。7 场、约 10 屏；招牌动作是一根红线：从首屏的光标里拉出，穿起设定卡片，在第 3 章打结、拉到第 200 章，最后收成书签丝带。星璃只在第 4 场（对话里的搭档）出现一次；第 3 场的伏笔标“在做”。三道题：这版往不往下做（推荐出分镜）、首屏第一句（推荐 a1“你心里那部长篇，从这一行开始。”）、哪一场要改。

脚本里“现在能用”“在做”的口径见 [t01 的“现状口径”](../t01-story-and-motion-design/README.md#现状口径2026-11-26-核对)。

## 下一步

等开发者答第 1 轮；同意往下做就定动效语言、关键帧与滚动地图，再做关键一幕的原型。
