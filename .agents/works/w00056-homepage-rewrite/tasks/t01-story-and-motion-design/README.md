## 流程（主会话 2026-11-26 提出）

1. **故事概念**：整页讲的那一个故事，一句话加一段梗概，出两三个候选，会话里定。
2. **分场脚本**：六到八场。每场写观众该明白或感到什么、屏幕上的字、画面里有什么、靠哪条事实撑（现在能用或在做）、怎么转到下一场。上面“并进脚本里定的事”在这一步定。
3. **动效语言与分镜**：先定全页共用的一套动效（一个招牌动作、两三种辅助动作、节奏规则），再给每场画关键帧，排滚动地图（每场占几屏、哪里钉住），每场选技法。低保真，上评审板。
4. **关键一幕的原型**：最难、最出彩的那一幕先做成能滚的真网页，A、B 两种美术并排；同时测手感与性能（普通笔记本、手机、减弱动效）。3D 值不值得做在这一步定。
5. **视觉定稿**：每场的高保真关键帧，桌面与手机。
6. **素材**：插画分层、3D 或序列帧、v2 真截图、小猫的心情动画、星璃裁图。
7. **实现**（另建 Task）：文字是真文字，每场有不动的版本，首屏快、重的东西延后加载。
8. **打磨与上线**（另建 Task）：节奏与缓动细调，中英文，部署到原地址。
