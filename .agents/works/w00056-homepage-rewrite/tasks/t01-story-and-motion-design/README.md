# 首页的故事、脚本与动效设计

## 目标与范围

定首页讲什么故事、怎么讲：定位与基调、故事概念、分场脚本、动效语言与分镜、关键一幕的原型、视觉定稿。整页的实现与上线另建 Task。

合同：行为合同未变（首页是对外的介绍页，不改产品行为）。

## 已定

1. **范围**：要重写的是文档站首页 `blog.notnotype.com/neuro-book/official/`，不是 w00037 的账号服务站（开发者 2026-11-26 纠正）。
2. **基调**：A、B 两个方向都试（开发者 2026-11-26）。按主会话在会话里列的三个方向理解：A 书房（象牙纸底、墨色正文、赤红与金色点缀、Fraunces 与宋体标题、产品真截图，小猫随滚动换心情）；B 星海书庭（夜色、星光、星璃的书庭）。第三个方向 C 工程工作台（沿用旧页的暗色演示路线）开发者没有提。
3. **要高级感，网页讲一个故事**：用滚动叙事，可以用 2D、3D 的滚动动画（开发者 2026-11-26）。

## 并进脚本里定的事

先前在会话里问过、还没答的几件，写分场脚本时一起定：

- 首屏第一句：品牌简报的“我的想法值得被写出来”，还是 README 的“用工程的方法，写完你的长篇”。主会话推荐两层：第一句说给心里有故事的人，紧接着一句讲为什么在这里写得完。
- 星璃出现多少。主会话与 @designer 都推荐点到为止、不上首屏。
- 现状与愿景怎么讲。主会话推荐现在能用的写成现在时、配真截图，愿景单列并标进度，不做假演示。
- 愿景列哪几项：README 的路线图列着 llmlint，但 [仓库现状](../../../../../PROJECT-STATUS.md) 写着它准备退役，w00037 t01 也写着已废弃。
- 主会话的默认（开发者还没表态）：只做首页；主按钮“下载桌面版”并标明预览版，关注进度、GitHub、Discord、QQ 群在次要位置；中文先定稿、英文按同一结构跟上；源码放本仓库，用 Vue 与 nb-ui；地址不变，上线改 GitHub Pages 时另取授权。

## @designer 的意见（2026-11-26）

输入是旧页与书架的截图、品牌标识、星璃的立绘和一份只写事实的说明，没有给它主会话的三个方向。它的首选是“纸本工坊”：书房的底子，加上用纸本画法讲的工程方法。

- 与主会话一致：一页写给“心里有故事的人”的首页；亮色纸底、衬线标题、真截图；小猫是全页唯一会动的角色；星璃最多一处、不上首屏（另一个理由是首屏放 NovelAI 插画和“去 AI 味”的主张冲突）；先讲现在能用的，愿景单列。
- 主会话采纳的补充：伏笔画成书签、人物状态画成人物卡，不用代码框；顶栏去掉四个还没上线的入口。
- 留到出稿时比较：愿景那一块换夜色或赤红底，和亮色的“现在能用”分开。

第一次把 11 张图内联发给它，30 分钟上限内没有返回；减到 5 张后 5 分钟返回。原文与旧页截图在本地 `.local/agent/works/w00056-homepage-rewrite/tasks/t01-story-and-motion-design/old-landing-and-designer/`。

## 流程（主会话 2026-11-26 提出）

1. **故事概念**：整页讲的那一个故事，一句话加一段梗概，出两三个候选，会话里定。
2. **分场脚本**：六到八场。每场写观众该明白或感到什么、屏幕上的字、画面里有什么、靠哪条事实撑（现在能用或在做）、怎么转到下一场。上面“并进脚本里定的事”在这一步定。
3. **动效语言与分镜**：先定全页共用的一套动效（一个招牌动作、两三种辅助动作、节奏规则），再给每场画关键帧，排滚动地图（每场占几屏、哪里钉住），每场选技法。低保真，上评审板。
4. **关键一幕的原型**：最难、最出彩的那一幕先做成能滚的真网页，A、B 两种美术并排；同时测手感与性能（普通笔记本、手机、减弱动效）。3D 值不值得做在这一步定。
5. **视觉定稿**：每场的高保真关键帧，桌面与手机。
6. **素材**：插画分层、3D 或序列帧、v2 真截图、小猫的心情动画、星璃裁图。
7. **实现**（另建 Task）：文字是真文字，每场有不动的版本，首屏快、重的东西延后加载。
8. **打磨与上线**（另建 Task）：节奏与缓动细调，中英文，部署到原地址。

## 故事概念（候选，待开发者选）

- **从文字到世界**（主会话推荐）：白天的稿纸上写下一行字，字浮起来变成星，夜里连成一个世界，天亮时落回书架成了一本书。白天讲现在能用的，夜里讲在做的，星璃在夜里出现一次，天亮时下载。招牌一幕是字化成星。
- **一部长篇的一生**：跟着一本书从一个念头走到完结，第 3 章挂上的枪在第 200 章响起，书合上、封面烫金。以书房为主，工程方法用纸卡、书签、红线讲。
- **书庭的一夜**：作者写作的一夜，镜头在星璃那边：字浮现在她的扉页上，读完一章结成记忆宝石，卡文时递来一杯茶。以星海为主。
