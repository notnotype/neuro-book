# 方案 B 星海书庭：书庭的一夜（脚本、分镜与关键一幕原型）

## 目标与范围

只用星海书庭的美术（夜色、金色星光、赤红，现成的星璃场景图与立绘拆层做视差，星点用代码画），讲作者写作的一夜里星璃在书庭替他做的事，产品的每样能力化成她做的一件事。先出分场脚本；开发者同意后出分镜与关键一幕的原型。整页的实现不在这里。

合同：行为合同未变（首页是对外的介绍页，不改产品行为）。

## 当前状态

2026-11-26 第 1 轮：分场脚本发在 [评审板](artifacts/review/index.html) v1。7 场、约 11 屏；招牌动作是镜头穿过书庭（星海、穹顶、阅读台、破晓的露台）。星璃是主角，第 2 到第 6 场都在；“她自己读稿、整理设定”这类在做的不写成现在，列在第 7 场。三道题：这版往不往下做（推荐出分镜，并先拿第 2 场做原型，看 NovelAI 插画放大、拆层后撑不撑得住）、首屏第一句（推荐 b1“万言星海里，有一颗是你的。”）、哪一场要改。
