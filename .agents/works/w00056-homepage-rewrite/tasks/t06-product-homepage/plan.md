# 第二幕（编辑器）原型的实施计划

开发者在 v12 上定了照板上的脚本做原型（`act-two-r12 = prototype`，见 [README](README.md) 已定第 18 条）。脚本：开场“沉幕落印”，五拍是照中文的规矩、一张图存进作品、章节的属性、链到设定、还是那份 .md，演完交给访客“轮到你写”。本计划只管怎么做；看起来是什么样以板上的脚本为准。

## 现状（2026-11-27 核对）

- 复原的工作台（`drafts/w00056-t06/HomepageDesk.vue`）用的是产品的编辑区、Markdown 控件与 Monaco 控件；文件在 Lab 的内存文件系统里（`fixtures/explorer-scene/memory-files.ts`：不能上传，`rawUrl` 一律为空）；菜单是 `fixtures/editor-scene/lab-editor-menus.ts`，Ctrl 点链接已经交给 `area.open`。
- 演示打字用 `document.execCommand("insertText")`，走浏览器的输入，编辑器的输入规则照常起作用；斜杠菜单能不能这样弹出来，要在片 3 先试。
- 链接与插图是 w00025 t09 做完的（`e2e/markdown-links-images.e2e.ts` 场景 27 到 30）；粘贴与插图卡片要 `markdownMediaKey`（`markdown/web/media.ts`），复原的工作台没给。
- 换源码编辑器：命令 `nbook.editor.reopen-with` 与编辑区的 `reopenWith` 都在，复原的工作台挂了 Monaco 控件。
- 页面结构：`.hs-run` 里一个钉住一屏的舞台，滚一屏俯冲落到第一幕；第一幕落地后自己连播，舞台滚走一半时停住（`hold = "away"`），回来接着演；第一幕后面是第二幕的占位（`.hs-next`）。

## 做法

1. **滚动分段**：舞台钉住的范围从“俯冲 + 第一幕”延到第二幕。滚动位置只决定现在是哪一幕（第一幕、第二幕），分界处带一段缓冲（进第二幕与回第一幕的位置错开），越过才放开场或回退的动画，不跟着滚动一帧一帧走。当前不是哪一幕，那一幕的连播就按“away”停住，回来接着演。
2. **开场与回退**：按时刻排的一段动画（真实经过的时间推进，见设计语言踩过的坑 82）：压暗与微退 0.3 秒；正中金线描出 II、副题与花饰展开 0.7 秒；印收进眉题，同时真的收起右边星璃那一栏（布局文档里改，产品的布局动画），第二幕的五段章节条依次点亮 0.65 秒。往回：不落印，薄暮至少压半秒，工作台换回第一幕离开时的样子（星璃那一栏回来）。眉题、章节条、指针、遮罩与金角都不进工作台的缩放层。眉题的字在它看不见时就换成目标那一幕的（眉题里新旧两行先出后进约 0.66 秒，显出来那一刻才换会先露出上一幕的字）；章节条在印收进眉题那一刻才换，让依次点亮看得见。
3. **第二幕的导演**：复用 `act-one.ts` 的 `createActOne`（它与第一幕无关，只按拍演、摆、恢复），另一组拍；连播的那一层（章节条进度、离台停住、跳拍与暂停）从页面搬进 `staged-act.ts`，两幕各一份。章节条换成第二幕的五段，眉题换成第二幕的名字与每一拍的句子。工作台在换幕时按那一幕自己记下的样子重新挂一台（落印的 0.7 秒盖在薄暮下）：第二幕第一次进来从它起头的样子起演，之后两幕各自从离开时的样子接着演。没有照原先写的“从第一幕交给访客时的样子起演”：第一幕的终态把作品树搬到了右栏、还有浮窗，和第二幕要的桌面对不上，就地收拾要连走几段布局动画，落印那一小段里放不下。离台时还在连播的那一幕记最后停稳那一拍的终态（导演的 `shelve`），回来接着演时不再先摆回一次。
4. **示例数据**：第五章加 frontmatter（视角、状态、出场）；设定里加一页“灰塔”；正文里要有能选的“灰塔”“霜港”。剖面版画用 SVG 画一张（七层有字、第八层空着一个问号，接第五章“第八层的位置还是一片空白”），演示时画成 PNG 当作粘贴的图，不另生成。
5. **文件服务**：在草稿目录里给内存文件包一层（`desk-blobs.ts`）：上传时在内存文件里排他新建同名的空文件（资源管理器列得出；存放目录没有先建；重名照服务端加序号），字节存成 Blob，`rawUrl` 给 object URL；用它提供 `markdownMediaKey` 与 `markdownAssetsKey`。Blob 存在页面那一份里，不随工作台重挂丢掉；记下的样子带上图的地址，重挂时按地址补回空文件。不改 Lab 共用的 `memory-files.ts`。
6. **工作台要开放的动作**（`HomepageDesk` 的 `defineExpose`）：收起与放回右栏；属性面板的几个目标（摘要行、某个属性的值、添加项）；把一张图当作粘贴发给编辑器（`ClipboardEvent` 带 `DataTransfer`）；选中文字后插链接（发 Ctrl K 或调编辑动作）与 Ctrl 点它；换成源码编辑器与换回；源码里某段文字的位置（描金用）。

## 风险

- 斜杠菜单在 `execCommand` 下弹不出来：改发键盘事件，或直接调编辑器的斜杠动作。
- Monaco 是异步加载的，换源码编辑器要等它挂上再描金。
- 开场里真的收起右栏，布局动画和描印的动画同时跑，帧率要量（设计语言踩过的坑 89 的做法）。
- 页面变长以后，俯冲、第一幕的“away”与指针那一层的对齐都要跟着改，片 1 先把第一幕重演一遍。
