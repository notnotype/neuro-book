# 产品介绍首页：给搜索进来的人（脚本、分镜与原型）

## 目标与范围

首页按产品介绍来做，给从搜索引擎进来、第一次听说 NeuroBook 的写作者：几秒内知道它是什么、给谁用，一分钟内看完能做什么、怎么装，然后下载。讲写作与编辑器、世界引擎、星璃与 Agent、剧情（在做），以及本地与开源、模型自选、插件与 SDK、桌面版。外观取 [w00050 t06 契约仪式](../../../w00050-lyra-persona-and-prompts/tasks/t06-contract-ceremony-onboarding/README.md) 的质感，骨架是产品页；不直接用现成的 NovelAI 场景图。书庭这类自由页面不在这里。先出分节脚本，再出视觉稿与原型。

合同：行为合同未变（首页是对外的介绍页，不改产品行为）。
