2. **（一般建议）插件激活实例的身份键与命名不统一**：生命周期阶段表第 249 行称“插件入口实例”，单位为“插件 id + 入口 + scope + 激活代次”；术语表第 92 行与资源作用域表第 220 行仍称“插件激活实例”，单位为“插件 id + 运行位置 + 激活作用域”；D2 第 1 条（118 行）按“不同运行位置的入口分别装配”表述，插件表前言（299 行）按“每个入口分别声明位置、作用域与依赖”表述。实现 `runtime.plugins` Spec 时无法确定“同一运行位置内同一插件的两个入口是否共享一次激活与一个 scope”（涉及 World/Plot 的多入口与同一插件的核心/Project 适配两类入口）。
3. **（一般建议）工作台作用域缺终止阶段且行名不一致**：共同规则第 232 行声明作用域统一经历“创建中 → 可用 → 停止中 → 已关闭”，但生命周期阶段表第 246 行“工作台工作面”只到“目标实例恢复已结算”，没有停止/关闭阶段；同一对象在资源作用域表第 216 行称“工作台实例”并给出结束语义（离开工作台撤回入口与实例、取消本地待执行选择）。D5 与 S7 都要求离开工作面时撤回入口并释放，批准者与 Spec 作者却无法在阶段表中找到该转换。
