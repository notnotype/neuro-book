== 现在的 master 上演练会生成的说明（0.13.0，没有上一个桌面版本）
NeuroBook 0.13.0 的 Windows 桌面版，**canary（早期验证版）**：功能能用，但未必经过完整的人工验收。之后还会有预览版，最后才是稳定版；已装的版本会自动更新到之后发布的版本。数据请自己备份。

npm 上的命令行版本与插件 SDK 同时发布：`bun add -g @notnotype/neuro-book@0.13.0`、`@notnotype/nb-plugin-sdk@0.13.0`。

## 变更

### 新增

- 第一个 Windows 桌面版：安装版装到当前用户下、不需要管理员权限；便携版解压即用，数据放在解压目录下。自带运行环境，不用另装 Bun；与命令行 `nbook` 共用同一个数据目录。
- 桌面版自动更新：有新版本时提示，同意后在后台下载，下次打开时换上；只升不降。便携版只提示并打开下载页。
- 关闭窗口前询问：有没保存的改动、Agent 或后台任务还在运行时先问，可以全部保存、不保存或取消。
- 后台任务：任务视图、状态栏上的进度与结束通知；通知中心与状态栏的铃铛。
- Skill：设置里的 Skill 页、Profile 页的 Skill 一节；输入框里用 `$` 选 Skill，还没初始化的在后台初始化，失败时能看输出、重试。
- 批注：给选中的文字加批注，页边卡片按段排列；按住 Ctrl 悬停或点批注末尾的小符号打开。
- 工作台：视图可以拖进别的容器、在活动栏上新建容器或换序；“移动到”菜单与命令面板用同一份目标。

## 下载哪个

- **安装版**：`win-x64-NeuroBook-Setup.zip`。解压后运行里面的 `NeuroBook-Setup.exe`，装到当前用户下，不需要管理员权限。装好以后有新版本时会提示，同意后在后台下载，下次打开时换上。
- **便携版**：`NeuroBook-0.13.0-win-x64-portable.zip`。解压到任意目录直接运行，数据放在解压目录下的 `data\`。便携版不自动更新，有新版本时只提示并打开这个页面。
- 其余文件（`.tar.zst`、`update*.json`、`.patch`）给自动更新用，不用下载。`SHA256SUMS` 是全部文件的 SHA-256。

## 第一次运行

安装包没有代码签名。Windows 可能显示“Windows 已保护你的电脑”：点“更多信息”，再点“仍要运行”。

## 回到旧版本

自动更新只升不降。要回到旧版本，先备份数据目录（安装版是 `%LOCALAPPDATA%\NeuroBook`，便携版是解压目录下的 `data\`），再从旧版本的页面下载重装：旧版本不一定读得了新版本写过的数据。
