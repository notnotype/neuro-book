## omp

| # | 归类 | 处理 |
|---|---|---|
| 1 更新会覆盖改过目标的同名快捷方式 | 成立，接受取舍 | 上游的写入，壳管不了；Spec 已知限制写明“更新会重建或改回同名快捷方式” |
| 2 装后迁移桌面让 2.0.6 拒绝旧清单 | 成立，不归本 Task | Electrobun 自身的限制，与本 Task 无关（不论壳动不动快捷方式都会发生）；记进调研 |
| 3 用缓存当 previous 会在启动时补建 | 成立 | `previous` 是本进程里上一次收到的页面值，首次为 null；只有本次运行里关→开才建 |
| 4 快速反向切换的竞态 | 成立 | 单写者队列，每次“重查、判断、修改”在一次 PowerShell 里做完，按收到的顺序收敛；停止时等在途的一次（有截止）再放锁 |
| 5 用户层恢复为 ok 而值不变时不报告 | 成立 | 页面在用户层由不可用变为 ok 时补交一次完整快照（开机自启同样受益） |
| 6 更新器算得出通道根不等于安装版 | 成立 | `installed` = 频道不是 dev、没有便携标记、可执行文件在通道根的 `app\bin` 下；开机自启共用这个判据 |
| 7 弯引号等路径破坏 PowerShell | 成立 | 脚本固定，路径经环境变量传入，用 `-EncodedCommand`（UTF-16LE）调绝对路径的 Windows PowerShell，`-LiteralPath`；桌面目录用 `DesktopDirectory` |
| 8 写主题、明暗、语言得 denied | 成立 | 同 Sonnet 1；命令按 `auto` 写，作品定了主题时改的是作品的设置，与命令面板的“切换主题”相同（Spec 写明，不另开写用户层的口子） |
| 9 探测与修改之间的替换 | 成立 | 同 4：重查与动作在同一条命令里；剩下的窗口（命令内的毫秒级）写进 Spec 已知限制 |
| 10 places 挡不住普通浏览器 | 不成立 | 普通浏览器与桌面窗口是同一个用户、同一台机器的回环页面，插件完全受信任（ADR 0022）；技能页、表情包页已经由服务端为浏览器打开文件夹，同一做法。失败只回码，原因进诊断 |
| 11 `open` 不等启动器退出 | 成立，接受取舍 | 现有 `openExistingFolder` 的共同行为（技能页、表情包页同样），本 Task 不改；记为已知限制 |
| 12 别名、相对路径、权限 | 部分成立 | 打开前 `realpath` 解析；区分不存在（中性提示）、无权限与不是目录（错误）；相对路径的作品目录照 `library()` 显示，不另解析（极少见） |
