== registry-smoke 第 1 次失败的原因
npm 接受发布后要“处理”一阵，版本才出现在安装元数据里（publish 打印 “Your package is being processed and may take a few minutes to become available”）。
发布与在 registry 上可见的时刻（npm 的 time 字段是可见时刻）：
  nb-story 0.2.3       发布 13:01:58  可见 13:06:07
  nb-plugin-sdk 0.13.0 发布 13:02:04  可见 13:05:12
  neuro-book 0.13.0    发布 13:02:10  可见 13:10:21（5.3 MB，约 8 分钟）
作业固定重试 3 次、间隔 2 分钟（13:02:37 到 13:06:46）：前两次 nb-story 还取不到，第 3 次 nb-story 过了，应用包仍取不到。
不是流水线或包的问题：13:10 之后重跑这个作业（job 132822460248）通过。
修正（master aef02a325）：release:smoke --from registry 加 --wait <分钟>，按 bun 读的缩略元数据轮询到要验的版本全部可见，再只装一次；流水线用 --wait 30。
本机在修正分支上对真实 registry 跑了一遍（prox bun run release:smoke --from registry --wait 2）：12 个版本第一轮可见，nbstory、Vite 宿主、bun add -g 应用、托管入口、SDK 生成插件、plugin install 全部通过。
