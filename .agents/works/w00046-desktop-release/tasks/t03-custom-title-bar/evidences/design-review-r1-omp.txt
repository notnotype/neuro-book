现象：计划让 Bun 主进程直接经 `bun:ffi` 调 `SetWindowLongPtrW`、`SetWindowPos`、`SendMessageW`，但 Electrobun 创建窗口及内置窗口操作都经 `MainThreadDispatcher::dispatch_sync` 在原生窗口线程执行。计划没有原生线程转交方案，也没有说明自定义调用如何避开同步跨线程消息。
为什么是问题：`SetWindowPos` 会同步进入窗口过程，`SendMessageW` 对另一个线程的窗口同步等待；若调用发生在 Bun 线程而窗口线程正在处理 resize/focus/关闭回调，可能阻塞或重入。即使当前机器不复现，方案没有满足跨线程 UI 操作的可证明时序，失败时会表现为窗口冻结而不是可恢复的图标失败。

建议改法：把补样式、图标加载和 `WM_SETICON` 放进 Electrobun 原生线程的一个小 shim，由 `MainThreadDispatcher::dispatch_sync` 执行，再由 Bun 调这个 shim；若坚持纯 FFI，必须先证明所有调用允许跨线程并把同步调用改为安全的消息投递，且把该证明和关闭/resize 并发验收写进计划。

建议改法：在计划中固定 `ptr` 空值检查、Win64 指针类型、`LONG_PTR` 返回值和 BOOL/LRESULT 映射；用显式的 null 结尾 UTF-16LE 缓冲区调用 W API，并保证缓冲区在调用结束前存活；统一记录 API 名、错误码和 HWND。

现象：计划为每个窗口注册 `resize` 监听并在关闭时删除 `windows` 项，但 Electrobun 2.0.6 的 `BrowserWindow.on()` 只有追加监听接口，没有 `off`/dispose；SDK 关闭清理只删除 `BrowserWindowMap` 和视图。计划没有说明 resize 监听如何解绑，也没有说明关闭后排队到达的 resize 如何处理。
为什么是问题：每开关一个窗口就可能留下一个闭包和窗口对象引用；关闭后延迟 resize 仍可能调用 `win.isMaximized()`、向已离开的页面发消息，或在窗口 id 被复用时把旧状态发给新窗口。`window-state` 的“与上一次相同不发”缓存也必须随窗口销毁收口，否则它会成为跨窗口状态污染源。
如何核实：连续创建并关闭窗口，检查 Electrobun 窗口事件发射器的监听数量和堆；关闭后手动发/等待一次同 id 的 resize 事件，观察是否调用已关闭窗口的 FFI。当前为 SDK 事件订阅接口和计划时序的代码推断。
建议改法：优先用一个全局 resize 监听按 `event.data.id` 查当前 `windows`，关闭时自然删除状态；或给适配层补可验证的解绑接口。发送前必须确认当前 `windows.get(id)` 仍是同一个 `BrowserWindow`，并在 `close` 中清除状态缓存、资源和监听。
14. 严重程度：重要；类别：合同；位置：`plan-r1.md:31,43-46,91`；`packages/neuro-book/desktop/src/bun/preload.ts:14-41`；`packages/neuro-book/src/shared/desktop-bridge.ts:94-103`。
现象：计划称 `window.__nbookDesktopFrame` 是预加载定义的“只读”能力标记，但没有写出属性描述符、覆盖/删除行为或页面导航后的寿命；当前预加载只有普通全局赋值/函数注入模式。验收中的 Playwright `addInitScript` 也没有要求验证标记不可写。
为什么是问题：如果实现成普通赋值，页面脚本可覆盖或删除标记，导致桌面页不画外框；如果普通浏览器页面能先写同名标记，宿主的“没有标记就什么都不做”合同也会被伪造。它不是安全边界，但会直接影响桌面与浏览器两条渲染路径；同一 WebView 从启动页换成产品页时还必须保持能力标记稳定。
如何核实：在真实预加载后依次执行覆盖、`delete`、重新定义和整页导航，检查 `window.__nbookDesktopFrame`；在普通浏览器用同一页面入口验证没有标记时不出现外框。当前无 Windows 机器时，预加载注入位置和页面宿主判断属于从代码推断。
建议改法：用 `Object.defineProperty` 明确 `writable:false、configurable:false`（并决定 enumerable），在 `BridgeGlobal`/页面全局类型中登记；测试覆盖覆盖、删除、启动页到产品页导航和普通浏览器无标记四个场景。注明它只是渲染能力信号，不承担安全鉴权。
