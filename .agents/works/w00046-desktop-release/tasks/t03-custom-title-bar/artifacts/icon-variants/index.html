桌面应用图标：四份 SVG 在各尺寸的效果

每一格都是从 SVG 直接渲染到这个像素尺寸（resvg），按 1:1 显示，没有缩放。Windows 的程序、任务栏、Alt+Tab 图标只能用 ICO（里面是位图，装不了 SVG），所以做法是每个尺寸各渲染一张放进 ICO。

现在的 ICO：32、48 用“不带边框”，64–256 用“标准（带封面边框）”，换尺寸就换样子。之前被去掉的 16、24 是另画的像素专用版（没有尾巴、装饰和光环），不在这四份 SVG 里，作对照放在最后。
