# frontmatter 属性的图标与类型贡献点

## 目标与范围

插件按属性名给图标、类型与显示名：属性面板据此画图标、给类型菜单与输入；t10 决定 6 的附言，开发者 2026-11-17 同意做。

合同：[`workbench/markdown-editing.md`](../../../../../docs/specs/workbench/markdown-editing.md) 的属性面板（输出 39–51）；本 Task 要加一个贡献点，改它的“不承诺”（现在写着不做按属性名给图标、类型与显示名的贡献点）。来源：[t10](../t10-frontmatter-panel/README.md) 决定 6 的附言。

## 当前状态

2026-11-17 经 nbdev 新建，尚未开工。t10 决定 6 的附言问的是“图标是怎么映射的、要不要提供贡献点或在 frontmatter 里指定图标”：现在图标按推断出的类型取（文字、日期、列表、数字、勾选、复杂各一个），同时是改类型的按钮；不在 frontmatter 里写图标（数据里混进显示用的东西，别的工具会读到）。开发者 2026-11-17 答“可以给图标、类型提供贡献点”，同意做。
