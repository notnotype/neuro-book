A. 只设计第一批。第二批（动作、光标、提示条与停止、后果大的确认、拖拽指引、租约）另开 Task，用第一批的实现与实验结果设计。决定 6、12、16 里属于第二批的内容不变，只是挪到那个 Task。随之不在本稿处理的条目：O2、O4、O17、O19 的租约与 runId 部分，G6、G9、G10、G17、G25，S18。
B. 引导的等待改为服务端向窗口订阅（O1 的改法 a）：高亮只在订阅存续期间存在；服务端取消订阅即撤高亮；连接结束、提供项撤回、服务端重启由通道合同（plugin-channel.md 输出 7）结束订阅，得到确定的结局；同一实例重连时订阅重建，窗口重装高亮。去掉回报合同、等待 id 与早到、迟到的处理。处理的条目：O1、O3、O6、O18，G1、G2、G3、G22，S9 的孤儿部分。
C. 去掉 until: "none"：每个高亮都等用户（click 或 next），调用结束高亮就撤，不再有没人管的高亮。处理 O6、S9。
D. 不做租约，不靠“窗口正显示着哪些会话”：选窗口按“这个会话上次用的窗口（还连着、看得见、2 分钟内用过）> 有焦点的 > 看得见且最近有真实输入的”。窗口转后台就重选，回到决定 3 的原文（第三稿写成“不重选”与决定 3 相反，G8）。处理 O2、O8、O14、O19，G8、G10、G11。同一窗口两个会话同时引导时，后一个替换前一个（前一个得 replaced）。
E. 去掉 Esc 结束引导：只有说明框里的“跳过引导”。处理 S12。

逐条（不属于上面 A 到 E 的）：

1. 回报合同 callers 写错（O18、G1）：随 B 去掉回报合同。窗口合同仍是 provider client、callers ["server"]（callers 比的是运行位置）。
2. 截图的远程调用与上传的先后、时限、提交点（O5、G7、G23）。改：服务端先签凭证，再调窗口 capture（15 秒）；窗口重画、编码、PUT 上传，上传完成后 capture 才返回；服务端以“凭证对应的上传已收到且 capture 成功”为提交点，二者缺一则作废并失败；只有提交后的图进工具结果。
3. 截图的判定对象类型（O15）。改：value 是字符串，of 缺省为 "window"、给了为 "element"。
4. 窗口回复的大小（O12、G21）。改：按 UTF-8 字节定上限（快照文字至多 64 KB、元素至多 500 个、details 至多 8 KB），窗口回复前量字节，超了截断并标记；maxTokens 也有上限。
5. ToolCallError 的 details（G16）。改：details 必须可序列化为 JSON、至多 8 KB，超了丢掉并在文字里说明。
6. ui 方法的并发档（O16、G4）。改：全部声明 shared；高亮的等待不挡同一段代码里的其它 ui 调用。
7. 对象文档按会话生成（O10、G15）。改：删掉这项上游改动：Profile 按对象一行开关（决定 14）后，同一会话里 ui 的方法要么全有、要么全无，文档列全部方法即可。
8. Profile 一行开关跨批次保持（G19）。改：上游的工具绑定支持按 eval 对象开关（存对象，之后新增的方法跟随对象的开关），写进上游表。
9. 前台限定工具与 required（G20）。改：写明 ui 只作可选工具，不进任何 Profile 的 required。
10. eval 对象公告与内核方法表取自不同快照（G18）。接受：会话中途换 Profile 时内核已按现有规则重置（eval.md 输出 11、12），差异窗口很短，记为已知限制。
11. 等待期间用户在对话框发的话要等高亮结束（O13）。接受：说明框里的“提问”是引导中的对话入口；对象文档写明；运行状态显示 eval 卡片里正在等的那一步。
12. 等待协议的用例（O11）。改：测试里补订阅收口的用例（取消、断线、同实例重连、新实例刷新、服务端重启、超时）。
13. 寿命表与现有合同不符（O14）。随 D 重写寿命表。
14. 界面目录的路径走不通（O9、S3、S4、S5、S10、G12、G13、G14、G24）。改：第一版目录收窄为三类可靠的入口：设置（设置窗口的入口 → 用户或作品层 → 节 → 行，全部用真实 id 与现有标记）、视图（按当前布局在 DOM 里实际渲染的位置，取不到时用声明的缺省并标明）、命令（出现在活动栏、视图标题栏、设置窗口里的，加快捷键；命令面板只在命令 human 为真、没有必填参数且此刻可用时列为入口）。菜单（右键、菜单栏、“⋯”溢出）第一版不进目录。路径每一步给出“这一步之后页面会出现什么”，引导按步等目标出现。示例改成真实 id（nbook.workbench/theme、分区 nbook.appearance、设置窗口由活动栏项打开）。实验 8 在真实工作台上先核一遍再写计划。
15. 搜索（S6）。改：复用命令面板已有的跨语言子序列打分。
16. 自动标记（S11、O9）。改：不另起 data-nb-command 等新标记，引擎按插件给的映射表读现有标记（data-title-action、data-activity-item、data-settings-row、data-settings-nav 等）；只给没有标记的地方补；状态栏的量宽副本带 aria-hidden 与 inert，快照本来就不列。
17. 高亮不等目标出现（S2）、点击的判定（S7）、missed 过敏（S8、O7）、confirm 与 next 下的 missed（O7）。改：高亮先等目标出现并滚进视野（至多 5 秒，否则 not-found）；“点了目标”认目标上的 click 或在目标上抬起的 pointerup，第一批没有 Agent 的动作，不必区分真伪；missed 只在 until: "click" 下、按下的是目标、说明框、引擎自己的节点、滚动条与遮罩之外的可交互元素时才算；until: "next" 不判 missed。
18. 说明框在 reka 模态里拿不到焦点、点按钮会关掉菜单（S1）。改：说明框挂进当前最上层的容器里（在模态或弹出层的 DOM 子树内），对焦点锁与“点外面就关”都算在里面；实验 3 验证，不成立时模态与菜单里不显示“提问”输入、按钮在 pointerdown 时处理。
19. 先聚焦让 faint 出现与不抢焦点矛盾（S13）。改：不聚焦；工作台的悬停样式加一个“Agent 指着这里时也显示”的属性（上游小改），引擎在高亮期间给目标的悬停范围加上它。
20. 高亮框跟随（S15）。改：ResizeObserver、捕获阶段滚动、过渡与动画结束事件、DOM 变化，都触发重算；层的判据写明采样点（元素可点区域的中心，退到四角）。
21. 拖拽指引的落点是几何分区（S14）：随 A 挪到第二批的 Task。
22. nbTarget 放在核心包（S16）。改：nbTarget 是一个只返回属性对象的纯函数，放进核心包的独立入口 ./attrs，零依赖；带装饰的 nb-ui 控件上属性落在外层时，定位落到它唯一的可交互后代（第一轮已定）。
23. 停止按钮的键盘路径（S18）：随 A 挪到第二批。
24. confirm 的语义（G17）、审批卡取目标名字（O17）：随 A 挪到第二批。
25. 子会话继承窗口（O2、G10）。改：不继承，子会话按同一规则自己选。
