# 流程声明：插件登记多步操作的引导路径，ui.find 交回完整步骤

## 目标与范围

模型常常不知道某件事在 NeuroBook 里怎么做（例如发文件要在对话输入框打 `@`），只能先看页面、再回来写引导。本 Task 让插件把“怎么做某件事”登记成流程：

- 一条流程是一串步骤，每步写定位、这一步做完页面上出现什么、给用户的一句话；
- `ui.find` 能搜到流程（新的 `kind`），交回从当前进度起的完整路径，模型拿到就能一个 eval 走完；
- 每条流程配一条 e2e 按步骤走一遍：界面改了、流程跟着坏，马上能看到；
- 第一批流程：把文件发给 Agent、在编辑器里插入表情、给一段话加批注；其余按 [t04](../t04-guide-one-eval/README.md) 评测里模型最常卡住的补。

这是 [t01 决定 16](../t01-design/README.md#决定) 里“可复用的引导脚本以后另开 Task”那一项；会改掉 [`agent/page-agent.md`](../../../../../docs/specs/agent/page-agent.md) “不承诺”里“界面目录不收多步才完成的流程”一句。依赖 [t05](../t05-guide-wait-targets/README.md) 的等待条件与稳定名：流程里打字、选中这类步骤要靠“等某个东西出现”判断做完。
