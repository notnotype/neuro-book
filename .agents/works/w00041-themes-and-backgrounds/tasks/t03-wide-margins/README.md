# 窄编辑区也露出两侧场景

## 目标与范围

1440 宽且右栏开着时，编辑区放不下两侧，只有侧栏下角；让正文两侧在这类宽度下也有场景，且不压到正文

合同：[`theme/skins.md`](../../../../../docs/specs/theme/skins.md) 输出 5（正文两侧）。

## 当前状态

开发者 2026-11-06 要求做遗留项里的这一项。worktree：`.worktree/w00041-t03-wide-margins`，分支 `feat/w00041-t03-wide-margins`，还没改代码。

实测（默认布局，真实页面，编辑组宽度）：视口 1920 为 1123px，1440 为 643px，1280 为 483px。正文版心 720px，所以 1440 下版心已经把编辑组占满，两侧没有地方可画：这是空间不够，不是判据设得太严。要两侧出现，编辑组至少约 960px，也就是右栏开着时视口约 1760px 以上，或者关掉右栏。

## 下一步

等开发者在三个办法里选：保持现状、窄时收窄版心、在右栏空状态里放场景（见会话里的提问）。选定后写进这里再改代码。
