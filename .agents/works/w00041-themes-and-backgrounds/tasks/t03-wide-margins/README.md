# 窄编辑区也露出两侧场景

## 目标与范围

1440 宽且右栏开着时，编辑区放不下两侧，只有侧栏下角；让正文两侧在这类宽度下也有场景，且不压到正文

合同：[`theme/skins.md`](../../../../../docs/specs/theme/skins.md) 输出 5（正文两侧）。

## 开发者的决定

1. （2026-11-06）编辑区放不下两侧时，在右栏下角放场景；正文版心不动，也不收窄。

## 当前状态

已合入 master（见提交记录）。书房加了 `crop.auxiliaryCorner`，右栏（auxiliarybar）下角和侧栏下角一样露出场景图，挂在 Part 外壳上；Spec 输出 6、验收 12。

实测（默认布局，真实页面，编辑组宽度）：视口 1920 为 1123px，1440 为 643px，1280 为 483px。1440 下版心 720px 已把编辑组占满，两侧没有地方可画，所以不动两侧的规则，只在右栏补上。

- 可读性：右栏最下面 240px 里、输入框以上的部分，次要文字与正文的最差对比度亮色 5.24、暗色 8.16。第一版淡出强度下亮色只有 4.21，所以右栏的图加了 0.7 的不透明度。
- 截图：1440 宽亮暗两种、欢迎页与写作两种状态，右栏下角是窗边与绿植，没有发现遮挡。

## 遗留

- 对话列表很长时压在图上的真实消息没有测（没有模型会话）：上面量的是这一带的最差像素对比度，不是真实消息。
- 小于约 1760px 且右栏关着时，仍然只有侧栏下角（编辑组不够宽时两侧本来就没有地方）。
