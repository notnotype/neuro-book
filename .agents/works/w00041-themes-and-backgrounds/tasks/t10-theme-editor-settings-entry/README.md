# 设置窗口里的主题编辑器入口

## 目标与范围

设置窗口左栏加一页“主题”，作为主题编辑器的入口。t08 交付时只有命令与标题栏菜单两个入口，设置里没有，开发者发现后补上。

合同：[`theme.editor`](../../../../../docs/specs/theme/editor.md) 输出 1、验收 15。

## 开发者的决定

1. （2026-11-06）“主题编辑器设置界面好像没有入口”：补设置里的入口。

## 当前状态

已合入 master。

- 设置窗口左栏（应用一组，仅用户标签）新增一页“主题”（`settings.pages`，由工作台的浏览器入口贡献，组件 `ThemeSettingsPage`）：标题区右侧“在浮动窗口中打开”“在页签中打开”，正文是一句说明、正在使用的主题、“我的主题”列表（在用的带“使用中”）。这一页不改设置，换主题仍在“外观”里选。
- 为什么是单独一页：设置行放不下操作按钮（t08 就是因此没做）；另做“行里的操作按钮”要改设置合同，范围大，没有必要。
- 验证：`theme-editor.e2e` 10 个全过（新增：打开“主题”页、两个按钮分别开页签与浮动窗口，且点得到编辑器里的控件，证明没被设置窗口挡住）；`settings.e2e` 18 个全过；workbench、settings、lab、ui 单测 625 个通过；类型检查与 `governance:check` 干净；Lab 新增 `ThemeSettingsPage` 三个场景，截图看过。
- 没做：打开编辑器后自动关设置窗口（页面上下文没有关窗口的口子，窗口又是非模态的，e2e 里点得到编辑器）；点“我的主题”里的某一套直接选中它来编辑。
