# 主题切换过渡动画

## 目标与范围

切换主题或明暗时整页平滑渐变；编辑器里连续改色、首次进入、减弱动效偏好下不动。顺带两处主题编辑器的改动（开发者随后提出）：对比度检查分区画成直观的样张，顶栏的亮/暗/关闭不再单独占一排。

合同：[`theme.system`](../../../../../docs/specs/theme/system.md) 运行时流程第 6 条；[`theme.editor`](../../../../../docs/specs/theme/editor.md) 输出 14、验收 5。

## 开发者的决定

1. （2026-11-06）“主题切换动画好不好做？好做的话就做一下”；其余自主发挥。
2. （2026-11-06）“对比度检查这个直观一点，拿出来给用户看”：按“看下”理解，做成样张加等级，不合格的排前。
3. （2026-11-06）“亮色、暗色、关闭这里没必要单独一行”。

## 当前状态

已合入 master。

- **渐变**：`createDocumentThemeWriter().apply` 在换了主题（主题目录 id，不是主题包 id：我的主题与 NeuroBook 同一个包）或明暗时，用浏览器的 View Transitions 交叉淡入。第一次写入、同一主题只改配色变量、浏览器不支持、偏好减弱动效时直接写；渐变回调在下一帧才调，期间又有新的写入或页面已卸载则不写旧主题。
- **对比度检查分区**：新组件 `ThemeEditorContrast`，两套明暗各一组，每个文字色一行：真实颜色的样张、变量与最差底色、比值、等级（不合格/AA/AAA）；不合格排前、红描边，“去修改”切到配色分区并把光标放进那个色值。`ContrastCheck` 加了 `sample`，另有 `contrastGrade`。
- **顶栏**：库操作自己换行，亮/暗与关闭固定在右上；手机宽度放不下才落到下一行。
- 验证：`theme-editor.e2e` 9 个全过（新增“整页渐变；改色与减弱动效时不渐变”，对比度用例加了样张与“去修改”）；`contrast-checks`、`themes`、`locales` 与 workbench、ui/theme 单测 406 个全过；类型检查与 `governance:check` 干净。真实截图看过 1000、760、560、420 宽的编辑器与对比度分区。
- 踩到的：e2e 默认开着“减弱动效”（`playwright.config.ts`），看动画的用例要 `emulateMedia` 开回来；一开始用主题包 id 判断“是否换了主题”，换到同包的我的主题时不渐变，改用目录 id。
- 没做：渐变的圆形展开（要点击坐标）；独立审查（改动小，靠 e2e 与单测兜底）。
