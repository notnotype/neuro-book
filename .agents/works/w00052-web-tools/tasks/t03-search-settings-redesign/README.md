# 搜索与网页设置页重做：服务商 logo、列表版式与四项新设置

## 目标与范围

“搜索与网页”页在服务商变多以后不变长：版式先出两版静态稿、评审后择一；每家服务商带 logo；加四项设置。定稿后改 Spec、再实现。

合同：[`web/settings-page.md`](../../../../../docs/specs/web/settings-page.md)、[`web/tools.md`](../../../../../docs/specs/web/tools.md)（新设置的行为），定稿后改。

## 来源

开发者 2026-11-25 看了 t02 的设置页：“设置怎么这么少？是不是少了一些设置？”；“使用”用分段单选，“如果搜索服务多起来后这个就会变得很长”；“可以给这些搜索服务的提供商提供 logo”。

现状：t02 的页面是单列，顶上“使用”一行分段单选（DeepSeek、Tavily），下面每家一整节（密钥、检测、说明）；接口地址只能改设置文件。参照是模型设置页的服务商列表（`ProvidersPage`：左栏 `ProviderRail` 加右边详情，窄于 600px 时左栏换成下拉；w00032 t29、t43 定的版式）。logo：模型页用的 `@lobehub/icons-static-svg`（MIT，应用的图标表 `src/ui/provider-icons/`）里已有 Tavily、Exa、DeepSeek、Brave、Bocha、Jina、Firecrawl、Kagi、Perplexity、SearXNG、Bing。

## 决定

开发者 2026-11-25（会话里选的）：

1. 加四项设置：每家的接口地址（现在只能改设置文件）、缺省结果条数（Agent 没写 `count` 时用）、屏蔽网站、Tavily 的搜索深度（basic 每条 1 点额度、advanced 2 点）。
2. 版式先出两版静态稿再定：照模型页的“左边列表、右边详情”，与“下拉加可折叠卡片”。

开发者 2026-11-25 在第 1 轮评审板答复：

3. 版式用 A：左边列表（顶上“搜索规则”，下面各家服务商）、右边详情；窄时左栏换成顶上的下拉（同模型页）。
4. 把还没填密钥的一家设为使用中：先不切，焦点进这家的密钥框、密钥行右边写“填写密钥后即可启用”，填好保存后自动切过去；正在用的那家也没有密钥时（第一次配置）照常切。

## 第 1 轮

草稿在草稿 worktree `.worktree/w00052-t03-drafts`（分支 `t03/drafts`，不合并），Lab 里是 `drafts/search-settings/SearchSettingsDraftA`、`SearchSettingsDraftB`。评审板 `artifacts/review/`（v1），问两题：版式 A（左边列表、右边详情）还是 B（下拉加可折叠卡片）；把还没填密钥的一家设为使用中时“先填密钥再切”还是“照切、提示补密钥”。

`@designer`（Gemini）的意见（本地 `reports/designer-reply.txt`）取用了这些，已画进两版稿、列进评审板的“直接修”：推荐 A（与模型页同构、家数多了不变长），但要分开“看哪家”与“用哪家”；没在用、也没填密钥的不挂警告，只有使用中那家缺密钥才挂黄钥匙；使用中写徽标不用蓝点（设置行的“已修改”是蓝点）；通用的两项叫“搜索规则”、A 放左栏顶上；删每家的说明句，DeepSeek 那句收进问号；计费提示改“可能计费”；搜索深度两档叫“标准 · 1 点”“深度 · 2 点”；“先填密钥再切”也是它提的。没取用：一家都没密钥时不标任何一家使用中（设置项有缺省值 DeepSeek，“未启用”要多一种状态）；屏蔽网站改成多行文本框（先用和别处一样的标签输入，评审时再看）。

## 实施

Spec 先改（`f408186c3`、`0c80ebfde`，新行为标 planned），代码在 worktree `.worktree/w00052-t03-search-settings`（分支 `feat/w00052-t03-search-settings`），提交 `20fbf8df5`、`b94e87398`。

实施者定的（低风险、可改）：

- 默认结果条数 1 到 10、缺省 5，一条查询与几条查询都用它（原先一条 8、几条 5）；给了 `count` 时上限不变（一条 20、几条 10）。
- 屏蔽网站只管搜索结果，不拦 `web_fetch`（按主机拦读取用权限规则）；至多 100 个；Tavily 给 `exclude_domains`，两家都在本地按“主机等于或是子域名”再筛（DeepSeek 没有原生参数，写成 `-site:` 会吃掉 128 字的查询上限）。检测不受深度与屏蔽影响。
- 接口地址与 Tavily 深度用设置行（`SettingsRow`：改过的标记、恢复默认）；设置项不写说明（界面不写说明句）。
- 抽出共用的 `ProviderLogo`（`ui/provider-icons`），模型页的 `ProviderIcon` 改用它画图标表与首字母；图标表登记 Tavily。
- 窄布局的下拉只写名称（下拉的选项只认图标类，画不了图片 logo）。

验证（`b94e87398`）：完整类型检查通过；网页插件、图标表、架构与约定键 158 过；DOM（网页插件、模型页、Lab 登记）78 过；e2e `web-settings` 3 过（含先填密钥再切、设置文件里的值）；Lab 截图 38 张没有溢出与焦点环被裁；开发服务真实页面点过主路径（设置窗口、换项、设为使用中、搜索规则）。变异检查 10 处：9 处被抓到，“只有使用中那家挂钥匙”那处补了断言后抓到；“域名转小写”那处活下来是因为 URL 解析本身就转小写，不算缺测试。
