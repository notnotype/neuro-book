# 星璃真名契约仪式与初始记忆生成设计

## 目标与范围

设计首次启用星璃（Lyra）时的**「真名契约仪式（True Name Contract Ceremony）」**交互与引导流程：

1. **解决“初见生硬科普”与“每次开场重复提通讯方式”的痛点**：
   - 将“缔结真名契约（*Astria Lyra Luminis*）、解释 NeuroBook 与忆星书庭的跨维联系”独立为一次性的**初见契约仪式**，使日常普通会话不再每次都从“刚签完契约、星语台刚亮起”开始。
2. **在契约仪式中自然收集作者信息、支持提示词模板变量并生成初始 `profile://memory/master.md`**：
   - 星璃在契约仪式中向作者自我介绍，自然交代 NeuroBook 是什么（与她怀中《万界真典》契约扉页相连的跨维创世终端）；
   - 引导收集并记录：**如何称呼作者（默认 `Master`，契约时可自定义）**、**作者的人称代词（默认 `他`，可自定义为 `她` 等）**、**作者想写什么样的故事或创作梦想**、**两人之间的契约约定**；
   - 系统提示词中的用户称呼与第三人称代词做成可替换模板变量（默认 `Master` 与 `他`），连同仪式结果一起初始化写入配置与 `profile://memory/master.md`。
合同：待排期设计具体交互形式（引导向导 / 专用初见会话脚本）与关联 Spec。
