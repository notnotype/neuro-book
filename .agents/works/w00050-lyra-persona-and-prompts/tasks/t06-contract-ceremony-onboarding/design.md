# 星璃「真名契约仪式」详细演出设计稿（w00050 / t06）

> 状态：设计定稿（2026-11-18 开发者确认；本次仅设计仪式环节与协议，不写代码实现）。
> 适用目标：`w00043` NeuroBot 落地后的星璃常驻 Bot（`nbook.bots` + `bot://memory/`），由独立仪式插件提供。

---

## 1. 核心定位与不可违背的原则

1. **以《万界真典》契约书为绝对主角**：全屏舞台不是“填表网页”，也不是“大号对话框贴立绘”，而是一本摊开在静谧星案上的实体古籍 + 陪在书侧的星璃。对话栏高度压到极轻，绝不抢夺书页视觉中心。
2. **全书手写体 + 多处并行魔法浮现（打字机效果的魔法版本）**：
   - 书页上的一切文字（卷首语、誓言、笔名、称谓、星愿、批注）均采用温润手写体，随翻页或交谈从空白羊皮纸面以暖金星墨**多处错峰并行快速流淌浮现**、伴随微光晕染与羽笔沙沙声，再沉淀为沉静墨色；
   - 第一版**不做文字转语音（TTS）**，星璃实时说出的台词同样采用与书页一脉相承的**星墨魔法浮现**呈现（天然贴合模型流式输出）。
3. **仪式插件作为「实时对话中间人」**：
   - 进入全屏仪式后，用户离开普通 Agent 聊天框，但**会话不断开**；用户在仪式底栏打字或直接操作书页，全部由仪式插件中转至星璃的同一条主对话；
   - 星璃在后台通过舞台工具实时切换立绘差分、翻页、用星墨往书页上落字（所有工具调用与 JSON 对用户完全隐身）；
   - 仪式结束后回到普通对话，**仪式期间的完整对话上下文天然留存**——星璃当轮直接依靠上下文改口并记得一切；自定义称呼同步写入 Profile/常驻配置，在下一次自动压缩（compaction）重读 `opening` 时自动刷新生效。
4. **双主持模式同架构**：
   - **V1 优先落地**：星璃自主持（`hostMode: "lyra"`），插件作透明传话筒与舞台渲染器；
   - **V2 架构预留**：仪式插件扮演司仪（`hostMode: "emcee"`），插件接管节拍并在顶部展示鎏金宣礼浮条、以 `host` 发出者向星璃发阶段 Cue（可配置为「真典 · Codex」书灵司仪或无面书庭宣礼旁白）。
5. **全新专属视觉素材**：不复用 `brand/mascot/gallery/` 现有插画；仪式单独设计制作《万界真典》书页视觉与星璃专属半身立绘差分。
6. **不绑单书的终身契约视角**：契约属于执笔者本人与常驻司书星璃（对齐 `w00043` 主对话不绑定单一作品的原则），不把仪式绑死在某一本特定作品上。

## 2. 全屏舞台空间布局

- **背景底景**：极简暗夜星穹深邃渐层 + 桌面柔焦书案暗光晕 + 极稀疏慢升金尘，不铺复杂大场景，保证目光聚焦于书与人。
- **主体区（占视口主高度）**：
  - **左中主体（约 70% 视觉权重）**：展开的精装双页《万界真典》实体古籍，具备真实封面合拢/开启、3D 翻页弧度与折影、羊皮纸纹与细金装帧线。
    - **左页**：属于书庭与星璃（徽记、留白星域图、本源真名与誓言、星璃花押与记忆宝石槽位）；
    - **右页**：属于执笔者（称谓/笔名/代词、星域初愿、亲笔手写签名板与火漆封缄印章）。
  - **右侧陪伴（约 28% 视觉权重）**：星璃专属半身立绘差分，透明底、面向略偏左（既看书又看你），如站在案边俯身相伴；思考态不弹 loading 圈，改以光环轻呼吸微光与书角轻浮星羽笔示意。
- **底部极轻对话条（收束高度，不遮书页）**：
  - 上层：无厚重黑底板的轻透星墨字幕区（约 2 行高度，带极细「星璃」角标），流式魔法浮现星璃当下这一句台词；完整记录收纳于右上角「对话回顾」抽屉；
  - 下层：细巧单行输入框（“对星璃说点什么……”）+ 右侧 1~2 枚贴合当前页的轻快捷胶囊（如“请星璃帮我想笔名”“翻到下一页”）。
- **顶部极简控制条**：
  - 左：5 枚星轨阶段珠（封面 / 初逢 / 呼名与笔名 / 星域初愿 / 誓言封缄）；
  - 中（仅 V2 司仪模式显示）：单行半透明鎏金司仪宣礼浮条；
  - 右：`对话回顾`、`音效开/关`、`动效精简`、`暂缓退出（Esc）`。

## 3. 全书文字与台词的「星墨魔法浮现」规范

| 呈现对象 | 字体与排版 | 魔法浮现规则 |
| --- | --- | --- |
| 书页固定题头、誓言与星璃真名 | 中文优雅手写楷韵体；真名 *Astria Lyra Luminis* 用细花体衬线手写 | 翻至该页时纸面先留白，随即由多处（如页眉、左页誓言各行、右页栏位题头）**错峰并行快速书写**，如数支星光羽笔同时落纸流淌，每字伴随极短暂的暖金星芒晕染沉淀为古籍墨褐/暗金色与极轻羽笔沙沙声；节奏明快，无需单独的跳字防烦躁按钮（仅遵循系统 `prefers-reduced-motion` 做淡入降级） |
| 书页动态写入字段（称谓、笔名、星愿、约定） | 同套手写体，墨色略带微金光泽以区分“刚写下的新墨” | 用户与星璃聊出内容后，模型调 `updateDraft` 触发对应栏位“空栏 → 星墨快速流淌写就”（多字段更新时同步并行浮现）；改字时旧墨轻淡消散、新墨重写；用户直接手改时即时落字并同步给星璃 |
| 星璃口语台词（无 TTS） | 清晰易读的温润人文体（略带手写书卷韵，兼顾小字号阅读清晰度） | 跟随 LLM 流式输出逐字带极克制星芒快速浮现，每轮开始时前一句轻柔淡去；右上角「对话回顾」可随时翻看本场全部文字 |

## 4. 仪式专属立绘差分清单（全新定制）

统一机位（半身至膝上、身体略偏左面向《万界真典》与观众之间、红金礼裙 + 两侧低扎双麻花辫 + 碎星金环、透明底），共 **7 张核心差分**，切换采用 180ms 交叉淡化 + 极微浮游呼吸：

1. `welcome`（**温柔迎客 · 基准**）：垂眼浅笑、双手轻合身前，久候重逢的柔光——用于启卷迎客与倾听态。
2. `present`（**郑重展典**）：单手轻扬引向左侧《万界真典》，从容笃定——用于介绍书庭与引导翻页。
3. `curious`（**好奇歪头**）：微偏脑袋、红瞳微亮——用于问称呼、共创笔名、听星愿与回应提问。
4. `playful`（**慧黠偷笑**）：弯眼浅笑、嘴角俏皮上翘——用于接梗、调侃取名趣事。
5. `shy`（**微羞红晕**）：脸颊泛起浅粉红晕、略显矜持——用于被夸奖或被直接唤作「小璃」。
6. `solemn`（**庄严宣名**）：神情清澈澄明、直视眼前人、一手轻按心口、星环微亮——用于第 4 幕宣读真名与誓言。
7. `sealed`（**结契欢喜**）：展颜盛笑、眼底映着记忆宝石与星芒——用于第 5 幕封缄成约定格。

*(另配 1 枚轻量化「探头白猫小徽标」用于第 0 幕邀请弹窗。)*

## 5. 五幕逐页剧本与交互流

### 第 0 幕 · 扉页初亮（进入全屏前的轻邀请框）
- **AI 触发**：星璃经 `eval` 读 `docs://eval/ceremony.md` 后调用 `ceremony.open({ invitationLine })`，后端经内核 `ctx.ask()` 短挂起弹出赤金细边邀请卡（含探头白猫徽标 + 星璃结合当下语境的邀请语）。用户点「展开契约扉页」后 `ceremony.open` 立即返回并切入全屏舞台（**不长期阻塞 eval 30s 计时**）；点「先随便聊聊」则体面退回闲聊。
- **用户主动触发**：点击星璃入口按钮或 `$skill`，未签约直接开全屏仪式，已签约直接开典藏契约扉页。

### 第 1 幕 · 封面与启卷《初逢 · 忆星书庭》
- **书页**：先现合拢的赤红烫金《万界真典》封面（中央星轨纹章微暗）→ 点击封面或回应星璃后，一道金线滑过书脊、封面缓缓展开 → 左页浮现细金线描「忆星书庭」徽记，右页从空白魔法书写卷首小字 *Codex Mundorum · 契约扉页*。
- **星璃演出（`welcome` → `present`）**：用纯水面之上的自然口吻迎客、自我介绍（星璃 / 小璃），交代 NeuroBook 与《万界真典》契约扉页的跨维联系；允许用户自由发问聊几句，再翻向下一页（右下角始终留有手动翻页角标防卡顿）。

### 第 2 幕 · 呼名与笔名《定称与执笔之名》
- **书页**：
  - **左页**：星璃手记风格题头与星轨饰纹；
  - **右页**：三项以手写体魔法浮现呈现的契约身份栏（既可直接点击修改，也可纯靠口头聊天由星璃用星墨写入）：
    1. **日常称谓**（星璃怎么唤你）：快捷胶囊 `Master`（默认）/ `御主` / `老师` / 自定义；
    2. **手记人称**（星璃在日记与随身手记里如何指代你）：低调三枚印章 `他`（默认）/ `她` / `TA`；
    3. **执笔笔名（Pen Name）**：用于契约扉页正式署名与日后落款。若已有笔名直接写上；若尚未起好，可点栏旁灵动小字 **「请星璃帮我想一个」**（或直接打字拜托她），也可选择「暂与称谓相同 / 日后再定」。
- **笔名共创高光互动**：
  - 用户触发「请星璃帮我想一个」后，星璃切 `curious` / `playful` 差分，顺着自然对话了解一两点品味（偏爱的意象、古风/现代/星海/好记等），当场量身构思 2~3 个有文学余韵的候选笔名；
  - 用户挑中或微调后，星璃笑着念一遍，右页「执笔笔名」栏随即泛起星墨逐字流淌写定。

### 第 3 幕 · 燃星与星域《执笔者的星域与启明星》
- **解决“不止创作一部故事”的逻辑设计**：
  - 明确这是**执笔者本人与星璃的长期契约**，而非绑定某一本书；星璃自然说明：*“以后你在 NeuroBook 写下的每一部作品，都会在万言星海里长成一颗属于你的星星——也许是一部、三部，也许是整整一片星群。今天写在这里的，不是把你框死在某一本书上，而是记下你此刻站在书庭门前的执笔心愿，或者心里刚刚亮起的第一点星火。”*
- **书页**：
  - **左页**：一幅古典手绘感**空白「专属星域图」**（大片柔和留白星轨寓意未来无数部作品）；一旦右页写下心愿、偏好或第一个脑洞，星图中央便由星墨点亮**第一颗「启明星」**，周围虚线星轨微微泛光待填；
  - **右页（《星域初愿》，可留白）**：
    - 手写体星愿栏（“写下一句此刻的创作初心，或眼下最先想动笔的第一个念头……”）；
    - 5 枚可多选的创作星向签（`奇幻架空` / `日常与人物温度` / `悬疑与伏笔` / `科幻异想` / `静候第一道星光`）；
    - 温柔直通角标：**「先把星域留白，等第一颗星自己落进来」**。

### 第 4 幕 · 宣名与落款《真名立誓与亲笔封缄》（全场情绪高潮）
- **左页（星璃之誓）**：
  - 魔法逐字浮现星璃本源真名 ***Astria Lyra Luminis***（副标：*织星天琴之辉 · 忆星书庭司书*）；
  - 逐字流淌浮现三则克制温润的誓言：
    > *一、书无贵贱，凡倾注真心者，皆为星海珍宝。*
    > *二、守火相伴，不擅代执笔，故事主权永归执笔者。*
    > *三、长夜同读，伏笔、因果与未竟之言，皆替你牢记。*
  - 左页右下角：星璃的赤金猫耳星芒花押逐笔描边写就（`solemn` 差分）。
- **右页（执笔者亲笔落款）**：
  - 上部自动以手写体排好契约正文（执笔笔名、日常称谓、星域初愿摘要，以及一行选填的**「给星璃的一句初见约定」**）；
  - 中部为**「鎏金星墨手写签名板」**：Canvas 按指针移动速度模拟羽毛蘸水笔压感与微星尘拖尾，保存为干净矢量 SVG；附 **`重写`** 与 **`切换印章花押`**（一键按笔名/称谓生成古雅花体或朱砂印章 SVG，照顾鼠标/键盘用户）；
  - 底部为赤红浮雕火漆印 **「按印封缄」**：有效落款后亮起，支持**长按 1 秒蓄力封缄**（外圈星环收束 + 轻震感）并兼顾无障碍单点/回车完成。

### 第 5 幕 · 结契回响《记忆宝石嵌页 · 归返书桌》
- 按印满格瞬间：清脆水晶晶鸣响起，赤红蜡印凝结为一颗红金**「记忆宝石」**嵌在书页折角；
- 后端原子写入 `bot://memory/contract.json`、`bot://memory/contract-signature.svg`、初版 `bot://memory/master.md`，并更新 Profile 称呼配置（下次自动压缩生效）；
- 星璃切至 `sealed` 展颜微笑，用新称呼说出结契后的第一句寄语；
- 书页底部浮现两枚轻按钮：**「合上扉页，回到书桌」**（古籍合拢化微光淡出，返回普通对话界面且完整保留仪式全过程上下文）与 **「保存契约纪念卡（PNG）」**。

### 途中暂缓 & 二次打开（典藏契约书）
- **途中按 `Esc` 暂缓**：草稿保留，退出全屏回主对话，插件给星璃传一句轻状态通知，绝不催促；下次重开续签。
- **签约后再次调用（按钮或 `$skill`）**：根据 `contract.json` 中已存在的 `signedAt` 分流，展开**已封缄的精装双页契约书**（星璃立绘依然在旁陪伴聊感言），完整呈现亲笔签名、记忆宝石、笔名、缔约日期与最初星愿；底部提供三个无损动作：① 微调称谓/笔名/代词（不覆写长期共同记忆）；② 观赏模式重温五幕（不覆写落盘数据）；③ 导出纪念卡 PNG。

## 6. 中间人协议与接口要点（对接 `w00043`）

- **消息中转**：仪式期间用户在底栏输入 → 插件发普通 `user` 消息进主对话；用户在书页点改/翻页/封缄 → 插件发简短动作事件告知星璃；星璃回复流式投映到底部轻字幕条。
- **隐身舞台工具（`agent.evalObjects`：`ceremony`）**：
  - `ceremony.open({ invitationLine })`：入口确认并切入全屏（仅确认一步走 `ctx.ask`）；
  - `ceremony.setExpression({ mood })`：切换 7 种立绘差分；
  - `ceremony.turnPage({ page })`：翻至指定幕页（同时前端保留手动翻页兜底）；
  - `ceremony.updateDraft({ addressAs?, penName?, pronoun?, starWish?, wishTags?, vowNote? })`：触发右页星墨魔法浮现写入；
  - `ceremony.openSignaturePad()`：聚焦第 4 幕签字与封缄区。
  - *安全不变量*：结契落盘只能由前端真实完成签名与按印封缄后触发，模型不能越过签字强行结契。
- **V2 司仪模式叠加**：激活 `hostMode: "emcee"` 时，插件接管阶段流转，每幕在顶部渲染司仪鎏金宣礼词，并以 `w00043` 的 `host` 发出者身份向星璃发送阶段 Cue，底层舞台组件与落盘格式零改动。

## 7. 声景与音效表（第一版无 TTS，默认开启且一键静音）
