# 表情选择器：编辑器补全与 Agent 输入框发表情

## 目标与范围

一个共用的表情选择器组件：Markdown 编辑器里打冒号弹补全、工具栏按钮；Agent 输入框能选表情发出写法原文，用户消息里的表情显示成图。模型只看名字与描述。来源：开发者 2026-11-18 意见第 3 条（“编辑器的菜单有没有表情包相关的输入控件，有没有做表情包选择器？agent composer 有没有表情包能否发表情包？”）；排在 t08 之后。

合同：[`agent/stickers.md`](../../../../../docs/specs/agent/stickers.md) 去掉“不承诺”里的输入框发表情与编辑器补全两条，新增选择器与补全的输出条目；[`ui/prompt-editor.md`](../../../../../docs/specs/ui/prompt-editor.md) 加表情写法；[`workbench/markdown-editing.md`](../../../../../docs/specs/workbench/markdown-editing.md) 的工具栏与斜杠菜单加“表情”。具体条目在设计定稿后写。

## 决定

开发者 2026-11-18 在会话里定（都选推荐）：

1. **入口**：编辑器里打 `:` 弹补全、工具栏加“表情”按钮、斜杠菜单加“表情”；Agent 输入框里打 `:` 弹补全、工具栏加表情按钮。按钮与斜杠打开同一个选择器（搜索框、按表情包分组的表情网格）。
2. **列哪些包**：全部有效的表情包（我的在前、各插件在后），最前面一排“最近用过”（本机记住，至多 16 个）；编辑器与输入框一样。
3. **补全的触发**：半角 `:` 前面不是英文字母或数字（`http:`、`10:30` 不弹），后面至少打了 1 个字才弹；按名字、拼音首字母与包名筛。全角冒号不触发，中文输入法下打半角冒号或用按钮。
4. **输入框与消息里的样子**：输入框里表情显示成行内小图（同编辑器）；发出去的用户消息与 Agent 回复同一规则：单独一段且不超过 3 个时是大图，句子里是行内小图。发出的文字是写法原文。

第 1 轮评审板（v1，2026-11-18 答复，都选推荐）：

5. **选择器版式 A**：顶上搜索框，下面一排表情包标签（第一个是“最近用过”），网格按包分组，底部一行写指着的表情的名字与写法；点一下插入并关上，Shift 点插入后不关。附言：“表情包标签图标。不要下边框和左边框”，当前的标签只用底色标出，不画强调色的下边线（B 的左边线同理不用）。
6. **补全菜单一行**：24px 小图、名字、右边淡色的表情包显示名；编辑器里跟着光标在下方，输入框里与外框同宽在上方；插入的写法一律带包。
7. **只有表情的消息不画气泡**：大图直接放在消息的位置；句子里夹着表情的照常在气泡里。附言：“表情包带文字的这个气泡这里，我感觉表情包和文字高度没有对齐”，行内小图要与同一行的文字在竖直方向上居中对齐，实现时在真实的展示器与编辑器里量。
8. **按钮位置**：编辑器工具栏在图片按钮后面；斜杠菜单在“块”组“图片”的后面；输入框工具栏在 `+` 后面（单行版式在前置按钮里）。选择器从按钮下方弹出（放不下翻到上方），插入在光标处；打开时焦点进搜索框，Esc 关上、焦点回正文。

设计审查后开发者 2026-11-18 在会话里定：

9. **补全不为单个英文字母弹出**：查询只有 1 个英文字母时不弹（`:D`、`:P` 这类颜文字回车时不插进表情），2 个字母或 1 个汉字照弹（`:kx`、`:开`）；没有匹配的表情时也不弹。
