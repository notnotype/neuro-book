# 关闭原生 Thinking 与外置显性角色思维链研究

## 目标与范围

解决模型在原生 thinking 中将角色提示词识别为“角色扮演指令”、从而把扮演当成一项任务并用默认 AI 助手视角思考的问题（开发者 2026-11-17 通过观察思考摘要发现）：

1. **核心问题**：开启模型原生 thinking 时，模型在内部思考链中倾向于以旁观助手口吻分析“我该如何按照星璃的设定回复用户”，而非真正把自己代入为星璃本人去思考；在系统提示词中点破可适当缓解，但无法根治。
2. **研究方向**：关闭模型原生 thinking，改用**外置显性思维链**（例如类似社区预设 `<think_nya>` 或角色第一人称内心独白块），让模型直接以角色第一人称在显性思维链中思考，彻底消除默认助手思维。

合同：尚未开工；作为 `t01` 之后的专项研究任务。
