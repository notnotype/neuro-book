# 秘密、知情与揭示计划

## 目标与范围

把 nb-story 的秘密矩阵（谁在何时知道什么）扩到作者侧：作者定好秘密的真相与揭示计划（哪一章让谁知道、让读者知道），写完后与正文层核对。

合同：讨论 Task，只定设计，行为合同未变；定稿后的 Spec 改动在实施时另定。

前置：t02、t04。

## 要讨论的问题

1. 作者层的秘密与读者层的秘密是不是同一个对象；作者没登记、抽取发现的秘密怎么处理。
2. 揭示计划的形状：对“读者”与对各角色分开计划；挂章节还是挂场景。
3. 泄底检测：计划第 N 章揭示，正文层在更早的位置已经让读者知道（或推断得出）；推断算不算泄底。
4. 旧版章级 brief 的“信息控制”四项与这里的关系：brief 从揭示计划编译出来，还是作者手写。
5. 误导与红鲱鱼：作者故意让读者相信错的东西，模型怎么表达（读者层的“相信”加作者层的“真相相反”）。
6. 与 t04 的交叉：回档后谁记得什么。
