### 19. 新增的作者签名摘要没有定义临时 id 的签名前后规范化
**严重程度**：阻断；**类别**：正确性
**位置**：审查 worktree `docs/specs/canon/revisions.md:49-53,108-110`，`docs/specs/canon/model.md:248`，`docs/specs/canon/components.md:127`。
**现象**：宿主在请求发出前，对需要作者来源的字段的改后值做规范 JSON 的 SHA-256 并签名；内核则按“请求结果里的实际改后值”重算。只有 binds.decision 明确允许新建决策用临时 id，about、标注等授权字段里的临时条目/决策/世界线引用怎样规范化没有规则。
**为什么是问题**：同一请求新建 K 并新建一个挂在 K 上的已定决策，是现有写入格式允许的原子操作。宿主签的是 about 里的 tmp:k，内核结果里却是 e1，两份摘要不同；改为全用正式 id 签名又要求宿主在发布前知道内核分配结果。并发的无关发布还会改变分配结果。不能靠忽略这类摘要差异解决，否则重新打开了替换授权对象的路径。
**如何核实**：在实现 worktree 的 nb-canon 包目录运行 `bun /tmp/w00039-specs-review1b-lab/source-binding.ts`。经真实 World.publish 新建条目与旧未决问题，同批 about.id 从 tmp:k 变为 e1；相同授权字段的 SHA-256 从 670b63d910f8d2199e72efe408e23ab593f7112b4fac96277b3a30767f3efd98 变为 720837b1e63cec985c4b72000f97691564acdc7677c4c139ac332b9c43e0f83e，equal=false。实验只证明既有真实发布路径的引用替换会改变载荷；新作者来源校验器未实现，拒收结论来自本版两条合同的组合，不伪称已跑过新校验器。
**建议改法**：明确签名针对原始请求里、保留临时 id 的授权字段投影；内核在替换前重算相同投影，替换时仅改执行载荷，不改已签 source。或者提供有身份与有效期保证的 id 预分配合同。补“同请求建条目+已定决策+互相引用”以及预览后其它无关对象发布的验收。

### 20. source 同时保存历史出处和本次授权，导致普通改写与还原无法同时满足合同
**严重程度**：重要；**类别**：不变量
**位置**：审查 worktree `docs/specs/canon/revisions.md:49,98,108-111`，`docs/specs/canon/model.md:145,205-206,242,247-248`，`docs/specs/canon/project.md:59,77`。
**现象**：source 是对象里保存的“最近一次需要作者来源的转换”的出处；新规则又要求它绑定当前 requestId、转换和字段。输出 21 还规定“不需要来源的写入带了来源，照样校验”。因此重新打开的 pending 决策保有旧 source，Agent 从 object 取整份对象、只改允许无来源修改的 candidates，也会把历史 source 当作本次凭据重验，并因 requestId 不同被拒。还原把旧 source 恢复回来时同样不能通过本次还原的绑定；换成本次来源又不再是“字段恢复成改前的值”。
**为什么是问题**：不能通过同一个持久化字段区分“历史出处原样携带”与“本次申请授权”。正常无授权的候选编辑和补偿还原都需要实现者另造例外。还原请求目前只有修订、连同依赖与请求 id，没有为每条受影响决策承载新来源的公开参数；一次还原涉及多条决策时更无法按输入表构造请求。
**如何核实**：`bun /tmp/w00039-specs-review1b-lab/source-binding.ts` 经真实 object→publish 保留已有 source 后打印 currentRequestId=add-hint、sourceRequestId=atomic；经真实 revert 得到对象删除的补偿 ops。实验验证既有整对象读改写与补偿机制，不模拟尚未实现的来源校验。按本版新增规则走“带来源已定→带新来源重新打开→无来源改候选”与“还原一次已定字段修改”两条序列，历史 source 与实际本次 binds 必定不相同。
**建议改法**：把本次授权放在写入/还原请求的独立映射里（按决策及转换绑定）；持久化 source 只由这次被接受的授权更新，原样携带不重验为新授权。明确定义补偿时出处例外：恢复内容，但记录本次还原的授权与此前出处各在哪里；给 revert 增加逐决策授权参数，并验收多决策连同依赖还原。
