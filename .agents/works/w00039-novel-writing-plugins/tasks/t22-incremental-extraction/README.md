# 改稿后重新记账

## 目标与范围

定作者改了已经记过账的章节以后怎么办：正文改动碰到讲述的原句，这一章的账才标“可能过期”（改别处的错别字不标）；出处按原句重新定位，找不到就标“出处失联”；重新记账时保留作者已经做过的决定（处理过的待处理、改过的数、采用或不改的建议）；第一版的退路是整章撤销后重记（提案第 8 节“出处”）。

合同：讨论 Task，只定设计，行为合同未变；定稿后的 Spec 改动在实施时另定。

前置：t27。

## 重切后要定的（2026-11-02）

1. “可能过期”的判断：改动范围与讲述原句、正文重述设定的链接怎么比。
2. 重记：新旧两次记账怎么对齐，作者的决定怎么带过去；对不齐的进待处理。
3. 触发：作者手动“重新记账”，不在每次保存时跑；费用。
4. 删章、调章序、拆合章时出处与生效位置怎么办（提案第 4 节：删章时生效位置在它上面的变更进待处理）。

## 10-31 的原问题

10-31 按“与 nb-story 合成一套故事模型”的方向写，原样保留作参照。这些问题按“正文层是抽取图”写；现在没有抽取图，改为剧情变更与讲述。

### 改稿后的增量抽取

1. 失效范围：改一章影响这一章的草稿，以及后面依赖它的知情推导、数值累加、身份合并；能否只重抽改动的章、程序重算后面的推导。
2. 触发：保存即抽、写完一章手动、定时；费用上限与提示（按 deepseek-flash 低谷价的口径）。
3. 抽取进行中作者继续改：版本对不上时怎么办。
4. 人工修正（nb-story 的修订）在重抽后怎么保留。
5. 大改（删章、调章序、拆合章）时章节编号与段落编号的稳定性：活页夹编号稳定，段落号会变。

### 剧情图谱进工作台与试读者（原 t18 的一部分）

1. 抽取何时触发、花多少钱、作者怎么知道图过期了。
