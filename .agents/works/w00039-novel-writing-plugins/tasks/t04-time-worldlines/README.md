# 故事时间与世界线

## 目标与范围

给故事时间加“世界线”一维，支持平行宇宙、死亡回档、轮回、梦境与 IF 线；对应 Issue #144（原挂在 WorldEngine 名下，这里放进两个视角共用的模型）。

合同：讨论 Task，只定设计，行为合同未变；定稿后的 Spec 改动在实施时另定。

前置：t02。

## 要讨论的问题

1. 世界线的种类：并存（平行宇宙、穿越目的地）、回档（从分叉点重来、旧线作废但有人记得）、假想（梦境、幻境、推演、IF 线）；还有没有别的（时间旅行改变过去、多周目游戏式）。
2. 分叉的表示：`{line, forkFrom: {line, time}}`；一条线能否合并回另一条（世界融合）。
3. 记录怎么归线：经时间点归线，没写的默认主线；跨线成立的设定（世界规则）怎么写。
4. 状态的计算：沿祖先线折叠到分叉点，再加本线变动；回档时数值、持有物、生死怎么重置。
5. 记忆跨线：谁带着记忆过线（回档者、穿越者），其余人知情停在分叉点；读者天然是跨线者。规则写成设定还是对象上的属性。
6. 时间坐标：作者层用“世界线加时间点”还是旧版的 bigint `instant` 加项目日历；修仙纪年、星历等自定义历法要不要支持、放在哪。
7. 抽取：nb-story 怎么判断本章切线（回档、穿越、入梦）；判断不稳时的退路；补叙判定改为同线内比较。
8. 没有世界线的书：模型、查询结果与界面和现在完全一样，不多出概念。
9. Issue #144 的验收条件（timeline、branch、event、fork point、跨线引用、Agent 写入与检索、章节绑定、冲突处理、旧数据迁移）哪些在这里定、哪些落到别的 Task。

材料：[调研：一节“平行宇宙与死亡回档”](../../research/2026-10-31-repo-survey.md)；GitHub Issue #144：为平行宇宙世界模型增加时间线维度。
