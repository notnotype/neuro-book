## 要讨论的问题

1. 样本：现有 100 章样本书之外，要一本回档或平行宇宙题材、一本多卷长篇、一部作者自己在写的书；来源与登记（第三方素材只读）。

3. 世界线抽取的稳定性要先做实验还是先定模型。
4. 评测的费用与频率。
