# 小说创作的 Agent 工具

## 目标与范围

定这套插件给 Agent 的工具：设定、剧情、状态、图谱的读写与查询。按 w00032 t04 的原则：一个工具只做一件事，不做复合工具。

合同：讨论 Task，只定设计，行为合同未变；定稿后的 Spec 改动在实施时另定。

前置：t02 到 t10、t14。

## 要讨论的问题

1. 工具清单：查对象、读设定、写设定、记状态变动、查某时刻状态、查谁知道什么、读剧情、改大纲、查差异……数量多时怎么让 Agent 找得到（w00032 t04 搁置了工具发现）。
2. 设定是文件时，Agent 直接用 read、edit 改文件，还是必须走专用工具（专用工具能校验 schema、维护引用）。
3. 旧版 `execute_world`（CodeAct 沙箱）的教训：bigint 时间、日历字符串、两套问题码；新工具的参数怎么让模型少出错。
4. 防剧透与权限：写手只读；按阅读位置限制写手能看到的未来设定（接 t21）。
5. nb-story 命令行与 Skill 已有一套查询接口，插件工具与它共用到什么程度。
6. 写入的审批与 History 记录（w00032 t06、t13）。
