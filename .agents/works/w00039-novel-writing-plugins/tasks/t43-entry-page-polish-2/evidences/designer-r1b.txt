## 一、4 张图上发现的其它问题（按影响从大到小）

### 1. 面板流水表头与数据列完全错位、折成两行（`06-panel.png`，右侧「魔力的流水」）
- **问题**：表头被挤成两行（上行 `位置 / 发生了什么`，下行 `变化 / 结果`）；数据行同样断成两行，`-90`、`3,110`、`改这一笔` 掉在下面一行，而 `最初` 整条记录第一列悬空、整体右偏，无法纵向扫读数值变化。
- **建议**：**直接去掉表头**（每项信息本身语义清晰，不必占行），把流水改成固定的两行式紧凑条目：首行左放时间点，右放等宽数字的变化量与结余；次行放原因，补充说明放第三行小字；`改这一笔` 改为 hover 才在首行最右出现（减少视觉噪音）。
  ```text
  [第 1 章]                              -90  →  3,110   [改]
  回房松开认知滤镜，变回原身
  估计：正文只写了“魔力又少了一点”
  ------------------------------------------------------------
  [最初]                                         3,200   [改]
  ```

### 2. 正文里的行内变更标签把数值和单位劈成两半（`07-text.png`，「现在」一段）
- **问题**：`魔力 3,110 第 1 章改过/12,000` 和 `存款 24,500 第 2 章改过 联邦币` 把 `第 X 章改过` 直接插进正文流里，硬生生拆断了分数和单位；叠加长句下方的整排点状虚线，阅读极碎。
- **建议**：正文流里**只渲染值本身**，删掉内联的 `第 X 章改过` 文字。引用值保留极轻的浅底或淡虚线下划线标识可点击；变更来历（哪章改过、出自哪组设定）收进 **hover 提示气泡** 与 **点击后的浮层**。若需一眼标出近期变过的值，最多在值右上角加一个极小的圆点，不打断语序，恢复成 `魔力 3,110/12,000，存款 24,500 联邦币`。

### 3. 面板左侧卡片外挂「改」字：宽度参差、入口语义重叠、破坏跨页一致性（`06-panel.png`，左栏 5 张卡片）
- **问题**：
  1. 前 4 张卡右侧挂了 `改`，第 5 张 `随身物品` 没有 `改` 而自动拉宽，导致 5 张卡右缘参差不齐；且 `随身物品` 同样标着 `第 1 章改过`，用户不知为何唯独它不能改。
  2. 左侧卡片外的 `改`、右侧 `记一笔`、流水里的 `改这一笔` 三处入口并存，看不出点 `改` 是改初值、设当前值还是改字段名。
  3. 4 个 `改` 孤零零飘在边框外，且与其它分页「点值就地编辑」心智分裂。
- **建议**：
  - 去掉卡片外侧的 `改` 列，**5 张卡统一等宽**；点击任意卡片都只做一件事——选中并在右侧看记录。
  - 把「直接设为某值 / 修改初值」放到右侧详情顶栏最右（如 `魔力的流水` 右侧放轻量按钮 `直接设值`），与下方的 `记一笔`（相对增减）在同一区域分工明确；`随身物品` 选中后右侧展示物品变更流水与增删入口。

### 4. 面板「记一笔」表单文案跑题、缺时间点归属、主次倒置（`06-panel.png`，右栏表单）
- **问题**：
  1. 当前选的是「魔力」，占位提示却写死成 `比如：领了工资`。
  2. 顶部写着 `在看 第 3 章末尾`，但下面只写 `记一笔`，没交代这笔记在第 3 章还是别的章节。
  3. 必填的变化量排在选填的原因后面，两框均无外置标签（一输入就忘含义）；`记一笔` 灰底灰字对比度极弱，像普通标签不像按钮。
- **建议**：改为**数值在前、原因在后**，按钮文案直接写明落点章节（随页头联动），尽量压成紧凑两行甚至一行：
  ```text
  魔力的流水                                         直接设值
  [ +300 或 -200    ]  [ 发生了什么（选填）          ] [记在第 3 章]
  ```
  未填数值时 `记在第 3 章` 保持清晰按钮描边但置灰，输入合法数值后亮起主色。

### 5. 编辑卡底部操作栏拥挤易折行、字号跳变、左缘偏出对齐线（`05-look-editing-looks.png`，右栏「外貌」编辑卡）
- **问题**：
  1. 底栏在一行 ~290px 宽内塞了 `[从最初起 | 从第 3 章起]` + `取消` + `[保存 Ctrl ↵]`，已几乎贴死；章数到两三位数（`从第 128 章起`）必然折行或挤压。
  2. 阅读态正文字号约 15px（两行），点进去变成 ~13px 灰底框（单行），字号和底色双重跳变，不像就地修改。
  3. 编辑卡整体左缘比上方标题 `外貌` 左探出一截，阴影快压到左侧立绘虚线框。
- **建议**：
  - 去掉主按钮里的 `Ctrl ↵` 文本（放 hover tooltip 里），按钮只写 `保存`，立省约 45px 宽度。
  - 输入框字号、行高与阅读态完全一致，去掉多余灰底（卡片本身已是白底阴影，细边框聚焦即可）。
  - 编辑卡左缘与字段标题 `外貌` 严格左对齐，不侵入两栏间距。

### 6. 形象页「现在穿的」空态文案生硬、与「衣柜」关系不明，且双大虚线框过重（`04-look.png`）
- **问题**：`现在穿的` 下面只有孤零零的灰字 `填写`，不像明确的可点击入口，也让人搞不清是手动写还是从下面的 `衣柜` 里选；同时立绘槽和衣柜 `添加一套` 都是同体量的巨型虚线框，空态时把整页撑满贴底，视觉喧宾夺主。
- **建议**：
  - `现在穿的` 空态改明确：衣柜为空时写成 `+ 填现在穿的`，衣柜有套装时写成 `+ 从衣柜选，或手填`（浅灰可点态）。
  - `衣柜` 空态时缩小视觉占位：改为一条轻量横向空态按钮（`+ 添加一套衣服`，高度 ~48px），有第一套之后再展开为紧凑的 3~4 列小卡网格，把视觉重心让给上方主立绘。

### 7. 三处细节收口（`06-panel.png` / `07-text.png`）
- **冗余来源词**（`06-panel.png`）：流水里 `最初` 下面多了一行 `作者给的`。初值默认即作者设定，无特殊来源（如 AI 推断）时不显示这行。
- **文字页编辑入口偏弱**（`07-text.png`）：右上角 `编辑` 像纯灰注释字，建议加上浅描边或浅底做成明确次按钮，并支持**双击正文空白处**直接进入编辑（单击动态引用值仍看/改该值）。
- **分页条归组顺序**（4 张图共有）：`人物 | 形象 | 文字 | 面板 | 经历 | 情节 20` 中，自由正文 `文字` 夹在两个结构化设定组中间，建议改为结构化设定组连续排、自由正文靠后（`人物 | 形象 | 面板 | 文字 | 经历 | 情节`）。

## 二、第 4 条：成段文字原处编辑——「浮在原处盖住下面」还是「展开把下面推开」？

**结论：选「浮在原处、盖住下面（占位不变）」。**

**理由**：
1. **零版面抖动，一并治好第 2、4、5 条的连带感**：编辑卡带底栏（`从最初起 | 从第 3 章起`、切换后可能出现的 `发生了什么`、`取消 / 保存`），天然比阅读态高 80~120px。如果推开下面，打开弹一次、切意图再弹一次、保存又弹回来；在形象页这种双栏布局里，还会把 `现在穿的` 和整块 `衣柜` 挤出屏幕甚至挤出滚动条。占位不变则底层纹丝不动。
2. **与短项彻底统一（同一件事处处一样）**：短项已是锚在值上的浮层；成段文字同样做成锚在原处的浮层，只是更宽、支持多行，全站只有一套「点哪哪浮起来改」的交互模型。
3. **契合专注写作（此刻没用的就不出现）**：改 `外貌` 时人盯着 `外貌`，临时盖住紧下面的一小块 `现在穿的` 反而减少干扰；极少数需要参照下一段的场景，比不上高频编辑时反复弹跳的损耗大。

**落地必须守住的 3 个细节**：
- **首行像素级对齐**：浮层内文本框首行文字的起点坐标、字号、行高与底下的原文完全重合，点下去像「原文这块纸微微抬起变成可写」，不是弹一个陌生窗口。
- **高度封顶与底边防遮挡**：浮层内文本框随输入自动增高，封顶设 `max-height`（如 6~8 行，约 220px）后内部滚动；若字段靠近视口最底端，浮层向上微移保证操作栏始终留在视口内（留 16px 底边距）。
- **防误丢内容**：未改内容时点外部或按 `Esc` 直接收起；**已改内容时点外部不静默丢弃**，改为轻抖动并在卡片底部提示 `放弃修改 / 继续编辑`（常用的好做、会丢东西的难误碰）。

## 三、第 6 条：一组设定的三种样子切换方案

### 1. 放哪、叫什么、默认哪个

- **放哪**：放在**当前设定组内容区的右上角**（紧贴分页条下方一条极薄的内容顶栏内，高度 28px，右对齐）。
  - **为什么不放分页条右端**：分页条宽时竖排、窄时横排，放分页条上位置不稳，还会跟「切分组」混淆层级；放在内容区内部右上角，一眼说明它**只管当前这一组设定**，且任何屏幕宽度下坐标固定。
  - **出现范围**：**只在设定组分页（人物、形象、面板等）里出现**；`文字` 和 `经历 / 情节` 不显示（此刻没用的就不出现）。
- **叫什么**：采用极轻量的三段式开关（Segmented Control），文案为：
  - **`卡片`**（给作者看的卡片）
  - **`给 AI 看`**（AI 读到的文字；避开「AI 文本」以免误解成 AI 写的，比「AI 读到的」更短且没对话过时也不违和）
  - **`原始数据`**（底层存下来的数据；不叫「JSON」，避免强绑格式术语）
- **默认哪个**：默认 **`卡片`**。作用域跟当前设定组走——离开条目或切到别的设定组时自动回到 `卡片`（避免作者忘切回来以为界面坏了；仅在排查同一组时来回点三段开关对比，按下去切、再按回 `卡片`）。

### 2. 版式草图

**状态一：默认「卡片」**（开关用极淡灰槽 + 低对比文字，不抢卡片视觉）
```text
人物   形象   面板   文字  |  经历   情节 20                   +
----------------------------------------------------------------
                                    [ 卡片 | 给 AI 看 | 原始数据 ]

  +------------------+  外貌
  |                  |  淡金色长发及腰，浅灰蓝的眼睛，个子娇小
  |     添加立绘      |  ----------------------------------------
  |                  |  现在穿的
  +------------------+  + 填现在穿的
```

**状态二：「给 AI 看」**（顶部一句交代时间点与体量，正文所见即模型所得）
```text
                                    [ 卡片 | 给 AI 看 | 原始数据 ]
  +------------------------------------------------------------+
  | 按「第 3 章末尾」生成 · 约 68 字                       [复制] |
  +------------------------------------------------------------+
  | ## 形象                                                    |
  | - 外貌：淡金色长发及腰，浅灰蓝的眼睛，个子娇小                  |
  | - 现在穿的：（未填）                                         |
  +------------------------------------------------------------+
```

**状态三：「原始数据」**（该长什么样）
- **内容真实**：直接展示这组设定**真实落盘的格式化 JSON**（含初值、各章变更流水、元信息，不截断、不二次粉饰），方便核对时间轴记录与排查异常。
- **身份说清**：顶栏左端明确写 `落盘数据 · 包含全部章节记录`（**必须点破它不受顶栏「在看 第 3 章末尾」过滤**，否则作者切章节看数据不变会以为出 bug），右边放 `只读` 灰标、`全部折叠 / 展开` 和 `复制`（点击变 `已复制`，2 秒恢复）。
- **默认只读**：不提供直接手改原始 JSON，防改坏结构破坏时间轴一致性（会丢东西的难误碰）。
- **视觉样式**：与亮色界面融为一体的浅灰米色代码框（不要突兀塞一块纯黑终端框），13px 等宽字体、行高 1.6、带行号、低饱和语法着色、对象与数组支持点击行首箭头折叠（默认展开前两层）。

```text
                                    [ 卡片 | 给 AI 看 | 原始数据 ]
  +------------------------------------------------------------+
  | 落盘数据 · 包含全部章节记录           只读   [折叠]   [复制]  |
  +------------------------------------------------------------+
  |  1  v {                                                    |
  |  2      "group": "panel",                                  |
  |  3    v "fields": {                                        |
  |  4      v "mp": {                                          |
  |  5          "initial": 3200,                               |
  |  6        v "changes": [                                   |
  |  7            { "at": "ch-1", "delta": -90, "note": "..." }|
  |  8          ]                                              |
  |  9        }                                                |
  | 10      }                                                  |
  | 11    }                                                    |
  +------------------------------------------------------------+
```
