# 剧情图谱进工作台与试读者

## 目标与范围

定 nb-story 查看器怎么作为工作台视图出现，以及对作者自己的书提供“试读者”视角：写完一章后看读者现在知道什么、在想什么。

合同：讨论 Task，只定设计，行为合同未变；定稿后的 Spec 改动在实施时另定。

前置：t02、t14。

## 要讨论的问题

1. 独立查看器的页面（本章、人物、秘密、数值、悬念、时间线、原文）搬进工作台的形态：一个视图多页签，还是拆成多个视图与面板。
2. 对作者的书：阅读位置默认跟随当前编辑的章节，还是最新一章。
3. “试读者”能给作者什么：本章读者新得知的、仍未解的悬念、对某人的印象；与 t08 的差异报告怎么分工。
4. 抽取何时触发、花多少钱、作者怎么知道图过期了（接 t22）。

材料：[剧情图谱查看器](../../../../../docs/specs/story/viewer.md)；[剧情图谱：以后接入 NeuroBook](../../../../../docs/proposals/novel-story-app.md)。
