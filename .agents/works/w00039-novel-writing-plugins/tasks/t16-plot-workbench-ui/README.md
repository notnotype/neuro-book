# 剧情工坊界面与可视化

## 目标与范围

定剧情工坊在新工作台里的界面（大纲、剧情线、场景、伏笔、决策，与活页夹的配合），以及关系、时间线、世界线、状态变化的图形化。可视化主要服务这两类界面，选型一起做。

合同：讨论 Task，只定设计，行为合同未变；定稿后的 Spec 改动在实施时另定。

前置：t02、t04、t09。

## 要讨论的问题

### 剧情工坊界面

1. 承载树（卷、章）与活页夹 `binder.xml` 的关系：卷是清单里的分组，章是编号；场景挂章。旧的 StoryAct、StoryChapter 退役后，因果树（阶段、剧情线、场景）怎么呈现。
2. 视图：大纲树、场景卡板（看板）、剧情线泳道、伏笔账本表；先做哪个。
3. 章级 brief 在界面上怎么编辑、预览（接 t20）。
4. 场景的“节拍”要不要独立结构（旧版只用 summary、purpose、writingTip）。

### 关系、时间线与世界线的可视化（原 t17）

1. 人物关系图：力导向图还是按阵营分组；按时间拨动（关系随剧情变）。
2. 时间线与世界线：多条线并排、分叉点、回档；与 nb-story 查看器的时间线页怎么共用。
3. 地图与地点层级要不要（地点的包含关系、路线）。
4. 数值曲线（nb-story 已有）推广到任意会变的字段。
5. 技术选型：现有稳定的图形库（按“实施前先做技术选型”）。

材料：[调研：三节](../../research/2026-10-31-repo-survey.md)；[`workbench/files-explorer.md`](../../../../../docs/specs/workbench/files-explorer.md)；[剧情图谱查看器](../../../../../docs/specs/story/viewer.md)。
