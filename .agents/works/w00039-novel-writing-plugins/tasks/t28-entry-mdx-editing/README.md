# 最基础的条目与主文字（MDX）的编辑器

## 目标与范围

开发者 2026-11-23 定为 w00039 的下一步（Work README 决定表同日）：“创建最基础的条目，我记得是有 mdx 的吧，mdx 编辑器能不能做一个？目标就是：世界引擎能像文件系统一样记录东西了”。范围两块：

- 条目树像文件树一样用：新建、改名、移动、删除都在树上找得到（[t37](../t37-write-foundation/README.md) 开发者审查的第 1、2、3 处）；
- 条目的主文字在页面里直接编辑，不经“改这一段”的对话框（同上第 6 处）。

之后是人物设定组（能放图片、生动的表单），另建 Task。

原来的范围（11-02）：定作者在界面里怎么编辑条目的主 MDX（开发者 11-02：先不考虑、以后另找办法，单列成 Task 免得忘掉）。已知要解决的：中文标点旁的粗体（`**“走吧。”**然后` 在 CommonMark 里不成粗体，有第三方插件 remark-cjk-friendly）；源码里的 `{` 与 `<`；没改的部分保持原样；字段引用（`{panel.魔力}`）在编辑器里怎么显示、怎么插入；按块存与编辑器的关系。

合同：要改 [`canon/author-ui.md`](../../../../../docs/specs/canon/author-ui.md) 的条目树与主文字几条，编辑器另看要不要单立 Spec；写计划时定。

前置：t37（已合入）。

## 重切后要定的（2026-11-02）

1. 编辑器选型：复用 nb-markdown 的编辑器加 MDX 扩展，还是另做。
2. 往返：打开、编辑、保存后没改的块与源码逐字不变。
3. 字段引用与带值写法在编辑器里的样子。
