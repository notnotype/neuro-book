# 世界引擎内核的 Spec

## 目标与范围

把已接受的[内核提案](../../../../../docs/proposals/world-engine-kernel.md)（[ADR 0037](../../../../../docs/adr/0037-world-engine-story-change-log.md)、[ADR 0038](../../../../../docs/adr/0038-world-engine-entry-text-is-whitelisted-mdx.md)）与 [t16 原型](../t16-plot-workbench-ui/README.md)定下的数据结构写成 Spec。capability 照提案第六部分：条目、剧情变更与状态、修订与还原、渲染与带值写法、Component 贡献点。t02 第三轮推到 Spec 去定的细节都在这里定。

合同：要写的就是 Spec（`docs/specs/` 下新的几个 capability），本 Task 交付的是这些 Spec 与它们的审查。

前置：t09、t10、t14。

## 重切后要定的（2026-11-02）

1. 只存六种对象（条目、剧情变更含计划、核对点、未决问题、正文建议、修订）；位置、来历、诊断、待处理、计划进展、回执都是算出来的（t16 第 2 轮）。
2. 修订只存变了的字段；“带来的变化”在发布时算好存进修订（11-02 定）；还原与依赖按字段算。
3. 初值与“第 1 章开头”分开（前史夹在中间）；初值的数带依据；正文重述初值的句子链到字段（11-02 定）。
4. 精确与语义两档：精确档程序加减、核对点比较；语义档的值与事件是文字，正文写明的数是新的起点，现在的样子由小模型归纳、按输入缓存（11-02 定，改了 ADR 0037 背后“模型不心算”的适用范围）。未知的数：精确档第一次在正文里出现的数定成初值，语义档用原话。
5. “与设定冲突”记成一条待定的剧情变更；未决问题可以挂在任何对象上，附“正文里可能的答案”；细纲里讲到的过去的事记成前史。
6. t02 第三轮推过来的：带值写法里“不完整”与“未知”的写法、地址文法与保留名、白名单、块的切分。
