# 条目页页头与分页条重做

## 目标与范围

按开发者试用人物卡的反馈与八条交互原则，重出条目页的静态稿：保存提示不推开页面、页头就地改名、位置与按计划好懂、分页条带图标与添加设定组的入口、编辑器标签带图标；定稿后写 Spec 并实施

合同：要改 [`canon/author-ui.md`](../../../../../docs/specs/canon/author-ui.md)（输出 6、7、9、16、18、38、50、51 与验收里的说法）、[`workbench/editor.md`](../../../../../docs/specs/workbench/editor.md) 输出 53（页面标签的图标），以及设定组、附加分页、条目种类三个贡献点的声明（加图标）；具体条目等静态稿定了再写。

### 起因

开发者 2026-11-25 试用人物卡（t41）后提出（原话整理）：

1. 加上一组设定后的提示（“加上‘形象’这组设定”）违反 UI 规范“状态不同，布局要相同”：它出现时把整页往下推（[`ui-development-spec.md`](../../../../../packages/nb-ui/docs/ui-development-spec.md) 第 82 行那一条）。
2. 分页条有点丑，要重新做，UX 有点烂：想添加一组设定不知道从哪加（藏在“···”里）；名字旁的“改”明显不对；“初值”是干什么的，用户不知道；设定组可以加图标；编辑器标签可以加图标（现在页面标签只显示名字，文件标签都有图标）。
3. “需要重新出这一个页面的静态稿”；按开发者给的八条原则（系统能判断的不留给用户、此刻没用的就不出现、能替人做的就直接做、同一件事处处一样、按下去有回应再按能收回、不打断人手上的事、常用的好做会丢东西的难误碰、界面自己说明自己）与动效标准看这一页；请 Gemini 当方案、文案与交互顾问（omp 的 `designer` 角色，同日改指 `extremelycat/gemini-4-neon-xhigh:xhigh`）。

主会话查到的另外几处：

- 编辑器给页面类的标签一律不画图标（`EditorGroupHead.vue` 对页面给 `icon: null`），条目页其实声明了 `i-lucide-book-open`。
- “按计划”开关与位置选择各占一个控件，空作品里位置只有“初值”一项、也没有计划，两个控件都没用却一直在。
- 九个分页带图标时 760 像素放不下（`adapt` 退到没选中的只剩图标）；设定组以后还会多（清单第二期的技能、物品栏、关系）。
- 页头与内容列左边不齐（t41 记下的后续）。
- 人物分页（t41 已合入的 `CharacterCard`）在 390 宽时值那一列被挤成一个字宽，Lab 的 `CharacterCard` 场景“填好的人物”用 phone 尺寸截图就能看到；t41 Spec 输出 49 的“宽度不够时的排法”留着 planned，没有断言守着。
