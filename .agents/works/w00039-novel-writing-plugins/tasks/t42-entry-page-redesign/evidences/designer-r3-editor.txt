## 一、三张图的问题诊断（按影响排序）

### 1. 建议列表二次悬浮，盖死模式切换且过滤逻辑坏了
- **位置**：`05-改性别.png` 输入框下方
- **问题**：
  1. 建议列表作为一个二级浮层叠在编辑浮层上面，直接挡住了底下的「这是 改设定 / 剧情里变了」；因为两层都是半透明毛玻璃，底下的蓝色「改设定」按钮糊成一大块蓝斑透出来。
  2. 点开「不明」时，列表用当前已填的「不明」做了过滤，导致下拉里**只剩「不明 ✓」一项**，完全看不到「男 / 女 / 其他」等真正想改去的选项，逼着用户先删字才能选。
- **怎么改**：建议列表改为**内嵌在主浮层内部**（位于输入框和底栏之间），取消二级悬浮；首次打开时**不过滤当前值**，展示全部建议并给当前项打 `✓`，只有用户开始输入新字符时才过滤。

### 2. 三处高饱和亮蓝抢焦点 + 输入框灰底像禁用态
- **位置**：`04-改年龄.png`、`05-改性别.png`、`06-改性格.png` 整个浮层内
- **问题**：
  1. 一个小浮层里同时出现三个刺眼亮蓝：输入框蓝光边框、实心蓝底「改设定」（还带蓝阴影）、实心蓝底「保存」。「改设定」视觉权重甚至比「保存」更重，像主提交按钮。
  2. 输入框（`04`/`05`）和文本框（`06`）用了偏深的灰底，在白浮层里像只读/禁用态，再配蓝发光框显得割裂。
- **怎么改**：整张浮层只保留**一个主色焦点——「保存」按钮**。输入框改为纯白底 + 1px 柔和边框（聚焦仅边框变深或细淡蓝边，去大外发光）；模式切换改为中性灰底滑槽 + 白底选中块 + 深色字，彻底去掉蓝底和蓝阴影。

### 3. 毛玻璃材质在纸感页面上显脏，且三张图都在越界遮挡
- **位置**：
  - `04-改年龄.png`：浮层右缘越过主栏竖线，盖住右侧边栏的图标与文字「试…」；向下盖住右列 6 行属性。
  - `05-改性别.png`：浮层右缘把右列「第 2 章改过」拦腰截断成「2 章改过」。
  - `06-改性格.png`：悬浮卡片盖住下一项的标题，底边外露出一行无头无尾的灰字「从哪里来，经历过什么」；卡片上边缘和左下角还能看到底层文字透出的灰斑。
- **怎么改**：
  1. 取消半透明毛玻璃，改为**纯不透明白底**（`#FFFFFF`）+ 1px 暖灰描边 + 轻阴影，与米白纸面拉开干净层次。
  2. 短项浮层宽度收窄到 **260–300px**，水平位置做**容器边界钳制**（贴近主栏右边界时自动左移/右对齐，绝不越过右侧竖线）。
  3. 长文字项（`06`）**不用悬浮浮层**，改为在页面文流中就地展开，自然把下一项往下推，做到零遮挡。

### 4. 盒子过大、内部空洞多，操作与反馈被拆散
- **位置**：`04-改年龄.png`、`06-改性格.png` 中下部
- **问题**：
  1. `04` 改两个字「二十」却弹出约 380×190px 的大卡片，左下预览和右下「取消 / 保存」之间隔着一大片无意义空白。
  2. `06` 全宽展开后，切换和预览缩在最左、按钮甩在最右，视线横向跨整页；底部留白过大；文本框右下角还露着浏览器原生的斜线拉伸手柄（`//`），显得粗糙。
- **怎么改**：把模式切换与「取消 / 保存」合并到**同一条底栏**（左切换、右按钮），正常无副作用时去掉常驻的预览占位行，短项总高度可压掉一半以上（从 ~190px 降到 ~88px）；长文字文本框改为自动增高，禁用原生拖拽角。

### 5. 「这是 改设定 / 剧情里变了」文案抽象，且与预览信息重复
- **位置**：`04-改年龄.png`、`06-改性格.png` 中部两区（`05` 同位置被遮挡）
- **问题**：
  1. 「这是」是多余口语。
  2. 「改设定」在值来自前史或某章时说不清到底改哪一笔；「剧情里变了」没写变在哪一章，作者必须再往下看小灰字「在第 3 章记一条变更」才能拼出完整意思。
  3. 「别的都不变」占了常驻一行，每次都在报平安，反而把真正需要注意的「多了 1 条待处理」淹没在常规灰字里。
- **怎么改**：删掉「这是」，把**具体落点直接写进切换项本身**（见下文方案）；无连锁影响时**隐藏**「别的都不变」，只在真有副作用或具体事件名时才出单行提示条。

### 6. 预览文字层级不统一，且缺少快捷键暗示
- **位置**：
  - `05-改性别.png` 预览首行「改最初的值」是近纯黑色，而 `04-改年龄.png` 和 `06-改性格.png` 同位置是浅灰色，组件自身样式不统一。
  - 三张图均未暗示「回车直接存 / 换行」的快捷键差异。
- **怎么改**：统一提示条字号（12px）与色彩语义（普通信息暖灰，连锁影响用暖黄警示底）；在短项保存键或输入右侧给轻提示 `↵`，长项按钮旁或底栏给 `⌘↵` / `Ctrl+↵`（短项也可直接写 `保存 ↵`）。

## 二、重做方案

### 1. 浮层里留什么、去掉什么

| 保留 | 去掉 |
|---|---|
| 纯白不透明卡片 + 1px 暖灰边 + 轻阴影 | 半透明毛玻璃、蓝外发光、深灰输入底 |
| 输入控件（短单行 / 内嵌建议列表 / 自动增高多行） | 二级悬浮建议菜单、原生多行拉伸角 |
| 精简的落点切换（仅在需要选择时出现，中性灰白分段） | 「这是」引导词、亮蓝切换底色 |
| **条件出现**的单行影响提示条（有副作用/具体事件名时才出） | 常驻的「改最初的值」重复行与「别的都不变」废话行 |
| 同一底栏右侧：`取消`（文字键）+ `保存`（唯一主色键） | 按钮上方的大块空白留白 |

### 2. 「改设定 / 剧情里变了」怎么改

按「系统能判断的不留给用户、此刻没用的就不出现、界面自己说明自己」重构：

1. **什么时候不问（直接隐藏切换）**：
   - 当前正在看「最初」；
   - 或作品只有一个时间点（还没写到章节变更）。
   - 此时底栏左侧只留一行极轻的静默字 `改最初`（或干脆留空），右侧 `取消` `保存`。

2. **需要问时，把抽象词换成带具体落点的短标签**（直接替代原第一行预览）：
   - **左项（改当前值的来源本身）**：
     - 值来自最初 → **`改最初`**
     - 值来自前史 → **`改前史`**
     - 值来自第 2 章 → **`改第 2 章`**
   - **右项（在当前时间点新记一条变化）**：
     - 当前在第 3 章 → **`第 3 章变了`**（当前在某章开头/末尾统一报章名即可，如 `第 3 章变了`；若只在计划中，可写 `第 3 章变了` 并在提示条里补一句 `记在计划中`）
   - 这样两项一眼对比：`[ 改最初 | 第 3 章变了 ]`、`[ 改第 2 章 | 第 3 章变了 ]`，作者不用再猜“设定是什么、变在哪一章”。

3. **缺省选中规则（坚持“同一件事处处一样”）**：
   - 始终默认选中**左项**（改原来源）。
   - 理由：作者在设定页点一个词，高频意图是修/补设定；不按字段偷偷切换默认项，避免按回车时误建一条剧情变更。若真想记新变化，点一下右项即可（且保存后有 6 秒「还原」兜底）。

### 3. 预览怎样呈现才一眼看懂

**原则：没意外就闭嘴，有意外才亮灯。**

- **无副作用，且落点名字已经说清（如 `改最初` + 别的都不变）**：
  - **不显示预览区**。浮层保持最紧凑高度，回车直接存。
- **无副作用，但改的是某笔带名字的剧情记录**：
  - 在底栏上方加 1 行 12px 暖灰提示：`改第 2 章「订了蛋糕」那一笔`。
- **有连锁影响（如多了待处理）**：
  - 在底栏上方展开 1 行**暖黄浅底提示条**（文字深棕/琥珀色，不刺眼但一眼看见）：
    `! 保存后会多出 1 条待处理`
  - 此时**不再按一次回车就默默存掉**（遵守“会丢东西/有副作用的难误碰”）：预览回来发现有影响后，按钮文案可保持 `保存` 或变为 `确认保存`，等作者显式点击或再按一次回车确认。

### 4. 三种控件的具体版式与文案

#### A. 短项（如年龄）
- **定位**：锚在被点值正下方 4px，宽 260–300px，自动贴边钳制在主栏内；原值仅给极淡暖灰底表示正在改它。
- **常规无影响（高度约 88px，回车即存）**：
```text
年龄  [十八]
      ┌───────────────────────────────────┐
      │ 二十                              │  ← 纯白底输入框，1px 聚焦边
      ├───────────────────────────────────┤
      │ [ 改最初 │ 第 3 章变了 ]  取消 [保存] │  ← 左中性分段，右唯一蓝键（悬停/提示 ↵）
      └───────────────────────────────────┘
```
- **有连锁影响时（自动向下撑出 1 条暖黄提示）**：
```text
      ┌───────────────────────────────────┐
      │ 二十                              │
      │ ! 保存后会多出 1 条待处理          │  ← 暖黄浅底单行，仅此时出现
      ├───────────────────────────────────┤
      │ [ 改最初 │ 第 3 章变了 ]  取消 [保存] │
      └───────────────────────────────────┘
```

#### B. 有建议值的项（如性别）
- **结构**：建议列表**内嵌**在输入框与底栏之间（max-height 约 160px，超出内部滚动），不再弹出第二层浮层，绝不遮挡底栏切换。
- **交互**：
  - 点开即全选输入框内原值（`不明`），同时下方**列出全部建议**，原值右侧打 `✓`；只有开始打字才按关键词过滤。
  - 上下方向键切选项、回车选中并按短项规则保存；鼠标单击建议项直接填入输入框并刷新预览（若在「最初」且无影响，可直接保存；有切换项时填入后停在浮层内，方便作者先切 `第 3 章变了` 或直接点 `保存`）。
```text
性别  [不明]
      ┌───────────────────────────────────┐
      │ [不明]                            │  ← 全选态，打字即覆盖并过滤
      ├───────────────────────────────────┤
      │   男                              │  ← 内嵌列表，首次打开显示全部
      │   女                              │
      │   不明                          ✓ │
      │   无                              │
      ├───────────────────────────────────┤
      │ [ 改最初 │ 第 3 章变了 ]  取消 [保存] │  ← 永远不被遮挡
      └───────────────────────────────────┘
```

#### C. 长文字项（如性格）
- **结构**：**不做悬浮浮层**，点击后把当前段落区就地变成带 1px 边线的纯白编辑块，自然把下方字段（如「从哪里来，经历过什么」）往下顺推。
- **交互**：文本框按内容自动增高（最少 3 行，无原生拖拽角）；回车正常换行，底栏明确给出保存快捷键（`⌘↵` / `Ctrl+↵`）；点外部空白且未改内容时自动收起，已改内容时不静默丢失（保持展开或轻抖提示保存/取消）。
```text
性格
┌─────────────────────────────────────────────────────────────┐
│ 嘴硬心软，其实很在意妹妹                                      │
│                                                             │  ← 纯白自动增高，无拉伸角
│                                                             │
├─────────────────────────────────────────────────────────────┤
│ [ 改最初 │ 第 3 章变了 ]              ⌘↵ 保存   取消  [保存]  │  ← 若有影响，上方插一行暖黄提示条
└─────────────────────────────────────────────────────────────┘

从哪里来，经历过什么                                            ← 被顺推到下方，完整可见
```
