# 人物设定组：图片、给作者填的表单、在条目上加字段

## 目标与范围

第一个做完整的设定组——人物：能放图片，有一份好用的表单给作者填数据，能在某个人物上自己加字段。开发者 2026-11-23：“第一个设定组——人物，能放图片，并且提供一份生动的表单给作者填数据”；2026-11-24 讨论后定：人物设定组允许实例字段、给加字段的入口（开发者：“这个功能可能还是挺常用的吧”）。

范围按[内置设定组的清单](../t10-setting-schema/component-catalog.md)的第一期：内核补四项（在条目上加、改名、删字段的写入操作；文字字段的建议值；允许加字段的类型不止面板；重整人物的字段），人物（重整）与形象（立绘、外貌、服装、现在穿的）两组，把人物类的设定画成一张角色卡的“资料”分页，图片的显示、从作品里选与上传。清单的第二、三期（数值的预设项、技能、物品栏、关系；组织、地点、物品与新建条目的模板）到时另建 Task。

合同：要改 [`canon/components.md`](../../../../../docs/specs/canon/components.md)（实例字段的写入、字段声明的建议值）、[`canon/author-ui.md`](../../../../../docs/specs/canon/author-ui.md)（“资料”分页、图片的选与显示）与 [`canon/project.md`](../../../../../docs/specs/canon/project.md)（写入操作），具体条目在计划里定。
