# 评审板的填写存在本机、换页刷新不丢

## 目标与范围

开发者 2026-11-10：评审板里输入了的文字要持久化保留。答复表单的填写、说明与备注存进浏览器，离开页面、刷新、面板重启后回来还在；提交成功或关闭评审后清掉。

分支 `feat/w00022-t21-answer-drafts`。开发者 11-02 定本 session 不做审查。

合同：[面板](../../../../../packages/dev-panel/docs/panel.md)的产物页一行与“偏好”一条；零件合同 `packages/dev-panel/src/web/parts/AnswerForm.md`。

## 决定

- **存在浏览器里，不存服务端**：一块评审一份，键是“Work/Task/产物”，经 `host/prefs.ts` 存 `localStorage`。换一台电脑或另一个浏览器看不到草稿；要跨设备得加服务端接口与文件，这次不做。
- **按题号存，不按版本**：会话改页面重新发布，同一题号的填写照样带过来；原来选的选项没了时题下当场报校验错。
- **什么时候清**：提交成功、开发者自己点“关闭评审”或“撤回没答的题”成功之后。会话用命令行关掉的评审不清（重新发布打开后填写还在）。没有内容的草稿（只展开了空说明框、清空了的题）不留。
- **两个标签页开同一块评审**：各存各的，后存的覆盖先存的；没有做标签页之间同步。
