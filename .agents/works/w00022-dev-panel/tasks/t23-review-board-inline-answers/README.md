# 评审板：页面里作答、侧栏确认，给页面更多地方

## 目标与范围

开发者 11-10（t22 评审板第 13 题与随后的两问）：评审板现在是中间 HTML、右边答题，题多了找不到题对应的材料，中间的页面也太小。定为：nbdev 提供评审板模板，答题控件放进页面里每道题的材料旁边，页面里填的只进草稿、在侧栏确认提交；给页面更多横向与纵向空间；手机上“页面 | 答题”两个切换（从 t22 第 3 条移来）。

合同：[面板](../../../../../packages/dev-panel/docs/panel.md)的“两个来源”与产物页、[文件格式](../../../../../packages/dev-panel/docs/file-formats.md)的提问标记；[Proposal](../../../../../docs/proposals/dev-panel.md) 第六条追加决策记录（iframe 只改草稿）。计划见 [plan.md](plan.md)。

## 决定（开发者 2026-11-10）

- 页面里填，侧栏确认：答题控件放进页面里每道题的材料旁边，页面里填的只进草稿，提交在面板自己的界面上按（页面脚本能伪造取值，最多改动草稿，不能替开发者提交）。
- 空间：横向给页面更多地方；纵向也省一点。
- 模板参考开发者 visualize skill 的经验。
- t22 第 3 条（手机“页面 | 答题”两个切换）并进本 Task。
