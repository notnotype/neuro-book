### 1. Agent 原样交回旧未知标签会静默规范化并发布修订
严重程度：重要；类别：正确性、不变量。
位置：`packages/nb-canon/src/grammar/text.ts:62-74`、`packages/neuro-book/src/plugins/canon/backend/agent-entry-text.ts:8-9`、`packages/neuro-book/src/plugins/canon/backend/agent-tools.ts:422-437,718-732`。
现象：已存块 `old <Plot  id="x"/>` 中的未知标签按合同作为坏块处理，但 Agent 渲染应把坏块原样交回。当前 `stripAgentText` 无条件调用 `stripEntryText`，把标签规范化成 `old <Plot id="x" />`；`writeBlock` 以这个结果作为 set 值，且 `currentBlock` 的 `source` 也来自同一规范化结果，因此这次差异被当成实际编辑。经真实 `World` 重放旧源文、`renderEntryForAgent` 后交回读取到的原样块并调用 `editEntries`，结果成功发布版本 3（原版本 2），存储源文变为规范化标签。即使用户/Agent 没改块文字，旧标签的空白与斜杠写法也被悄悄改写并留下修订；若同时改了普通文字，改动同样会顺带重写标签。
核实：复现输入 `old <Plot  id="x"/>`；Agent 可见文本逐字相同，`stripAgentText` 得 `old <Plot id="x" />`；真实内核回写成功、版本递增且存储值已变。`canon.rendering` 输出 4 要求坏块给 Agent 原样源文，输出 8 要求注记以外的源文字逐字相同；S5 对已登记/未知插件标签原样保留的修复已在 `decorateEntryText` 实施，但去值入口仍规范化。
改法：对非坏块使用带值去除；当块渲染带 `error` 时，读写两侧都以原样源文比较与交回，不对其中未知标签做序列化规范化。加入真实 Agent 工具回归：从旧数据读取含非规范未知标签的块，原样交回不得发布或改变字节；修改周围正文后标签片段仍逐字保留。
