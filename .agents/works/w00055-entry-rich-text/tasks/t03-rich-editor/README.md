# 富文本编辑器：条目主文字用富文本编辑，可切到源文字

## 目标与范围

条目页文字分页点“编辑”默认进富文本：值、计算、条件、条目引用、图片是小块，`{` 与 `@` 插入，点开小块改；可以切到源文字；去掉分屏预览；暂存、提交、冲突沿用 w00039 t39、t40。建在 t02 的内核与条目文法上，t02 合入 master 之后开工。

合同：[`canon/author-ui.md`](../../../../../docs/specs/canon/author-ui.md) 输出 10、11、39、48 与验收场景 16 要改（见[计划](plan.md#spec-与文档改动)）；世界服务另加按名字找条目的读取。

## 当前状态

2026-11-27 写了[计划第 1 稿](plan.md)。动笔前用 t02 的代码核对了三件事：

- 内核已有规范标签的写法函数 `tagText`，小块改了属性用它写回，不搬 spike 的转义。
- 编解码器写回不给节点到偏移的对照；t02 的性质测试已证明编辑器认出的原子与内核的活标签落点相同，值表按先后配对。
- `EntryTextEditor` 的输入框可换（合同同 `PlainSourceInput`），富文本做成同一合同的另一个输入框，状态行、暂存、提交、冲突不动。

`@designer`（Gemini）看了 spike 与现在的编辑、阅读视图（[说明](evidences/designer-r1-brief.txt)、[意见](evidences/designer-r1.txt)），15 条里采纳的写进了计划，没采纳的列在计划的“不做与风险”。
