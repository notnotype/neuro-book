### 待开发者定（第二轮）

1. **本机进程的鉴权**（B7）：gateway 只挡浏览器，bot 自己执行的命令也是本机进程，能连上 RPC 以用户身份批准审批、改任务清单。推荐第一版就要：gateway 每次启动生成口令，由页面的引导接口下发（只有页面拿得到），RPC 与写请求不带口令一律拒绝；实现为 nb-host 的可选项（NeuroBook 暂不开），在 t04 做。
2. **联网工具**（B8）：需求的例子“每周整理某领域的简报”要读网页。推荐第一版加 NeuroBot 自己的只读抓取工具：只取 http(s)，拒绝回环、链路本地与内网地址，结果标为外部内容；任务清单缺省不放行 `shell`。
3. **主对话里“等用户”的处理**（B15、F4、F9、F14）：推荐输入框一直可用，审批或提问挂着时用户发消息，就把它结算为“没批准，用户说：……”再进对话；没人理 30 分钟按过期结算（内核写“过期”，不冒充用户），同一调用在本次运行里不再申请；只保留一个按 bot 的“记住”。
4. **第一版 web 的范围**（F7、F11、F12、F15）：推荐第一版只做标签页标题未读数、页面内的未读分隔线（位置存在 gateway、按 bot）、按天分隔线；设置页做最小版（服务商与密钥、绑定主模型与压缩两个角色、缓存档位），其余先改文件；首次启动自动建缺省的看板娘，人设在一个可改的文件里；输入框里的模型选择隐藏。浏览器通知、按 bot 按天的用量、记忆页的“让她改这一段”放进路线。

开发者 2026-11-10 答：“都按推荐，第一版先把框架搭起来就行”。四项按推荐；第一版的范围以搭起框架为准，拿不准的功能放进路线。
