# t18 第 3 条设计审查第 1 轮的处理

审查：Claude Sonnet（2026-11-25），对象是计划草稿 1，[报告](design-review-1.txt)。13 条：阻断 2、重要 8、建议 3。处理后计划改成草稿 2。

| 条 | 级别 | 归类 | 处理 |
|---|---|---|---|
| 1 按钮在外框层，被内容层盖住 | 阻断 | 成立，要改 | 盖层画在 `float-chrome` 窗口零件层，本身不接指针、只有按钮接；外框里不画这块面板的头 |
| 2 内容上边距是常量，飞行、四角、改动范围没写 | 阻断 | 成立，要改 | `layoutContents` 收自绘头集合给 0；裁切框四角圆；飞行时终点矩形已含 0、不跳；加第二个标签时直接换（待确认 3）；改动清单补上表面与 `layout-present`。nb-layout 仍不改 |
| 3 `fromElement` 没有坐标，按高度判不了；叶的属性写法自相矛盾 | 重要 | 成立，要改 | 改成视图声明拖动区 `data-window-drag`，按内容层的 `data-content-leaf` 找叶 |
| 4 头 0 高时落点几何的 `strip` 消失 | 重要 | 成立，要改 | 自绘头的窗 `strip` 取顶上 `band` 那一条；验收加“拖到顶上那一条成标签条” |
| 5 可交互清单漏头像、`label`、role 等；没禁选与 `touch-action` | 重要 | 成立，要改 | 清单补齐、只在拖动区里面往上查；头 `user-select:none`、拖动区 `touch-action:none`、头像 `draggable=false`；风险描述改成“拖它会移动窗口” |
| 6 右键“移动到”没写谁监听，会吞掉视图与浏览器的右键 | 重要 | 成立，要改 | 只在按下的就是拖动区本身、没有 `preventDefault` 时开；文字上留给浏览器 |
| 7 标题按钮隐藏方式、与移动把手并存、窄版 Enter 开不了抽屉 | 重要 | 部分成立 | 隐藏用透明加不接指针、淡入；窄版 Enter 不开抽屉、抽屉由头像列按钮开（待确认 2）。与移动把手并存不改：普通浮动窗今天就是标题加移动把手两个键盘入口，分工不同（拿起与落点、方向键挪位置），位置按开发者定的左上角 |
| 8 就绪时内容跳 32px；版式阈值随头翻 | 重要 | 成立，要改 | 判据不看实例状态，加载与出错也不画面板头（待确认 1）；版式阈值随加第二个标签翻，那一刻头本来在换，接受并写进计划 |
| 9 `insetEnd` 经 ref 来回、窄版抽屉压头、居中偏移 | 重要 | 成立，要改 | 外壳写 CSS 变量、视图只读变量，去掉 ref 与事件；窄版抽屉自绘时让出头高；居中左移半组按钮宽，接受。`band` 保留：工作台要用它定盖层高度与落点那一条 |
| 10 验收映射缺项、Lab 场景放错层 | 建议 | 成立，要改 | 验收表重写，看得见与点得到一律 `elementFromPoint`；Lab 场景放在 `WorkbenchSurface` |
| 11 按钮挪层后悬停范围失效 | 重要 | 成立，要改 | 盖层自带范围，`data-hover-actions-active` 用表面的 `actionsShownOn` |
| 12 互斥交给视图反写 `claim` | 建议 | 成立，要改 | 外壳在自绘时让 `headOfPanel` 返回 null，视图不碰 `claim` |
