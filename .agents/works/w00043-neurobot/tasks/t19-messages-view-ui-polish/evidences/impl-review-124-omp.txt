### 1. 坏侧轨值可以使布局读入抛出异常
- 严重程度：重要；类别：正确性。
- 位置：`packages/nb-workbench-layout/src/layout-doc-validate.ts:60-62`，`packages/neuro-book/src/plugins/workbench/web/state/layout-doc-store.ts:94-98,131-137`。
- 现象：布局其余字段有效，仅某容器的 `rail.expanded` 是 JSON 对象 `{"toString":0}`、`width` 是合法的 `310` 时，读入抛 `TypeError: No default value`（Bun 1.4.4），而不是保留布局与 `width:310`、仅把 `expanded` 当缺省。`rail.width` 同样调用 `String(坏值)`，存在同一问题。
- 原因：发现坏值后直接做字符串强制转换；普通 JSON 对象也能用自有属性覆盖 `toString`，回退的默认 `valueOf()` 仍返回对象，诊断构造本身抛错。违反布局 Spec 输出 50 的非致命修复合同。
- 核实：在实现检出 `13364cb00` 运行 `bun --tsconfig-override packages/neuro-book/tsconfig.json /tmp/review-t19-impl-124/rail-records.ts exception`（临时根见报告末尾）。真实 SQLite 存下后新开窗口，异常由实际 storage 响应经 Vue effect 抛出。
- 建议：字段路径与有限的值类别足够诊断，不对未知对象强制转换；在现有存储往返用例补合法宽度和带自有 `toString` 键的坏值，断言新窗口照常打开并保留宽度。
### 2. “重置位置”把展开意图从浮动窗带回，而不是清掉

- 位置：`packages/neuro-book/src/plugins/workbench/web/commands/view-commands.ts:86-89,169-178`，`packages/neuro-book/src/plugins/workbench/web/state/layout-doc-store.ts:529-537,556-561`，`packages/nb-workbench-layout/src/layout-doc.ts:551-565`。

- 建议：让菜单和命令面板把重置作为单独的操作意图传到 store，同一次提交中归位并清除其项；普通停靠继续保留。

- 建议：预算接收与求解器相同的区域可缩下限（取实际约束与聊天下限的较大值），再算部分展开与拒绝；用该组合断言左栏几何不变。
