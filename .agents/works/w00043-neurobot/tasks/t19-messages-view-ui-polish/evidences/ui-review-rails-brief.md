## 请审

1. **状态是否齐全、是否自相矛盾**：逐表找漏掉的状态组合（例如展开着时浮出、展开着时区域隐藏、窗口变窄时展开着、列表搜索中切了页、当前会话被归档、bot 被删、第一次打开时什么都没有），以及两条规则打架的地方。
2. **标“（拟）”的做法**：逐条判断合不合适，给更常规或更好的做法（附你确知的同类产品依据，不确定的写“不确定”）。
3. **用户的方位感**：收着与展开、停靠与浮动、区域隐藏与显示之间，用户能不能一直知道自己在哪、东西去了哪、怎么回去；选中状态、按下状态、未读与“等你处理”是否一眼分得开（按设计语言的颜色角色）。
4. **键盘与读屏**：能否走通清单里的全部动作；焦点在每个动作之后落在哪里；侧轨展开后列表的读屏结构。

6. **你认为还缺的动作**（例如拖会话到别处、从侧轨直接拖出浮动窗、侧轨里重排 bot）：只列值得做的，各给理由。
