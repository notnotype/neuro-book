# 侧轨与视图段：状态与动作清单

配合提案 [侧栏的侧轨](../../../../../docs/proposals/workbench-side-rails.md)，列出侧轨、视图段与消息视图的全部状态与动作，交 UI 审查。标“（拟）”的是提案没写、这里先给的做法，审查可以改。

## 词

- **区域**：左侧栏（`sidebar`）、右栏（`auxiliarybar`）。
- **侧轨**：区域贴窗口外缘的竖条，从上到下是容器入口、视图段、底段。左轨就是活动栏。
- **容器入口**：区域里一个有成员的容器一项。
- **视图段**：当前容器唯一那个视图交给侧轨的一段；消息视图的视图段收着是 bot、新对话、最近会话，展开是完整列表。
- **底段**：视图段的固定按钮（消息视图：“全部 bot”“会话历史”），主侧那条再加全局项（账号、设置），最下面是展开按钮。

## 一、区域与侧轨的状态

| 区域 | 侧轨 | 备注 |
|---|---|---|
| 有成员容器、显示着 | 在，和区域卡片相连（接缝处不圆、不留缝，内侧一条上下缩进的短线） | 常态 |
| 有成员容器、隐藏（标题栏开关） | 在，自己一张圆角卡片；当前容器的入口不按下 | 同活动栏 |
| 有成员容器、拖到零 | 在，同上 | 同活动栏 |
| 放不下被收走（窗口窄） | 先把展开的侧轨按收着算；还放不下时区域按现有顺序收走，侧轨（拟）留着收着的 48 | 输出 10 |
| 没有成员容器（唯一的视图浮出去、或所有视图搬走） | 不在，跟着区域收走 | |
| 别的面板最大化 | 在，不被盖住 | 同活动栏 |

侧轨自己：

| 状态 | 样子 |
|---|---|
| 收着 | 48 像素，只有图标与头像 |
| 展开 | 展开宽度（消息视图缺省 260，可拖到 200–420），视图段换成完整列表；容器入口（拟）图标后跟名字；底段按钮后跟名字 |
| 悬停 | 同活动栏：项的悬停底色、提示 |
| 焦点在里面 | 同活动栏：一站，项之间方向键移动（拟） |
| 拖动中、拖到侧轨上 | 两个入口之间是新建容器的落点，入口上是并入；消息视图的容器不接收（不高亮、没有落点） |

## 二、容器入口的状态

| 状态 | 样子 |
|---|---|
| 当前容器、区域显示着 | 按下（底块），底块是条里一个独立的块，切换时滑过去 |
| 当前容器、区域隐藏或拖到零 | 不按下 |
| 不是当前容器 | 普通 |
| 入口放不下 | 排在后面的收进“更多”，当前容器的入口总在外面 |
| 有计数（视图的未读、待处理） | 角上的数字，同活动栏 |

## 三、视图段的状态

出现的条件：区域此刻只显示一节、这节的视图声明了视图段、实例已就绪。

| 状态 | 视图段 |
|---|---|
| 当前容器是消息视图、就绪 | 在 |
| 视图加载中、渲染出错、交付撤回 | 不在；侧轨只有容器入口与底段的全局项（拟） |
| 当前容器是别的视图（没声明视图段） | 不在 |
| 区域隐藏或拖到零 | 在（点头像或会话会把区域打开到那里）（拟） |

### 消息视图的视图段，收着

从上到下：

1. bot：圆头像，未读是一个点，等你处理是黄点；当前在聊的 bot 有底色（拟：和当前会话一样用描边）。
2. 一条短线。
3. 新对话（铅笔图标）。
4. 最近会话：方块写标题首字，当前会话一圈描边，有未读的有点；最多 5 个。
5. 高度不够：最近会话先少放，底段两个按钮不被挤走（拟）。

底段：“全部 bot”（机器人图标）、“会话历史”（搜索列表图标）、展开按钮。

### 消息视图的视图段，展开

| 状态 | 样子 |
|---|---|
| 刚展开 | 顶上搜索框（按“全部 bot”“会话历史”展开时焦点在搜索框，按展开按钮时焦点留在按钮（拟）） |
| Bot 一页 | 每个 bot 一行：头像、名字、最后一句或状态、未读数 |
| 会话一页 | 搜索、作品范围（当前作品、全部作品）、筛选（Profile、显示已归档）；按日期分组，子会话在父会话下；行菜单改名、归档 |
| 搜索有字 | 只列命中（只查标题与说明）；没有命中写“没有匹配的会话” |
| 加载中 | 行的骨架 |
| 读不到 | 原因与重试 |
| 没有 bot、没有会话 | 空的说明与新建 |
| 选中一项 | 在消息视图打开；侧轨保持展开，焦点留在列表 |

## 四、消息视图的状态

| 位置 | 样子 |
|---|---|
| 停靠在右栏 | 聊天区（头、消息、输入框）；视图段在右轨 |
| 停靠在左侧栏（单独一个容器） | 同上，视图段在左轨（活动栏）的中段，当前容器是消息时出现 |
| 浮动（只能单独一个标签） | 窗的右边缘由视图画视图段，顶上一格让给“回到停靠”；窗里的聊天自绘头（t18） |
| 浮动、展开 | 窗向外长出展开的差值，聊天区宽度不变；靠屏幕右边放不下时窗往左挪 |
| 没有打开会话 | 聊天区写“选一个 bot 开始聊天”（输出 51） |

头：只写标题与动作；“新对话”不在头上了。

## 五、动作

| 动作 | 结果 | 过渡 |
|---|---|---|
| 点容器入口（不是当前） | 切到那个容器；区域隐藏或拖到零时同时显示 | 内容滚过去，按下的底块滑过去（输出 42） |
| 点容器入口（当前、区域显示着） | 隐藏区域；侧轨留着 | 区域收起走布局过渡 |
| 点容器入口（当前、区域隐藏或拖到零） | 显示区域 | 区域长出来 |
| 右键容器入口 | 容器的菜单（移到别的区域、重置） | |
| 拖容器入口 | 搬容器到别的区域或入口条；消息视图的容器只能落在左右侧栏 | 同活动栏 |
| 点 bot 头像 | 在消息视图打开它的对话；区域隐藏时先显示 | |
| 点会话方块 | 打开那个会话 | |
| 点新对话 | 新会话 | |
| 点“全部 bot” | 侧轨展开、切到 Bot 页、焦点进搜索框；已展开时只切页 | 侧轨变宽走布局过渡，编辑区让出 |
| 点“会话历史” | 同上，切到会话页 | 同上 |
| 点展开按钮 | 展开或收起 | 同上；收起时焦点回到展开按钮（拟） |
| Esc（焦点在展开的列表里） | （拟）先清搜索，再按一次收起侧轨、焦点回到打开它的按钮 | |
| 拖侧轨内侧的边（展开时） | 改展开宽度，记住 | 跟手，松手不回弹 |
| 双击那条边 | （拟）回到缺省宽度 | |
| 在展开的列表里选中一项 | 打开那个对话，侧轨保持展开 | |
| 点消息视图头上的“浮动” | 视图浮成窗；视图段跟着视图到窗的右边缘；右栏没别的容器时右栏与右轨一起收走 | 窗的飞行走布局过渡；视图段从侧轨到窗边一次只改位移的过渡，同时长同曲线 |
| 点浮动窗右上角“回到停靠” | 回到声明的容器；右栏与右轨回来；视图段回到侧轨 | 反过来 |
| 浮动时拖别的标签到这个窗 | 没有落点（消息视图只能单独一个标签） | |
| 拖别的视图到消息的容器、或拖消息视图到底部面板 | 没有落点 | |
| 标题栏的右栏开关 | 隐藏、显示右栏；侧轨留着 | 区域走布局过渡 |
| 拖右栏与编辑区之间的边到零 | 右栏到零，侧轨留着 | |
| 窗口缩窄到放不下 | 展开的侧轨先按收着算（只改呈现，不改记住的展开状态），再按现有顺序降级 | 窗口变宽时回来 |
| 系统减少动态效果 | 所有过渡直接到位 | |
| F6、Shift+F6 | 在面板之间按从左到右走：左轨、左侧栏、编辑区…右栏、右轨 | |

## 六、要审的重点

- 状态是否齐全、有没有自相矛盾（例如区域隐藏时视图段还在、点了会打开区域）。
- 标“（拟）”的做法是否合适，有没有更常规的做法。
- 收着与展开、停靠与浮动之间，用户能不能一直知道自己在哪、怎么回去。
- 键盘与读屏能否走通全部动作。
- 过渡是否把“谁去了哪里”讲清楚，又不过度。
