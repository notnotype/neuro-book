# 侧轨与视图段：状态与动作清单（第二稿）

配合提案 [侧栏的侧轨](../../../../../docs/proposals/workbench-side-rails.md) 第二稿。第一稿的审查与处理见 [`evidences/design-review-rails-disposition.md`](evidences/design-review-rails-disposition.md)。消息视图只停右栏与单独浮动，所以下面的“侧轨”除特别写明外都指右轨；左轨（活动栏）的行为不变。

## 词

- **侧轨**：区域贴窗口外缘的竖条，从上到下是入口条、视图段、底段。左轨就是活动栏。
- **入口条**：区域里一个有成员的容器一项。
- **视图段**：当前容器唯一那个视图借给侧轨的一段；消息视图收着是 bot、新对话、最近会话，展开是完整列表。
- **底段**：视图段的固定按钮（“全部 bot”“会话历史”），主侧那条再加全局项，最下面是展开按钮。

## 一、右栏与右轨

| 右栏 | 右轨 |
|---|---|
| 有成员容器、显示着 | 在，和右栏卡片相连（相连处不圆、不留缝，内侧一条上下缩进的短线） |
| 有成员容器、隐藏或拖到零 | 在，自己一张圆角卡片；当前容器的入口不按下；视图段的“当前”退成弱描边 |
| 放不下被收走（窗口窄） | 在，收着的 48 |
| 没有成员（唯一的视图浮出去、或视图都搬走） | 不在，跟着右栏收走 |
| 用户显式打开的空右栏 | 右栏照常显示、可落入；没有右轨 |
| 别的面板最大化 | 在，不被盖住；轨宽手柄不可用 |

## 二、右轨的展开

| 状态 | 有效样子 |
|---|---|
| 用户收着 | 48 |
| 用户展开、编辑组让得出 | 展开宽度（消息视图缺省 260，200–420），编辑组让出 |
| 用户展开、编辑组压到最小仍差 | 再压右栏到最小（聊天区 320） |
| 用户展开、聊天区也压到最小仍差 | 按收着呈现；展开按钮 `aria-expanded=false`，提示“窗口太窄”；窗口变宽自动恢复 |
| 当前容器没有视图段（别的容器、渲染出错、交付撤回） | 按收着呈现，记录不改 |
| 视图加载中 | 保留视图段骨架，厚度不变 |

展开状态与宽度按容器记在右栏锚上。

## 三、入口条

| 状态 | 样子 |
|---|---|
| 当前容器、右栏显示着 | 按下（底块），切换时底块滑过去 |
| 当前容器、右栏隐藏或拖到零 | 不按下 |
| 不是当前容器 | 普通 |
| 入口放不下 | 收进“更多”，当前容器的入口总在外面 |

## 四、视图段（消息视图）

借给侧轨的条件：消息视图在右栏、右栏显示的分节就是它、实例已就绪。右栏隐藏或拖到零时，已就绪的实例照样借给侧轨；冷开就隐藏、还没加载时不提前加载，侧轨只有入口条与底段。

### 收着

| 项 | 样子 |
|---|---|
| bot | 圆头像；当前 bot 是头像侧边一条竖条；未读是数字徽标；等你处理是 warning 色、形状不同于未读；太多时并成“+N” |
| 分组 | bot 一组，一条短线，新对话与最近会话一组 |
| 新对话 | 铅笔图标 |
| 最近会话 | 方块写标题首字，悬停与键盘聚焦给全名；当前会话描边；当前会话永远占位，其余按最近使用、数目随高度只在末尾增减；普通会话不画未读 |
| 底段 | “全部 bot”（带汇总徽标：未读合计，有等你处理时 warning 色）、“会话历史”、展开按钮 |
| 高度不够 | 底段与当前入口总在；中段独立滚动 |

### 展开

| 状态 | 样子 |
|---|---|
| 刚由“全部 bot”“会话历史”展开 | 切到对应页，焦点在搜索框；对应按钮显示按下 |
| 由展开按钮展开 | 停在上次的页，焦点留在展开按钮 |
| Bot 页 | 现有的 bot 列表 |
| 会话页 | 现有的会话面板：搜索（标题与说明）、作品范围、筛选（Profile、显示已归档）、行菜单（改名、归档、恢复）、新建；排序照现有（最近活动），不按日期分组 |
| 加载中、读不到、空 | 照现有列表 |
| 搜索词 | 两页各自保留，收起再展开不清 |

## 五、消息视图

| 位置 | 样子 |
|---|---|
| 停靠在右栏 | 聊天的头接管面板头的标题区（左列返回、中间会话标题、右列子代理与更多，按标题不开列表）；下面是消息与输入框；视图段在右轨 |
| 浮动（只能单独一个标签） | 窗的右边缘由视图画视图段；顶格只放“回到停靠”（悬停写“回到右栏”）；别的标题动作在聊天头里 |
| 浮动、展开 | 窗向外长出展开的差值，聊天区宽度不变；靠屏幕右边时呈现位置往左挪，记录位置不改；放不下时按收着呈现 |
| 没有打开会话 | Bot 页的首屏盖层照旧，给一个按钮（等同“全部 bot”） |

## 六、动作

| 动作 | 结果 | 焦点 | 过渡 |
|---|---|---|---|
| 点入口（不是当前） | 切到那个容器；右栏隐藏或拖到零时同时显示 | 留在入口 | 内容滚过去，底块滑过去（输出 42）；两端轨宽不同时走一次布局过渡 |
| 点入口（当前、右栏显示着） | 隐藏右栏，右轨留着 | 留在入口 | 区域收起 |
| 点入口（当前、右栏隐藏或拖到零） | 显示右栏 | 留在入口 | 区域长出来 |
| 右键、拖动入口 | 容器菜单、搬容器；消息的容器只能落在右栏 | | 同活动栏 |
| 点 bot、会话方块、新对话 | 经揭示通道：显示右栏、退出别的最大化，在消息视图打开或新建 | 聊天输入框 | |
| 点“全部 bot”“会话历史” | 展开（已展开只切页）、切页、聚焦搜索；窗口太窄时不展开并提示 | 搜索框 | 轨宽走布局过渡，编辑组让出 |
| 点展开按钮 | 展开或收起 | 留在按钮 | 同上 |
| 在展开的列表里打开一项 | 经揭示通道打开；侧轨保持展开 | 聊天输入框 | |
| 归档当前项、行被移除 | 焦点到相邻行，没有就到搜索框 | | |
| Esc（在搜索框） | 有字时清空；已空时焦点交回聊天输入框，不收起 | | |
| 拖轨的内侧手柄 | 改展开宽度，只由编辑组补偿，触界即停 | 手柄 | 跟手，松手不回弹 |
| 手柄上方向键、Home、双击 | 每次 10 像素；回缺省 | 手柄 | 回缺省走过渡 |
| 拖手柄时 Esc、失去捕获、布局变了 | 取消，零写入 | | |
| 点消息头上的“浮动” | 视图浮成窗；视图段跟着到窗的右边缘；右栏没别的成员时右栏与右轨一起收走 | 窗里的“回到停靠” | 窗飞走、右栏收走、编辑组变宽同时、同曲线；视图段随窗整块飞；右栏还有别的容器时视图段在过渡层里单独飞 |
| 点“回到停靠” | 回到右栏；右栏与右轨回来；视图段回到侧轨 | 聊天头的“浮动” | 反过来 |
| 浮动窗拉边 | 只结算动的那条边 | | |
| 拖别的视图到消息的容器、拖消息到底部面板或左侧栏、往消息的浮动窗加标签 | 没有落点；命令直传也拒绝、零写入 | | |
| 在侧轨的视图段或底段上松手 | 取消（不开新窗） | | |
| 标题栏的右栏开关 | 隐藏、显示右栏；右轨留着 | | 区域走布局过渡 |
| 别的面板最大化时点侧轨的对话或展开 | 先退出最大化 | | |
| 窗口缩窄 | 先按收着算展开的轨（不改记录），再按现有顺序降级 | 焦点在被收起的列表里时交给展开按钮 | 窗口变宽回来 |
| 系统减少动态效果 | 过渡直接到位 | | |
| F6、Shift+F6 | 从左到右：左轨、左侧栏、编辑区…右栏、右轨 | 进入落在上次的焦点处 | |
| 命令“搜索会话” | 同“会话历史” | 搜索框 | |

## 七、键盘与读屏

- 侧轨整条：`navigation`，名称写区域（“右侧栏”）；F6 一站。
- 收着：入口、视图段各项、底段是一条纵向工具条（roving tabindex，上下方向键、Home、End）。
- 展开：工具条只剩入口与底段；列表是它自己的区域（名称“会话列表”或“Bot 列表”），里面 Tab：搜索框、筛选、列表；搜索、`tablist`、行菜单保留原有按键（行菜单按钮、Shift+F10、菜单键）。
- 名称：bot 头像“名字，未读 3，等你处理”；会话方块是完整标题加状态；当前项 `aria-current`；展开按钮 `aria-expanded`，名称“展开消息列表”“收起”；手柄 `separator`。
