# ADR 0044：工作台除标题栏外是一棵布局树，内容按矩形摆放，布局工具自写并收进 nb-layout

- 日期：2026-11-05
- 决策者：开发者
- 关联工作：[w00026](../../.agents/works/w00026-layout-package/README.md)
- 相关文档：[工作台布局：一棵树、按矩形摆放与 nb-layout](../proposals/workbench-single-tree-layout.md)；取代 [工作台外壳的抽象](../proposals/workbench-shell-abstractions.md) 的第 2、3、6、7、8 节

## 背景

工作台原来是七个固定 Part 的网格，工具区域里每个容器一棵树，编辑区再一棵。跨树移动各写一套规则，编辑器的节点没法自然地移到外层。渲染用递归 DOM，结构一变节点就换父元素，浏览器会清掉滚动和焦点，外壳靠三层 Teleport 补救，邻居实时让位做不到丝滑。递归 DOM 当初的来由是 reka-ui 的嵌套分割原语，2026-09-20 的改造后它已不再承担拖动、命中、键盘与收起，这个理由已经不成立。

一次性原型（w00026 t02）经开发者试过认可：按矩形摆放后，跨面板搬动不重建实例，滚动、输入、光标都在，现有的 `solveSashDrag`、`collectSashHits` 不改就能接上。

## 决策

1. **一棵树**。除标题栏外，活动栏、状态栏、工具视图、编辑组都是树上的节点。同轴嵌套总是展平，单子分支塌陷，所以同一画面只有一种树形。编辑组只是 `role: "editor"` 的面板，不再有编辑区这个子树，树里至少留一个。
2. **按矩形摆放**。面板外框、分隔线、视图内容、条都是同一父元素的绝对定位子元素。视图内容按实例身份建一次，不换父元素，移动只改矩形。Tab 顺序由布局层管理，读屏顺序用 `aria-owns`，不依赖 `reading-flow`（不在浏览器基线内）。
3. **取消 ViewContainer**。带标签的面板就是组，多个视图同屏就是树里分开的几个面板。失去“点一个入口，一组视图一起切换”。
4. **工作台拥有摆放，插件拥有内容**。工作台是 `LayoutDoc` 的唯一写者；编辑器拥有地址、语言、preview、固定、光标、dirty，存在自己的记录里，结构变更经工作台的原子操作，dirty 与 preview 由编辑器先结算。两个窗口同时改布局时整棵树后写胜出，不按节点合并。
5. **自写，不用现成的布局库**。dockview 停靠时搬 DOM，多行标签、固定标签、键盘导航是付费档；Trellis 的许可证与 AGPL 不兼容（判断，不是法律意见），只借交互想法。golden-layout、Lumino 没有核实。
6. **布局工具全部进 `@notnotype/nb-layout`**，包括 Splitter 与分隔线核心，统一用一套库。`.` 是纯 TS（模型、求解器、落点规则、手势状态机），不依赖 Vue 与全局 `window`、`document`；`./vue` 是 DOM 适配与组件，依赖 nb-ui；nb-ui 不重导出，否则循环依赖。nb-story、dev-panel 的迁移单列，迁移前 nb-ui 暂留一份冻结的 Splitter 与分隔线核心。
7. **反馈样式是参数**。视觉走主题的 CSS 变量与 motion 令牌，行为数值由宿主经配置传入，调样式不用改库。

## 备选方案

- **外壳树加编辑区子树**：改动小，但跨树移动要各写规则，边界两侧同一个位置有两种结果。
- **保留递归 DOM，只加过渡**：每换一次落点就搬一次节点，滚动和焦点靠补救。
- **Splitter 与分隔线核心留在 nb-ui**：nb-story、dev-panel 不用改，发布依赖不增加；开发者选择统一用一套库。
- **按节点合并多窗口的改动**：移动、拆分、删除的合并规则很复杂，两个窗口同时调布局很少见。
- **编辑器状态全进布局文档**：光标约 1 秒一写，不能和拖动抢保存，内容的所有者也是编辑器。

## 后果

- 要重写外壳一到三的大部分 Spec，改约 1 万行工作台代码与编辑器的组和标签。拆包、手势、渲染层各自独立交付，一棵树开工前开发者再确认一次手感。
- 已有用户的布局、尺寸和打开的标签升级时丢一次；回滚回去读到的是升级前的旧记录。
- 工具视图的摆放从跨项目共享变成每个项目一份。
- 能力缩减（开发者接受）：面板横跨左右侧栏这类摆法没有拖动入口；左右方向的 32px 竖条与拖动手势版最大化取消。
- nb-story 的发布依赖在迁移那时从 8 个包变成 9 个，要写新 ADR 部分取代 [ADR 0029](0029-workspace-packages-publish-source-to-npm.md)。
