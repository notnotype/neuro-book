# ADR 0049：生成的图存进本机的应用级仓库 `user://images/`，它是生成批次的唯一主人；书里存副本、快照、缩略图与 `.image` 插图，靠对账进书；仓库平铺、到上限自动清

- 日期：2026-11-10
- 决策者：开发者
- 关联工作：[w00042 t03](../../.agents/works/w00042-image-generation/tasks/t03-core-contracts/README.md)
- 相关文档：[图像生成第一版：工作台、配方与标签库](../proposals/image-generation-v1.md) 的第 1、6、7 节；[产物管理的纸面模拟](../../.agents/works/w00042-image-generation/research/2026-11-10-artifacts-and-model-stress-test.md)

## 背景

抽卡产出的图很多，重度使用三个月估计有二十几 GB，九成以上是失败品。少数好图要留，进书的图要跟着书走。

按现有规则，有几种放法走不通：
- **历史写进配方文件：** 作者正改着配方、还没保存时写回生成记录，就是磁盘冲突，总要丢一样；作品文件正文上限约 960 KiB，常用的配方两三周就超。
- **图放在 `.nbook/` 下：** 浏览器读不到。
- **插图对照表放 project 分区的 Storage：** 它不进 Git。
- **生成与写书分在两个进程、靠推送交付：** 三轮设计审查都在时序上找到缺口，例如宽限期里回来时，没有东西触发交付。

## 决策

1. **两处存放。**
   - 本机的应用级仓库 `user://images/`：全部原图、缩略图、本机记录、内容快照、收藏。
   - 书里：生成记录的副本、内容快照、缩略图，以及用进书里的图（`.image` 文件夹，一张一个，装各个版本与 `image.json`）。
2. **一件事实一个主人。**
   - 这台机器上生成的每一批，以及之后的标记（排队、提交、完成、失败、取消、扔掉、原图已清、收进书里），主人是这台机器的仓库。
   - 书里按安装 id 分目录存副本，每台机器只写自己那份。
3. **对账进书。** 仓库每一行带“安装 id 加递增序号”。项目入口以副本里最后的序号为游标，补齐其后属于本书的行，并按序号去重。对账在项目激活时、读历史时、收到推送时做，不设待交付记录。
4. **跨仓库与书的操作都由服务端做。** 收进书里、清理、收藏都由服务端做，用同一把锁，因为服务端既读得到仓库，也能写进书里。持久引用只指向书里的图，引用由发起方自己写。
5. **仓库由程序管理，作者不在里面整理。**
   - 仓库平铺，按内容哈希命名，只认“文件名等于内容哈希”的文件。
   - 用进书里的图，在书的目录里按作者的层级管；收藏的图用收藏夹（多对多）分组。
   - Agent 经检索工具查，检索条件与图库页同一套；索引可以重建。
6. **空间管理。**
   - 收藏是应用级的，书删了还在，第一版只存本机、可导出。
   - 上限缺省 40 GB，只管没收藏的原图。到上限自动清：先清扔掉的，再清最久没看过的；最近 7 天生成的不清。
   - 清掉原图以后，书里的缩略图与记录还在。

## 备选方案

- **原图放书里：** 拷书能带走全部，但书会涨几到二十几 GB，Git 必须忽略，同步盘会被撑爆。
- **仓库放插件私有目录：** 作者看不到、碰不着，但平台还没有私有目录，读图还要另开路由。`user://` 已经有读字节的路由，主题素材也有同样的先例。
- **待交付记录加确认**（多实例拓扑提案的“文生图”一例）：要单独存待交付记录、处理退役，而且缺触发的时机。
- **平铺加一份总清单，或者让作者在仓库里分目录：** 文件被挪动以后，索引和文件就对不上了，这是各家图库软件最常出的故障。
- **到上限只提醒：** 一张都不会意外丢，但作者不理提醒时会涨到磁盘满。开发者要的是 Telegram 那样不用操心。

## 后果

- 要平台新增三样，都做成任何插件都能用的能力：改动记账与变更事件的排除贡献点；服务端代作者写入时带上发起者；仓库记录的追加写法。
- 资源管理器的“用户资产”根（缺省折叠）下看得到 `images/`；作者在里面挪走、删掉的原图，算作“原图已清”。
- 换了机器，别的机器生成的批次在本机只读，标“不在本机”。
- 清掉的原图回不来；能不能按种子重抽出同一张，等 t02 实测。
- 书里的缩略图只增不减，扔掉的图的缩略图随原图一起清掉；重度使用一年约几百 MB。
- 协议细节在 `images/library` 的 Spec 里定，提案列出了开放项：引用由谁写、记录坏了怎么办、副本被人改了怎么办、id 索引、同一张图属于几批、别的机器的批次。
