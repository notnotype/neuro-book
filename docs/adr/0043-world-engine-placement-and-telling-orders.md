# ADR 0043：故事里的事实按安放折叠，读者看到的按讲述算；时间是约束，不决定折叠

- 日期：2026-11-05
- 决策者：开发者
- 关联工作：[w00039 t32](../../.agents/works/w00039-novel-writing-plugins/tasks/t32-plot-side/README.md)
- 相关文档：[作者视角的世界引擎：剧情侧（第一版）](../proposals/world-engine-plot-side.md) 的“总原则”“时间”“知情”小节

## 背景

内核的位置是一条全序（前史与章）。补叙、回溯、平行视角让“故事里先发生的”与“读者先读到的”分开；nb-story 的评测里，“读者知道被当成角色知道”是知情题最大的错因。时间方面，旧 WorldEngine 用精确时刻，逼作者编造精确值、撞时刻就失败；作者给的大多是“十五岁那年”“三天后”这类粗略的说法。

## 决策

1. **两种先后**（开发者 2026-11-04）：故事里的事实（状态、在场、知情、目标）按**安放**折叠，安放是作者排定的故事先后（前史序号、章序、章内排序键，以及世界线）；读者看到的（揭示、伏笔节点）按**讲述**算，讲述的先后是活页夹章序与段。安放缺省是第一次讲到的那一章。
2. **读者不是条目**，不从角色的知情推；读者的知情、伏笔的阶段、计划节点的兑现与泄底的判断，只认当前活页夹正文里能定位到的讲述，失联的不算（开发者 2026-11-04、11-05）。
3. **时间是剧情变更上可选的说法**，精度不限，用时间约束网络算出范围与矛盾。时间不决定折叠，安放的先后也不放进网络；安放与时间对不上单独报出来（开发者 2026-11-04）。历法与网络放在无依赖的 `nb-time`；存作者按历法写的说法，绝对时间不落盘。

## 备选方案

- **只有一种先后（按章）**：补叙与回溯表达不了，读者与角色的知情混在一起。
- **时间决定折叠顺序**：大量事件没写时间，补叙与回溯会让相对的加减断掉。
- **安放的先后放进时间网络**：一处安放错了会让整张网矛盾。
- **精确时间轴**（旧 WorldEngine）：逼作者编造精确值。
- **读者从角色的知情推**：场景讲出来了，读者不一定知道。

## 后果

- 不写时间、不写补叙的书，两种先后重合，作者不用多记。
- 讲述要有稳定的发生点（id 与段位置），改稿后要重新定位；重写删掉的句子上的揭示与节点不再算，读者的知情与伏笔的阶段会退回去。
- 不支持按故事时间读状态（“某年某月那天她有多少钱”），只按安放读。
