# 桌面宿主页面规范

适用：`desktop/electron/src/**/*.html`、`desktop/tauri/frontend/**` 等宿主自带的启动、Manager 和错误页面；不适用于 Nuxt 产品界面。

- 页面只承载宿主启动、进度、错误和恢复操作；产品功能留在 Nuxt 应用。
- 与主进程或 Tauri bridge 的交互使用宿主已定义的窄接口；页面内容不能形成任意 IPC、command、shell、URL 或文件路径。
- 使用语义 HTML、键盘可达控件、可见焦点和明确状态文字。长错误、路径和版本信息可换行或滚动，不遮挡恢复按钮。
- 启动、等待、失败、重试和已完成状态具有稳定尺寸；无脚本或 bridge 不可用时显示可诊断失败，不停留空白页。
- 修改后在实际 Electron 或 Tauri 宿主中走受影响状态；静态 HTML 可打开不等于宿主 bridge 已验证。

完成标准：目标宿主的启动与失败状态可见、可操作、键盘可达，页面只调用允许的 bridge，长文本不破坏布局。
