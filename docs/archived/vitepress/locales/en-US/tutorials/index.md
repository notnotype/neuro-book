# From Your First Book to Chapter Three

This tutorial series walks you through the first complete creative path in NeuroBook: create a project, initialize your worldbuilding, call Skills, write the first three chapters, and import a SillyTavern character card.

It is not a developer manual, and you do not need to understand any technical concepts. Just get the studio, the book, the worldbuilding and the chapters set up in order.

::: tip Not installed yet?
Go back to [Quick Start](/en/quick-start) first. This series assumes the app already opens and a model is already configured.
:::

## What You Will End Up With

After finishing this series you will have:

- A Project Workspace you can keep working in.
- A minimal but usable `lorebook/` worldbook.
- Draft prose for the first three chapters.
- An archive of material imported from a SillyTavern character card, plus the settings migrated out of it.
- An initialized World Engine: the timeline exists and the opening state is on the books.

## Recommended Route

1. [Before You Start](./00-before-you-start.md): confirm the app, the model provider and the Agent all work.
2. [A Tour of Your Novel Studio](./01-studio-tour.md): learn what each area of the page is responsible for.
3. [Create Your First Book](./02-first-project.md): create a Project Workspace and understand how Agent, session, profile and Skill fit together.
4. [Ignite the Story with Skills](./03-skills-bootstrap.md): from a raw idea through project setup, worldbook and character design to World Engine initialization.
5. [Write the First Three Chapters](./04-first-three-chapters.md): turn worldbuilding and plot into real chapter prose.
6. [Import a Character Card](./05-import-character-card.md): unpack a SillyTavern card, archive it, and import it into your Project Workspace.

## When to Read the Reference

The tutorials only cover how to get started. When you want to know why the system organizes files the way it does, or you need the Agent to change the project more precisely, go to the Reference:

- [Agent Reference](https://github.com/notnotype/neuro-book/blob/master/packages/neuro-book/assets/reference/agent/README.md): Agent, profile, Skill, Workflow, Job and Harness.
- [Project Workspace Guide](https://github.com/notnotype/neuro-book/blob/master/packages/neuro-book/assets/reference/agent/project-workspace-guide.md): project files, content nodes and the semantics of Agent file access.
- [Content Reference](https://github.com/notnotype/neuro-book/blob/master/packages/neuro-book/assets/reference/content/README.md): `lorebook/`, `world-engine/`, retrieval and information control.
- [Novel Writing Workflow](https://github.com/notnotype/neuro-book/blob/master/packages/neuro-book/assets/reference/agent/novel-writing-workflow.md): the main collaboration chain in writing mode, the writer handoff, and the three tiers of writing skills.
