# 0.7.x 更新日志

0.7 这条线做了两件事：把 Markdown 编辑器的长文输入卡顿治好，以及给 AI 改动的文件加上「先看再收」的审查入口。许可证也在这条线上换成了 AGPLv3。

## 0.7.10-canary - 2026-07-13

- **容器更新失败会自动回滚**：换新容器之前先停旧容器并备份数据库。新容器起不来、迁移失败或健康检查不过，就把数据库、配置和镜像统统恢复原样再启动旧版本。
- 全新安装失败也会清理干净，不再留下半成品容器和配置。
- 发布流程改成：先公开所有文件，从公开下载地址重新校验大小和校验和，全部通过后才发布索引。这样安装管理器永远看不到「还没验完」的版本。

## 0.7.9-canary - 2026-07-13

0.7.8 便携版有两个致命问题，这一版是紧急修复。

- **修复启动窗口一闪而过**，以及服务起来了但首页白屏。白屏是打包时代码分块互相引用导致的。
- 启动脚本现在会去掉目录末尾多余的反斜杠，命令失败时保留窗口并显示错误码，不再一闪就没。
- 发布前会真的启动一次程序，用浏览器验证首页能打开、静态资源能加载、控制台没报错，不再只靠接口返回版本号就认为健康。

0.7.8 的便携版不要继续用。正确升级方式：备份旧目录的 `data/` → 解压 0.7.9 到新目录 → 把 `data/` 复制过去，不要复制旧的 `.output`、`.runtime`、`.deploy`。

## 0.7.2-canary - 2026-07-11

- **AI 的自动摘要和上下文压缩可以分层设置了**：全局默认 / 全局某个助手 / 项目默认 / 项目某个助手，四层依次覆盖。留空表示继承上一层，界面会标出当前值来自哪一层。
- **文件变更提醒改成 Git 风格**，能区分新增、修改、删除、重命名、还原、撤销，而不是笼统说「文件变了」。
- 敏感路径即使超出展示上限，也只显示一个不可点击的路径，不会引导 AI 去读它。
- **登录开关移到启动配置**：服务器部署默认开启，Windows 便携版默认关闭。创建管理员后会自动打开，重启生效。
- **llmlint 的自动修复更保守**：默认只有 3 条纯机械规则（零宽字符、重复标点这类）允许自动修，其余一律要人确认。规则里带替换模板不再等于允许自动应用。
- 修复富文本和源码模式切换时，300 毫秒内的最后一点输入可能丢失。

## 0.7.1-canary - 2026-07-10

这一版不加新功能，主要是把文件变更收件箱的行为确认清楚并写进文档。

- **旧页面不会覆盖新数据**：接受、回退、查看差异时如果你手上的是过期版本，服务端会直接要求刷新，而不是在旧版本上继续操作。
- 切换项目或刷新收件箱时，上一个项目还没返回的请求会被取消，延迟返回的旧结果不会覆盖当前界面。
- **敏感文件在读取正文前就被拦截**：`.ssh`、`.aws`、`.kube`、`.gnupg`、各种 `.env`、常见凭据文件和私钥格式。
- 明确了提醒的体积上限：最多展开 4 个文件的差异、最多逐条列 50 个文件、内联差异总共不超过 8192 字符。助手配置只能把上限调得更小，不能放宽。

## 0.7.0-canary - 2026-07-10

- **长文输入不卡了**：富文本和源码编辑器统一改用防抖更新，打字时不再每敲一个键就把全文序列化、扫描、同步一遍。切换文件、保存和外部改动之前会先结算待提交的输入，也不会再被自己刚保存的内容覆盖回去。
- **Markdown 方言扩展**：评论统一成 `<comment>`，支持行内和跨段落；新增 `<ruby>` 注音、`<bilingual>` 双语对照，以及可交互的 `<html>` 块。未知 HTML 默认只显示源码不执行，显式 HTML 块要你点一下才在沙箱里渲染。
- **AI 输入框上方新增文件变更卡片**：默认收起，展开能看项目内相对路径和小体积差异，可以单个接受或全部接受，完整审查对话框仍然保留。
- **剧情工作台收敛成三个真实页面**：线程规划、承诺账本、决策记录。承诺可以看铺垫/升级/兑现的时间线并执行兑现、放弃、重开；决策可以记候选方案、风险、拍板理由和失效原因。
- **许可证改为 AGPLv3**。你用 NeuroBook 写出来的作品不会仅仅因为用了本软件就要跟着开源。
