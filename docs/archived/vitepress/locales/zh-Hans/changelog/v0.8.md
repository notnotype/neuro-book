# 0.8.x 更新日志

0.8 这条线的主题是「把安装和部署做扎实」。0.8.0 重写了 AI 长对话的加载方式，之后的十几个小版本几乎全在修安装、更新、容器停机这些没人愿意碰但一出事就致命的地方。

## Manager 0.1.0-canary.30 - 2026-07-25

这次只更新安装管理器，应用本体没变。

- `start` 命令新增 `--no-health-check`：跳过启动检测和自动打开浏览器，用于「服务其实起来了但检测卡住」时手动救场。仍然会做迁移和数据检查，只是不等探测结果。
- 只对 Windows 便携版有效，其他安装方式会直接拒绝。
- 已经解压 0.8.19 便携版的用户可以在便携版根目录跑下面这条，然后自己打开 `http://127.0.0.1:3000`：

```cmd
.runtime\bin\bun.cmd x --bun @notnotype/neuro-book-manager@0.1.0-canary.30 --root "%CD%" start --no-health-check
```

这条命令是临时借用新版管理器，不会替换压缩包里自带的那个。下次双击 `Start Neuro Book.cmd` 还是老样子。

## 0.8.9-canary - 2026-07-19

这一版集中修了一批安装和权限问题，是 0.8 线里改动最大的一次。

- **Windows 便携版登录失败**：以前数据库路径会跟着「你从哪个目录启动」变，结果从错误的位置找数据库，一登录就报错。现在路径固定按数据目录解析。
- **更新过程改成记账式**：每一步动手之前先记下「准备做什么」，做完再记「做成了什么」。中途断电或失败可以照账本原样回滚，不会留下半新半旧的实例。
- **下载的运行时先验货再上架**：Bun、ripgrep、Git 下载后会在暂存区校验完整性、可执行性和真实版本，验不过就不会替换掉正在用的那份。
- **AI 模型配置身份更严**：改了服务地址或代理就算换了一套连接，不会偷偷沿用旧密钥；删除某个模型服务前必须先处理掉引用它的地方。
- **文件权限统一**：AI 的读取、写入、改写、打补丁和记忆功能现在共用同一套权限检查，符号链接和跨项目路径统一拦截。

如果你在用 0.8.6 的 Windows 便携版，升级方式是：备份整个 `data/` 目录 → 解压新版到新目录 → 把 `data/` 复制过去。不要复制旧的 `.deploy`、`.runtime`、`.output` 和根目录的启动脚本。

### 旧对话的模型引用怎么处理 {#session-model-refs}

从这一版开始，AI 对话只记「哪个服务、哪个模型」，不再存整份模型配置。更早的对话如果没法证明它当初用的是哪个服务，系统**不会替你猜**——它只会让那一条对话用不了，不会悄悄换成默认模型。

要修的话，先写一个对照表，把每条对话指到正确的服务和模型：

```json
{
    "mappings": [
        {
            "sessionId": 241,
            "entryId": "model-change-entry-id",
            "providerConfigId": "my-provider",
            "modelId": "my-model"
        }
    ]
}
```

然后先空跑看看会改什么，确认无误再真正执行：

```text
bun scripts/maintenance/migrate-session-model-refs.ts --workspace-root <你的工作区目录> --mapping <mapping.json> --dry-run
bun scripts/maintenance/migrate-session-model-refs.ts --workspace-root <你的工作区目录> --mapping <mapping.json>
```

命令会核对配置里确实存在这些服务和模型，对照表写错或有多余项都会直接报错。执行前建议先备份整个数据目录。

## 0.8.0-canary - 2026-07-15

这个中版本重写了 AI 长对话的加载和推送方式，目标是让几百轮的对话也不卡。

- **长对话不再一次性全量加载**：打开时只给最近一页，往上滚动才继续加载旧内容。加载旧页时视口不会乱跳，AI 的回复和它对应的工具结果也不会被从中间切开。
- **实时消息改成只发增量**：以前每次都重发整段累计内容，包括工具参数、差异和图片。现在只发新增部分。
- **工具卡片只显示摘要**：路径、短预览、原始大小，不再把整个文件内容推到前端。
- **AI 图片改成附件引用**，同 0.8.2 的做法。
- **模型配置有了严格校验**：坏配置不会进运行时；设置页支持实时校验和一键修正，改的是草稿，不会自动保存。
