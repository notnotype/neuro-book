# 0.5.x 更新日志

0.5 这条线是「写作模式」的第一个完整形态：剧情、世界设定、AI 助手、AI 痕迹检测这四块第一次凑齐并稳定下来。

## 0.5.7-canary - 2026-07-06

这一版更新面比较宽，写作工作台、剧情结构、AI 可观测性和配色系统都动了。

- **能看 AI 到底发了什么了**：新增请求追踪查看器。每次请求用了哪个模型、花了多少 token、耗时多久、首字延迟多少、实际发出去的内容长什么样，都能查。顶栏有入口。追踪记录默认不会进可分享的日志包，避免把提示词和正文泄露出去。
- **剧情升级为两棵树**：一棵管「章节怎么排」（故事 → 卷 → 章 → 正文），一棵管「因果怎么串」（故事 → 阶段 → 线索 → 场景）。场景通过章节编号和章节挂钩。章节简报成为一等公民，用来存这一章的目标、视角、信息控制、节奏、开头收尾和禁写事项。
- **主题系统 v2.1**：配色收敛到 36 个变量、8 套内置主题，设置页新增自定义主题编辑器，支持实时预览、按主色重新生成整套、JSON 导入导出和屏幕取色。
- 新增 AI 的三种模式（正常 / 只读讨论 / 只读计划）的基础改造，目标是让「只读」真的只读，写操作走你确认。

## 0.5.6-canary - 2026-07-03

- 修复容器部署时安装器会拉到旧镜像的问题：测试版安装器不再默认拉「最新稳定版」。
- 创建管理员的命令按安装方式分开给出，容器用容器内的脚本，不会误跑到宿主机源码上。
- 缺少数据库客户端时的提示更明确：源码运行会自动补，打包版本则直接告诉你该重新拉镜像，而不是在运行机上现生成。

## 0.5.3-canary - 2026-07-01

- 修复打包后的程序加载运行时生成的文件失败。这类文件路径是运行时才知道的，打包器接管后解析不了，现在走专门的加载入口。
- **llmlint 迁到独立开发仓**，NeuroBook 里的那份从此只是运行副本。同步脚本会顺手清掉仓库元数据、依赖目录和评测语料，不再把这些同步进你的工作区。
- 修正 llmlint 评测指标：文档负担分数改成按去重后的命中计算，同一句被多条规则命中不再被重复放大。

## 0.5.2-canary - 2026-07-01

- 世界引擎的配置文件加载更稳：仍然写 TypeScript，但运行时会先转译再加载，不依赖你的环境能不能直接跑 TypeScript。
- 异常中断后残留的临时文件会被清理干净，不影响下次加载。
- AI 的结构化提问面板高度调高了，选项多的时候不再挤成一团。
- llmlint 文档更正安装和运行方式：推荐用 `skills` 命令安装，运行需要 Bun 或 Node + `tsx`，直接拿 Node 跑 TypeScript 源码不是支持的用法。

## 0.5.1-canary - 2026-06-30

- **项目列表打开更快**：加了短缓存和分层统计缓存，主入口不再发绕过缓存的查询。服务启动后会在后台慢慢预热，不阻塞启动，也不会让第一个真实请求替所有人扛全量预热。
- **llmlint 命令行更像正经工具**：支持 `manuscript/**/*.md` 和 `!drafts/**` 这类通配符，终端下有颜色，输出到管道或给 AI 抓取时自动转纯文本。
- llmlint 现在自带自己的运行依赖，不再指望「根目录碰巧装了」。

## 0.5.0-canary - 2026-06-30

写作模式第一版的收尾，剧情系统、世界设定、AI 助手、AI 痕迹检测这几块做稳定了。

- **剧情不用再进单独界面**：直接在正常写作界面里写。结构也砍简单了，只保留「场景」这一个概念，原来那套故事线和剧情节拍废弃。每个场景靠「什么时间、在哪、有谁出场」跟世界设定挂钩。
- **场景能联动世界设定**：写场景时能直接查到对应的设定和角色当时的状态。工作台支持编辑场景与设定的关联、选角色和地点、看上下文。AI 也能拿到「这一章该怎么写」的简报。
- **AI 配置更可靠**：编译后的配置换了存储方式，保证绝不会用到过期或编译失败的旧版本。设置页能看到编译状态，而且这套机制不再拖慢编辑器。
- **AI 工具交互更顺**：「AI 向你提问」独立成专门机制；读文件、改文件、审批、计划模式这些操作在中断后能更好地恢复。
- **llmlint 增强**：规则从目录自动加载，新增整篇稿件级别的检测；命令行能扫整个目录，能自动修掉零宽字符、重复标点这类一眼假的机械痕迹。
