# 账号与云备份

::: warning 这是可选功能
NeuroBook **不需要账号也能完整使用**。所有功能都在本地运行，账号只用来接云备份和后续的资源分发。不想联网的话跳过这一页。
:::

设置页的 **NeuroBook 账号**分区管这件事。

## 关联设备

关联走**设备码流程**：客户端拿到一个码，你在浏览器里批准，客户端轮询拿到凭据。整个过程 API Key 之类的东西不会在两端之间明文传递。

关联后可以随时**解绑**。凭据支持轮换——轮换会撤销旧凭据链，所以某台设备的凭据泄露不会长期有效。

## 云备份

关联之后可以把**整个实例数据**备份到云端——不是单个项目，是 State Root 下的 workspace、配置和密钥。

备份走**冷快照**：先对数据库做一致性快照，再流式打包上传，不会因为你正在写作而拿到一个半截的数据库。上传是流式的，大项目不会把内存吃爆。有配额限制，超了会轮转旧备份。

面板里能看到备份列表、备份时间和说明，可以删除不要的备份。

**恢复是半自动的**：下载的备份会解包到一个暂存目录，然后需要**停机手动替换**。这是刻意的设计——自动覆盖正在使用的作品数据风险太高，宁可多一步人工确认。

::: danger 备份包含什么
云备份打包的是**整个实例数据**，范围比你想的大：

- 所有项目的 workspace（正文、世界书、World Engine 数据库）
- **文件历史数据库**，也就是包含你删除过的内容
- **`.env` 和 `config.yaml` 等机密**，其中有你的模型 API Key 和实例密码

这是备份该有的行为（否则恢复出来的实例跑不起来），但意味着**备份文件本身必须当作机密对待**。另外注意：用备份恢复之后，实例密码等配置会回退到备份时的状态。

服务端存的是账号级的不透明数据块。
:::

## 本地备份仍然是首选

云备份是额外保险，不是唯一手段。**最可靠的备份仍然是拷贝 State Root 目录**——里面全是普通文件和 SQLite，没有任何外部依赖，拷到移动硬盘上就能用。见 [你的数据在哪](/operations#你的数据在哪)。

## 创意工坊

创意工坊（Workshop）是配套的资源分发平台，用来分享和下载 profile、Skill、模板这类可安装资源。

::: warning 尚未开放
工坊站点**还没有公开上线**，NeuroBook 客户端里的一键安装也**尚未接入**。当前版本里没有工坊入口。

这一节记录的是规划形态，不是现在能用的功能。等上线后这里会更新为实际使用说明。
:::

## 状态说明

账号关联与云备份的客户端和服务端都已实施，**浏览器端完整验收仍在进行中**。如果你在意数据安全，现阶段建议以本地备份为主。
