# 设置中心

设置入口在顶栏最右侧的**账号头像 → 设置**。

设置页有两个维度：**作用域**决定这条配置影响谁，**分区**决定你在配什么。

## 四个作用域

| 作用域 | 存在哪 | 影响范围 | 改完要重启吗 |
| --- | --- | --- | --- |
| **启动** | State Root 的 `config.yaml` | 端口、鉴权等启动参数 | **要** |
| **全局** | `<State Root>/workspace/.nbook/config.json` | 所有项目 | 否 |
| **项目** | `<项目>/.nbook/config.json` | 仅当前项目，覆盖全局 | 否 |
| **浏览器** | 浏览器本地 | 仅这台设备这个浏览器 | 否 |

优先级是**项目覆盖全局**。字体大小这类偏好通常放浏览器作用域，模型和 API Key 放全局，单本书的特殊设定放项目。

::: warning 启动作用域是只读展示
配置中心只展示当前进程的启动状态，不提供热改写。要改端口或鉴权，改 `config.yaml` 后重启服务。
:::

## 分区一览

| 分区 | 配什么 |
| --- | --- |
| **安全** | 登录鉴权状态 |
| **界面** | 主题、界面语言（中 / 英）、编辑器视图默认模式 |
| **编辑器** | 正文字体（含中文衬线 / 黑体 / 楷体）、字号、行高、正文宽度、段首缩进、Monaco 编辑器偏好 |
| **模型** | Provider、Base URL、API Key、默认模型、模型库 |
| **Embedding** | 向量检索服务端点 |
| **成本** | token 计价与币种换算 |
| **联网工具** | `web_search` / `web_fetch` 的配置 |
| **Agent Profile 模型** | 给不同 Agent 单独指定模型 |
| **小说数据** | 榜单选题服务端点 |
| **可观测** | 请求 trace 记录开关与保留条数 |
| **NeuroBook 账号** | 账号关联与云备份，见 [账号与云备份](/guide/account) |

## 模型与成本

**模型**分区是必配的——不配 Agent 就不能工作。Provider 就是提供大模型 API 的服务商，你在服务商那里申请 API Key 填进来。同一个端点可以复用已保存的密钥。

**Agent Profile 模型**让你按角色分配算力：写正文的 `writer` 用最强的模型，后台跑标题摘要的 `summarizer` 用便宜的。这是长期使用中最实际的省钱手段。

**成本**分区管计价。token 按**输入 / 输出 / 缓存创建 / 缓存命中**四项分别计量——这四项单价通常差很多，合并统计会严重失真。配好单价后，界面会把消耗直接换算成美元和人民币。

## 可观测（请求 trace）

打开后，每次调用模型的完整过程都会被记录：规范化后的上下文、原始请求体、HTTP 状态、token 用量、首字延迟和总耗时。顶栏 **Trace** 按钮打开查看器，可以按会话筛选、按调用分组、六个标签页看细节，也能和会话双向跳转。

调 prompt 或排查"AI 为什么这么答"时，这是唯一能看到真相的地方。

::: danger trace 含完整正文
trace 里有完整的 prompt 和小说正文。默认每个会话保留最近 100 条，落在 `<State Root>/workspace/.nbook/agent/traces/`。**分享机器或目录前先清掉它**。它不会进入可分享日志包，但会留在磁盘上。详见 [隐私边界](/operations#隐私边界)。
:::

## 界面语言

界面分区可以在**简体中文**和**English** 之间切换。这只影响界面文案，不影响 Agent 用什么语言跟你说话——那个由模型和提示词决定。
