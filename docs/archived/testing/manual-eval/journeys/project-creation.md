# 项目创建

> 依据：`vitepress/locales/zh-Hans/tutorials/02-first-project.md`
> 目的：第一本书能否顺利建出来，Agent 能否识别当前项目。

## 前置

- 应用可用（先走「启动检查」）。

## 检查项

### 新建项目

- 操作：书架 → 新建项目 → 填写标题和简介（如「星灯列车 / 一名失去记忆的列车检票员……」）→ 创建。
- 预期：创建成功。
- 通过判据：出现成功反馈并进入新项目。
- 失败形态：创建无反应（P0/P1）；缺必填校验提示（P2）。

### 进入工作区

- 操作：创建完成后观察页面去向。
- 预期：自动进入新项目工作区。
- 通过判据：当前项目切换为新项目。
- 失败形态：仍停留在书架页（P1）。

### 骨架确认

- 操作：展开文件树。
- 预期：出现预期骨架目录（同「工作台漫游」的文件树骨架检查项）。
- 通过判据：目录齐全。

### Agent 识别项目

- 操作：向 Agent 问「当前项目是什么」。
- 预期：答出刚创建的项目。
- 通过判据：项目名正确；答错时用教程的追问路径能纠正。
- 失败形态：答错或找不到且提示无效（P1）。

### 标题可改

- 操作：在项目设置中修改标题。
- 预期：标题可修改并保存（教程声明「标题随时能改」）。
- 通过判据：修改后页面与文件系统同步。
- 失败形态：无法修改（P2）。
