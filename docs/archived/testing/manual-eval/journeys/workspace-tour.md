# 工作台漫游

> 依据：`vitepress/locales/zh-Hans/tutorials/01-studio-tour.md`
> 目的：界面各区域是否可靠、可发现，编辑器基本编辑链路是否闭环。

## 前置

- 已有可打开的 Project（无项目时先走「项目创建」旅程）。

## 检查项

### 顶栏入口

- 操作：书架、World、Plot、Trace、Jobs、变更、用户资产、Agent 面板、账号菜单逐个点开再返回。
- 预期：每个入口有明确内容，可返回。
- 通过判据：无空白页、无报错。
- 失败形态：某入口空白或无反应（按入口重要度 P1/P2）。

### 文件树骨架

- 操作：展开文件树。
- 预期：可见 `project.yaml`、`lorebook/`、`manuscript/`、`world-engine/`、`reference/`、`.nbook/`。
- 通过判据：骨架目录齐全，可展开。
- 失败形态：骨架缺目录（P2）；文件树无法展开（P1）。

### 打开文件

- 操作：在文件树打开 lorebook 或 manuscript 文件。
- 预期：Markdown Studio 显示文件内容。
- 通过判据：内容可见可编辑。
- 失败形态：打不开或空白（P1）。

### 双模式切换

- 操作：富文本 ↔ 源码模式来回切换。
- 预期：两种模式内容一致。
- 通过判据：切换后内容不丢、格式不乱。
- 失败形态：切换后内容丢失或不一致（P1，数据风险）。

### 编辑保存

- 操作：改一个字 → 保存 → 刷新页面。
- 预期：刷新后内容仍在。
- 通过判据：内容持久化。
- 失败形态：刷新后丢失（P1）。

### 状态栏字数

- 操作：打开文件后查看状态栏。
- 预期：显示当前文件字数。
- 通过判据：字数可见且随编辑变化。
- 失败形态：缺失（P2）。

### 窄屏收起

- 操作：缩窄窗口（390×844）。
- 预期：部分按钮自动收起，页面无横向溢出。
- 通过判据：无文档级横向滚动（对照 Task 141：390×844 下配置中心无文档级溢出为通过）。
- 失败形态：横向溢出（P2）。
