# Skill 初始化

> 依据：`vitepress/locales/zh-Hans/tutorials/03-skills-bootstrap.md`
> 目的：novel-setup 四阶段是否真正把灵感落成项目文件，而不是只聊天。
> 依赖：全部检查项需要真实 provider；provider 不可用时整体标「未验证」。

## 前置

- 「项目创建」完成；真实 provider 可用。

## 检查项

### 灵感探索

- 操作：使用 novel-idea-exploration 从灵感（如失忆检票员/夜行列车/梦境城市）讨论。
- 预期：得到故事雏形，能回答题材、主角、第一卷承诺。
- 通过判据：产出可继续开发的故事雏形。
- 失败形态：只闲聊不产出（P2）；provider 不可用 → 未验证。

### 先列文件再写入

- 操作：要求「先列出将创建/更新的文件路径，等我确认后再写入」。
- 预期：Agent 先列路径，确认后才写。
- 通过判据：未经确认不写文件。
- 失败形态：未经确认直接写文件（P1，可控性）。

### 阶段一落盘

- 操作：novel-setup 阶段一（项目初始化）。
- 预期：作品概念、主角、初始冲突、最小 lorebook 骨架、开篇三章方向写入项目。
- 通过判据：文件系统出现对应产物。
- 失败形态：只聊天不写文件（P1）。

### 世界书骨架

- 操作：novel-setup 阶段二（世界书框架）。
- 预期：lorebook 出现 character/location/world/instruction 等与前三章相关的条目。
- 通过判据：条目有实质内容、路径符合项目约定。
- 失败形态：条目是空文件（P1）；路径不符合约定（P1）。

### 角色设计

- 操作：novel-setup 阶段三（角色设计与细化）。
- 预期：主角与重要配角稳定设定写入 lorebook。
- 通过判据：设定落盘可读。
- 失败形态：设定只留在聊天（P1）。

### World Engine 初始化

- 操作：novel-setup 阶段四（World Engine 初始化）。
- 预期：确认纪年方式、开篇时间点、登记需追踪角色 → 开局状态写入。
- 通过判据：时间线有开局状态。
- 失败形态：声称完成但时间线为空（P1）；确认环节缺失直接写（P2）。

### 文件旁证

- 操作：对照各阶段产物检查文件系统。
- 预期：产物实际存在（证据要求见 criteria.md 第 5 节）。
- 通过判据：文件存在且有内容。

### 新会话可读

- 操作：新建一个 session，询问已写入的设定。
- 预期：能读取已写入内容。
- 通过判据：回答与落盘内容一致。
- 失败形态：新会话找不到已写内容（P1，检索/记忆问题）。
