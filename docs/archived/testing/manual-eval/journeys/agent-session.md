# Agent 会话与 Composer

> 依据：Task 141 浏览器验收记录（`.agents/tasks/141-merged-pr-browser-acceptance/README.md`）
> 目的：对话交互的边界情况——键盘、图片门禁、停止/恢复、错误、刷新、Workflow/Jobs。
> 依赖：部分检查项需要真实 provider；无法稳定复现的边界（IME、metadata 失败、预算超限）标「未验证」。

## 前置

- 真实 provider 可用；必要时准备真实可回答的 Workflow 请求。

## 检查项

### 键盘分支

- 操作：普通 Enter；Shift+Enter；运行中 Ctrl/Meta+Enter；中文输入法 composing Enter。
- 预期：Enter 发送；Shift+Enter 保留换行不发送；Ctrl/Meta+Enter 显示「消息已排队」；IME 行为正常。
- 通过判据：各分支行为符合预期，无重复发送。
- 失败形态：Enter 不发送或重复发送（P1）；排队无提示（P2）；IME 无法稳定复现 → 未验证。

### 图片门禁

- 操作：选非图片文件（如 package.json）→ 再选合法 PNG → 移除图片。
- 预期：非图片被拒（提示「仅支持 PNG、JPEG、GIF 和 WebP」）且不创建预览不发送；PNG 出现预览与附件路径；移除后草稿恢复为空。
- 通过判据：门禁行为符合预期。
- 失败形态：非法文件被发送（P1）；失败时创建乐观消息（P1）；metadata 失败与 32 MiB 预算超限（难复现 → 未验证）。

### 停止与半截正文

- 操作：运行中点「停止」。
- 预期：出现「已停止生成」，已有正文保留。
- 通过判据：停止有明确反馈，半截正文不丢。
- 失败形态：停止无反馈（P1，Task 140 已记录）；半截正文丢失（P1）。

### 取消后重试

- 操作：停止后再次发送新消息。
- 预期：可正常发送。
- 通过判据：Composer 可继续使用。
- 失败形态：停止后无法再发送（P1）。

### 错误去重

- 操作：触发一次失败并观察提示。
- 预期：错误提示不重复弹出、可理解。
- 通过判据：单一清晰提示。
- 失败形态：重复错误气泡（P2）；错误原文抛内部术语（P2）。

### 刷新恢复

- 操作：刷新页面。
- 预期：会话列表、消息、运行状态恢复；历史失败可读。
- 通过判据：先显示「正在恢复对话」再恢复内容。
- 失败形态：刷新后丢失（P1）；恢复卡在「正在恢复对话」（P1）。

### Workflow 多 Run 分别应答

- 操作：在等待应答的 Composer 中对多个 Run 分别作答。
- 预期：每个 Run 独立应答。
- 通过判据：回答与 Run 一一对应。
- 失败形态：只能答一个或串场（P1）。

### 结果回流与防重复

- 操作：应答后观察结果去向；尝试重复提交。
- 预期：答案进入正确会话；`wf.ask` 重复提交被拦截。
- 通过判据：结果回流正确、重复提交被拦。
- 失败形态：答案进错会话（P1）；可重复提交（P1）。

### Jobs 任务中心

- 操作：打开 Jobs 入口。
- 预期：任务状态可见（进行中/已结束），徽标显示运行中任务数。
- 通过判据：入口有内容且状态更新。
- 失败形态：入口空白（P1）；状态不更新（P1）。

### 附件路径与缓存观察

- 操作：上传 PNG 后查看附件位置。
- 预期：原图在 `workspace/.nbook/agent/attachments/...`。
- 观察：图片变体是否落仓库根 `cache/image-variants`（Task 141 观察项，继续记录不处置）。
