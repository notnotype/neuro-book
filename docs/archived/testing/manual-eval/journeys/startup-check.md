# 启动检查

> 依据：`vitepress/locales/zh-Hans/tutorials/00-before-you-start.md`
> 目的：新用户打开应用后能否确认「应用能用、AI 能工作」。

## 前置

- 应用已启动；服务端模式默认需要登录（Windows Portable 默认关闭认证，按部署形态记录）。

## 检查项

### 打开应用

- 操作：打开应用。
- 预期：能到达登录/首页。
- 通过判据：无白屏、无持续 loading；console 无报错。
- 失败形态：白屏或卡加载（P0）；console 报错但页面可用（观察项）。

### 登录

- 操作：登录（服务端模式；Windows Portable 默认关闭认证）。
- 预期：能进入应用。
- 通过判据：登录成功进入主界面。
- 失败形态：登录失败且无明确提示（P1）。

### 配置模型

- 操作：账号菜单 → 设置 → 模型分区，配置 Provider、API Key、默认模型并保存。
- 预期：配置被保存。
- 通过判据：保存后有确认反馈，重新打开仍生效。
- 失败形态：保存后不生效或无保存反馈（P1）。

### Agent 最小测试

- 操作：展开 Agent 面板，发送「请简单回复：你现在可以作为 NeuroBook 的创作 Agent 工作吗？」。
- 预期：收到回复。
- 通过判据：消息发出后有明确回复。
- 失败形态：无回复且提示不清晰（P1）；provider 不可用 → 标未验证，不伪造结果。

### 当前项目确认

- 操作：查看页面当前选中的项目。
- 预期：显示的是预期项目。
- 通过判据：项目名与预期一致。
- 失败形态：显示错误项目（P1，存在写错项目风险）。
