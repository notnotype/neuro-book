# 评测报告模板

> 每轮评测按此模板产出一份报告。判定口径见 criteria.md；检查项见 journeys/ 对应文件。

```markdown
# 评测报告 <版本或批次> <日期>

## 环境
- 实例地址与端口：
- State Root / Cache Root：
- 评测 Project（真实/临时）：
- Provider / 模型：
- 视口（桌面/窄屏）：
- 评测范围（旅程清单）：

## 各旅程结果

### <旅程名>
- 判定：通过 / 部分通过 / 未验证 / 环境阻塞
- 检查项结果：

| 检查项 | 判定 | 证据 | 备注 |
| --- | --- | --- | --- |

- 问题条目：按 criteria.md 第 4 节格式逐条列出（场景 → 影响 → 证据 → 原因 → 位置 → 置信度）。

## 汇总
- P0/P1 清单（结论先行，按影响排序）
- 未验证清单（含原因：缺 provider / 缺前置数据 / 环境）
- 环境阻塞清单
- 用户复核记录（改判项与理由）
- 检查边界：本轮看了什么、没看什么
```
