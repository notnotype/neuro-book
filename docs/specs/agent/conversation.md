# Agent 的对话界面

## 目标与非目标

把纯受控的对话视图（[`ui/agent-conversation-view.md`](../ui/agent-conversation-view.md)）接到新内核，在工作台里用起来：作者在右栏和 Agent 对话、切换会话、批准写入、回答提问、看上下文和费用。

不承诺：

- 横屏方案、一键切换布局、布局预设：等布局包，开发者体验后再定。这里只保证对话能放到编辑区；
- 分支树、附件、草稿、`/` `$` `@` 触发符、Agent 模式：见第二批；
- 子代理的卡片与子会话入口：随多 Agent；
- 按块采纳改动、收件箱：随历史接入；
- 搜对话内容：只搜标题和说明；
- 刷新页面时正在生成的那条从头补发：刷新后从下一个增量接着显示，这条写完时换成日志里的全文；
- 异步提问（`ask` 的 `async`）：第一版只用同步提问，活动条目不覆盖异步待答；
- 回退、编辑重发、分支：第二批；日志里已有回退的会话照常显示当前路径。

## 术语与参与者

- **宿主**：`nbook.agent` 的浏览器入口。持有当前窗口的当前会话，把日志与帧合成视图要的 `ctx`，把视图的 action 换成远程指令。
- **当前会话**：一个对话位置（右栏的视图或编辑区的页面）正在显示的会话。运行期间每个窗口各选各的，两个窗口开同一会话看到同一份；刷新后回到这个位置最近切到的会话（两个窗口共用这份记录）。
- **向导**：审批向导与提问向导，等用户时替换输入框的位置。
- **中断的会话**：当前路径的最后一次运行以 `interrupted` 结束，之后还没有新一轮。

## 输入与前置条件

贡献：

| 贡献点 | id | 默认位置与说明 |
|---|---|---|
| `workbench.views` | `nbook.agent.conversation` | 右栏 |
| `workbench.views` | `nbook.agent.sessions` | 左栏，会话面板 |
| `editor.pages` | `nbook.agent.conversation` | 编辑区的“Agent 对话”，和视图同一个宿主组件；命令 `nbook.agent.open-in-editor` 打开它 |

## 输出与可观察行为

### 会话

1. 新建会话用 `nbook.agent.main`，目录里不隐藏、可用的 Profile 多于一个时先选。会话归属当前打开的作品。没有当前会话时第一次发送自动新建。
2. 会话面板是同一个组件，在点标题弹出的下拉和左栏视图里各放一份。每行是 Profile 图标（`agent.profiles` 声明的 `icon`，没写用缺省，名字在悬停提示）、标题、时间、说明、状态（运行中、等你处理、已中断），按今天、昨天、更早分组。
3. 面板顶部是搜索（只查标题和说明）、作品范围（当前作品、全部作品）、过滤按钮。过滤菜单选 Profile、显示已归档；选了的条件是过滤按钮上的条数，菜单里能一次清除；有没有选，面板高度都不变。改名、归档、恢复在每行悬停的菜单里。
4. 切换会话只换这个对话位置的当前会话，不影响别的窗口。当前会话被归档时位置还显示它，输入框只读，可以恢复。

### 对话

5. 打开会话：先订阅 `frames` 并缓存；取 `snapshot`，得 `head`、`leaf` 与会话级基线；固定这个 `leaf` 分页取 `path`；处理缓存，seq 不大于 `head` 的日志帧丢掉，`snapshot` 返回之前的状态帧丢掉。内联放不下的事件经 `eventChunk` 拼回，按 seq 保序。收到 `leafChanged` 按新叶子重取路径，不把各分支的日志接在一起。重连后（`onResync`）按现在的快照与路径整份重建：比按 seq 用 `log` 补（[`sessions.md`](sessions.md) 输出 8）多读一次路径，但回退、切分支不用另外处理。
6. 发送走 `send`，运行中走 `enqueue`（回车插话，Ctrl/⌘ 加回车排队）；排队中的消息显示在待处理区，能删，能取出到输入框改了再发。用户消息先乐观显示；明确被拒时撤掉，文字放回输入框并说明原因；连接断开、结果未知时标出来，可以重发或移除。停止走 `abort{keepQueue: true}`，排队的消息留着；状态栏显示“正在停止”和用时，超过 10 秒提示工具没有响应，以快照的状态收口。
7. 模型与推理档选的是这个会话的设置（`changeSettings` 的 `core.model`、`core.effort`）。选择器（[`ui/agent-conversation-view.md`](../ui/agent-conversation-view.md) 的“带角色的选择器”）列“跟随默认”（`core.model: null`）、模型角色（`core.model: "role:<id>"`，[`models/service.md`](../models/service.md) 输出 8）与启用、可用、有凭据的模型；当前选中的不合格也列出并标“不可用”。实际模型、窗口、推理档来自快照的 `model`。模型服务不在时选择器隐藏。
8. 模式菜单第一版只有审批模式：每次询问（默认）、放行写入、全部放行，写 `core.approvalMode`。
9. 中断的会话不单独提醒：输入框占位文字变成“上次运行已中断。按回车继续，或输入内容后继续”，发送按钮换成继续。空着按回车走 `start`，写了字走 `send`。发出之后恢复原样。

### 审批与提问

10. 运行等用户时向导替换输入框的位置：贴在消息流底部，往上滚时浮在内容上；贴底时不盖最后一条。最高占视图的 60%，内容内部滚动，内容区最少 8 行高，放不下时整体滚动。表面和其它浮层相同（磨砂）。输入框隐藏但不卸载，草稿还在。
11. 模型一条回复发起多个要审批的调用时，向导一步一个，标“第 1 / 3 个”，和提问一样作答：每步选批准、本会话都批准或拒绝（可带附言），能来回改，全部选完才能提交。“全部拒绝”随时可点，可带一段附言。可以收起成一条小条，写等什么、第几个，没有批准按钮；这时不能发新消息，要先处理它。出现时焦点到向导容器（不落到批准按钮），有读屏播报，没有焦点陷阱；收起后焦点到展开按钮，答完回输入框；Esc 只收起。
12. 审批显示工具与目标。`edit`、`write` 用只读查询 `approvalPreview` 取改前改后，用 `DiffView` 显示，一次改多个文件时按文件分节，过大或读不了的写明原因；命令显示等宽代码块，工作目录与超时一行小字；别的工具列出参数的键与值（这里只有参数，没有 schema，nb-form 的展示态也只能画成 JSON 框）。按钮：批准（`allow`）、本会话都批准（`allow-session`）、拒绝（`deny`）。附言框写了字就是拒绝，这段话交给模型，这时批准不可点。“本会话都批准”同时选中这批里同一个工具的其余调用。一批审批是一起问的，还没执行：同一个文件前面有别的调用、预览算不出来时写明，并显示参数。
13. 提问一次 1 到 4 题，单选或多选，总带“其它”；带表单的题用 nb-form 的编辑态。提交走 `resolve{answer}`（`text` 是拼好的人话，`data` 是逐题的回答），“停止这一轮”走 `abort`。已答的答案在提交前可以来回改，切走标签再回来还在，未提交的只在这一批里保留。
14. 别的窗口先答了，这个窗口的向导跟着消失；答复撞上 `already-answered` 时不报错。

### 状态栏

15. 输入框下面一行小字。左边：上下文圆环与百分比（90% 起变红，分母是快照 `model` 的窗口，不知道时只显示绝对数）；运行阶段与用时（请求中、生成中、执行工具、正在压缩、正在停止）；等重发（第几次、还等多久）；等你批准或回答；费用告警；“全部放行”的警告；断线时的连接状态。右边：累计 tokens、输入、输出、缓存命中、费用，图标与轮末用量相同，明细在悬停；右栏窄时右边只留缓存命中与费用。单价未知时不显示费用，为 0 显示“免费”。
16. 上下文占用是最近一次模型回复的输入、缓存读取与缓存写入之和，即下一次请求至少要带的量。压缩后到下一次回复之前，取压缩后的估算加放回的量（估算不含系统提示与工具，所以比真实值低，下一次回复后会跳回）。
17. 累计费用到告警线（快照的费用与设置 `warnCost` 算）时费用那一项变色，左边写“超过告警线”；有没有单价的请求时费用项的悬停写“这个模型没有单价，费用上限对它不起作用”。累计跨回退，含失败与后台用途。
18. 运行结束的码显示成人话：`cost-limit`、`tool-call-loop`、`empty-reply`、`thinking-loop`、`first-event-timeout`。等重发时收到带 `retry` 的 `modelFailed`，丢掉那次的半截文字。

### 工作台状态栏条目

19. 空闲时不显示。有运行中或等用户的前台会话时显示“Agent：1 运行中 · 1 等你处理”，等用户时用警告色；点击打开对话位置并切到那个会话，优先切到等用户的。

### 压缩

20. `/compact [要求]` 走 `compact`。没有会话时不新建，说明还没有对话。被拒时文字放回输入框并说明原因：`nothing-to-compact`、`no-compaction-model`（文字提示到设置里给“压缩”角色绑定模型）、`read-only`。运行中受理（`next-boundary`）时说明“将在这一步结束后压缩”，运行结束时清掉。结果未知只说明，不重发。对话模型不可用时输入框只读，这时不能手动压缩。
21. 只压缩的运行不算上一轮的一部分：上一轮不展开、不转圈；停止显示“压缩已停止”，失败显示压缩没成功、对话没动、可以换压缩模型或开新会话，都不改上一轮回复的状态。
22. 解析到的模型跟着变：模型库变了（绑定角色、设密钥、改模型）或会话的 `core.model`、`core.effort` 变了，不用重开会话，状态、窗口与推理档就跟上：未绑定的说明消失、能发送。运行中也一样，运行状态、队列与正在生成的那条都不动。
23. 缓存命中率是累计的缓存读取除以输入、缓存读取、缓存写入之和；读写都是 0 时不显示，不写 0%：有的服务商不报缓存。
24. 上下文详情：点状态栏的圆环或缓存命中、或顶栏菜单打开，内容见 [`ui/agent-conversation-view.md`](../ui/agent-conversation-view.md) 的“上下文检查器”。数据来自 `preview`，打开与刷新时才取，不调模型；算不出（`preview-unavailable` 等）时写原因。开着时不跟着运行自动刷新。
22. 输入框 `/` 菜单只列宿主支持的命令。

## 状态与转换

| 向导状态 | 进入 | 离开 |
|---|---|---|
| 无 | 没有等用户的事项 | 收到 `interactionRequested` |
| 展开 | 有等用户的事项 | 全部提交，或运行结束 |
| 收起 | 用户收起 | 用户展开，或全部答完 |

时序与寿命：

- 宿主按位置放在插件级，组件借用并计数，归零后 30 秒取消订阅：编辑区页面切标签就卸载，也没有关闭信号。未提交的答案、收起状态放在宿主里。
- 切换会话时，正在生成的内容丢弃，进来时按输出 5 重新取。
- 插件停止时对话位置显示停止原因，刷新后回到原来的会话。
- 服务端换进程后浏览器节点是终态（[`runtime/plugin-channel.md`](../runtime/plugin-channel.md)），走现有的重新加载页面，加载后从存储恢复当前会话，会话显示中断的样子。
- 最近用过的会话按位置存在 `nbook.storage` 的本地记录，作品范围按作品分区；会话不在了就显示未选择会话。

## 副作用与数据

只经 `agent.sessions` 的远程指令改会话。界面状态（当前会话、向导收起、面板的过滤）在浏览器本地，不进会话日志。

## 失败与恢复

| 情况 | 显示 | 恢复 |
|---|---|---|
| 会话打不开 | 位置里显示原因 | 重试、选别的会话 |
| 没有模型、没有凭据、角色未绑定 | 输入框上方显示原因，发送不可用 | “打开设置”跳到模型服务 |
| 服务端换进程 | 重新加载页面，不丢已写下的内容 | 点重新加载 |
| `already-answered` | 向导跟着服务端的状态 | 自动 |
| 发送被拒 | 撤掉乐观消息，文字放回输入框，上方说明原因 | 改了再发 |
| 发送结果未知 | 消息标“未确认” | 重发（同一个指令 id）或移除 |
| 预览查询失败 | 向导写“预览不可用”，显示参数 | 审批照常 |
| 活动订阅失败 | 条目不显示，写诊断 | 刷新 |

## 边界与兼容

- `nb-agent-ui` 仍是纯受控视图，不依赖内核；新内核的适配器在它的核心里，输入是 JSON。nb-story 迁移之前旧适配器留着。
- 公开状态键 `nbook.agent/active`、命令 `nbook.agent.open`、`nbook.agent.open-in-editor`、`nbook.agent.new-session`、`nbook.agent.focus-session` 是公开合同。

## 验收与 Smoke

1. 真实浏览器、真实服务端、本机端点：右栏打开视图、发一条、看到流式与最终回复、状态栏变化；刷新后回到同一会话。
2. Agent 改文件：向导浮动显示 diff，收起再展开，批准后文件变了；拒绝并附言，模型收到这段话。
3. Agent 用 `ask`：单选加其它、多选、表单各答一次，结果回到模型。
4. 两个窗口开同一会话，一个批准，另一个的向导消失。
5. 服务端在运行中重启：重新加载后回到这个会话，显示中断的样子，回车继续。
6. 把对话打开到编辑区页面，文件视图拖到右栏：都能用。
7. Smoke：真实模型跑主创改一个文件，经批准。

## 实现合同

- **公开入口**：贡献（视图、编辑区页面、活动条目）的 id，公开状态键与命令（见“边界与兼容”）；宿主与组件不对外导出。
- **owner 与依赖方向**：`nbook.agent` 的浏览器入口。依赖 `nb-agent-ui`（纯受控视图，新内核的适配器在它的核心里）与 `agent.sessions` 的远程指令；`nbook.models` 不在时选择器隐藏。
- **关键不变量**：
  - 打开会话先订阅再取快照，日志帧按 `head` 去重；`leafChanged` 与重连都按新路径整份重建，不把分支接在一起（输出 5，`session-host.test.ts`“打开过程中”“回退”）。
  - 乐观消息只由实时帧确认；结果未知时重发用同一个指令 id，服务端其实受理了也只有一条（输出 6，`session-host.test.ts`“结果未知”）。
  - 宿主按位置放在插件级，组件借用并计数，归零后 30 秒才取消订阅；向导的界面状态在宿主里，这一批答完就清（`session-host.test.ts`“组件都还回去之后”“向导的界面状态”）。
  - 活动条目先订阅后取快照，只数前台会话（输出 19，`session-host.test.ts`“活动条目”）。
