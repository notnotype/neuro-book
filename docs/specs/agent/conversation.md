# Agent 的对话界面

## 目标与非目标

把纯受控的对话视图（[`ui/agent-conversation-view.md`](../ui/agent-conversation-view.md)）接到新内核，在工作台里用起来：作者在右栏和 Agent 对话、切换会话、批准写入、回答提问、看上下文和费用。

不承诺：

- 横屏方案、一键切换布局、布局预设：等布局包，开发者体验后再定。这里只保证对话能放到编辑区；
- 分支树、上下文检查器、附件、草稿、`/` `$` `@` 触发符、Agent 模式：见第二批；
- 子代理的卡片与子会话入口：随多 Agent；
- 按块采纳改动、收件箱：随历史接入；
- 搜对话内容：只搜标题和说明；
- 刷新页面时正在生成的那条从头补发：刷新后从下一个增量接着显示，这条写完时换成日志里的全文。

## 术语与参与者

- **宿主**：`nbook.agent` 的浏览器入口。持有当前窗口的当前会话，把日志与帧合成视图要的 `ctx`，把视图的 action 换成远程指令。
- **当前会话**：一个对话位置（右栏的视图或编辑区的页面）正在显示的会话。每个窗口各选各的，两个窗口开同一会话看到同一份。
- **向导**：审批向导与提问向导，等用户时替换输入框的位置。
- **中断的会话**：当前路径的最后一次运行以 `interrupted` 结束，之后还没有新一轮。

## 输入与前置条件

贡献：

| 贡献点 | id | 默认位置与说明 |
|---|---|---|
| `workbench.views` | `nbook.agent.conversation` | 右栏 |
| `workbench.views` | `nbook.agent.sessions` | 左栏，会话面板 |

## 输出与可观察行为

### 会话

1. 新建会话用 `nbook.agent.main`，目录里不隐藏、可用的 Profile 多于一个时先选。会话归属当前打开的作品。
2. 会话面板是同一个组件，在点标题弹出的下拉和左栏视图里各放一份。每行是 Profile 图标（`agent.profiles` 声明的 `icon`，没写用缺省，名字在悬停提示）、标题、时间、说明、状态（运行中、等你处理、已中断），按今天、昨天、更早分组。
3. 面板顶部是搜索（只查标题和说明）、作品范围（当前作品、全部作品）、过滤按钮。过滤菜单选 Profile、显示已归档；选了的条件显示成可去掉的标签。改名、归档、恢复在每行悬停的菜单里。
4. 切换会话只换这个对话位置的当前会话，不影响别的窗口。当前会话被归档时位置还显示它，输入框只读，可以恢复。

### 对话

5. 打开会话时先订阅 `frames`，再按 `path` 取当前路径，丢掉 seq 不大于它的帧；重连后按最后收到的 seq 用 `log` 补（[`sessions.md`](sessions.md) 输出 8）。服务端换进程时重新打开。
6. 发送走 `send`，运行中走 `enqueue`（回车插话，Ctrl/⌘ 加回车排队）；排队中的消息显示在待处理区，能改能删。停止走 `abort`。
7. 模型与推理档选的是这个会话的设置（`changeSettings` 的 `core.model`、`core.effort`），可选项来自 `nbook.models` 的快照。服务商或模型变了，下拉跟着变。
8. 模式菜单第一版只有审批模式：每次都问（默认）、放行写入、全部放行，写 `core.approvalMode`。
9. 中断的会话不单独提醒：输入框占位文字变成“上次运行被中断。回车继续，或者写点什么再继续”，发送按钮换成继续。空着按回车走 `start`，写了字走 `send`。发出之后恢复原样。

### 审批与提问

10. 运行等用户时向导替换输入框的位置，浮动盖在消息流上，不占高度；消息流底部留出同样的高度，最后一条能滚出来。最高占视图的 60%，内容内部滚动。表面和其它浮层相同（磨砂）。
11. 向导逐个处理，标“第 1 / 3 个”。可以收起成一条小条，写等什么、第几个，没有批准按钮；这时不能发新消息，要先处理它。
12. 审批显示工具与目标。工具给了预览（`edit`、`write`）时用 `DiffView` 显示改前改后；命令显示等宽代码块，工作目录与超时一行小字；别的工具的参数用 nb-form 的展示态。按钮：批准（`allow`）、本会话都批准（`allow-session`）、拒绝（`deny`）。附言框写了字就是拒绝，这段话交给模型。
13. 提问一次 1 到 4 题，单选或多选，总带“其它”；带表单的题用 nb-form 的编辑态。提交走 `resolve{answer}`，“停止这一轮”走 `abort`。已答的答案在提交前可以来回改，未提交的只在这一批里保留。
14. 别的窗口先答了，这个窗口的向导跟着消失；答复撞上 `already-answered` 时不报错。

### 状态栏

15. 输入框下面一行小字。左边：上下文圆环与百分比（90% 起变红）；运行阶段与用时（请求中、生成中、执行工具、正在压缩）；等重发（第几次、还等多久）；等你批准或回答；费用告警；“全部放行”的警告；断线时的连接状态。右边：累计 tokens、输入、输出、缓存命中、费用，图标与轮末用量相同，明细在悬停。单价未知时不显示费用，为 0 显示“免费”。
16. 上下文占用是最近一次模型回复的输入、缓存读取与缓存写入之和，即下一次请求至少要带的量。
17. 费用告警（`costWarned`）时费用那一项变色，左边写“超过告警线”；`costUnpriced` 时费用项的悬停写“这个模型没有单价，费用上限对它不起作用”。
18. 运行结束的码显示成人话：`cost-limit`、`tool-call-loop`、`empty-reply`、`thinking-loop`、`first-event-timeout`。等重发时收到带 `retry` 的 `modelFailed`，丢掉那次的半截文字。

### 工作台状态栏条目

19. 空闲时不显示。有运行中或等用户的前台会话时显示“Agent：1 运行中 · 1 等你处理”，等用户时用警告色；点击打开对话位置并切到那个会话，优先切到等用户的。

## 状态与转换

| 向导状态 | 进入 | 离开 |
|---|---|---|
| 无 | 没有等用户的事项 | 收到 `interactionRequested` |
| 展开 | 有等用户的事项 | 全部答完，或运行结束 |
| 收起 | 用户收起 | 用户展开，或全部答完 |

时序与寿命：

- 宿主的订阅跟着对话位置：视图隐藏时保留，位置被关闭时取消。
- 切换会话时，正在生成的内容丢弃，进来时按输出 5 重新取。
- 插件停止时对话位置显示停止原因，刷新后回到原来的会话。
- 当前会话的 id 按窗口与对话位置存在浏览器本地；会话不在了就显示未选择会话。

## 副作用与数据

只经 `agent.sessions` 的远程指令改会话。界面状态（当前会话、向导收起、面板的过滤）在浏览器本地，不进会话日志。

## 失败与恢复

| 情况 | 显示 | 恢复 |
|---|---|---|
| 会话打不开 | 位置里显示原因 | 重试、选别的会话 |
| 没有模型、没有凭据、角色未绑定 | 输入框上方显示原因，发送不可用 | “打开设置”跳到模型服务 |
| 服务端换进程 | 重新打开，不丢已写下的内容 | 自动 |
| `already-answered` | 向导跟着服务端的状态 | 自动 |

## 边界与兼容

- `nb-agent-ui` 仍是纯受控视图，不依赖内核；新内核的适配器在它的核心里，输入是 JSON。nb-story 迁移之前旧适配器留着。
- 公开状态键 `nbook.agent/active`、命令 `nbook.agent.open`、`nbook.agent.new-session`、`nbook.agent.focus-session` 是公开合同。

## 验收与 Smoke

1. 真实浏览器、真实服务端、本机端点：右栏打开视图、发一条、看到流式与最终回复、状态栏变化；刷新后回到同一会话。
2. Agent 改文件：向导浮动显示 diff，收起再展开，批准后文件变了；拒绝并附言，模型收到这段话。
3. Agent 用 `ask`：单选加其它、多选、表单各答一次，结果回到模型。
4. 两个窗口开同一会话，一个批准，另一个的向导消失。
5. 服务端在运行中重启：会话显示中断的样子，回车继续。
6. 把对话打开到编辑区页面，文件视图拖到右栏：都能用。
7. Smoke：真实模型跑主创改一个文件，经批准。
