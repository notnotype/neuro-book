# 剧情：作者界面（剧情侧）

## 目标与非目标

作者在工作台里看剧情侧的账：侧栏“剧情”是入口；“谁知道什么”“伏笔账本”“目标表”三张表各是编辑区的一页；人物条目页多出“知道什么”“目标与态度”“经历”三个分页，秘密（知识点）的条目页多出“谁知道”。每一屏按窗口在看的那条线读（[`canon.author-ui`](../canon/author-ui.md) 输出 34），可以换位置、把计划也算上。本能力只定界面；数据的规则在 [`plot.knowledge`](knowledge.md)、[`plot.foreshadowing`](foreshadowing.md)、[`plot.goals`](goals.md)、[`plot.decisions`](decisions.md)、[`plot.checks`](checks.md)。

不承诺：

- 章的工作单（开写前、细纲、写完以后）、底部面板的“决定”、侧栏的“这几章”、状态栏“动笔前 N 件事”、时间线、改设定以后的牵连、作者自定的检查：后续各期再加。
- 剧情表。
- 在这些表里写入：改知情、伏笔、目标从剧情变更的详情页与条目页走（[`canon.author-ui`](../canon/author-ui.md)）。
- 知识点很多时，“谁知道什么”的“选要看的人”的候选只按已经读到的几页算。
- 区分同名的人：两个同名的人在表头写同一个名字。

## 术语与参与者

- **秘密**：保密档为 `secret` 或 `topSecret` 的知识点（[`plot.knowledge`](knowledge.md)）。界面上“秘密”“保密”“绝密”是作者的说法。
- **主要角色**：在所选位置上持有进行或受挫目标的人（[`plot.goals`](goals.md) 输出 1）。
- **程度的写法**：`knows` 写“知道”、`misbelieves`“信错了”、`suspects`“怀疑”、`unaware` 与没有行写“不知道”、`forgot`“忘了”。
- **页头**：三张表与第一批条目页同一种：标题、位置选择、“把计划也算上”，世界有两条以上线时还有线的选择（[`canon.author-ui`](../canon/author-ui.md) 输出 34）。

别的词按 [`canon.author-ui`](../canon/author-ui.md) 的术语。界面文字里不出现记录 id、Component、命名空间、知识点、`程度` 这些词。

## 输出与可观察行为

### 侧栏

1. **剧情视图。** 侧栏视图“剧情”在活动栏有入口，排在“设定”之后。两组：“表”下面是“谁知道什么”“伏笔账本”“目标表”，点了打开对应页面；“剧情线”下面是种类为“剧情线”的条目，按条目树的顺序，写缺省位置上的名字，点了打开它的条目页（`nbook.canon.open-entry`）。没有剧情线时这一组写“还没有剧情线”。窗口没有绑定项目时，视图里只有一句“打开作品后可用”。当前前台是这三页之一时，“表”里对应的一项是选中的样子。

### 三张表的共同行为

2. **页头与面包屑。** 页头见术语；面包屑是“剧情 › 页面名”，点“剧情”显示剧情视图（`nbook.view.open`）。位置选项与缺省同第一批条目页（[`canon.author-ui`](../canon/author-ui.md) 输出 7）。
3. **标签自己的状态。** 位置、“把计划也算上”、分段筛选、选的人、展开与收起，是这个标签自己的状态：切走再回来不变；关掉或刷新以后回到缺省。窗口在看的线不是标签的状态，换线以后三张表按新的线重读。
4. **读取与失败。** 新鲜度、断开与重连同第一批（[`canon.author-ui`](../canon/author-ui.md) 输出 26、27）。剧情插件没有启动、或剧情的读取失败时，页面写“剧情的数据读不出来”与服务给的说明，并有“重试”；`line-not-found` 写“这条线在这个位置读不到”，`chapter-not-found` 按第一批输出 7 回到缺省位置。
5. **名字与链接。** 人、秘密、伏笔、目标、决策、剧情线的名字都是链接，点了打开它的条目页；名字按所选位置读（同第一批）。

### 谁知道什么

6. **行与分组。** 一行一个秘密（`plot.checks` 输出 9 的保密账本），按主体分组：组名“关于某某”，主体是秘密在条目树里的父条目，没有父条目的归“别的”；组按主体在条目树里的顺序，组内按名字。秘密的名字后面写保密档（“保密”“绝密”）。
7. **列。** 秘密；选中的人各一列，格子写程度（文字，不只靠图标），信错了的格子下面写他以为的那句；“别的人”：没选的人里知道、信错了、怀疑的，写名字与程度，没有时写“没有人知道”；“读者”：读者的程度，到怀疑以上时写“第 N 章第 M 段起”；“打算怎么揭”：指向它的揭示计划（“第 N 章明说”“第 N 章暗示”，已兑现的写“已写”）与挂在它上面的决策（已定的写结论，待定的写“还没定”与“第 N 章到期”，到期的用警告色），都没有时写“没有打算”。表头是表头语义，秘密一列在横向滚动时固定。
8. **分段筛选。** “全部”“只有读者知道”（读者到怀疑以上、角色里没人知道或怀疑）、“读者还不知道”（读者不知道）、“没打算怎么揭”（读者还没到知道，而且没有揭示计划与决策），每段写条数；条数按已经读到的行算。
9. **选要看的人。** 表右上角“选要看的人（选中数 / 候选数）”，点了列出候选、可多选。候选是在任何一行里知道、信错了、怀疑的人加上主要角色；缺省选主要角色里按名字的前 3 个，没有主要角色时选在行里出现最多的前 3 个。列按候选的名字排。

### 伏笔账本

10. **行与列。** 一行一个伏笔（`plot.foreshadowing` 输出 8）：名字；“到哪一步”（还没埋、埋了、呼应中、收了一部分、收了）；“上次提到”（“第 N 章”，很久没提的另写“N 章没提”，用警告色）；“接下来”（所选位置之后最早的计划节点，“第 N 章呼应”；没有且没收完写“没有打算”，用警告色）；节点带。没打算怎么收的伏笔，名字下面写“还没打算怎么收”。
11. **节点带。** 只画有节点（写了的或打算写的）的章，按章序，中间跳过的章收成一个省略格；每格写章号与一个字（埋、应、误、部、收），写了的实心、打算写的虚线框；所选位置所在的章有标记。表下有图例。
12. **分段筛选。** “还没收”（缺省）、“很久没提”、“没打算怎么收”（没有计划的回收节点、也没收完）、“全部”，各写条数。

### 目标表

13. **按人分组。** 每个主要角色一组：名字；他的态度，一行一个“对某某：态度”（态度未归纳时写“还没归纳”）；目标一行一个：状态（“进行”“受挫”）、名字、有隐秘时“瞒着别人”、“和这些打架：某某：目标”、“因为：秘密的名字”、右边“第 N 章动过”，按 [`plot.goals`](goals.md) 输出 4 停滞时用警告色写“N 章没动过”。开关“也列达成与放弃的”打开后，这两种另列在后面。
14. **筛选。** 顶上按人筛：“所有主要角色”（缺省）或其中一个人。

### 人物与秘密条目页的分页

15. **知道什么**（`nbook.canon.person` 之外另启用了 `nbook.plot.knowing` 的条目）。两组：“保密的事”列出所有秘密（没有行的写“不知道”），“别的事”只列有行的；每行写程度、秘密的名字、他以为的那句或怎么知道（“当时在场”“听某某说”“读到的”“推断的”）、右边是那一行从哪里来（“第 N 章”“前史”）。按所选位置与窗口的线读。
16. **目标与态度**（启用了 `nbook.plot.attitude` 的条目）。他的目标（同输出 13 的一组，不含态度行）与态度表：对象、态度、起因、称呼。没有目标也没有态度时写“还没有目标与态度”。
17. **经历**（人物，附加分页）。到所选位置为止他在场的剧情变更（`plot.knowledge` 输出 8），按章分段（“前史”“第 N 章”），每条写文字与同时在场的人；末尾写“还有 N 条没记谁在场”（N 为 0 时不写）。一页 50 条，读不完时末尾“再显示更早的”。点一条打开变更详情页。
18. **谁知道**（启用了 `nbook.plot.point` 的条目）。三节：“角色”：有行的人一行一个（名字、程度、怎么知道或他以为的那句、从哪里来），末尾“别的 N 个有名字的人都不知道”；“读者”：程度，到怀疑以上时写从哪一段起与那一段的开头；“和它有关的”：挂在它上面的决策（结论或“还没定”与到期）、以它为答案的伏笔（到哪一步）、起因是它的态度（“某某对某某的态度是从它来的”）、隐秘是它的目标。没有的一节不出。

### 宽度、键盘与文字

19. **宽度。** 三张表与几个分页的内容列封顶。宽度 390 像素时都没有横向滚动：谁知道什么改成一行一个秘密的列表，名字在上，下面一行依次写选中的人的程度；伏笔账本的节点带换到名字下面一行；页头同第一批换行。
20. **键盘与读屏。** 分段筛选用左右方向键切换；表格的行与链接都能用 Tab 到达；“选要看的人”的列表能用键盘多选与关闭。程度、阶段、到期都有文字，不只靠颜色或图标。
21. **界面文字。** 界面文字都经界面文字机制给出（[`ui.i18n`](../ui/i18n.md)）；名字、他以为的那句、剧情变更的文字是作品内容，原样显示。

## 状态与转换

三张表的页面状态同第一批条目页（加载中、正常、断开），另有“读不出来”（输出 4）。

时序与寿命：

- 页面与分页的读取在窗口的读取层里，与 canon 的读取同一代、同一轮换上（[`canon.author-ui`](../canon/author-ui.md) 输出 35）：一页里 canon 读到的名字与剧情读到的行不会一新一旧。
- 窗口在看的线变了以后，前台可见的表与分页按新线重读，重读期间保留旧内容。
- 剧情插件的浏览器入口停止后，三种页面的标签显示编辑器的“这个页面已经不在了”，侧栏视图按声明消失处理，四个分页按第一批的规则消失（[`canon.author-ui`](../canon/author-ui.md) 的“状态与转换”）。

## 副作用与数据

本能力不存自己的数据，也不写世界。开着哪些页面由编辑器记；视图在哪由工作台的布局文档记。

## 失败与恢复

界面自己不产生失败码；剧情读取的失败按输出 4 呈现，canon 读取的失败按 [`canon.author-ui`](../canon/author-ui.md) 的失败表。

## 边界与兼容

- 公开接口：上表的视图、页面、分页与命令的 id。组件的名字与内部状态不是公开接口。
- 界面只经 canon 的读取服务与剧情插件的远程合同读，不直接读世界日志与插件存储。

## 验收与 Smoke

1. **星瑕的秘密。** Given 带剧情数据的星瑕样本，When 打开作品，Then 活动栏有“剧情”；When 点“谁知道什么”，Then 开出页面，“关于星瑕”一组里“哥哥就是星瑕”一行星瑕“知道”、星瑾“不知道”、读者“知道，第 1 章第 9 段起”；When 选“没打算怎么揭”，Then 只剩没有揭示计划与决策的那一行。
2. **伏笔与目标。** When 打开伏笔账本，Then “还没收”有 4 条，没有打算的那条“接下来”写“没有打算”；When 打开目标表，Then 星瑕一组有“瞒着别人”的目标，“和这些打架”里有星瑾的目标。
3. **人物页。** When 打开星瑾的条目页，Then 分页有“知道什么”“目标与态度”“经历”；“知道什么”里“那几年哥哥是被软禁”写“信错了”与她以为的那句；When 换到“第 1 章末尾”，Then “经历”只列到第 1 章。
4. **秘密的条目页。** When 打开“那几年哥哥是被软禁”的条目页，Then 有“谁知道”分页，读者一节写“怀疑”与从哪一段起，“和它有关的”里有到期的决策。
5. **换线。** Given 有回溯分出的第二条线，When 在状态栏换到那条线，Then 谁知道什么、星瑾的“知道什么”按那条线读到的值换上，没有出现加载占位。
6. **窄屏。** Given 宽度 390 像素，Then 三张表与四个分页都没有横向滚动。

Smoke：`bun run --cwd packages/neuro-book test:e2e -- e2e/plot-author.e2e.ts`（生成带剧情数据的星瑕样本，走验收 1 到 4 与 6）。
