# 剧情：作者界面（剧情侧）

## 目标与非目标

作者在工作台里看剧情侧的账：侧栏“剧情”是入口；“谁知道什么”“伏笔账本”“目标表”三张表各是编辑区的一页；人物条目页多出“知道什么”“目标与态度”“经历”，秘密（知识点）的条目页多出“谁知道”。每一屏按窗口在看的那条线读（[`canon.author-ui`](../canon/author-ui.md) 输出 34），可以换位置、按计划读。本能力定界面与给界面用的读取 `nbook.plot/author`；数据的口径在 [`plot.knowledge`](knowledge.md) 输出 11 到 17、[`plot.goals`](goals.md) 输出 6、[`plot.foreshadowing`](foreshadowing.md) 输出 9。

不承诺：

- 章的工作单（开写前、细纲、写完以后）、底部面板的“决定”、侧栏的“这几章”、状态栏“动笔前 N 件事”、时间线、改设定以后的牵连、“再查一项”：后续各期再加。
- 剧情表。
- 打开决策：决策不是条目，这一期在表里只写结论或“还没定”与到期章，不可点。
- 在三张表里写入；专门界面里嵌的通用字段可以改（[`canon.author-ui`](../canon/author-ui.md) 输出 12、16），别的写入从剧情变更的详情页走。
- 分页的顺序：数据分页按条目读取结果里命名空间的顺序，“知道什么”与“目标与态度”的先后随条目启用的先后。
- 没有目标也没有态度的人也有“目标与态度”分页（分页按启用的类型出），里面写“还没有目标与态度”。
- 位置选项随章数增长（1000 章是 2001 项），同第一批。
- 区分同名的人：两个同名的人在表头写同一个名字。

## 术语与参与者

- **秘密**：保密档为 `secret` 或 `topSecret` 的知识点（[`plot.knowledge`](knowledge.md)）。界面上“秘密”“保密”“绝密”是作者的说法。
- **主要角色**：[`plot.goals`](goals.md) 输出 6。
- **人群**：[`plot.knowledge`](knowledge.md) 输出 13。
- **程度的写法**：`knows` 写“知道”、`misbelieves`“信错了”、`suspects`“怀疑”、`forgot`“忘了”、显式的 `unaware`“不知道”；没有行时按人群的规则写“不知道”或“没有记录”。
- **页头**：canon 交的页头（[`canon.author-ui`](../canon/author-ui.md) 输出 35）：标题、位置选择、“按计划”、两条以上线时的线选择。

别的词按 [`canon.author-ui`](../canon/author-ui.md) 的术语。界面文字里不出现记录 id、Component、命名空间、知识点、`程度` 这些词。

## 输入与前置条件

本能力由剧情插件的浏览器入口提供（随窗口启动激活），窗口绑定了项目才有内容；读取经 canon 浏览器入口交的读取服务（[`canon.author-ui`](../canon/author-ui.md) 输出 35），剧情的数据经下面的远程合同读。它登记：

| 种类 | id | 说明 |
|---|---|---|
| 视图 | `nbook.plot.sidebar` | 侧栏，“剧情”，`order: 20`（排在“设定”之后），图标 `i-lucide-git-branch` |
| 页面（[`workbench.editor`](../workbench/editor.md) 输出 33，无参数） | `nbook.plot.secrets` | 谁知道什么，刷新后恢复 |
| 页面 | `nbook.plot.ledger` | 伏笔账本，刷新后恢复 |
| 页面 | `nbook.plot.goals` | 目标表，刷新后恢复 |
| 数据分页（`canon.component-views`） | `nbook.plot.knowing` | “知道什么” |
| 数据分页 | `nbook.plot.attitude` | “目标与态度” |
| 数据分页 | `nbook.plot.point` | “谁知道” |
| 附加分页（`canon.entry-tabs`） | `nbook.plot.experience` | “经历”，`requires: nbook.canon.person` |

命令（域 `plot`，[`workbench.commands`](../workbench/commands.md) 的域词表；都只改这个窗口的布局、不改作品，不暴露给 Agent，Agent 读剧情走 `nbook.plot/world`）：

| 命令 | 参数 | 做什么 |
|---|---|---|
| `nbook.plot.open-secrets` | 无 | 打开或切到“谁知道什么” |
| `nbook.plot.open-ledger` | 无 | 打开或切到“伏笔账本” |
| `nbook.plot.open-goals` | 无 | 打开或切到“目标表” |
| `nbook.plot.show-sidebar` | 无 | 显示侧栏“剧情” |

远程合同 `nbook.plot/author`（项目实例提供，调用方 `browser`）：作者界面用的读取。现有的 `nbook.plot/world`、`nbook.plot/checks` 给写手上下文、检查与 Agent 工具用，口径不同，不变。每个方法用同一份读取输入算出一个页面块要的全部东西；结果都带 `version`、`inputDigest`、实际读的线 `line`（按 [`canon.worldlines`](../canon/worldlines.md) 输出 12 解析）与名字表 `names`（页面要显示或点开的条目 → 同一线、位置、模式上的名字与种类，删了的另标已删除；分页的方法每页只给这一页用到的，调用方把读到的各页合起来用）。读取位置与模式缺省同 `nbook.plot/world`（最新一章末尾、实际模式）。

| 方法 | 输入 | 给出 |
|---|---|---|
| `secrets` | 读取位置、模式、分段、点名的人（至多 12 个）、游标、条数（至多 200） | 保密表的一页、分段条数、候选的人与主要角色（[`plot.knowledge`](knowledge.md) 输出 14） |
| `point` | 知识点、读取位置、模式 | 一个知识点谁知道（同上 输出 15） |
| `person` | 人、读取位置、模式 | 他的知情（同上 输出 16）、目标与态度（[`plot.goals`](goals.md) 输出 6） |
| `goals` | 读取位置、模式、持有者、是否列达成与放弃的、游标、条数 | 作者用的目标表（[`plot.goals`](goals.md) 输出 6） |
| `ledger` | 读取位置、模式、分段、游标、条数 | 作者用的账本（[`plot.foreshadowing`](foreshadowing.md) 输出 9） |
| `experience` | 人、读取位置、模式、游标、条数 | 经历，从新到旧（[`plot.knowledge`](knowledge.md) 输出 17） |
| `plotLines` | 读取位置、模式 | 侧栏的剧情线：这条线的视图里已出场、未删除、种类为“剧情线”的条目，按条目树的顺序（输出 1） |

游标与读取输入的规则同 [`canon.project`](../canon/project.md) 输出 19：读取输入变了，旧游标得到 `cursor-stale`，在算整页之前就判。会变大的子列表有上限，截断后另给总数或截掉的条数：“谁知道”有行的人至多 200、“和它有关的”各列表至多 50（`relatedTotals`）、保密表一行的揭示计划与决策各至多 10（`plansMore`）。整页（连同名字表）超过远程单次预算时减半条数重取，单条也装不下回 `too-large`。人物页的知情行、目标表一组的目标与态度、账本一行的节点没有上限（每项几十字节，到不了预算）。

## 输出与可观察行为

### 侧栏

1. **剧情视图。** 侧栏视图“剧情”在活动栏有入口，排在“设定”之后。两组：“表”下面是“谁知道什么”“伏笔账本”“目标表”，点了打开对应页面；“剧情线”下面是种类为“剧情线”的条目，按条目树的顺序，写缺省位置上的名字，点了打开它的条目页（`nbook.canon.open-entry`）。没有剧情线时这一组写“还没有剧情线”。最后显示出来的那张表在“表”里是选中的样子（同 [`canon.author-ui`](../canon/author-ui.md) 输出 5 的说法）。窗口没有绑定项目时，视图里只有一句“打开作品后可用”。

### 三张表的共同行为

2. **页头与面包屑。** 页头见术语；面包屑是“剧情 › 页面名”，点“剧情”显示剧情视图（`nbook.view.open`）。位置选项与缺省同第一批条目页（[`canon.author-ui`](../canon/author-ui.md) 输出 7）。
3. **标签自己的状态。** 位置、“按计划”、分段筛选、选的人、展开与收起，是这个标签自己的状态：切走再回来不变；关掉或刷新以后回到缺省。窗口在看的线不是标签的状态，换线以后按新线重读。
4. **读取与失败。** 新鲜度、断开与重连同第一批（[`canon.author-ui`](../canon/author-ui.md) 输出 26、27）。剧情的浏览器入口还没交出页面时，按编辑器的页面状态显示；页面已经开着、剧情的读取失败（项目实例里的剧情服务没有就绪、取数出错）时，写“剧情的数据读不出来”与服务给的说明（`not-found` 写“找不到这个条目”），并有“重试”（重读读失败了的那几个）；读到过的页面留着旧内容，失败写在上面。`line-not-found` 写“这条线读不到”。选过的章不在章表里了，页头写“原来选的那一章已经不在了”，按缺省位置读；章表更新之前单次读到 `chapter-not-found` 按普通读取失败写。
5. **名字与链接。** 每行的主名字（秘密、伏笔、目标、人）、宽表表头的人名、侧栏的剧情线、“和它有关的”里的伏笔与目标是链接，点了打开它的条目页；别处出现的名字（“别的人”、同时在场的人、态度的对象等）是文字。名字取读取结果的名字表（同一线、位置、模式；翻过页的把各页的合起来），删了的条目写“已删除的条目”。
6. **宽度。** 内容列封顶 1100 像素。容器宽度不足 640 像素时，表格换成一行一条的列表（只渲染这一种）：主要的名字在上，其余的列依次写在下面。

### 谁知道什么

7. **行与分组。** 一行一个秘密，按主体分组：组名“关于某某”，主体是秘密在条目树里的父条目，没有父条目的归“别的”；顺序按服务给的（主体在条目树里的顺序、再按名字）。秘密的名字后面写保密档（“保密”“绝密”）。一页 200 行，读不完时末尾“再显示（还有 N 项）”；接着读的行并进已有的组。
8. **列。** 秘密；选中的人各一列（表头是名字链接），格子写程度（文字，不只靠图标），信错了的格子下面写他以为的那句；“别的人”：没选的人里知道、信错了、怀疑、忘了的，写名字与程度，多了写“等 N 人”，没有时写“没有人知道”；“读者”：读者在这个位置的程度，到怀疑以上时写“第 N 章第 M 段起”（整书第一次）；“打算怎么揭”：揭示计划（“第 N 章明说”“第 N 章暗示”，已兑现的写“已写”）与决策（已定的写结论，待定的写“还没定”与“第 N 章到期”，到期的用警告色），都没有时写“没有打算”；一行的揭示计划与决策各至多列 10 条，多了写“还有 N 项”。表头是表头语义，行头（秘密）是行头语义，秘密一列与表头在滚动时固定。
9. **分段筛选。** “全部”“只有读者知道”“读者还不知道”“没打算怎么揭”，各写条数（服务给的整张表的数，[`plot.knowledge`](knowledge.md) 输出 14）。
10. **选要看的人。** 表右上角“选要看的人（选中数 / 候选数）”，点了打开多选的弹层，候选来自服务（整张表的）。缺省选主要角色里按名字的前 3 个；没有主要角色时选候选里出现最多的前 3 个。最多选 12 个。

### 伏笔账本

11. **行与列。** 一行一个伏笔（[`plot.foreshadowing`](foreshadowing.md) 输出 9）：名字与重要程度（主线、支线、次要）；“到哪一步”（还没埋、埋了、呼应中、收了一部分、收了；放弃的写“已放弃”）；“上次提到”（“第 N 章”，久没提时另写“N 章没提”，用警告色）；“接下来”（下一步计划，按角色写“第 N 章埋下”“呼应”“误导”“收一部分”“收”；没有且没收完写“没有打算”，用警告色）；节点带。没打算怎么收的伏笔，名字下面写“还没打算怎么收”。
12. **节点带。** 只画有节点（写了的或打算写的）的章，按章序，中间跳过的章收成一个省略格；每格写章号与一个字（埋、应、误、部、收），写了的实心、打算写的虚线框；所选位置所在的章有标记。宽表下面有图例。容器宽度不足 640 像素时节点带换到名字下面一行（窄版不另画图例）。
13. **分段筛选。** “还没收”（缺省）、“很久没提”、“没打算怎么收”、“已放弃”、“全部”，各写条数（服务给的）。

### 目标表

14. **按人分组。** 每个主要角色一组，可以折叠：名字（人或组织）；他的态度，一行一个“对某某：态度”（未归纳时写“还没归纳”）；目标一行一个：状态（“进行”“受挫”）、名字、有隐秘时“瞒着别人”、“和这些打架：某某：目标”、“因为：秘密的名字”、右边“第 N 章动过”（从没动过写“出场以后没动过”），停滞时（[`plot.goals`](goals.md) 输出 4）换成用警告色写的“N 章没动过”。开关“也列达成与放弃的”打开后，这两种接在同一组的进行、受挫目标后面。
15. **筛选。** 顶上按人筛：“所有主要角色”（缺省）或其中一个。已知限制：可选的人取已读到的组（一页 50 组），主要角色多于 50 个时后面的要先“再显示”才能选。选的人在新的位置或线上不再是主要角色时按“所有主要角色”画，标签里记的人不改。

### 人物与秘密条目页的分页

16. **知道什么**（启用了 `nbook.plot.knowing` 的条目）。两组：“保密的事”列出所有秘密（没有行的按术语写），“别的事”只列有行的；每行写程度、秘密的名字、他以为的那句或怎么知道（“当时在场”“听某某说”“读到的”“推断的”）、右边是来处（[`plot.knowledge`](knowledge.md) 输出 11：“最初”“第 N 章第 M 段”“前史”“目标出场时”“从某某线带过来”）。下面一节“字段”是这一页的通用字段（`FieldTable`：知情、听过的说法），可以看来历、可以改。
17. **目标与态度**（启用了 `nbook.plot.attitude` 的条目）。他的目标（同输出 14 的一组，各状态都列）与态度表：对象、态度（未归纳时写“还没归纳”）、起因、称呼；下面一节“字段”是通用字段（态度）。没有目标也没有态度时写“还没有目标与态度”。
18. **经历**（人物，附加分页）。他在场的剧情变更，从新到旧，按章分段（“第 N 章”“前史”）；每条写文字与同时在场的人，“记得原线上的”另带标记；末尾写“还有 N 条没记谁在场”（N 为 0 时不写）。一页 50 条，读不完时末尾“再显示更早的”。点一条打开变更详情页。
19. **谁知道**（启用了 `nbook.plot.point` 的条目）。顶上写保密档。三节：“角色”：有行的人一行一个（名字、程度、怎么知道或他以为的那句、来处），末尾写其余的人数（“别的 N 个人都不知道”或“别的 N 个人没有记录”）；“读者”：在这个位置的程度，到怀疑以上时写整书第一次从哪一段起与那一段的开头；“和它有关的”：挂在它上面的决策（结论或“还没定”与到期，不可点）、只经读者守卫关联的决策、以它为答案的伏笔（到哪一步）、起因是它的态度（“某某对某某的态度是从它来的”）、隐秘是它的目标。列表多了写“还有 N 项”。“角色”与“读者”两节总在；“和它有关的”一项都没有时不出。下面一节“字段”是通用字段（保密、规则、表现、揭穿、读者问题）。

### 规模、键盘与文字

20. **速度**（在 [`canon.project`](../canon/project.md) 输出 14 的参考机器与负载下，1000 章、500 个秘密、200 个人、60 个目标、30 个伏笔的模拟作品）：`nbook.plot/author` 的每个方法，读取输入变了以后的第一次 1 秒以内，同一份读取输入上再读与下一页 100 毫秒以内（项目进程里直接调用，不含远程）。
21. **键盘与读屏。** 分段筛选用左右方向键切换；行里的名字按钮与别的按钮都能用 Tab 到达（行本身不停焦点）；“选要看的人”的弹层能用键盘多选与关闭。程度、阶段、到期都有文字，不只靠颜色或图标。
22. **界面文字。** 界面文字都经界面文字机制给出（[`ui.i18n`](../ui/i18n.md)）；名字、他以为的那句、剧情变更的文字、讲述的开头是作品内容，原样显示。

## 状态与转换

三张表的页面状态同第一批条目页（加载中、正常、断开），另有“读不出来”（输出 4）。

时序与寿命：

- 一个页面块的数据来自一次 `nbook.plot/author` 的读取（同一份读取输入）；页面与分页的读取在窗口的读取层里，与 canon 的读取同一代、同一轮换上（[`canon.author-ui`](../canon/author-ui.md) 输出 35）。不同的块之间可能差一轮，下一轮就对齐。
- 窗口在看的线变了以后，前台可见的表与分页按新线重读，重读期间保留旧内容。
- 剧情插件的浏览器入口停止后，三种页面的标签显示编辑器的“这个页面已经不在了”，侧栏视图按声明消失处理，四个分页按第一批的规则消失（专门界面换回通用字段表，附加分页消失）。

## 副作用与数据

界面不存自己的数据；专门界面里嵌的通用字段的写入同第一批（经世界服务发布成修订）。开着哪些页面由编辑器记；视图在哪由工作台的布局文档记。`nbook.plot/author` 只读。窗口的读取层按调用方插件、方法与输入合并读取；项目实例里按读取视图与参数复用算好的整张结果，请求只做分页、名字表与大小核对。

## 失败与恢复

| 码 | 含义 | 调用方怎么办 |
|---|---|---|
| `line-not-found`、`chapter-not-found`、`cursor-stale`、`too-large`、`stopping` | 同 [`canon.project`](../canon/project.md) | 同左；界面按输出 4 |
| `not-found` | `point`、`person` 指向的条目不存在或不是这一种 | 界面写“找不到” |

## 验收与 Smoke

1. **星瑕的秘密。** Given 带剧情数据的星瑕样本，When 打开作品，Then 活动栏有“剧情”；When 点“谁知道什么”，Then 开出页面，“关于星瑕”一组里“哥哥就是星瑕”一行星瑕“知道”、星瑾“不知道”、读者“知道，第 1 章第 8 段起”；When 选“没打算怎么揭”，Then 只剩没有揭示计划与决策的那几行，条数与分段上写的相同。
2. **伏笔与目标。** When 打开伏笔账本，Then “还没收”不含已回收与已放弃的，“已放弃”里有放弃的那一条，没有打算的那条“接下来”写“没有打算”；When 打开目标表，Then 星瑕一组有“瞒着别人”的目标，“和这些打架”里有星瑾的目标；When 打开“也列达成与放弃的”，Then 多出达成的那一个。
3. **人物页。** When 打开星瑾的条目页，Then 分页有“知道什么”“目标与态度”“经历”；“知道什么”里“那几年哥哥是被软禁”写“信错了”与她以为的那句，忘了的那一行写“忘了”；下面的“字段”里能点“改”；When 换到“第 1 章末尾”，Then “经历”只列到第 1 章。
4. **秘密的条目页。** When 打开“那几年哥哥是被软禁”的条目页，Then 有“谁知道”分页，顶上写“保密”，读者一节写“怀疑”与从哪一段起，“和它有关的”里有到期的决策（不可点）。
5. **换线。** Given 样本里已写的回溯分叉，When 在状态栏点“在看：跟着章”、选那条子线，Then 状态栏写“在看：”加子线的名字，谁知道什么、星瑾的“知道什么”按子线读到的值换上，没有出现加载占位。
6. **宽度。** Given 宽度 390 与 600 像素，Then 三张表与四个分页都没有横向滚动，谁知道什么是一行一个秘密的列表。
