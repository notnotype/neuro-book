# 图像提示词：项、权重与写法

## 目标与非目标

给图像插件一套与后端无关的提示词表示。一段提示词是一串带数值权重的项，这套表示要能做到：
- 读入 NovelAI 与 SD 两种写法；
- 写出 NovelAI 的规范写法；
- 对随机项抽签；
- 按空行把一整段原文切成几段，并保住每个词的实际权重；
- 做只靠语法就能查出的检查。

配方（[`images/recipes`](recipes.md)）、体检与粘贴拆分（`images/checks`）、后端适配器（`images/generation`）与工作台都用它。

不承诺：

- 一个词收没收录、属于哪一类、放没放错节：归 `images/checks` 与 `images/tags`。
- 写成 NovelAI 以外的写法：归各后端的适配器。
- `@{名字}` 解析到哪个片段：归 [`images/recipes`](recipes.md)。
- 词的先后对生成效果的影响。

已知限制：

- **连写的数值权重。**`1.6::甲, -1::乙`（前一个没结束就写下一个）的语义，NovelAI 没有公开。读入时按“后一个替换前一个”处理，并给出诊断 `chained-weight`。
- **权重为 0 的项。**`0::词::` 照样读成权重为 0 的项，是不是等于没写，NovelAI 没有公开。

## 术语与参与者

- **项**：提示词的最小单位，种类见“输入与前置条件”。
- **一段提示词**：有序的一串项。节的内容、角色框的正面与负面、片段的各部分，都是一段提示词。
- **实际权重**：一项最终发给模型时乘上的倍数。
- **原文**：一段提示词从文字读进来时的那段文字。
- **自成一段**：一段文字读完时，没有开着的花括号、方括号或数值权重，开头也不依赖前文开着的权重。
- **规范写法**：本 Spec 写出 NovelAI 文字时唯一的写法（输出 10）。
- **规范化文字**：判断两项是不是同一项时比较的文字（输出 13）。
- **读法**：`novelai` 或 `sd`。
- **诊断**：只靠语法查出的问题，带码、位置，以及能不能一键改。

## 输入与前置条件

一段提示词的数据形状。它写在配方、预设、片段文件与内容快照里，所以本身就是持久格式：

```ts
type Prompt =
  | {items: Item[]; source?: string}   // source：原文，只在输出 12 的条件下保留
  | {raw: string};                     // 拆不开的原文，整段保存（输出 11）

type Item =
  | {kind: "tag"; text: string; weight: number; disabled?: true}
  | {kind: "sentence"; text: string; weight: number; disabled?: true}
  | {kind: "fragment"; ref: string; part?: number; weight: number; off?: string[]; disabled?: true}
  | {kind: "choice"; options: Item[][]; weight: number; disabled?: true}
  | {kind: "text"; text: string; disabled?: true}
  | {kind: string; [field: string]: unknown};   // 不认识的种类，原样保留
```

- `weight` 是有限的数，可以为负，缺省是 1，存的时候总是写出来。
- `fragment` 的字段：
  - `ref` 是片段的 id；
  - `part` 指片段的哪一部分：不写是主提示词那部分，写数字是第几个角色框那部分（从 0 数起）；
  - `off` 是关掉的陪衬词，记它们的规范化文字。
- `choice` 是随机项：
  - 至少两个选项；
  - 每个选项是一串非空的项，里面不再有随机项与图中文字。
- `text` 是图中文字，没有权重。一段提示词里最多一个，而且总在最后。
- `disabled` 表示停用：展开时跳过，写出时照样写。

读入的输入：一段文字加一个可选的读法。没给读法时按输出 9 自动判断。

NovelAI 写法的读入规则：

| 写法 | 含义 |
|---|---|
| `,`、`，`、换行 | 分隔项 |
| `{`、`}` | 给它右边的全部内容乘、除 1.05，不要求配对 |
| `[`、`]` | 给它右边的全部内容除、乘 1.05，不要求配对 |
| `数值::` | 开始一段数值权重，和开着的括号相乘 |
| `::` | 结束数值权重，并把开着的花括号、方括号都清掉 |
| `\|\|甲\|乙\|\|` | 随机项 |
| `Text:` | 图中文字，从这里到全文末尾都算 |
| `@{名字}` | 片段引用，`名字` 是本书里片段的名字 |
| 圆括号 | 普通字符 |

SD 写法的读入规则：

| 写法 | 含义 |
|---|---|
| `(甲)` | 每套一层乘 1.1 |
| `(甲:数值)` | 权重就是这个数值 |
| `[甲]` | 每套一层除以 1.1 |
| `\(`、`\)` | 字面的圆括号 |
| `BREAK`、`<…>`（例如 `<lora:名字:0.8>`） | 照原样读成词，给出诊断 `sd-only` |

## 输出与可观察行为

1. **按 NovelAI 读法读入。**每一项的实际权重，等于它左边全部花括号、方括号的乘除之积，再乘上包住它的数值权重。存的时候保留到小数点后四位。一个逗号段里实际权重中途变了（例如 `beautiful {detailed} eyes`），就在变化的地方切成几项，给出诊断 `split-in-item`；写出时这几项之间按规范写法加逗号。
2. **词与句子。**
   - 按分隔符切开，每一段是一项；空段丢掉，给出诊断 `empty-item`。
   - 一段如果以大写字母开头、至少有三个词，就是一个句子的开头。句子一直延续到 `.`、`!`、`?`、`。`，或者全文末尾，中间的逗号不切。
   - 含中文的一段也读成句子。
   - 其余的读成词。
3. **图中文字。**
   - `Text:`（不分大小写）之后到全文末尾，读成一个 `text` 项，里面的换行与空行都是文字的一部分。
   - `Text:` 前面的内容照常读。
4. **随机项。**`||` 与 `||` 之间按 `|` 分成选项，每个选项照输出 1 到 2 读成一串项。随机项本身的权重，是它所在位置的实际权重。
5. **片段引用。**`@{名字}` 读成一个 `fragment` 项，权重是它所在位置的实际权重。在这一层只记名字，名字换成 id 由调用方做（[`images/recipes`](recipes.md)）。
6. **全角逗号与下划线。**全角逗号当逗号读，给出诊断 `fullwidth-comma`。下划线照原样保留在文字里，给出诊断 `underscore`。
7. **数值权重没有结束。**到全文末尾还开着的数值权重或括号，照 NovelAI 的规则一直作用到末尾，给出诊断 `unclosed-weight`。前一个数值权重没结束就开始下一个，后一个替换前一个，给出诊断 `chained-weight`。
8. **按 SD 读法读入。**照“SD 写法”的表算实际权重，其余同输出 2 到 6。
9. **自动判断读法。**
   - 文字里出现 `(词:数值)` 这种写法，就按 SD 读，其余按 NovelAI 读。
   - 读入的结果里写明用的是哪种读法，调用方可以指定另一种读法重读。
   - 按 NovelAI 读的文字里出现 `(词:数值)` 时，给出诊断 `sd-syntax`。
10. **规范写法。**写出一段提示词时：
    - 项之间用 `, ` 隔开；
    - 实际权重为 1 的项不加包裹；
    - 权重不为 1、相邻且权重相同的几项，合成一段 `数值::甲, 乙::`。数值最多写到小数点后四位，去掉末尾的 0。
    - 句子照原样写；
    - 随机项写成 `||甲|乙||`，选项里照同样的规则写；
    - 片段引用写成 `@{名字}`，名字由调用方给出；
    - 图中文字写在最后，和前面隔一个换行，写成 `Text: 内容`。

    规范写法的结果总是自成一段，也不出现连写的数值权重。
11. **拆不开的随机项。**随机项的选项按输出 4 读不成项时，整段提示词存成 `{raw: 原文}`，给出诊断 `unparsed-choice`。例如选项是半个词，或者选项里带着没结束的权重。`raw` 写出时照原样，不能抽签、不能切段。
12. **原文的保留与写回。**一段文字读进来时，如果它自成一段，就在结果里保留 `source`。之后只要有任何一项改了（增删、改字、改权重、停用、一键改），`source` 就丢掉。写出时，有 `source` 就照原样写出，没有就用规范写法。
13. **规范化文字。**转小写、下划线换成空格、连续的空白合成一个空格、去掉首尾空白。两项的规范化文字相同，就是同一项。
14. **往返不变。**没有 `source` 的一段提示词，按规范写法写出、再按 NovelAI 读法读回来，得到的项、顺序与实际权重都和原来一样。
15. **切段。**把一整段文字按空行切成几段，用于粘贴拆分：
    - 先对全文按读法算出每一项的实际权重，再切。所以一个权重跨了几段时，切开以后每个词的实际权重不变。
    - 图中文字单独作为最后一项，不参与按空行切。
    - 切出来的每一段都是一段提示词。只有当它自己的文字自成一段，而且单独读进来的权重和切出来的一样时，才保留 `source`。
16. **抽签。**
    - 给一段提示词和一个随机源，对每个随机项独立、等概率地选一个选项，得到不含随机项的一串项，以及选了哪几个选项（按随机项出现的顺序记下标）。
    - 同一个随机源给出同样的结果。
    - 选中的选项里每一项的实际权重，是它自己的权重乘上随机项的权重。
17. **检查。**给一段提示词，交回一组诊断。诊断是可序列化的数据：码、位置（第几项，或原文里的字符范围）、能不能一键改。码见“失败与恢复”的诊断表。
18. **一键改。**
    - 对能一键改的诊断：`underscore` 把下划线换成空格；`fullwidth-comma` 与 `empty-item` 改成规范写法。
    - `duplicate` 在两项权重相同时，删掉后出现的那一项。
    - 改完 `source` 丢掉。
19. **不认识的项。**数据里不认识的种类，存回去时原样保留；写出 NovelAI 文字时跳过它，给出诊断 `unwritable-item`。

## 状态与转换

- 读入、写出、切段、抽签、检查、一键改都是纯运算：没有状态，不读写文件，浏览器与服务端都能用，同样的输入总是得到同样的结果（抽签另要同一个随机源）。
- `source` 的寿命：读入时按输出 12 的条件得到，任何改动都让它失效，失效以后不会恢复。

## 副作用与数据

- 没有副作用。
- 数据形状写进别的文件，版本跟着所在文件的格式走（[`images/recipes`](recipes.md)）。
- 存回去时，不认识的字段与项原样保留。
- 权重存的时候保留到小数点后四位。

## 失败与恢复

失败：

| 码 | 含义 | 调用方怎么办 |
|---|---|---|
| `too-long` | 要读入的文字超过 65536 个字符 | 不解析，提示作者分开粘贴 |
| `invalid-prompt` | 数据形状不对：权重不是有限的数、随机项少于两个选项或选项为空、图中文字不在最后或不止一个 | 所在文件按 [`images/recipes`](recipes.md) 的 `invalid-file` 处理 |

除了 `too-long`，读入文字不会失败，问题都以诊断交回。

诊断：

| 码 | 含义 | 能一键改 |
|---|---|---|
| `unclosed-weight` | 到末尾还开着的数值权重或括号 | 否 |
| `chained-weight` | 前一个数值权重没结束就开始下一个 | 否 |
| `empty-item` | 连续的分隔符 | 是 |
| `fullwidth-comma` | 全角逗号 | 是 |
| `underscore` | 词里有下划线 | 是 |
| `duplicate` | 同一段里规范化文字相同的项出现两次 | 两项权重相同时是 |
| `sd-syntax` | 按 NovelAI 读的文字里出现 SD 的 `(词:数值)` | 否（改用 SD 读法重读） |
| `sd-only` | `BREAK`、`<…>` 这类 SD 专用写法 | 否 |
| `unparsed-choice` | 随机项的选项读不成项，整段按原文保存 | 否 |
| `unwritable-item` | 不认识的项，写不成 NovelAI 文字 | 否 |
| `cjk` | 含中文的一段 | 否 |
| `split-in-item` | 一个逗号段里权重中途变了，切成了几项，写出时会多出逗号 | 否 |

## 边界与兼容

- 公开的有两样：数据形状，以及读入、写出、切段、抽签、检查、一键改这几种运算。数据形状是配方、预设、片段文件与快照格式的一部分，Agent 用文件工具读到的就是它。
- NovelAI 对连写数值权重的语义一旦实测清楚，输出 7 的读入规则会随之修改；规范写法不写连写的数值权重，所以写出不受影响。
- 片段引用的写法 `@{名字}` 只用于“原文”这个视图与粘贴；存的时候存 id。

## 验收与 Smoke

1. **跨段的权重。**输入是 `{{a, b` 空一行 `c}}, d`。整体读入后，a、b、c 的实际权重是 1.1025，d 是 1。按空行切成两段，各自写出为 `1.1025::a, b::` 与 `1.1025::c::, d`；两段各自读回，权重不变。
2. **带括号的标签名。**`saber (fate), 1girl` 自动判断为 NovelAI 读法，读成两个词，权重都是 1；同一串指定按 SD 读时，`fate` 读成权重 1.1 的一项，并给出 `split-in-item`。
3. **随机项与图中文字。**`1girl, ||red hair|blue hair||, rain, Text: Hello` 空一行 `World`：读成词、随机项（两个选项）、词、图中文字（含空行）。用同一个随机源抽签两次，结果相同；写出时图中文字在最后。
4. **原文的保留。**读入一段自成一段的原文，不改就写出，与原文逐字相同；改一项的权重再写出，得到规范写法，且按 NovelAI 读法读回来与改后的项一致。
5. **拆不开的随机项。**`||red|blue|| hair` 存成 `raw`，写出与原文相同，并给出 `unparsed-choice`。

Smoke：随实现补；本能力是纯运算，合同测试覆盖全部输出条目。
