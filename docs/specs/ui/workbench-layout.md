# 工作台布局：一棵树

## 目标与非目标

除标题栏外，工作台是一棵布局树：工具视图和编辑组都是树上的面板，活动栏和状态栏是树上的条。骨架固定：`活动栏 | 侧栏 | 编辑区 | 右栏`，面板在编辑区下面（输出 1）。面板在骨架内换位置时，它的内容不重建，并从旧位置滑到新位置。工作台是这棵树的唯一写者，插件只提交意图。

本 Spec 取代了 [ui.workbench-shell](workbench-shell.md) 的外壳一到三与输出 39。标题栏、状态栏的条目、无项目首页、活动栏底部条目、页面浮层与主题变量表（输出 38）留在那里。设计理由见[布局提案](../../proposals/workbench-single-tree-layout.md)与 [ADR 0044](../../adr/0044-workbench-single-layout-tree.md)。

不承诺：

- **操作系统级窗口**：只有应用内浮动（输出 39）；拖出窗口也是应用内浮动，夹回树区域。
- **资源树拖出树外**：文件拖到编辑组的行为见 [workbench.files-explorer](../workbench/files-explorer.md)，这里不变。
- **手机呈现**：窄于 600 时只有这棵树，界面会很挤，放不下按输出 10 降级。
- **条移到四边**：条在树里，位置固定。
- **改变骨架**：面板移到编辑器旁边、工具视图夹在编辑组之间、编辑器标签拆到工具面板旁边、整块拖动面板，都没有入口（开发者 2026-11-06）。编辑器标签想离开编辑区用应用内浮动（输出 39）。
- **面板横跨左右侧栏**这类摆法没有拖动入口。

## 术语与参与者

```text
Workbench（每个窗口一个，nbook.workbench 拥有）
├─ TitleBar ──── 树外，固定在最上面
└─ LayoutDoc（布局文档）
   ├─ tree ───── 文档树：结构、id、ref、两轴尺寸意图
   ├─ panels ─── 面板 id → 角色、名字、标签、活动标签、隐藏、收起
   └─ floats ─── 浮动的面板与矩形，后面的压在前面的上面
```

- **面板**：带标签的组，树的叶子。工具面板（`role: "tool"`）装工具视图，编辑组（`role: "editor"`）装编辑器标签。
- **具名面板**：名叫 `sidebar`、`auxiliarybar`、`panel` 的工具面板。面板 id 等于名字。标题栏开关、命令和视图声明的 `location` 都认这个名字。
- **条**：活动栏、状态栏。固定厚度，不可调、不可收起。
- **骨架**：见输出 1。**侧栏这一列**是 `sidebar` 和与它上下分开的工具面板，**右栏这一列**同理；**面板这一排**是 `panel` 和与它左右分开的工具面板；**编辑区**是全部编辑组。
- **文档树**：用户的布局，会保存。隐藏的面板也在里面。
- **呈现树**：这一刻交给 grid 求解的树，由文档树和呈现事实算出，不保存。隐藏的、放不下被收走的面板不在里面。
- **呈现事实**：实测容器尺寸、最大化、焦点。可能让呈现和文档不同，不写回文档。
- **内容项**：一个视图或一个编辑器标签的内容（没有标签的编辑组也有一个，画空态），和叶外框是同一父元素的子元素，从建到销毁不换父元素（[ui.nested-grid](nested-grid.md) 的“内容层”）。
- **当前面板**：最近获得焦点的面板。焦点移到外壳之外时保持原值。
- **活动编辑组**：工作台记着的 `currentEditor`；编辑器的“活动组”就是它。
- **有效可见**：见输出 17。

## 输入与前置条件

- 触发：打开或刷新窗口、容器尺寸变化、用户操作（拖动边界、面板头按钮、状态栏、命令、活动栏、拖动标签）、插件打开或关闭标签、视图声明变化。
- 输入：记录 `workbench.layout`（可缺失、损坏、版本不支持）；实测的外壳容器尺寸；视图目录；窗口是否绑定项目。
- 前置：工作台浏览器入口已激活。Storage 不可用时按默认树渲染，只是不能保存。

文档的形状（`@notnotype/nb-layout` 导出，校验函数 `validateLayoutDoc` 是唯一权威）：

```ts
interface LayoutDoc {
    version: 1;
    tree: GridSnapshot;                     // 叶的 ref：`panel:<id>` 或 `bar:activitybar`、`bar:statusbar`
    panels: Record<string, PanelRecord>;     // 树里的面板和浮动的面板都在这里
    floats: ReadonlyArray<{panel: string; rect: {x: number; y: number; width: number; height: number}}>;  // CSS px，相对树区域，写入时取整；至多 16 个
    hiddenBars: ReadonlyArray<"activitybar" | "statusbar">;
    currentEditor: string | null;
}
interface PanelRecord {
    role: "tool" | "editor";
    name?: "sidebar" | "auxiliarybar" | "panel";
    tabs: ReadonlyArray<TabRef>;            // 顺序就是显示顺序
    active: string | null;
    hidden?: boolean;                       // 只有具名面板会隐藏
    collapsed?: boolean;
}
type TabRef =
    | {kind: "view"; viewId: string}                  // 工具视图，每个视图只有一个实例
    | {kind: "tab"; type: string; tabId: string};     // 动态标签，例如 type 为 nbook.editor
```

校验：每个面板恰被树引用一次；`TabRef` 全局唯一；`active` 属于 `tabs`；条恰各一个；具名面板名唯一；至少一个编辑组；节点不超过 256 个、深度不超过 16 层；id 不能是 `__proto__`、`constructor` 这类键。

## 输出与可观察行为

### 模型

1. **默认树与骨架**：默认树是 `V[H[活动栏, sidebar, V[编辑组, panel], auxiliarybar], 状态栏]`。第一次生成文档时，有视图的具名面板显示，空的隐藏。任何操作之后树都合这个骨架：状态栏在最下；活动栏、侧栏这一列、中间、右栏这一列从左到右；中间是编辑区在上、面板这一排在下。侧栏与右栏这一列只上下分，面板这一排只左右分，编辑区里只有编辑组、可以任意分。
2. **规范形**：每次结构操作之后，同轴嵌套展平，单子分支塌陷。所以 `(A | B) | C` 只会存成 `H[A, B, C]`。展平前后每个叶的尺寸不变（差不到 1px）。
3. **不变量**：树里至少有一个编辑组，可以是空的。没有名字的工具面板拖空后移除。具名面板拖空或关掉最后一个标签时隐藏，留在树里，它记住的位置就是默认位置。编辑组拖空后移除，最后一个除外。结构操作失败时整批不改，文档保持原样。
4. **视图放哪**：声明 `location` 的视图第一次出现时，加到这个具名面板的标签末尾，面板隐藏着就保持隐藏，直到用户打开。之后它在哪由文档决定。声明消失的视图（插件暂时缺失）留在树上显示占位，写明原因，可以关闭；文档就是所见的样子，别的操作写回时不丢。

### 尺寸

5. **固定尺寸**：标题栏 36px，状态栏 22px，活动栏 48px，都不可调。条两侧的缝宽为 0，其余缝占 1px，命中区向两侧扩展。
6. **约束**（CSS px）：

    | 面板 | 宽 | 高 |
    |---|---|---|
    | `sidebar` | 160 到 560，默认 340 | 至少 80 |
    | `auxiliarybar` | 160 到 max(360, 视口宽 × 0.45)，默认 400 | 至少 80 |
    | `panel` | 至少 160，默认 320 | 至少 80，默认 200 |
    | 其它工具面板 | 至少 160，默认 320 | 至少 80，默认 200 |
    | 编辑组 | 至少 220 | 至少 120 |

    视图声明的最小最大尺寸，面板取所有标签的并（最大的最小值），切标签不改布局。拖过最小或最大值时停在边界，不弹回。
7. **谁吸收余量**：一个子节点按比例分配（`weight`），当且仅当它含编辑组，或它的兄弟都不含编辑组；其余保留像素（`fixed`）。所以侧栏、右栏、面板和编辑区并排时保留宽度，编辑组吸收余量；全是工具面板的一列按比例分，不留白。
8. **尺寸意图**：保存的是 CSS px，只从呈现尺寸写回：手势落账后、结构操作之前各一次。呈现为零的轴和收起的面板不写，那就是展开时的尺寸。全是工具面板的分支里有收起或隐藏的兄弟时，其余的只更新彼此的比例，总量保持原来的份额，所以展开后回到原来的尺寸。测量、夹取、放不下时的压缩、拖动期间都不写文档。
9. **手势**：边界的手势按 [ui.nested-grid](nested-grid.md)：十字交汇同时调两轴、方向键 10px、Shift 1px、Home、End、Enter，一次手势只落账一次；Escape、指针取消、失焦、容器尺寸或结构变化取消整场，不提交。
10. **放不下时只改呈现**：先把工具面板压到最小；还放不下时，按 `auxiliarybar`、`panel`、`sidebar`、其它工具面板的顺序从呈现树里收走，焦点所在的面板最后收；放得下之后，没帮上忙的放回来（窄的时候收走纵向的那块不省宽度）；再放不下才压编辑组。每种降级给诊断，不写文档。窗口变大时自动回来。所有几何非负且在容器内。
11. **面板的几种状态**互不等价：

    | 状态 | 文档 | 呈现 | 怎么回来 |
    |---|---|---|---|
    | 隐藏 | `hidden` | 不在呈现树里，不占空间，也没有缝；内容停放 | “显示”清掉 `hidden` 与 `collapsed`，按意图回来 |
    | 收成标题行 | `collapsed` | 所在分支是纵向时，高度等于面板头；内容停放 | 点标签，或面板头的按钮，或拖开 |
    | 拖到零 | `collapsed` | 所在分支是横向时，宽度为 0，保留 1px 边界；内容停放 | 拉开边界，或活动栏，或“显示” |
    | 被最大化盖住 | 无 | 还在原来的矩形，被盖住；内容停放 | 退出最大化 |
    | 放不下被收走 | 无 | 不在呈现树里；内容停放；有诊断 | 窗口够大时自动回来 |

    “显示”指状态栏按钮、活动栏、命令 `nbook.view.set-part-hidden`。隐藏与收起同时为真时，“显示”把两个都清掉。
    一列的面板全部收成标题行时，标题行排在上面，下面留空；这一列和同一行的编辑区高度不变。
12. **拖过最小尺寸**：工具面板的边界往最小尺寸以下拖，越过 24px 时横向分支里拖到零，纵向分支里收成标题行；边界上的 Enter 是同一个切换。编辑组不可收起。**从零拉回**：用指针拉回时在合法展开区跟随指针（按下边界加累计位移）；按钮、命令与 Enter 恢复意图尺寸。拉回的过程中内容就出现，不等松手：里面的视图没加载过时在拖动中加载，`ViewContext.visible` 跟着拖动中的几何；按着拖回零时内容回到停放。拖动中不写文档，落账时才写。
13. **最大化**：对任意面板，它盖住树除条以外的区域，只在内存，不落盘。其余面板原地不动：矩形不变，内容马上不可交互，过渡结束后隐藏；还原时最大化的面板缩回去露出它们，它们不重新长出来。入口是面板头的按钮和命令，没有拖动手势；期间没有分隔线可拖。隐藏或收起这个面板（包括标签被搬空）、显示被它盖住的面板、结构操作、放不下时退出，刷新不复活。

### 渲染

14. **按矩形摆放**：面板外框、分隔线、内容项、条是同一父元素的子元素（[ui.nested-grid](nested-grid.md) 的“按矩形摆放”“内容层”）。结构变化不重建还在的实例，内容的输入、滚动与焦点保留。三层 Teleport 与滚动焦点记忆都不再需要。
15. **位移**：程序引起的布局变化都有过渡（[ui.nested-grid](nested-grid.md) 的“过渡”）。面板移到别处时外框从旧矩形滑到新矩形；标签并入已有面板时，内容从旧面板滑到新面板，即使两块面板都没动。飞行中的内容压在别的面板上面，不被它们裁切。容器尺寸变化与手势不过渡。系统减少动态效果时直接到终点。
16. **停放与焦点**：内容停放时不可交互，不进读屏与 Tab 顺序，保持最后的非零尺寸，不卸载。焦点所在的内容被停放、或焦点所在的面板头随面板隐藏时，焦点移到同一面板可见的标签；面板不可见时移到活动栏里这个视图的条目（只有侧栏这一列的视图有），都没有时移到外壳根；编辑组移到活动编辑组。焦点在外壳之外（菜单、对话框）时不抢。
17. **有效可见**（`ViewContext.visible`）：在已提交的文档里，面板不隐藏、不收起、不是零尺寸，是活动标签，不被放不下收走，不被最大化盖住；浮动窗的活动标签总算可见，被别的窗盖住、树里的面板最大化时也算。手势预览不改可见性；从零拉回时按拖动中的几何算。第一次有效可见才加载（[workbench.views](../workbench/views.md)）。
18. **Tab 与读屏顺序**：面板内按 DOM 顺序走；走出一块时按树的先后跳到下一块（标签条、内容、下一个面板）。F6、Shift+F6 在面板之间循环。读屏顺序按树序（`aria-owns`）。从外面 Tab 进来时落在树序的首或尾。
19. **外观**：卡片还是平铺由主题决定，变量沿用 [ui.workbench-shell](workbench-shell.md) 输出 38 的那组。缝、圆角、整缝与半缝、活动栏与侧栏相连，都按矩形邻接算：贴着窗体、标题栏或状态栏的一边留整缝，挨着别的面板的一边留半缝；活动栏与相邻且等长的工具面板相连，相连与否按拖动中的几何算。状态栏不是卡片。面板自己不画外框与圆角；面板头与编辑器标签栏不画底线；工具面板的当前标签是下划线加正文色，编辑组的当前标签是与正文同色的一块（[workbench.editor](../workbench/editor.md) 输出 53）。工作台页占满视口，自己不滚动，页面根不预留滚动条位置。悬停线两端的连接按邻接算。工具面板之间的线取 `--shell-pane-divider`，编辑组之间的线贯通整个高度。

### 面板头与活动栏

20. **工具面板的面板头**：32px，顺序是标签带、当前视图的动作、框架按钮（浮动、收起、最大化、隐藏）。视图声明不许浮动或不许移动时没有“浮动”。浮动窗的框架按钮只有“回到停靠”。**只写标题**：侧栏这一列的面板（切视图靠活动栏，输出 22），以及别的工具面板、工具视图的浮动窗只有一个标签时，不画标签带，只写当前视图的标题；按已提交的文档算，拖动中标签数变了头不跟着变。标题是可聚焦的拖动源，可访问名称是视图标题，可访问描述说明“按空格拿起并拖动”；内容不再是 `tabpanel`，是以标题命名的 `region`（标签数变化时跟着变）。点标题激活它，面板收成标题行时展开。只写标题的头没有插入位，拖到头上是添加到最后。活动栏隐藏时侧栏这一列按别的工具面板算，否则切不了视图。框架按钮经命令执行，不可用时禁用并有名称；无名面板没有隐藏按钮。收起按钮只给上下排的面板：横向分支里收起就是拖到零，和隐藏重复，无名面板还找不回来；命令 `nbook.view.set-panel-collapsed` 不变。视图动作与滚动条随鼠标显示的范围是这块面板（[workbench.views](../workbench/views.md) 输出 10、12）。动作透明时也占位，所以按面板宽度算放几个按钮，总给标签带留一个截断的标签加其余标签的图标那么宽，放不下的收进“⋯”。标签带的键盘：方向键、Home、End 切换并跟焦点，Alt 加方向键换一位（活动标签不变），菜单键开“移动到”。标签带放不下时逐级让位，不横向滚动：完整标题，每个标签最宽 96px，选中的保留标题其余只留图标，放不下的收进末尾的“更多 N”。选中的始终带标题。放宽一档要多出 16px 余量。
21. **编辑组的面板头**：和工具面板一样画在外框里：提示条、标签条与标题动作，一到三行（[workbench.editor](../workbench/editor.md) 输出 34、53 到 58）。内容从头下面开始，头高了（标签折行、提示条出现）内容立刻让开，不做过渡。组矮时头先收，正文至少留面包屑、进度条与一行字。面包屑、横幅与控件在内容里。两种标签条是同一个 `TabStrip`（[`TabStrip.md`](../../../packages/nb-layout/src/vue/TabStrip.md)）。
22. **活动栏**：上段只列侧栏这一列的视图，顺序就是这一列的标签顺序（按树序、面板内按标签序）；底段是贡献的全局项（`workbench.activitybar-items`）。视图移到右栏或面板后不在这里，靠那边的标签带切换。点一个视图：不可见时显示它所在的面板、激活它并把焦点给它；可见时隐藏它所在的具名面板，无名面板是收起。条目的按下态等于视图有效可见，所以这一列只有一块面板时至多一项按下。声明消失的视图也有条目（写它的 id），点了能看到占位（输出 4）。放不下时排在后面的收进“更多”，有效可见的总在外面。条目是拖动源，拖它等于拖这个视图的标签（输出 24），右键菜单同标签（输出 23）。活动栏的上段也是落点：工具视图放上去就是放进 `sidebar`（这一列里别的面板的条目不算插入位），插到指针下面第一个 `sidebar` 条目之前，下面没有 `sidebar` 条目时插到最后，落点指示画一条横线，实时布局和别的标签条一样（输出 38）；来源不在 `sidebar` 时同一次写入把它显示出来并激活这个视图，来源就在 `sidebar` 时只换序，不改显隐，也不改活动标签。最大化时不接收。编辑器标签不接收，底段不接收。
23. **移动到**：标签的右键菜单（键盘是菜单键）里有“移动到”：目标是别的工具面板、“新面板（挨着 X）”（X 只能是工具面板，侧栏、右栏这一列放在下面，面板这一排放在右边），视图不在第一次放的具名面板时另有“重置位置”。具名面板写它的名字，无名面板写它活动标签的标题。菜单打开时记下视图、所在面板、交付状态与视图代际，任一变化即关闭，过期点击零写入。经 `nbook.view.move-view` 执行。“新面板”从相邻两块取空间，不跟设置 `dropSplit` 走（输出 27）。

### 拖动

24. **手势**：按 [ui.layout-drag](layout-drag.md)。来源是视图标签、侧栏这一列的标题、活动栏里的视图条目、编辑器标签。树里面板头的空白处不起拖，整块面板不能拖；浮动窗能整窗拖（输出 39）。
25. **落点规则**，先命中的算；按这一刻看到的矩形判（实时布局按拿起时的矩形，输出 38），预览不进输入：

    | | 指针在哪 | 结果 |
    |---|---|---|
    | 0 | 浮动窗（上面的先判） | 标签条是插入位，正文添加为标签；不接收就是被拒绝（输出 39），不穿透到底下 |
    | 1 | 工作台外、标题栏、状态栏、活动栏底段 | 没有落点 |
    | 2 | 活动栏上段 | 插入位（输出 22） |
    | 3 | 缝（离中线 6px 内，最近的缝胜出；只有输出 26 允许的缝） | 放到两块之间：跨这条缝的整个长度，新块只从两边按比例取，别的块不动 |
    | 4 | 标签条 | 插入位。头只写标题的面板没有插入位，等于中央 |
    | 5 | 正文外缘（四角归最近的边） | 这一块往这个方向分（输出 27） |
    | 6 | 正文中央 | 添加为标签；空面板整块都是这个落点 |

    不是落点的缝里，指针归 4px 内最近的能接收的那块，按它继续判；两块都不接收是被拒绝（输出 39）。
    外缘窄带占这一块的 28%，只有输出 26 允许的边才有，别的边的窄带算中央。标了 `data-no-drag` 的按钮区不起拖也不接收；被菜单、对话框挡住的不接收。
26. **接受矩阵**：

    | 被拖的 | 工具面板的标签条、中央 | 工具面板的外缘 | 编辑组的标签条、中央、外缘 | 活动栏上段 |
    |---|---|---|---|---|
    | 工具视图 | 接受 | 侧栏、右栏这一列只有上下；面板这一排只有左右 | 拒绝 | 接受 |
    | 编辑器标签、文件 | 拒绝 | 拒绝 | 接受 | 拒绝 |

    缝只有两边同类才是落点：编辑组之间，同一列或同一排的工具面板之间。活动栏、侧栏、编辑区、右栏之间，编辑区与面板之间都没有缝落点。所以骨架不变（输出 1）：编辑组下面挨着面板时，放到编辑组下缘是分这一组，面板的高度不变；放到侧栏与编辑组之间的缝上，视图归侧栏，编辑器标签归编辑组。限制是去掉落点，不改道。接受矩阵在提交时再验一次。
27. **往一个方向分**（设置 `nbook.workbench/dropSplit`，缺省 `half`，只有用户层）：`half` 只分本窗口，新块取这一块的一半，别的块不动。`shared` 同方向的窗口一起分：这条边和所在分支同方向时，新块占分支里可分配总量的 1/(n+1)，可分配的 n 块按原比例缩，不占份额的（隐藏、收起）和保留像素的（输出 7）不动；不同方向时和 `half` 一样。所以编辑区分屏不分走侧栏、右栏、面板的空间。**移动的单位**：只有一个标签的面板移到外缘时是同一块面板移动，面板 id 不变，内容不重建。具名面板不移动：它只有一个标签时也是拆出新面板，具名面板拖空隐藏，留在骨架上（输出 3）。放回挨着来源那块的边上是原位（输出 28）。移动时面板的收起清掉：放到别的方向，收成标题行会变成零宽。多标签面板的一个标签移到外缘时拆出新面板，继承来源的角色；内容都不重建（编辑器标签见 [workbench.editor](../workbench/editor.md) 输出 49）。从别的面板放进收成标题行的面板时，同一次写入把它展开；面板里自己换序不展开。
28. **放回原处**：结果的结构、顺序、标签集合、活动标签都和现在相同时，什么都不提交，尺寸意图也不动。预览画来源自己所在的位置，提示“原位”。只有一个标签的面板，放到它自己或紧挨着它的那块朝向它的那条边、那条缝，都是原处。
29. （删除，开发者 2026-11-07。）隐藏的、拖到零的面板不是落点，拖动时不浮出任何东西。要放进隐藏的面板用“移动到”（输出 23）；侧栏还可以放到活动栏（输出 22）。
30. **反馈**：拖影是“图标加文字”。指示画真实结果：区域矩形用提交时的同一个函数算，不估算；标签条的插入只画一条线。同区两半切换时高亮连续过渡。放下时高亮立刻消失，不留在原处，也不滑向结果，内容自己滑过去（输出 15）。落点文字走 `aria-live`，只在语义变化时更新。这一条说的是落点指示；实时布局的反馈见输出 38。
31. **键盘**：与指针同一套规则：空格拿起，Tab 在落点区域之间循环（活动栏、工具面板、编辑组、浮动窗，最后是“浮动”：没有指针可以指，无落点要明确选），方向键逐个位置移动（缝也是位置），Enter 放下，Escape 取消，焦点回到拿起时的来源。拿起时停在原位，直接 Enter 不移动。标签、侧栏这一列的标题与活动栏条目是可聚焦的拖动源，可访问描述说明“按空格拿起并拖动”。
32. **结构变化取消**：拿起时记下结构键（树的拓扑、浮动窗的集合、标签集合、来源是否还在），只比已提交的文档。结构变了（插件撤回视图、文件被删关掉标签）整场取消。只是尺寸或滚动变了时按当前位置重算落点；实时布局下容器尺寸变了也整场取消（输出 38）。

### 编辑器的接缝

33. **谁拥有什么**：工作台持有树、面板、标签顺序、活动标签、活动编辑组；编辑器持有地址、编辑器、语言、preview、固定、光标、dirty、文档。编辑器经服务 `editorPanelsKey` 改结构（`PanelTabs`：插入、替换、拿掉、激活、移动、移到外缘；`PanelTree`：活动编辑组、拆一块、右侧相邻），两边靠 `tabId` 对上。preview 替换一次写完。固定分区的插入限制归编辑器，放下时先过它。`"side"` 是活动编辑组右侧相邻的编辑组，只在编辑组里找，工具面板跳过，没有就拆一个。
34. **恢复**：工作台先读文档；文档和 `editor.tabs` 都读完、编辑器入口交付后才渲染编辑组。`editor.tabs` 里没有的 `tabId` 显示原因并可以关闭；文档里没有的 `tabId` 由编辑器丢弃。页面标签不恢复：`editor.tabs` 里留一个记号，恢复时从文档里拿掉。编辑器入口未交付或撤回时编辑组里写着不可用的原因，文档里的标签不动，再次交付后恢复。

### 命令与公开状态

35. **命令**（参数与条件见 [workbench.commands](../workbench/commands.md)）：

    | 命令 | 参数 | 处理 |
    |---|---|---|
    | `nbook.view.set-part-hidden` | `{part, hidden?}`，`part` 是三个具名面板或两条条 | 合并 `set-panel-hidden` |
    | `nbook.view.set-panel-collapsed` | `{panelId?, collapsed?}` | 缺省当前面板 |
    | `nbook.view.toggle-panel-maximized` | `{panelId?}` | 缺省当前面板 |
    | `nbook.view.move-view` | `{viewId, target}`（工具面板 id）或 `{viewId, newPanelNextTo}`（工具面板 id） | 目标改成面板；给编辑组时被接受矩阵拒绝 |
    | `nbook.view.open` | `{viewId?}` | 不变：显示视图所在的面板、激活并聚焦 |
    | `nbook.view.float` | `{panelId?, tab?}` | 把标签浮出来，缺省这块面板的活动标签；不能浮动时 `unavailable` |
    | `nbook.view.dock` | `{panelId?}` | 浮动窗回到停靠；不是浮动窗时 `unavailable` |
    | `set-panel-position`、`set-panel-alignment` | | 删除 |

    当前面板执行时重验，已不存在时返回 `unavailable`。
36. **公开状态**：`layoutReady`、`sidebarVisible`、`auxiliaryBarVisible`、`activityBarVisible`、`panelVisible` 保留，按名字求值：隐藏、拖到零、被最大化盖住、放不下被收走都不算可见，收成标题行算。新增 `hasCurrentPanel`、`nonPhone`（手机呈现之前恒为真）、`maximized`，后两个取代 `nonCompact`、`panelMaximized`。`focusedPart` 取当前面板的名字，没有名字时取 `editor` 或 `tool`。`panelPosition`、`panelAlignment`、`panelHorizontal`、`panelMaximizable` 删除，不留别名。 当前面板浮动时是 `float`。
37. **落点分区**（设置 `nbook.workbench/dropSectors`，缺省开，只有用户层）：拖动经过能接收的面板的正文时，把这块面板能往哪放画出来：编辑组上下左右中五块，侧栏、右栏这一列上下中，面板这一排左右中；进不了中央时没有中央，空面板整块是中央。形状就是输出 25 的判定：指针在哪块，放下就是哪块。正文压暗（不透明度加调暗，不模糊），线与每块的字都显眼；指针所在的那块线更粗、底更深，它自己不写字：输出 28 的提示还在说这次落点（“放到两块之间”“原位”）。放不下字的块不写。指针在编辑组的标签条、活动栏上，或这块面板不接收、被菜单挡住时没有分区；只写标题的头算中央，分区照画。指针在缝上时没有分区。拖动结束即消失。设置关掉时落点不变，只是不画。
38. **实时布局**（设置 `nbook.workbench/dragFeel`：`live` 或 `indicator`，缺省 `live`，只有用户层）：拖动中布局真的变，反馈就是布局本身。键盘拖动、系统减少动效、有面板最大化、容器还没量到时这一场是落点指示；拿起时定一次，整场不变。
    - **判定**：规则同输出 25，文档用已提交的，矩形用拿起时的（进行中的过渡先到终点再量）。容器尺寸变了整场取消：基准没了，也没法从预览里量回来。
    - **预览**：候选连续 150ms 不变才按它摆，邻居真实让位，缓出约 470ms（`--motion-layout`、`--ease-layout`）；来源自己那条标签条、已经吸收它的那条不等。预览过又没有候选了（同样等 150ms）：来源收起，留下的填满它的位置。预览只给渲染：不写记录，不改可见性（输出 17），预览里露出来的、没打开过的视图不加载，没读过的编辑器标签不读文档，都是空白；已提交的文档、活动组、命令都不变。目标组已有同一文件、有未裁决输入时不摆预览（放下的结果和布局层算的不同）。
    - **卡片**：离开标签条就拿起：那个标签的内容离开它的面板跟手，是同一个实例，不重排，上面一条头写图标、标题与落点文字。盖在别的面板与分隔线上，不接指针，抓住的点一直在指针下。从此刻显示着它的那块面板的大小开始缩，缩到 380×260（不大于来源面板）。缩小的时机是设置 `nbook.workbench/dragCardShrink`（只有用户层）：`strip`（缺省）一拿起就缩；`panel` 指针还在来源面板里时是面板原大小，离开才缩。来源面板是这一场拿起时它所在的面板，被别的标签条吸收过也不变。头只写标题的面板没有标签条，一拖就是卡片。拿起的标签没有实例（不活动的工具视图没打开过、编辑器标签没读过）时卡片的内容是空白，同预览。
    - **标签条上**：指针落在任何标签条上（自己的、别人的、活动栏：活动栏是侧栏的标签条），来源就被它吸收：预览是放下的真实结果，卡片收回，只有标签跟手（拖影），它留着位置、看不见，别的标签或条目滑开（`--motion-move`）。该成为活动标签的照样成为活动标签，内容是同一个实例，落进这块面板；原来的活动内容停放。离开标签条重新拿起卡片，预览换走之后目标恢复。别人的标签条、活动栏第一次进去也要等 150ms，路过不变；在吸收它的这条标签条里换位马上预览。摆不出预览（同文件合并、未裁决输入）时卡片留着，卡片头写落点文字。头只写标题的面板没有插入位，算中央。活动栏的条目放不进侧栏的（编辑器标签、有面板最大化）不吸收。侧栏隐藏时放到活动栏，预览同样展开它。
    - **空位**：长出新块的落点（外缘、缝），让出的位置什么都不画，露出窗体底：没有卡片的底与投影，不画头、没有内容。主题要画可以给 `--layout-slot-border`、`--layout-slot-fill`，缺省都透明。头、底和内容放下才有。指针在已显示的空位内（含 8px 边距）候选不变；并入没有空位，也没有粘滞。
    - **并入**（中央）：布局只因来源收起而动，目标的头与活动标签都不变。目标整块盖一层（`--layout-merge-fill` 的底，`--layout-merge-border-width` 宽的 `--layout-merge-border` 内描边），中间写“添加为标签”，跟着目标过渡。收成标题行的目标，盖层就是那一行，放下才展开。
    - **分区**：输出 37 的分区在卡片后面，不压暗、不写字，只留淡线（`--layout-live-sector-line`）。
    - **松手**：提交指针下的候选，不等预览稳定（放回原处不提交）；内容从卡片飞到结果，内容体一次到终点尺寸。**取消**：布局回原样，内容飞回，零写入。
    - **读屏**：落点文字经常驻的 `role="status"` 节点，只在语义变化时更新。
    - **开销**：跟手的东西（卡片、拖影、拖动中的窗）不走渲染。候选不变、预览的过渡与卡片的缩放结束之后，移动中每帧至多一次样式重算、不布局，指针不动一次也没有。判据按帧，不按秒：每秒的次数等于它乘以刷新率。
39. **应用内浮动**：浮动窗是一块不在树里的面板，带标签，工具视图和编辑器标签都能浮动。浮出来、回到树里，内容都不换父元素、不重建。
    - **无落点就浮动**：松手时指针不在任何面板上（输出 25 第 1 行、窗口外），这个东西又允许浮动，就在松手处开一个窗，指针落在头上，大小 460×340（不小于最小尺寸，不大于树区域）；靠边时整个窗夹回树区域，不开到屏幕外。拖动中反馈画这个矩形，提示“浮动打开”；实时布局下来源收起，卡片头写同样的字，松手内容从卡片飞到窗。到 16 个窗之后不再开。
    - **被拒绝**：指针在面板上但放不进去（编辑器标签在工具面板上、工具视图在编辑组上、浮动窗不接收、两块都不接收的缝）：光标是禁止，读屏写“不能放在这里”，松手取消，不开窗（开发者 2026-11-07）。
    - **不浮动**：视图声明 `floatable: false`（[workbench.views](../workbench/views.md)）；指针在 `data-no-drag` 的按钮区；被菜单、对话框挡住；活动栏上段放不进（编辑器标签、有面板最大化）：拖到活动栏是想放进侧栏，放不进不该开窗。这些松手就是取消。Esc 照旧取消。
    - **整窗移动**：拖头的空白处（标签条空白），或只有一个标签的窗的那个标签。多标签时拖标签是撕下，走普通的标签拖动。窗一直跟手，没有拖影，不走实时布局，不写记录，放下写一次。
    - **回到停靠**：拖窗经过别的面板时，只有标签条、缝和 14% 的外缘窄带能停靠，经过中央继续浮着；窗不接收时不穿透。全部标签一起并入。落点按输出 30 画，窗继续跟手。框架按钮“回到停靠”：工具视图各回声明的具名面板，编辑器标签回树序最后一个编辑组。
    - **缩放**：四边四角的手柄，到了最小尺寸（角色与视图声明，同输出 5）、最大尺寸（再加树区域）时对边不动；拖动中不写记录，放下写一次；Esc 取消。
    - **键盘**：右下角手柄与一个聚焦时才露出来的移动把手能聚焦，方向键 10px，Shift 1px，每次写一次。“移动到”与编辑器标签的右键菜单都有“浮动”。F6、Tab 经过浮动窗，排在树之后。
    - **叠放**：后面的压在前面的上面。点击或焦点进入提到最前，已在最前不写。浮动窗在分隔线、最大化的面板之上，在下拉菜单之下。
    - **夹取**：呈现时窗至少留 80px 宽与头的高度在树区域里，夹取不写回：窗口变小再变大，窗回到原处。拖窗从呈现的位置开始。
    - **资源树的文件**：出树后同一份规则与反馈（输出 25、26、30、37），是编辑器标签的来源：外壳根登记落点（`WORKBENCH_FILE_DROP`），资源树的手势在树外问它。不在面板上时一个窗里开多个标签；被拒绝时松手取消，光标归资源树的会话，没有禁止样式（[workbench.files-explorer](../workbench/files-explorer.md)“拖出树”）。
    - **不可**：最大化、收起（命令 `unavailable`），隐藏只有具名面板。树里至少一个编辑组：最后一个组的标签都浮出来，它留着、是空的。浮动的编辑组空了移除，活动组换到树序最后一个编辑组。

## 状态与转换

| 层级 | 内容 | 记录与分区 |
|---|---|---|
| 布局 | `LayoutDoc` | `workbench.layout`：绑定项目时 project / local，否则 user / local |
| 新项目的初始布局 | 去掉动态标签的 `LayoutDoc` | `workbench.layout-template`：user / local |
| 编辑器标签 | `tabId` → 地址、编辑器、语言、preview、固定、光标 | `editor.tabs`：project / local，未绑定只在内存 |
| 只在内存 | 最大化、放不下被收走、拖动预览、当前面板 | 不保存 |

| 初始状态 | 事件 | 下一状态 | 拒绝条件 |
|---|---|---|---|
| 记录未读完 | 打开外壳 | 默认树显示，尺寸手势与依赖就绪的命令不可用 | 无 |
| 无记录 | 读取完成 | 有模板用模板，没有用默认树 | 无 |
| 记录损坏或版本不支持 | 读取完成 | 默认树加诊断，原件保留，普通保存不覆盖 | 不做部分恢复 |
| 记录或模板合法但不合骨架（2026-11-06 以前存的） | 读取完成 | 记录不合：默认树，不读模板，外壳根写一条诊断，下次保存覆盖它；模板不合：当作没有模板。第一次保存也会清掉 `editor.tabs` 里已经不在文档里的标签，开着的标签不恢复 | 不做部分恢复 |
| 恢复尺寸越界 | 读取完成 | 呈现时夹取到最小或最大值并诊断 | 不改写记录 |
| 已恢复 | 结构操作、手势结束、打开、关闭、切标签 | 整棵文档提交，确认后更新已确认值 | 同值不保存 |
| 另一窗口保存了同一记录 | 收到订阅 | 只更新已确认值，本窗口显示不被强改 | 无 |
| 保存冲突 | 条件保存被拒 | 重读 revision，用本窗口的文档覆盖，不合并 | 再失败时保留显示，提供重试与放弃 |

时序与寿命：

- 文档变了或呈现事实变了，呈现树才重算；算出的结果和上一次相同时不重建。重建会取消进行中的边界手势（[ui.nested-grid](nested-grid.md)），所以容器尺寸连续变化时只有被收走的集合变了才重建。
- 外层过渡中，叶里嵌的内容尺寸逐帧变化。视图不要把过渡中的尺寸当事实记下来；最终尺寸在过渡结束后稳定。
- 放下后内容的飞行由文档变化触发，提交是同步的；飞行中开始新的手势，飞行直接到终点。
- 一次打开先写 `editor.tabs`，它确认后再写 `workbench.layout`；前者失败后者不写。崩在两次之间只多一条无主的标签项，恢复时丢弃，不会出现引用不存在的标签。属性变化（光标、固定）随时写，删除只在布局存盘前一起写：标签关掉到布局落盘之间刷新，不会把已经关掉的标签恢复成占位。布局记录被保护或读不了时不删。
- `tabId` 是随机不透明串，跨窗口不撞；`editor.tabs` 按键合并，`change` 在最新值上重放。
- 结构键变了时，进行中的拖动在下一次判定前取消；已经开始的飞行照常结束。

## 副作用与数据

- 只写上表的三条记录，都显式取 1MiB 上限。16 组、每组 200 标签时 `workbench.layout` 约 250KB。打开、关闭、切标签合并着写（至多 150 毫秒一次，只合并一连串的动作：等得再久，刚打开标签就刷新时这个标签就丢了）；手势结束立刻写。
- **未绑定项目的窗口**：`editor.tabs` 不落盘，所以 `workbench.layout` 存盘前去掉动态标签，只留工具面板与空编辑组。
- **行为变化**：工具视图的摆放从跨项目共享变成每个项目一份。新项目的初始布局取模板，没有就用默认树。
- **切换**：都是新 key，旧的 `layout-sizes-side`、`layout-sizes-panel`、`views-customizations`、`editor.session` 不读、不写、不删。首次启动用默认树，已有用户的布局、尺寸和打开的标签丢一次。回到旧版本读到的是升级前的旧记录，新版本里的调整不会带回去。
- 多窗口整棵树后写胜出，不做按节点合并。
- 视图只发出结构化意图；视图自己的状态由所属插件保存。

## 失败与恢复

结构操作失败时返回 `{ok: false, code}`，文档不变；不合骨架的结果在提交前被拒绝（`rejected`），不管来自哪个入口：

| 码 | 含义 | 调用方怎么办 |
|---|---|---|
| `not-found` | 面板或标签已不存在 | 命令返回 `unavailable`（目标面板或视图中途不在了是 `stale-target`）；拖动整场取消 |
| `rejected` | 接受矩阵拒绝 | 没有落点，不提交 |
| `limit-exceeded` | 超过 256 节点或 16 层 | 给诊断，不提交 |

- 记录损坏、版本不支持：回落默认树并诊断，不阻塞外壳打开；原件保留。
- 保存失败（写入失败、结果未知）：当前显示保留，状态栏“布局未保存”给出原因与重试、放弃；放弃回到已确认值，开着的编辑器标签不算在内（关掉的不回来，开着的留着，它们背后是打开的文档）。`editor.tabs` 保存失败同样显示，不自动重试，点重试才再试。
- 呈现降级：只影响当前呈现，诊断写在外壳根上，不保存。
- 视图加载失败、入口停止：按 [workbench.views](../workbench/views.md)，不拖垮外壳。
- Escape、指针取消、失去捕获、失焦、页面隐藏或目标失效：结束拖放并清除反馈，不提交。

## 边界与兼容

- **归属**：`nbook.workbench`。树、尺寸求解、落点规则、内容层是 `@notnotype/nb-layout` 的能力，接受矩阵、约束、默认树由工作台经策略对象给。
- **公开合同**：命令与公开状态（输出 35、36）、`ViewContext`、贡献点是对插件与 Agent 的合同。`location` 的含义变成“第一次放到哪个具名面板”；`ViewContext.location` 类型加 `null`。删除的命令与状态键不留别名，写进 SDK 作者文档。记录字段是内部合同，靠版本演进。
- **贡献点**：`workbench.editor-area` 给一个区级组件（关闭询问、标签的拖动；属性 `attachTabDrag`）、每个编辑器标签一个的内容组件（属性 `panelId`、`tabId`、`context`；空的编辑组也有一个，`tabId` 是 null；标签换组时不重建，`panelId` 跟着变）与可选的头（属性 `panelId`；不给时没有头，内容占满）；动态标签类型只给内置插件，不进 SDK。
- **标记**：`data-editor-group`、`data-editor-group-active` 在编辑组此刻显示的内容项的根上（每组一个），头的根写 `data-editor-group-head`、`data-editor-group-head-active`。标签写 `data-panel-tab`（标签键，工具视图与编辑器标签都是），标签条那一行写 `data-panel-strip`（面板 id）；`data-no-drag-start` 只是不起拖（标签上的关闭按钮），拖动经过时还算标签条。具名面板的叶 id 就是名字，`[data-leaf="sidebar"]` 可用。内容项的根带 `data-content`（它的 key）与 `data-content-leaf`（所属叶 id）。
- **窄屏**：`390 × 844` 无页面级横向滚动，关键按钮可达；不保证好用。
- **Lab**：外壳的 Lab 场景用局部状态，不读写产品布局记录。

## 验收与 Smoke

1. Given `侧栏(视图 A | 视图 B) | (编辑器 A.md | 编辑器 B.md) | 右栏(视图 C | 视图 D)`，When 把视图 A 拖到右栏里 C、D 之间并放下，Then 过渡中 A 的内容矩形严格在旧矩形与新矩形之间，与外框的差值恒为面板头高度，不被编辑组裁切；结束后实例不变（创建 1 次、卸载 0 次），输入、滚动保留；侧栏只剩 B，占满整列。When 改放到 C 的标签条，Then 两块面板都不动，A 的内容仍从侧栏滑到右栏。
2. Given 编辑区 `H[A, B, C]`，When 把编辑器标签放到 B、C 之间的缝，Then 新块只从 B、C 取，A 不动；When 放到 B 的右缘，Then 只分 B，A、C 不动；When 设置 `shared` 再放到 B 的右缘，Then 新块占四分之一，A、B、C 按原比例缩。Given 编辑区 `H[V[A, B], C]`，When 放到 B 的右缘，Then 拆 B，新块只有 B 那么高；When 放到 `V` 与 C 之间的缝，Then 新块整高。Given 侧栏这一列 `V[A, B, C]`，When 把视图放到 B、C 之间的缝，Then A 不动。Given `V[e1, e2, panel]` 与设置 `shared`，When 放到 e1 的上缘或 e2 的下缘，Then 只在 e1、e2 里分，面板的高度不变。
3. Given 只有一个标签的面板紧贴在目标的那条边上，When 拖到这条边放下，Then 预览画来源自己、提示“原位”，什么都不提交；比例是非整数时意图也不变。
4. Given 全是工具面板的一列，When 视图放进去或拖走到只剩一个，Then 不留白，占满整列。Given 隐藏的面板在分支的首、中、尾，或相邻两个，或挨着条，When 读缝，Then 可见的两块之间恰好一条可拖的缝，拖它只改这两块。
5. Given 面板，When 分别隐藏、收成标题行、拖到零、最大化，Then 按输出 11 互不等价；同值操作不写入；最大化不写盘，刷新不复活。Given 几块面板，When 最大化其中一块再还原，Then 过程中别的面板矩形不变，不重新长出来，内容实例不变。
6. Given 窗口从 1440 缩到 700 再放大，When 读呈现，Then 按输出 10 的顺序压缩、收走、压编辑组，有诊断，文档不变；放大后回到原样。
7. Given 视图里有输入与滚动，编辑组里有正文，When 移动、隐藏、最大化、放不下收走再回来，Then 实例不变，输入、滚动与焦点保留；焦点所在内容被停放时焦点按输出 16 移走；外部菜单或对话框的焦点不被抢。
8. Given 右栏隐藏，When 把视图拖到它原来的位置，Then 那里是编辑组，没有落点、光标是禁止；When 用“移动到”选右栏，Then 右栏显示并接收。
9. Given 视图标签，When 只用键盘拿起、Tab、方向键、Enter，Then 结果与指针相同；Escape 不改任何东西，焦点回到来源；拿起后直接 Enter 不移动。
10. Given 编辑器标签与工具视图，When 互相拖到对方的标签条、中央与外缘，Then 都没有落点，松手不改任何东西。Given 编辑组下面是面板，When 把编辑器标签放到编辑组的下缘，Then 拆这一组，面板的高度不变。Given 侧栏，When 把视图放到它的左右窄带，Then 添加为标签；放到上下窄带，Then 上下拆。Given 面板，When 放到它的上缘，Then 添加为标签；放到左右窄带，Then 左右拆。Given 面板头的空白处，When 按住拖动，Then 不起拖。Given 侧栏与编辑组之间的缝，When 放视图，Then 归侧栏；放编辑器标签，Then 归编辑组。Given 收成标题行的无名面板，When 把它的标题放到面板这一排的外缘，Then 展开，不是零宽。
11. Given 同一客户端的两个窗口，When 各改布局，Then 后保存的整棵胜出；另一窗口显示不被强改。Given 两个窗口各开一个标签，When 都刷新，Then 都没有占位。
12. Given 记录被写成损坏内容与不支持的版本，When 打开外壳，Then 回落默认树并诊断，原件不变；旧记录 `views-customizations` 等原样保留。Given 未绑定项目的窗口开着标签，When 刷新，Then 没有坏标签。Given `editor.tabs` 保存失败，Then `workbench.layout` 不写，状态栏显示“布局未保存”。
13. Given `editor.tabs` 缺一个 `tabId`、编辑器入口未交付、视图声明消失，When 打开工作台，Then 各自显示占位与原因，可以关闭，再次交付后恢复。
14. Given 活动栏，When 读条目，Then 只有侧栏这一列的视图；把视图移到右栏后它不在活动栏，移回来又在。When 视图分别不可见、可见时点它，Then 分别显示并聚焦、隐藏；条目放不下时收进“更多”，有效可见的在外面。When 把条目拖到右栏，Then 和拖它的标签相同。When 把右栏的视图放到活动栏，Then 它进了侧栏并成为当前视图，内容从右栏滑过去；侧栏隐藏着时同一次写入显示出来。When 拖条目换序，Then 顺序变了，显隐不变。When 把编辑器标签放到活动栏，Then 没有落点。When 拖一个没激活的条目换序或放回原处，Then 活动标签不变。Given 活动栏隐藏、侧栏有两个视图，When 读侧栏的头，Then 有标签带。Given 右栏只有一个视图，When 读它的头，Then 只写标题；When 再放进一个，Then 放下后变成标签带。Given 侧栏收成标题行，When 点标题，Then 展开。
15. Given 标签带，When 窗口从 1920 收窄到 860，Then 依次经过完整、截断、只留图标、“更多 N”四档，选中的始终带标题。Given 标签的右键菜单打开，When 视图被命令移走，Then 菜单关闭，旧点击零写入。
16. Given 1440×900 的产品页（nbook、macos 各明暗两态），When 读计算样式与截图，Then 卡片的缝、圆角与相连按输出 19，移动面板之后仍成立。
17. Given 四主题 × 明暗的 Lab 外壳场景，When 截图，Then 外壳颜色等于 token 的解析值，结构边界只有一个绘制者；直接打开 `/lab` 的窗口不打开、不订阅产品布局记录。
18. Given 390×844，When 打开产品页，Then 无页面级横向溢出，活动栏与框架按钮可达，编辑组取得非负余量。
19. Given 10 万字章节开着，When 相邻面板让位，Then 记录单帧耗时（无头环境不设门槛）。
20. Given 记录里存着合法但不合骨架的文档（面板在编辑组旁边），When 打开工作台，Then 显示默认树，没有“布局未读”，外壳根有诊断；下一次改动覆盖这条记录。Given 没有记录、模板不合骨架，When 打开工作台，Then 显示默认树。
21. Given 编辑组、侧栏与面板都显示，When 拖工具视图或编辑器标签经过它们的正文，Then 分区的块数符合输出 37，指针靠哪条边那块就是当前块，在任意位置放下的结果都是当前块说的那个；键盘停在正文的落点上同样有分区；设置关掉时没有分区，放下的结果不变；指针在缝上时没有分区。
22. Given 实时布局，When 把视图拖到面板这一排的右边，Then 拖动中面板真的变窄、卡片跟手、记录零写入，松手一次写入、结果就是预览的样子；候选还没预览就松手，提交指针下的候选；Escape 布局回原样、零写入；拿起的内容是同一个实例，输入与滚动都在；键盘、减少动效、设置关时是落点指示。Given 编辑器标签拆到新组，When 预览，Then 新块没有头，编辑器的组模型不变，放下才有头。Given 视图拖到别的面板中央，When 预览，Then 目标的头与活动标签不变，盖层在，拿起的内容是同一个节点；放下才变。Given 视图拖到别的面板的标签条或活动栏上，When 预览，Then 卡片收回，来源在这条标签条里留着位置、看不见，结果就是放下的样子，内容是同一个节点，记录零写入；离开卡片回来，目标恢复。Given 长出新块，When 预览，Then 让出的位置没有卡片的底、投影与边框。
23. Given 工具视图拖到状态栏，When 松手，Then 开一个窗，内容是同一个节点，写一次，刷新后还在原处；声明不许浮动的、按钮区上的、Esc 都不开窗、不写。Given 工具视图拖到编辑组上，When 悬停，Then 光标是禁止；When 松手，Then 不开窗、不写。Given 窗，When 拖它的头经过面板中央，Then 窗跟手、没有过渡、不写，放下写一次；到标签条、14% 窄带才停靠，内容还是同一个节点。Given 窗口变小，Then 窗夹回来、标签条抓得到，变回来还在原处。Given 编辑器标签拖到工具面板上，When 松手，Then 不开窗、不写；When 拖到状态栏再松手，Then 开一个窗，能接着输入、撤销还在；整窗停靠时目标组已有同一文件就并掉，固定标签进固定区，有未裁决输入时不动。

## 实现合同

- **公开入口**：`@notnotype/nb-layout`（`layout-doc`、`layout-drop`、`layout-project`）与 `./vue`（`NestedGrid`）；工作台的 `web/state/layout-doc-store.ts`（store）、`web/components/WorkbenchSurface.vue`（表面）、`web/layout-drag.ts`（拖动）；服务键 `editorPanelsKey`（`workbench/shared/contracts.ts`）。
- **owner 与依赖方向**：`nbook.workbench` 是树的唯一写者。`nb-layout` 不知道角色与骨架的含义，规则经 `LayoutPolicy` 由 `web/state/layout-constraints.ts` 给。编辑器只经 `editorPanelsKey` 改结构。
- **骨架靠三处守住**：落点只给合骨架的目标（`layoutEdgeTarget`）；具名面板不移动（`moveTabToEdge`）；store 的 `apply` 出口过 `fitsSkeleton`。`default-tree.test.ts` 的随机操作性质测试钉住。
- **文档只在内存里有一份**：打开时从记录读一次，之后记录只管存，别的窗口保存不改本窗口的显示。
- **内容项不换父元素**：这是内容不重建、滚动不丢的唯一保证（[ui.nested-grid](nested-grid.md) 的“内容层”）。
