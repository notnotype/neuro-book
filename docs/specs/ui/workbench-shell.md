# Workbench 外壳接入

> 2026-09-22 拖拽需求已获开发者批准并进入实现，规格状态仍为 `planned`，不由 Tasker 自行晋升。Editor 合同保持不变；Workbench 内容区前后各 50%、Switcher 单 View 建容器、空成员清理、半区比例与全收起剩余区域已接入模型及宿主，验证证据以关联 Task 的最新实施记录为准。

## 目标与非目标

**目标**：主应用外壳按 Part、ViewContainer、Switcher、View 分层；容器单轴编排、视图动作按可见数量呈现、拖放与保存复用统一模型。保留既有业务入口与业务数据权威，不因容器移动、合并、模式切换销毁视图实例。

**非目标**：

- 不迁移 `files` / `characters` / `plot` 等消费者——逐个切换 descriptor 属后续阶段；
- 不删除未完成消费者迁移的固定入口或旧组件；Storage 首批已迁字段按迁移合同退出旧写者；
- 不改变 Project、Session、文件、History、Job 的数据 authority；
- 不做第三方可执行插件（L3）、跨窗口浮动与状态栏换位；
- 不建立第二套 resize 边界或第二套布局存储；
- 不覆盖 Workbench 的后续能力（注册表对外开放、内置插件注册路径、命令与只读描述快照桥接）——它们各自另有可独立验收的 Spec。

## 术语与参与者

- **Part**：工作台的大区域（标题栏、图标栏、主侧栏、右侧栏、编辑器区、面板、状态栏），拥有区域级几何与可见性。
- **图标栏（活动栏）**：图标入口条；图标项分两类——容器切换项与命令项。
- **视图容器（ViewContainer）**：组织工具视图归属、顺序与尺寸的单位；一个容器对应一个 Switcher 入口，其全部可见 View 同屏。实际成员数为 0 时移除容器及入口；成员仅隐藏或暂时不可见不构成空容器。
- **容器切换器（Switcher）**：按容器选择导航，主侧栏由 Activity Bar 承担；面板与右侧栏始终显示容器标签带，可与内容不在同一 DOM 子树。
- **视图**：一项能力的描述与内容面板，由 descriptor 描述（稳定标识、标题 key、图标、`layout: scroll | fill`、可见性条件、所需 authority、容器归属、顺序与工厂键）；描述与内容分离，注册表不持组件。
- **现有固定槽位**：今天主页面写死的入口区域与入口实现（写死的图标栏列表、左右栏模板、编辑器区模板、面板与状态栏）。
- **主题宿主**：按 [theme.system](../theme/system.md) 发布产品与 nb-ui 变量的宿主；浮层复用现有 portal 能力，主题已可从 html 继承。
- **布局快照**：版本化的布局恢复数据；Project 尺寸与 user 视图定制分别寻址和版本化，不是一个用户级整桶。
- **宿主**：持有注册表、布局读写与主题的调用方（主应用外壳根）；视图只消费渲染模型、只发出结构化意图。
- **参与者**：用户（操作外壳、容器与视图）；外壳宿主（渲染、持久化、诊断）；descriptor 注册表（描述来源）；可序列化拆分树原语与唯一 resize 边界（几何）。

### Editor 与 Workbench 的容器层级

| 对象 | 定义 | 标签与内容的关系 | 分屏单位 |
|---|---|---|---|
| EditorWorkbench | Editor Part 内的整个编辑工作区 | 同时承载一个或多个 EditorGroup | 编辑组 |
| EditorGroup（编辑组） | 有独立文档标签栏、活动文档与内容区的编辑窗格 | 组内多个文档 Tab，内容区显示当前选中文档 | 边缘拖入会创建另一个编辑组 |
| Editor Tab（文档标签） | 某文档在一个编辑组中的打开实例 | 一个 Tab 对应一份文档视图；同文档可在不同组打开并共享正文 | Tab 本身不是工具视图容器 |
| Part（工作台区域） | 主侧栏、辅助侧栏、Panel 等外层区域 | 承载容器切换器及当前容器；Editor Part 另承载 EditorWorkbench | 区域级尺寸独立于内部 View 尺寸 |
| Switcher（容器切换器） | 在某个工具区域内选择容器的导航 | 主侧栏的容器图标项位于 ActivityBar；辅助侧栏与 Panel 用 Tab 栏 | Switcher 不直接持有 View 正文 |
| Switcher Tab／ActivityBar 容器项 | 一个 ViewContainer 的入口 | 一个入口对应整个容器，不对应某一个文档 | 拖动它携带容器全部成员 |
| ViewContainer（视图容器） | 一组工具 View 的共同归属和单轴布局 | 同一 Tab 下多个可见 View 同屏分栏 | 边缘并入只拆分命中的 View 窗格，归属仍为同一个容器 |
| View 与 View 窗格 | View 是完整工具视图；窗格是它在容器中占用的矩形 | View 标题是拖动手柄，不是另一种 View；正文内部拖文件、选文字仍归该 View 自己处理 | 一个可见 View 占一个窗格 |
| 布局分支 | 描述窗格或编辑组如何分割空间 | 不产生额外的业务容器、Tab 或工具标题 | 只表达几何关系 |

```text
WorkbenchShellLayout：外层 Part 布局
├─ Editor Part
│  └─ EditorWorkbench
│     ├─ EditorGroup G1：文档 Tab A、B、C → 当前选中文档
│     └─ EditorGroup G2：文档 Tab D、E → 当前选中文档
└─ 主侧栏／辅助侧栏／Panel Part
   ├─ Switcher：容器入口 X、Y（主侧栏入口在 ActivityBar）
   └─ 当前 ViewContainer X
      ├─ View A 窗格
      ├─ View B 窗格
      └─ View C 窗格（可见成员同时显示）
```

`WorkbenchShellLayout` 只管理外层 Part 的几何与受控手势；容器导航、View 归属与移动由工作台宿主持有。容器标题文字／工具按钮区与 Switcher 的条目带是不同落点；前者不接收投递，后者接收容器插入。文中“销毁空容器”指移除空的布局容器及导航入口，不表示删除 View 定义、文档或业务数据。

## 输入与前置条件

- 触发方式：打开或重新进入主应用页面、打开或切换 Project、窗口尺寸变化，以及用户操作（点击图标栏、收起侧栏、拖拽 sash、拖动视图、切换面板）。
- 输入：descriptor 注册表（视图与容器的标识、标题、图标、`layout`、可见性条件、所需 authority、归属与顺序、工厂键）；当前工作面的布局快照（可缺失、可损坏、可来自旧版本）；主题（浅色 / 深色 / 自定义配色）与主题宿主的存在性；窗口尺寸（桌面宽度与窄屏 `390 × 844`）。
- 前置状态：外壳根已挂载主题宿主；Project 是否打开只影响视图动作的可用性，不阻塞外壳渲染。
- 权限：无。外壳自身不读写领域数据，不直接触碰 Project 文件、Session、History 或 Job。

## 输出与可观察行为

- 外壳渲染出与接入前**等价的布局**：区域的种类、顺序与相对位置不退化，不出现双重边框、双重标题条或双重标签条。
- 图标栏：上半只列**当前实际位于主侧栏的容器**，最多一项选中；点击非活动项切换该位置显示的容器并使其可见；重复点击当前项保持选择并显式打开被隐藏或拖收起的主侧栏（不切换成 null）。底部账号/设置等命令保留且不参与容器选中；未接入的视图命令禁用并给出原因（不渲染假业务）。
- 侧栏与面板：主侧栏、右侧栏与面板可收起；收起后图标栏仍在，重新点击可展开；图标栏、编辑器区与状态栏不可收起。
- 拖到零保留1px恢复边界与展开尺寸意图。pointer展开使用原始按下边界加累计位移，在合法展开区跟随鼠标；按钮、菜单与Enter恢复记忆尺寸。Escape取消整场，无变化不提交。
- 容器可见成员为0/1/多时分别为empty/single/multiple；hidden不计数，collapsed仍计数。single隐藏重复View标题，动作上提容器右上角，不单独收起View；已有collapsed意图保留到multiple重新应用。multiple每个View保留标题和动作，主/右侧栏vertical、Panel horizontal，与Panel外壳位置无关；全部可见成员同屏。horizontal收起为32px竖条，vertical为32px横标题，展开控件与名称始终可达。主侧栏single时，32px标题行左侧显示当前容器名，整行除动作区外可拖走该容器；multiple不渲染容器标题行。Panel与右栏继续用标签。
- 编辑器区：**逐组**标签条 + 内容区；多组（分屏）由同一棵布局树渲染，组可分裂、移动、关闭，同文档可在两个组各有一个视图实例（共用一份正文权威）。
- 活动栏与主体：活动栏是主体左侧的**通高列**；主体（左右侧栏、编辑区、面板）永远在它右侧，任何面板位置/对齐都不得跨过活动栏。
- 状态栏固定22px、不可收起。Panel支持四位置与四水平跨度，默认bottom+center；justify不跨Activity Bar。Panel高80..600（默认200）、侧向宽160..600（默认320）；左右侧栏最小宽160，Editor最小120。两轴记忆独立，默认值、max、800px紧凑阈值不因新下限改变。
- 面板四种「消失」形态互不等价：**拖到零**（保留节点与展开意图、内容 0px、相邻 1px 保留边界、偏好位 `dragCollapsedParts`）、**32px 标题头收起**（叶仍在树里、编辑实例不重挂，只对水平位置有效）、**隐藏**（整个面板零占用，状态栏「显示面板」同时清除隐藏与收起）、**瞬时最大化**（只在左右位置或水平居中可用；占满编辑区所在列，侧栏、活动栏、标题栏、状态栏保留，编辑器内容停放而非卸载；不落盘，换位置/对齐/隐藏/收起、换工作面或进入紧凑呈现即清除）。
- 容器宽 < 800 时按实际**容器宽**（不是 window 宽）进入紧凑呈现：活动栏仍是主体左侧通高列，其余主体叶纵向排布、面板强制底部两端对齐（不覆盖保存偏好）、没有可拖边界、位置/对齐/最大化不可用并给出原因；返回宽屏恢复偏好。
- 尺寸装不下时只改呈现：宽度轴进入紧凑呈现；高度轴先把面板退到 32px 标题头，仍不足时编辑器取非负余量并给出诊断。所有几何保持非负且在容器内。
- 工具区域拖放按下方“Workbench 拖拽行为表”执行：View 标题搬单个 View，容器入口搬整容器；Switcher 统一解释为容器插入位，内容区沿目标轴前后各 50% 接收。实际成员数归零的容器自动移除；非法方向禁投且无落点反馈。
- 状态栏：显示真实工作面 / Project 名、活动文档保存态、活动组序号 / 总组数、活动编辑器名、可见视图与容器计数，并提供底部面板显隐按钮；只读项不可点击，不显示假 Git / 行列号 / 通知计数。
- 动作顺序为single的View贡献→容器管理→Part框架；multiple的View动作在各自标题。复用 `{viewId,generation}`、命令、busy/authority/when执行门禁；切模式、容器、首View或代际立即关旧菜单，过期点击拒绝。框架动作在空Part仍可达，业务内部标签不升级为工作台View。
- **现有入口全部可用**：文件树、角色、情节、设置、Agent 面板与侧栏、历史、World Engine 等今天的固定入口保持可打开、可切换、可关闭，行为与外壳接入前一致（阶段 1 不迁移它们的实现）。
- **主题跟随**：外壳与其浮层的颜色来自主题宿主发布的变量；在非 sepia 的浅色与深色主题下都不出现 `:root` 兜底底色。
- 布局恢复：主动调整与用户定制按各自记录保存；重新进入时恢复并按当前尺寸约束夹取。程序重算和临时可见性变化不保存。

### EditorWorkbench 拖拽行为表

本表保留已对齐的 Editor 行为，不把 Workbench 的工具容器规则套到文档标签上。Editor 的正文中央目前不创建 Tab；文档移入现有组必须落到该组标签栏。

| 拖动源 | 落点 | 释放动作 | 几何与反馈 |
|---|---|---|---|
| 文档 Tab | 本组标签栏插入位 | 调整标签顺序；固定／普通分区沿用各自规则 | 一条插入线，编辑组尺寸不变 |
| 文档 Tab | 另一组标签栏插入位 | 移入该编辑组，成为其中的 Tab | 不创建新编辑组；源空组按下条收口 |
| 文档 Tab | 目标组正文上／下／左／右 | 创建新编辑组并移动文档 Tab | 新组取得原目标组一半的尺寸意图，预览对应半区 |
| 文档 Tab | 任一组正文中央 | 不移动、不创建 Tab、不分屏 | 整区“保持当前布局”反馈可见，释放无写入 |
| 本组唯一文档 Tab | 自己组的正文四边 | 拒绝无意义的分屏移动 | 不承诺有效分屏落点 |
| 文档 Tab | 原位插入位 | 不提交移动 | 原位插入线仍可见 |
| 最后一个 Tab 被移出／关闭 | 源编辑组 | 多组时收掉空组；最后一个组保留欢迎页 | 不删除文档数据；关闭仍遵守未保存保护 |

工具栏“分屏打开同一文档”属于复制视图：来源组保留标签，新的编辑组引用同一正文。它与拖动 Tab 的移动语义不同。四向分屏以命中的编辑组为范围，不以整个 EditorWorkbench 为范围。

### Workbench 拖拽行为表

| 拖动源 | 落点 | 释放动作 | 容器与尺寸结果 |
|---|---|---|---|
| 单个 View（从其标题起拖） | Switcher 的 Tab 插入位，包括已有 Tab 上求得的插入位 | 创建一个 ViewContainer 并将该 View 移入，在插入位出现新 Tab | 不并入悬停 Tab 的容器；源容器若实际成员归零则移除 |
| 容器 Tab／ActivityBar 容器项 | 同一个 Switcher 的插入位 | 整个容器换序 | View 归属和内部排列不变；原位不提交 |
| 容器 Tab／ActivityBar 容器项 | 另一 Switcher 的插入位 | 整个容器迁移至目标区域并选中 | 沿目标区域的轴排列，保持成员顺序 |
| 单个 View | 目标内容窗格允许的边缘 | 移入目标容器并拆分命中窗格 | 视为 n=1 的边缘并入；不增加目标 Tab |
| 含 n 个 View 的容器 | 另一容器中某个内容窗格允许的边缘 | 原子并入全部成员，保持来源成员顺序 | 命中窗格保留一半；另一半按来源比例分给拖入 View；源空容器及 Tab 移除 |
| 单个 View／容器 | 被禁用的方向 | 不接受 drop，不改变状态 | 无落点 Indicator、无“保持布局”提示；指针拖影仍可显示 |
| 单个 View | 空 Switcher 内容区或空 Tab 栏 | 创建容器并移入 View，出现且选中第一个 Tab | 单个 View 填满内容区 |
| 整个容器 | 空 Switcher 内容区或空 Tab 栏 | 搬入并选中该容器 | 不额外套一层容器，按目标轴排列 |
| 任意内部拖动源 | 容器标题文字、工具按钮区或外部遮挡区域 | 不接收投递 | 不显示有效落点反馈 |

View 标题只说明起拖手柄，表中所有“单个 View”都指同一种移动对象。只有一个可见 View 时沿用省略重复 View 标题的呈现；主侧栏从显示容器名的标题行搬动这个单成员容器，Panel 与右栏从容器 Tab 搬动。ActivityBar 的账号、设置等命令项不属于容器 Switcher，不参与上述插入位计算。

### 方向、命中与反馈范围

| 目标 | 可提交方向 | 中央行为 | 边缘预览范围 |
|---|---|---|---|
| EditorGroup 正文 | 上／下／左／右 | 保持布局，整区反馈，不提交 | 命中编辑组的对应一半 |
| 主侧栏／辅助侧栏的 View 窗格 | 上／下 | 禁投，无落点 Indicator | 命中 View 的上半／下半 |
| Panel 的 View 窗格 | 左／右 | 展开窗格没有中央禁投区，中点归右半 | 命中展开 View 的左半／右半；全部收成细条时覆盖细条后的剩余内容区 |
| 无任何 Tab 的 Switcher 内容区 | 整区一个落点 | 属于空态接收，不属于非空中央落点 | 整个空内容区 |
| Switcher 的 Tab 栏／ActivityBar 容器条目带 | 前／后插入位 | 无内容分屏语义 | 只有插入线 |

“五方向”是通用的方向词汇，不表示 Workbench 每处开放五个动作。目标区域固定内部单轴：侧栏禁左右、Panel 禁上下，非空中央都禁投；Panel 外壳停靠到左／右侧不改变它内部的横向排列。容器从 Panel 移到侧栏时自动横转纵，反向移动自动纵转横；不引入嵌套工具容器。

边缘**命中带**与半区**反馈范围**在 Workbench 展开内容窗格上重合：每个目标窗格前／后各 50%，中点归后半，没有中央禁投区；Indicator 覆盖对应 50%。容器内可见 View 全部收成细条时，细条不再提供半区：落点是细条之后、内容盒之内没被细条占用的连续区域，反馈覆盖整块区域，拖入 View 在这块区域展开，原有 View 保持收起。Editor 仍按其四边 20% 命中规则显示半区，中央显示整区保持布局。反馈层的边缘留白不改变语义上的 50%。指针在同一展开内容区前后两半之间移动时，半区 Indicator 连续过渡。

### 半区分配与来源比例

拆分范围是鼠标命中的 **View 窗格**，不是整个 ViewContainer；“并入目标容器”规定归属，不意味着把目标容器所有成员重新均分。以下比例表示可分配内容空间的尺寸意图，实际像素继续服从分隔线和已有最小／最大尺寸约束。
- 容器内可见 View 全部收起时，不把 32px 细条当作被拆分的窗格，也不放大细条去吸收剩余空间。剩余内容区作为一个落点：拖入成员在这块区域展开，原有 View 保持收起。

- 命中窗格原份额为 S：原 View 保留 S/2，拖入成员合计取得 S/2，其它目标成员的尺寸意图不因这次局部分屏重置。此规则只用于**跨容器**边缘并入。
- 拖入可见成员的来源相对份额为 r₁…rₙ：每项取得 `(S/2) × rᵢ / Σr`；保留顺序，不将不等比例重置成均分。
- 同一目标区域中，结果是同一容器内直接可操作的同层 View；不产生包着新成员的第二层 Tab 或容器标题。
- 跨轴边缘并入时，来源相对比例用于目标轴上的新增半区分配，不把旧像素宽度直接当作新像素高度。
- 可测量来源使用释放时当前轴几何；未活动容器使用保存的当前轴展开意图。隐藏成员随归属迁移但不占当前可见分配，收起位及另一轴意图保留。
- 同一容器内把一个 View 拖到另一个 View 的允许边缘时，只改变成员顺序：来源与命中 View 交换相对位置，容器内每个 View 的尺寸意图保持不变。来源已经紧贴目标侧时是原位，不提交。整容器跨区域移动保留两轴各自记忆，不把源轴像素写到目标轴。

例：纵向容器内 A、B、C、D 原本各占 25%，把另一容器的 E、F 拖到 D 下侧：

| View | 原占比 | E:F 原为 1:1 | E:F 原为 3:1 |
|---|---|---|---|
| A | 25% | 25% | 25% |
| B | 25% | 25% | 25% |
| C | 25% | 25% | 25% |
| D | 25% | 12.5% | 12.5% |
| E | — | 6.25% | 9.375% |
| F | — | 6.25% | 3.125% |

同一容器内 A、B、C 原本各占 100，且顺序为 A | B | C：把 C 拖到 A 左侧得到 C | A | B，把 C 拖到 A 右侧得到 A | C | B。三次的尺寸都仍是各 100；C 本来紧贴 A 右侧时，再拖到 A 右侧不提交。

### 拖影与落点反馈

| 场景 | 跟随指针的 Drag Preview | 目标位置的 DropIndicator |
|---|---|---|
| 容器 Tab 与 ActivityBar 容器项起拖 | 同一种“图标＋文字”拖影，长标题可截断但完整名称可达 | 随当前合法落点显示 |
| Switcher 插入／换序 | 保留上述唯一拖影 | 仅一条插入线；不加拖放专用 Tab 高亮，不加底部横线 |
| Workbench 有效边缘 | 保留拖影 | 命中 View 对应半区；不叠加插入线。同区前后两半切换时矩形连续过渡 |
| Workbench 非法方向 | 保留拖影 | 无区域、无线、无落点提示 |
| 空 Switcher | 保留拖影 | 内容显示“将视图拖动到此处显示”，整区一个落点；Tab 栏使用插入反馈 |

Switcher 的正常选中样式与拖放高亮不同：本规则删除拖放额外高亮，不要求清除已选 Tab 的正常选中态。空区域不再显示“这里没有容器：把容器拖到上方标题栏，或用菜单恢复默认落点”；保留真正的 Switcher 条目带作为第二个接收入口，普通标题／工具按钮区仍禁投。

### 浏览器标题栏

- 无桌面 bridge 的浏览器同样渲染自绘标题栏；桌面专有窗口控制、退出应用和缩放入口按平台能力显示。
- 应用菜单动作由宿主提供实际能力与 enabled 状态；未接入的视图或演示占位不算可用功能。
  编辑动作针对真实焦点/编辑器，不能以某个编辑器的 undo 代替所有输入框的撤销。
- 项目可在本标签或新标签打开。本标签遵守现有领域未保存守卫及 Storage 收口；新标签不改变原工作面，独立完成 Project 就绪。
- 菜单不被外壳裁剪，支持 Escape、键盘导航、outside 关闭及焦点归还；窄屏提供紧凑呈现。
- 标题栏几何由产品同一来源驱动模型与 CSS；主题不另行改变几何。搜索与统一命令系统尚未实现，不以可操作的假入口呈现。

## 状态与转换

布局状态分四类，外加一类排除项：

| 层级 | 内容 | 作用域与键 |
|---|---|---|
| 布局尺寸 | 主工作台左右尺寸与面板高度/宽度 | project/local；未开项目和用户资产使用显式 user/local 记录。面板两轴在 `workbench.layout/panel-size`（同一 schema 的可选 `height`/`width`），左右宽度仍合成在布局记录的叶字段上 |
| 布局定制 | 容器位置/顺序/选择、View位置、width/height/collapsed、抑制、显式隐藏及Panel状态 | user/local `workbench.views/customizations`，schemaVersion 1可选扩展；`useWorkbenchViewPlacements`唯一写者，最大化和降级仅内存 |
| 编辑器会话 | 分组拓扑（grid 快照）+ 逐组标签实例 + 活动组 | project/local `workbench.editor/session`；用户资产工作面走同 owner 的 `user-assets-session`；一条记录原子保存，不按组拆键 |
| 编辑器正文 | 打开的标签的正文与磁盘基线 | 沿用既有标签页会话键（`novel.ide.session`，sessionStorage）：刷新草稿记忆，不是布局 |
| 视图自身 | 展开项、筛选等视图内 UI 状态 | 按视图声明的 `stateScope: user \| project` 提供默认记忆归属；插件的其它状态可独立声明 |
| 内存态 | 当前焦点、临时展开态、Dialog 开关 | 组件或模块内存状态，生命周期结束即释放；不是 Storage scope |
| （排除）领域数据 | Project 文件、Session、Job、Trace | 各自 authority，不进任何布局快照 |

状态转换：

Config 与 Storage 的归属、有效 Project 上下文及插件消费边界按 [Storage 架构规范](../storage/boundaries.md) 区分。
持久化、并发、切换与首批迁移按 [storage.persistence](../storage/persistence.md)，未承诺 Storage 跨独立 data 同步。

| 初始状态 | 事件 | 下一状态 | 拒绝条件 |
|---|---|---|---|
| 无快照 | 打开外壳 | 默认布局 | 无 |
| 已恢复布局 | 用户定制 / 尺寸调整结束 | 提交明确改变的记录字段，确认后更新已保存值 | 目标非法、布局只是测量或临时夹取 → 不产生保存 |
| 快照版本不符或结构/身份不可靠 | 打开外壳 | 默认布局 + 诊断，保留原记录 | 不做部分恢复，不开放普通覆盖 |
| 快照引用未知容器或视图 | 打开外壳 | 丢弃该条覆盖 + 诊断，其余照常恢复 | 不整树回默认 |
| 恢复尺寸越界 | 打开外壳 | 夹取到该叶的最小/最大值 + 诊断 | 不拒绝整个快照 |

- 容器选择归工作台宿主，单个容器内不引入活动 View 权威。显隐、换轴、single/multiple 切换不得销毁仍有成员的容器或重挂 View；仅实际成员数归零才移除空容器与入口。
- 同一次拖拽手势的内存预览以最新值为准，正常结束后提交一次保存意图；收起/展开与容器切换幂等。
- 一次边缘并入同时接纳成员归属、顺序、尺寸分配、目标选择与源空容器清理；任一成员不可移动、来源变化或命中窗格失效则整组拒绝，不逐个移动留下半状态。整容器携带全部成员，含隐藏／收起成员，不因当前不可见而遗漏或删除。
- 空容器判定使用实际归属成员数：最后一个 View 被单独移出与整个容器被并入，都适用同一清理规则。保留隐藏或条件暂不可见的成员及其容器；恢复默认落位不得制造一个没有成员的空 Tab，也不把已移动 View 无条件拉回。
- 指针和键盘使用同一落点判定：空格拿起、方向键沿目标轴、Tab切换目标区域、Enter放下、Escape取消；工作面/成员/轴/活动内容变化取消，失去锚点不能降级为append。结束载荷清空但保留该次拖动的点击抑制。
- 非空 left 的整个 header（当前容器标题、空白与动作区）不接受投递，标题仅保留整容器拖动源；容器切换与接收归活动栏。非空 Panel/right 的带落点只覆盖 selector，外侧动作区不接收。两类来源共用拖动激活、命中、会话、预览和提交路径，按来源保留移动 View、移动容器与整组并入的语义差别。
- 空 Switcher 指该区域没有任何容器 Tab，不等同于当前容器无可见 View。空 Switcher 保留条目带接收能力，内容区显示“将视图拖动到此处显示”并登记整区落点；两处均接收单个 View 或整个容器。取消或被拒绝不得先留下空容器／新 Tab。目标自身后代不算外部遮挡。
- Editor 与 Workbench 共用 nb-ui 的拖影与落点反馈皮肤，动作语义各自拥有。区域反馈只用于有效分屏、空态接收或全收起后的剩余内容区，内容区不叠加插线；展开内容区前后各 50%，中点归后半。Switcher 只画插入线，不叠加条目高亮或底部横线；源拖影与有效区域提示须可读且不拦截指针。坐标变化不重复播报，结束后清除反馈和观察器。
- Editor 的标签排序、跨组移动与四边分屏共用独立 dnd-kit 会话；仅发原有 move/transfer/split 意图，宿主仍是编辑会话与Grid的唯一写者。标签列表用公共 `resolveListInsertion` 统一间隙及末尾锚点，一个插入位只画一条线。其他场景后续接入遵守 [nb-ui拖放反馈规范](../../../packages/nb-ui/docs/ui-development-spec.md#拖放反馈dropindicator--dropindicatorlabel--dropfeedbackoverlay)，不另造样式。
- Workbench 每个宿主提供唯一 Custom DragOverlay，容器 Tab 与 ActivityBar 容器项统一显示图标和文字；源 View 标题、容器标签及活动条目保持可见、矩形与不透明度不变，不插 placeholder、不实时重排。两类源共用 Switcher 插入位，首尾插线留 4px；容器原位插入仍显示线但不提交。
- Editor源Tab保持可见且布局不动，使用Custom DragOverlay，不插占位；默认多行，固定/普通各自独立换行且有可见模式切换按钮，显式单行固定区拒绝拖入。固定区不铺灰底，图钉为独立可访问的取消固定按钮。正文中央整区高亮但释放无操作，跨组移动走标签栏。原位落点仍显示插线但不提交移动；插线首尾留4px、内部12px槽居中。区域/居中提示首次淡入，连续换区复用单节点并平滑改变位置/尺寸，命中与提交即时更新；插线不动画，取消立即清除，减少动效时取消过渡。

## 副作用与数据

- 持久化：宿主按工作面写 Project 尺寸或显式 User 布局记录；不写领域数据，不新增第二套尺寸持久化。
- 既有键：主左右尺寸和书架模式按 [首批迁移合同](../../../packages/neuro-book/docs/migrations/storage-state.md) 迁移；
  `novel.ide.session` 与其它旧字段不整桶退役，同一逻辑数据只有一个写者。
- 尺寸提交：所有尺寸仍经现有唯一 resize 边界提交，原语只做夹取与传播；不新开第二套拖拽实现。
- 视图副作用：视图只发出结构化意图；写入、dirty、save/discard、Session、Job 与 Project 文件仍归原 authority。
- 网络与文件：视图与布局原语通过宿主意图和 Storage 适配器访问状态，不直接写文件或领域数据。
- View尺寸仅记录主动变化的当前轴正有限CSS px（≤1_000_000），部分补丁逐字段合成，保留另一轴/collapsed/未知字段；重复View或非法条目整批拒绝，空补丁不创建记录。sourceLocation与contextKey防换Part后旧轴迟到提交，不写0、补偿值、降级值或single填满值。
- descriptor双轴minimumSize/maximumSize可选；有效主轴min为max(33,声明值或64)，max低于有效min注册失败；默认意图240×正有效weight（否则1）。跨轴填满；尺寸像素不直接跨轴拷贝，边缘并入的来源比例按“半区分配与来源比例”计算目标轴的新份额。
- 记录维持 schemaVersion 1，可选 `customContainers` 表保存 `{originViewId, location, order}`，缺字段保持原有静态目录。未知 id／字段与失效覆盖原件继续保留；坏已知字段按不可用记录保护。本次不执行数据迁移。
- 单 View 拖到 Switcher 由会话生成一次稳定 `custom:<UUID>` 身份；创建、归属、顺序、目标选择和源空容器清理同次保存。CAS 重放复用该身份，刷新后按记录恢复；自建容器实际搬空时清除其布局记录，静态注册定义保留但无入口。边缘并入的目标轴尺寸同次写入，独立 resize 仍只保存主动变化叶。

## 失败与恢复

- 布局快照损坏、版本不符或根结构非法：回落默认布局并给出诊断，不阻塞外壳打开；诊断逐条可枚举，不静默吞掉。
- 回落默认、夹取尺寸或过滤未知引用只影响当前呈现；持久化原件的保留与版本兼容遵守 [Storage 架构规范](../storage/boundaries.md)，不能因恢复失败触发自动覆盖。
- 快照引用未知容器、未知视图或非法尺寸：丢弃对应条目（或夹取尺寸）并逐条给出 issue，其余布局照常恢复。
- descriptor 或工厂失败：以**视图级 issue** 呈现该视图的错误与重试入口，不遮蔽其它视图、不拖垮外壳。
- 上下文不可用（Project 未打开、authority 缺失）：视图仍可见，动作不可执行并给出原因；可见性不等于权限。
- 目标切换后到达的迟到异步结果：标记为 superseded，不覆盖当前目标、不触发全局错误屏；目标切换本身失败表达为「当前目标无数据」，不沿用上一目标的数据。
- 主题宿主缺失或未挂载：不阻塞外壳渲染，但必须在诊断中可见，不得把兜底变量当作主题静默通过。
- CAS结果由实际composition回执裁定，不在保存后重演历史并按最后entity掩盖冲突。请求已保存但丢应答时用内存字段后置条件确认，不重复合并；后置条件保留原有冲突诊断，空写集不当成成功。
- 未确认传输失败保留pending并可retry/abandon；确认冲突为终态拒绝，持续显示诊断直到dismiss或下一次明确操作，不能被底层saved回执吞掉。独立意图已保存的不回滚，新入队意图不被旧回执清除。
- 新容器创建、成员迁移或半区尺寸计算失败时，保留原归属与布局，不留空 Tab、不丢 View。Workbench 中央或非法方向释放不生成保存意图；Escape、pointercancel、窗口失焦、页面隐藏或目标失效都结束当前拖放并清除反馈，不提交旧预览。

## 边界与兼容

- 归属：主应用 UI 层（owner `ui`）；嵌套与调整结束等原语合同由 [ui.nested-grid](nested-grid.md) 提供，本能力负责消费接线。
- 公开接口：本能力不承诺对外 API；descriptor 形状、布局键名与恢复规则属内部合同，升级走版本化快照。
- 主题与浮层接入沿用 theme.system 和 nb-ui 现有 portal 通道，不新增第二套主题或浮层接入通道。
- 兼容：未迁消费者的固定槽位和旧组件继续保留；逐项满足入口闭环、行为等价证据、生命周期安全、owner 迁移及单 Editor Group 不变后才能删除。
  已迁主题与 Storage 不为了旧槽位维持第二个 authority。
- 既有验收不回退：nb-ui 组件与布局原语的合同测试、验证台的交互验收继续有效，不因外壳接入放宽。
- 窄屏：窄屏（`390 × 844`）与桌面共享同一模型；窄屏下不产生页面级横向滚动。

## 验收与 Smoke

1. Given 接入前的当前主页面，When 打开接入外壳后的页面，Then 区域种类、顺序与相对位置等价（标题栏 / 图标栏 / 主侧栏 / 编辑器区 / 右侧栏 / 面板 / 状态栏），无双重边框、双重标题条或双重标签条。
2. Given 现有固定入口清单（文件树、角色、情节、设置、Agent 面板与侧栏、历史、World Engine 等），When 逐项打开、切换、关闭，Then 行为与接入前一致，且没有入口被移除或降级为占位。
3. Given 浅色主题与深色主题（各含一次自定义主题），When 对照外壳与其中打开浮层的截图，Then 颜色来自主题宿主发布的变量，深色下无 sepia 兜底底色。
4. Given 活动栏与侧栏，When 点击容器或恢复隐藏/拖收起Part，Then 容器选择互斥且能打开；显式恢复保记忆，pointer恢复在可行区贴鼠标，不用记忆尺寸断言冒充跟随证明。
5. Given 尺寸拖拽，When 拖过该叶的最小/最大值，Then 尺寸停在夹取边界且不弹回；When 随后重新进入页面，Then 布局从快照恢复。
6. Given 快照被注入版本不符、未知容器引用与非法尺寸，When 打开外壳，Then 逐条给出诊断并按规则回落/丢弃，不出现空白外壳或未捕获异常。
7. Given 桌面宽度与 `390 × 844` 窄屏，When 完成核心操作（切换容器、收起展开、打开现有入口、切换主题），Then 操作可完成且无页面级横向滚动。

## 实现合同

- **几何一律 CSS px**：`Splitter` 受控 props 为 `sizesPx`（合计 = 面板空间，不含 sash）；面板配置 `{defaultSizePx,minSizePx,maxSizePx,sizing,collapse}`；百分比往返与逐分支百分比事件已退役。
- **一次手势一份会话**：一个公开 `GridRenderer` 独占一份 `useSashGesture` scope，一次按下命中的最多两根轴属于同一场手势；拖动中发布预览布局，松手把一次 `GridGestureCommit` 交给宿主的 `onGestureCommit`，由宿主 `grid.resizeBranches(changes)` 一次原子落账（任一项不通过则整批不改）。
- **零值绝不进入尺寸记录**：拖收起那一刻只写布尔偏好位；尺寸意图保持展开值。
- **多记录非原子**：一次交汇的补丁可同时含侧栏宽度与面板两轴，会话先整份校验、再一次性呈现，然后按记录分项写入，回执 `{status, records:{widths,panel}}`；某项失败不回滚另一项，重试只补未确认项。
- **保存只认直接主动的叶**：left/right 宽度与 panel 两轴进记录，编辑器与嵌套分支只是余量；`compensated` 永远不变成持久意图。
