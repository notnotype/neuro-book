# 书架页

## 目标与非目标

没有绑定项目的窗口打开 `/` 时看到书架页（书房）：上半是“继续写作”，一步回到上次写到的地方；下半是全部作品，书脊与列表两种视图，能新建作品、加入已有目录、修改作品信息与移出书架。数据来自 `nbook.projects` 的远程服务（[`runtime.projects`](../runtime/projects.md)），统计只读缓存与运行中项目的实时状态，不为显示统计而打开项目。

不承诺：

- 封面图、按天的写作量细条、云同步。
- 删除作品目录：“移出书架”只取消登记，删除文件留给文件管理器。
- 书名同步到已打开窗口的标题栏：已打开的窗口仍显示短名，刷新后也是（窗口绑定不带书名）。
- 按统计状态筛选。

## 术语与参与者

- **作品**：一个已登记的项目（[`runtime.projects`](../runtime/projects.md)）。
- **显示名**：书名，没有书名时用短名。
- **新鲜度**：书架上一部作品的统计是不是最新的。
  - `fresh`：作品正在运行，统计完整；
  - `counting`：作品正在运行，还在统计，先显示上次的快照；
  - `stale`：作品没在运行，或在关闭后的宽限期里，显示的是某时刻的快照；宽限期里的快照最多比实际旧 30 秒；
  - `none`：从没统计过。
- **继续写作的目标**：所有作品里最近编辑时间最晚的那个文件。

## 输入与前置条件

- 页面：`nbook.projects` 的浏览器入口向工作台的 `workbench.home`（[`ui.workbench-shell`](../ui/workbench-shell.md) 外壳四之后的“无项目首页”）贡献书架页；只在没有绑定项目的窗口出现。
- 数据：远程服务 `nbook.projects/projects` 的 `shelf()`，返回每部作品的登记项、作品信息与统计摘要（形状见 [`runtime.projects`](../runtime/projects.md)）。
- 设置：作品目录 `nbook.projects/library`（user 层字符串，缺省空）；书架的视图与排序记在 user 分区的 `nbook.projects` / `shelf-preferences`（`locality: local`）。
- 显示语言跟随配置（中英）。

## 输出与可观察行为

**页面**

1. 页面直接压在窗体底纹上，内容列至多 1040px 宽、居中；页面自身纵向滚动，没有横向滚动。顶部左边“NeuroBook · 书房”，右边“进入工作台”：整页导航到 `/workbench`（不打开作品，进入空工作台）。
2. 继续写作：显示继续写作的目标所在的作品——书名与片段名、该文件最后一段的前几行（宋体稿面，至多三行）、今天与总字数、“继续写作”按钮。
   - 统计是 `stale` 时写“统计于某时”；今天的统计不是今天的时不显示今天。
   - 没有任何编辑记录时换成一段欢迎文字；书架为空时提示先新建或加入一部作品。
3. 书架：标题行“书架 · N 部”，右侧视图切换（书脊、列表）与排序（最近编辑、书名、字数）。视图与排序记住，跨刷新保留。
4. 页面宽度不足 720px 时只用列表视图，视图切换不显示；继续写作上下排。

**书脊视图**

5. 每部作品是一根竖排书名的书脊，厚度随字数（30 到 64px）、高度四档（200 到 220px），颜色取作品的主题色，没有时按 id 在主题色板里取一档；正在打开的作品书脊底部有圆点。书架末尾是“新建作品”“加入已有目录”两根虚线书脊。
6. 书脊组成一个列表框：左右方向键移动选中，Home、End 到两端，Enter 打开选中的作品，Delete 请求移出书架；点书脊选中它，双击打开。聚焦时没有选中就选第一部。
7. 扉页跟随书架的选中项显示在书架下方（不随悬停变化）：书名、简介、字数、篇数、最近编辑时间、新鲜度说明、目录路径，以及“打开”“在新窗口打开”“编辑信息”“从书架移除”。

**列表视图**

8. 每部作品一行：书名、一行简介、字数、篇数、最近编辑时间与新鲜度说明（`stale` 写“统计于某时”，`counting` 写“正在统计”，`none` 写“尚未统计”）；点行打开作品，行尾“更多”列出在新窗口打开、编辑信息、从书架移除。末尾两行文字按钮“新建作品”“加入已有目录”。

**动作**

9. 打开：整页导航到 `/?project=<短名>`。在新窗口打开：经宿主在新标签页打开同一地址；被浏览器拦截时提示。
10. 继续写作：整页导航到 `/?project=<短名>&open=<地址>&at=end`，编辑器在那个文件的末尾放下光标（[`workbench.editor`](editor.md) 的“继续写作”）。
11. 新建作品：对话框填书名（必填）与简介；作品目录没设时先经命令面板的路径输入选一个服务端上的目录。成功后新作品出现在书架上并被选中；作品目录在新建成功后才记住，记住失败单独提示，作品照常建成。失败按失败码提示（同名目录已存在时建议改书名或用“加入已有目录”；登记失败时说明目录已建好、可以用“加入已有目录”接着完成）。
12. 加入已有目录：与“打开项目”同一种路径输入，登记成功后出现在书架上。
13. 编辑信息：对话框改书名、简介与主题色；保存后书架立即显示新值。失败按失败码提示，对话框保留输入。
14. 从书架移除：先确认（说明只取消登记、不删目录）；作品正在打开或在关闭宽限期内时说明原因并不移除。移除后选中下一部（没有时上一部），焦点回到书架；书架空了时焦点到“新建作品”。

**取数与刷新**

15. 第一次取数期间显示骨架；第一次取数失败显示原因与“重试”。
16. 页面可见时每 30 秒刷新一次，窗口重新获得焦点时也刷新，两者合并；同一时间至多一个请求在途，迟到的旧响应丢弃；页面隐藏或离开时停止。
17. 刷新失败保留上次的数据，顶部提示“书架没有更新”并带“重试”；某部作品的统计取不到时只影响那一部，按 `stale` 或 `none` 显示。

## 状态与转换

| 当前 | 事件 | 下一状态 |
|---|---|---|
| 首次加载 | 取到 | 显示书架 |
| 首次加载 | 失败 | 整页出错，带重试 |
| 显示书架 | 刷新失败 | 保留数据，顶部提示“书架没有更新” |
| 显示书架 | 刷新成功 | 更新数据，提示消失 |
| 显示书架 | 选中的作品被移出或不在了 | 选中相邻的一部；没有作品时不选中 |

时序与寿命：

- 页面卸载或隐藏后不再发出刷新；卸载前在途的响应回来时不改变任何状态。
- 新建、修改信息、移出书架成功后立刻刷新一次；它们的结果以服务端为准，界面不先行修改数据。

## 副作用与数据

- 视图与排序写在 `shelf-preferences`（`{view, sort}`），每个客户端一份。
- 作品目录写在用户层配置 `nbook.projects/library`。
- 页面本身不写作品目录里的文件；新建、修改信息、移出书架由服务端执行（[`runtime.projects`](../runtime/projects.md)）。

## 失败与恢复

| 情形 | 界面 |
|---|---|
| 首次取数失败 | 整页显示原因与重试 |
| 刷新失败 | 保留数据，顶部提示与重试 |
| 新建、修改信息失败 | 对话框保留输入，按失败码写原因 |
| 移出书架被拒（`project-running`） | 说明作品正在打开或在关闭宽限期内 |
| 新标签被拦截 | 提示允许本站打开弹出窗口 |
| 继续写作的文件不在 | 项目照常打开，编辑器提示（[`workbench.editor`](editor.md)） |

## 边界与兼容

- 书架页只经 `nbook.projects/projects` 的远程服务取数与操作；合同升级时旧页面得到 `version-changed`，按浏览器宿主的规则提示刷新。
- `/workbench` 与 `workbench.home` 由工作台定义（[`ui.workbench-shell`](../ui/workbench-shell.md)）。

## 验收与 Smoke

1. Given 两部登记的作品，其中一部打开过并写过字，When 关闭全部窗口、等那部作品停止后打开 `/`，Then 书架显示两部作品，写过的那部有字数、片段与“统计于某时”，没打开过的写“尚未统计”；继续写作显示写过的那部。
2. Given 书架，When 点“继续写作”，Then 打开那部作品并在那个文件的末尾可以接着输入；刷新页面不再重新定位。
3. Given 作品目录没设，When 新建作品并输入一个服务端目录，Then 作品出现在书架上并被选中，作品目录被记住；同名目录已存在时提示改书名或加入已有目录。
4. Given 一部正在打开的作品，When 从书架移除，Then 被拒并说明原因；关闭并等宽限期结束后移除成功，选中相邻的作品，目录还在。
5. Given 390 × 844 的窗口，When 打开书架，Then 只有列表视图，新鲜度说明可见，没有横向滚动。
6. Given 书架已显示，When 服务端暂时不可用导致刷新失败，Then 数据保留、顶部提示并可重试，恢复后提示消失。

Smoke：`e2e/bookshelf.e2e.ts`（生产构建、真实服务端与项目子进程、本机 Chrome）；Lab 场景 `BookshelfPage`、`SpineShelf`、`ShelfList`、`ShelfTitlePage`、`ContinueCard`、`BookSpine`。
