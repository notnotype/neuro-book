# Markdown 编辑命令与菜单

## 目标与非目标

**目标**：写作者在 Markdown 富文本编辑器里用固定工具栏、选区浮动菜单、斜杠菜单、块按钮与块菜单、正文右键菜单完成常用编辑；每个编辑动作都是工作台命令，命令面板找得到，插件能往每种菜单里加菜单项。批注（[`workspace.markdown-dialect`](../workspace/markdown-dialect.md) 输出 11）能在编辑器里添加、查看、修改与删除：意见在批注旁的浮层里（点批注末尾的小符号，或按住 Ctrl 把鼠标停在批注上），或在稿纸右边的页边里。文件开头的 frontmatter 在正文上方的属性面板里按属性看与改，也能就地改它的 YAML 源码（输出 39–51）。链接用一行卡片加上或改地址，图片从作品里选、粘贴或选本机文件插入，本机的图存进作品（输出 52–58，planned）。

**不承诺**：

- 插入引用文件（`@`，归 Agent 输入框）；给插件的编辑器接口（读写选区、转交光标）。链接与图片的插入见输出 52–58。
- 批注的作者、时间、回复与“已解决”（方言没有这些，见 [`workspace.markdown-dialect`](../workspace/markdown-dialect.md)）；编辑器右边的“全部批注”侧栏列表（页边打开时页边就是总览）；不用鼠标走到卡片上的“删除”（键盘只管添加与修改意见，输出 28）。
- 下划线（方言没有）；增减缩进的按钮（列表里 Tab、Shift+Tab 照旧）。
- 源码编辑器与别的编辑器：它们不提供编辑动作，这些命令在它们活动时不可用。
- 用键盘走到块按钮：按钮不进 Tab 顺序，键盘经快捷键与命令面板。
- 右键菜单粘贴文件或图片（Ctrl+V 照旧）。
- 跨列表移动列表项的按钮（拖动的落点按 ProseMirror 的结果）。
- 多块选区上的块动作：副本、移动、删除只作用于选区起点所在的那一块。
- 链接与图片：把文件拖进正文（归桌面发布 Work 的拖放）；右键菜单里粘贴图片（Ctrl+V 才行）；SVG、BMP、AVIF 的图片；一次选多个本机文件；插入前压缩、改名或缩放图片；改图片说明与对齐的界面；删掉正文里的图片时一并删磁盘上的文件；链接按名字搜作品里的文件（链接卡片只填地址）。
- 属性面板：全书统一的属性类型（同一个属性名在整部作品里只有一种类型）；日期时间类型；嵌套字段（映射、对象的列表、多行文字）的表单编辑；属性名与值的补全；拖动排序；隐藏面板、只显示源码的设置；`tags`、`aliases` 这类键的特殊处理；几个文件一起改属性；源码编辑器里的面板；新的输入类型（例如指向角色条目，要贡献一个输入组件）；按文件夹类型限定属性的图标与类型。
- 属性面板的已知限制：展开状态按文件地址记，文件改名、移动后回到收起；本组改了 frontmatter 之后别处（磁盘、另一组）又改了它，再在本组撤销自己那次修改时，frontmatter 回到那次修改之前的整段原文，别处的修改随之丢掉（正文的撤销按段映射，不受影响）。

## 术语与参与者

- **编辑动作**：控件能执行的一次编辑，例如加粗、换成标题 2。工作台经控件句柄的 `editing` 使用它（下面的“输入与前置条件”）。
- **块**：块按钮与块菜单作用的对象，见下面的块模型表。
- **属性**：frontmatter（[`workspace.markdown-dialect`](../workspace/markdown-dialect.md) 输出 22）顶层的一项，有名字与值；**属性面板**：正文上方显示与编辑属性的卡片（输出 39）。
- 参与者：`nbook.editor`（命令、公开键、菜单位置、设置）、`nbook.markdown` 的 Markdown 控件（画菜单、实现动作）、贡献菜单项的插件。

## 输入与前置条件

控件句柄（[`workbench.editor`](editor.md) 的控件合同）增加可选字段：

```ts
interface EditorEditing {
    run(action: string, args?: Readonly<Record<string, unknown>>): boolean;
    active(action: string): boolean;
    enabled(action: string): boolean;
    readonly hasSelection: Readonly<Ref<boolean>>;
}
```

命令表（都由 `nbook.editor` 登记，`effect: write`，Agent 不可调用，键位不写进声明，由 Markdown 控件在自己有焦点时处理）：

| 命令 | 参数 | `when`（都另要 `nbook.editor/writable`） | 快捷键 |
|---|---|---|---|
| `nbook.edit.bold`、`italic`、`strike`、`code` | 无 | `canFormat` | Ctrl+B、Ctrl+I、Ctrl+Shift+S、Ctrl+E |
| `nbook.edit.superscript`、`subscript` | 无 | `canFormat` | — |
| `nbook.edit.clear-format` | 无 | `canFormat` | — |
| `nbook.edit.text-color`、`highlight` | `{color: string \| null}` | `canFormat` | — |
| `nbook.edit.ruby` | `{text: string}` | `canFormat`、`hasSelection` | — |
| `nbook.edit.ruby-remove` | 无 | `canFormat`（选区或光标处没有注音时 `unavailable`） | — |
| `nbook.edit.comment` | `{text: string}` | `canFormat`、`hasSelection` | Ctrl+Alt+M（打开卡片，输出 28） |
| `nbook.edit.paragraph`、`heading-1`、`heading-2`、`heading-3` | 无 | `canConvertBlock` | Ctrl+Alt+0–3 |
| `nbook.edit.bullet-list`、`ordered-list`、`task-list` | 无 | `canConvertBlock` | Ctrl+Shift+8、7、9 |
| `nbook.edit.quote`、`callout`、`code-block` | 无 | `canConvertBlock` | Ctrl+Shift+B、—、Ctrl+Alt+C |
| `nbook.edit.align` | `{value: "left" \| "center" \| "right" \| "justify"}` | `canConvertBlock` | — |
| `nbook.edit.bilingual` | `{text: string}` | `canConvertBlock` | — |
| `nbook.edit.divider`、`table` | 无 | `canConvertBlock` | — |
| `nbook.edit.block-up`、`block-down` | 无 | 无另外条件 | Alt+↑、Alt+↓ |
| `nbook.edit.block-duplicate`、`block-delete`、`block-unwrap` | 无 | 无另外条件 | — |
| `nbook.edit.properties`（输出 48） | 无 | 无另外条件 | — |
| `nbook.edit.link`（输出 52） | `{href: string, label?: string}`（`label` 只在光标处没有链接、要插入一段链接文字时用） | `canFormat` | Ctrl+K（打开链接卡片） |
| `nbook.edit.link-remove` | 无 | `canFormat`（光标处或选区里没有链接时 `unavailable`） | — |
| `nbook.edit.image`（输出 54） | `{src: string, alt?: string}` | `canFormat` | — |
| `nbook.edit.sticker`（输出 62） | `{text: string}`（一个表情写法） | `canFormat` | — |

另有 `nbook.view.toggle-editor-toolbar`（无参数，勾选状态读 `toolbarVisible`，任何时候可用）切换设置 `nbook.editor/markdownToolbar`。

改意见与删除批注是控件的内部动作，不是命令：卡片经控件句柄的 `editing.run` 调用 `comment-edit`、`comment-delete`，参数是批注的序号（输出 31 的先后，从 0 起）、卡片显示时记下的指纹（意见与被批注的开头文字）和新意见；控件在最新的文档里按指纹核对，对不上（正文被别处改了、重载）就不执行、返回 false，序号只在一个事务内有效，不对外。空意见（去掉首尾空白后为空）是取消，不是删除（输出 29）。

另有 `nbook.editor.toggle-comment-margin`（无参数，勾选状态读 `commentMargin`，活动控件提供批注页边时才可用，输出 33）切换这部作品的页边开关（本机记录 `editor.comment-margin`，见“副作用与数据”）。

撤销、重做用已有的 `nbook.edit.undo`、`nbook.edit.redo`。带参数的命令不进命令面板。

公开键（布尔，`nbook.editor/` 下，未就绪为假；除 `toolbarVisible`、`commentMargin` 读设置与记录外都读活动控件）：`canFormat`、`canConvertBlock`、`hasSelection`、`toolbarVisible`、`hasComments`（活动控件提供批注页边）、`commentMargin`（这部作品的页边开关开着，读本机记录，不看活动控件），以及勾选状态 `formatBold`、`formatItalic`、`formatStrike`、`formatCode`、`formatSuperscript`、`formatSubscript`、`formatHeading1`、`formatHeading2`、`formatHeading3`、`formatBulletList`、`formatOrderedList`、`formatTaskList`、`formatQuote`、`formatCallout`、`formatCodeBlock`、`formatLink`（光标在链接里，planned）。

设置：`nbook.editor/markdownToolbar`（布尔，缺省开）、`nbook.editor/markdownToolbarPlacement`（`full`、`merged`、`bottom`，缺省 `full`），在设置窗口“编辑器”分区。页边开关不是设置（输出 33）。图片存放位置（输出 56）：`nbook.editor/imageLocation`（`folder`、`root`、`same`、`sibling`，缺省 `folder`）与 `nbook.editor/imageFolder`（目录名，缺省 `插图`），同在“编辑器”分区，两层都能设、项目层优先，所以一部作品里的设置跟着作品走。

菜单位置（规则见 [`workbench.menus`](menus.md)；五个位置都有 `context: "resource"` 给出 `{address}`）：`editor.toolbar`（`icon`、`placement`）、`editor.selection`（`icon`）、`editor.slash`（`icon`）、`editor.block`（`icon`）、`editor.body-context`（`icon`）。

块模型：

| 指针下的内容 | 块 | 转换为 | 副本、移动、删除 |
|---|---|---|---|
| 段落、标题、空段落 | 这一块 | 全部 | 可用 |
| 代码块 | 这一块 | 全部（内容转为文字） | 可用 |
| 列表项与任务项（任何层级） | 这一项连同子项 | 正文、标题：提出列表再转换，列表从这里断开；列表类型：改整个列表；其余置灰 | 移动限于同一列表，到头时置灰 |
| 引用、提示块、对齐、批注块、双语 | 整个容器 | 只有“正文”（解开容器；提示块的标题留成开头一段），其余置灰 | 可用 |
| 表格、分割线、原样块、HTML 嵌入 | 整块 | 全部置灰 | 可用 |

## 输出与可观察行为

1. **工具栏的内容**：撤销、重做｜块类型｜粗体、斜体、删除线、行内代码｜文字颜色、高亮｜链接、图片、表情（有表情包插件时，[`agent/stickers.md`](../agent/stickers.md) 输出 39）｜无序、有序、任务列表｜引用、提示块、代码块｜对齐、清除格式｜⋯（上标、下标、分割线、注音、双语）。贡献的 `inline` 项在内置按钮之后，`menu` 项进“⋯”。文字颜色与高亮是拆分按钮：左半边一点就上色，用上次选过的颜色（第一次是红色文字、黄色高亮），图标下的色条就是这个颜色；右半边的小箭头打开色板。在色板（包括“⋯”里的）选了颜色就记住，选“无”不改记住的颜色；刷新、重开应用后仍记得，选区菜单与工具栏共用一份。
2. **工具栏的位置**：只有 Markdown 编辑器有，不随正文滚动。设置 `nbook.editor/markdownToolbarPlacement` 决定位置：`full`（缺省）在面包屑下面通栏，按钮居中、和版心同一条中轴（页边画出来时版心左移半个页边宽，工具栏仍在编辑组的中轴上，输出 33），下面一条贯通的分隔线；`merged` 并入面包屑那一行的右侧，放不下时比面包屑先收；`bottom` 是编辑区底部居中的浮条，滚到底时不挡最后一行。
3. **工具栏的宽度**：放不下时按钮从右往左收进“⋯”，贡献的项最先收；“⋯”始终在最右。任何宽度都不出现横向滚动。
4. **工具栏的显隐**：设置关掉或“视图”菜单取消勾选后，所有组的工具栏立即消失，正文上移；再打开时恢复。切到别的编辑器时不留着。
5. **按钮的状态**：按钮显示自己这一组控件的状态（勾选、可用），不随别的组变化。只读文档全部置灰，版面不变。点按钮不夺走正文的焦点，动作之后光标留在正文。
6. **选区浮动菜单**：内容是块类型｜粗体、斜体、删除线、行内代码｜链接、文字颜色、高亮｜注音、批注、清除格式｜贡献的项。在选区上方出现（放不下时翻到下方），随滚动跟着选区。块类型是与工具栏相同的下拉（正文、标题 1–3，当前类型打勾），选了以后焦点回到正文；颜色是与工具栏相同的拆分按钮（输出 1）。选区里有注音（盖住一部分也算）时注音按钮显示按下。
7. **选区菜单的显隐**：以下全部满足才显示：选区非空；焦点在正文或菜单里（包括菜单自己打开的色板与块类型下拉；工具栏打开的不算，焦点进去时选区菜单收起，免得盖住它们）；指针已松开（拖选中不显示）；不在输入法组字；不在代码块、原样块；文档可写；选中之后没有打字；没有按 Esc。切标签回来恢复的选区不显示，要重新选。
8. **清除格式**：移除粗体、斜体、删除线、行内代码、文字颜色、高亮、上标、下标。批注、注音、链接与块类型不变。
9. **注音与双语的输入**：点了在选区下方开一张一行的卡片：字直接写在卡片里（输入框没有自己的框），右边是确定按钮；输入框里回车或点确定写回，Esc 取消，焦点离开时收起；把字清空再确定等于取消。焦点在卡片的按钮上时回车是那个按钮的动作；输入法组字时的回车与 Esc 归输入法。没有说明文字，输入框有可访问名称。卡片开着时原来的选区仍画成选中的样子，选区菜单不显示。注音另有：选区里已有注音时，确定按钮左边多一个“移除注音”（`nbook.edit.ruby-remove`，去掉选区碰到的整段注音）；碰到的注音只有一种读音时卡片预填它，碰到几段读音不同的注音时不预填（确定会把整个选区写成一个读音）。点正文里注音的小字（不带修饰键），选中这整段注音并打开卡片（只读文档不打开）；卡片开着时点另一段的小字，卡片换到那一段、重新预填。双语的卡片不预填，没有移除按钮。
10. **斜杠的触发**：`/` 在行首或空白之后打出时打开斜杠菜单；`、` 只在行首也算（中文输入法下这个键打出的字符）。代码块、原样块、表格单元格里不触发；组字时不触发。接着打的字是查询，Esc、删掉触发字符、光标离开时收起；Esc 收起后同一处不再打开。
11. **斜杠菜单的内容**：基本（正文、标题 1–3）、列表（无序、有序、任务）、块（引用、提示块、代码块、分割线、表格、图片、表情（有表情包插件时）、双语对照、属性），贡献的项在各组之后。每项只有图标与名称。
12. **筛选**：按名称，也按拼音首字母（`bt` 找到“标题 1”）。拼音库第一次打开时加载，加载完成前只按名称筛。筛不出项时菜单不显示，回车照常换行。
13. **选择**：上下键移动、回车或 Tab 选择。选择后 `/查询` 被删掉并执行动作；撤销一步回到 `/查询`。光标留在输入处，打开与关闭都不移动焦点。
14. **块按钮**：指针停在一块上，或光标在这一块且没有选中内容时，左侧出现 `+` 与手柄（指针优先）；打字时跟着光标，正文失焦时收起。按钮右缘离正文 14px，悬停底色圆角 4px，与这一块第一行垂直居中。所有层级的列表项按钮都在同一列。只读文档不出现。
15. **`+`**：在下方插入一个段落并打开斜杠菜单（点的时候按住 Alt 插在上方）。菜单放弃（Esc、失焦、光标离开）且这一块还只有触发字符时，这一块被删掉，文件字节不变；这一过程不留撤销步骤。
16. **拖动手柄**：拖动移动这一块，正文里有落点线；松手在正文外或按 Esc 取消，文档不变。取消之后从别处拖进来的内容不受影响。
17. **块菜单**：点手柄打开：转换为（子菜单，当前类型打勾）｜批注｜创建副本、复制｜上移、下移｜贡献的项｜删除。各项是否可用见块模型表。“批注”给这一块加批注，见输出 28。
18. **副本**：紧接在这一块之后，内容相同；写回时按新内容写出，不和原块共用原文。原块里的批注在副本里也在。
19. **移动**：移动后没有被编辑的块，写回的字节不变（方言的间隔规则照旧，见 [`workspace.markdown-dialect`](../workspace/markdown-dialect.md)）。macOS 上 Option+↑↓ 被这两个快捷键占用，不再跳段落。
20. **右键菜单**：正文里右键打开：剪切、复制、粘贴、粘贴为纯文本｜添加批注｜全选｜贡献的项。没有选区时剪切、复制、添加批注置灰。只读文档只有复制、全选。这个菜单盖掉浏览器自带的右键菜单。
21. **右键的选区**：点在选区内时保留选区；点在选区外时光标移到点击处。右键点别的组时，那一组变成活动组，菜单作用于它。
22. **复制与剪切**：结果和 Ctrl+C、Ctrl+X 相同，粘贴回编辑器时列表与提示块的结构保留。块菜单的“复制”复制这一块。
23. **粘贴**：结果和 Ctrl+V 相同（文字与 HTML）。浏览器不给读剪贴板时给出通知，说明原因并建议用 Ctrl+V：接口不可用、权限被拒、剪贴板里没有文字（例如图片或文件）是三条不同的文字。
24. **命令面板**：不带参数的编辑命令在 Markdown 编辑器活动时可选，条件不满足时不列出；执行结果与点按钮相同。
25. **贡献的项**：显示与可用规则同 [`workbench.menus`](menus.md)；点了以后命令收到 `{address}`。
26. **注音是一个整体**：加上或去掉格式（粗体、斜体、删除线、行内代码、文字颜色、高亮、上标、下标、链接、批注、清除格式，以及设新注音、去掉注音）时，只盖住一段注音的一部分，就连整段注音一起改，不把注音切成两段；不管是从按钮、菜单、快捷键还是 `**…**` 这类输入规则来的，都一样，与原来的改动在同一个撤销步里。行内代码排斥注音：盖住注音的一部分时整段注音变成代码。拖选经过注音时注音的小字不画成选中，复制出来的文字也不带它。已知限制：在注音中间带着存下的格式打字、往注音中间粘贴带格式的文字，注音照旧被切开。
27. **含注音的行里的行首行尾**：Home、End 与 Shift+Home、Shift+End 在含注音的行里到这一行真正的行首、行尾（折行的段落里是这一行，不是整段），行尾的光标画在这一行的末尾，不跑到下一行行首。编辑器里的注音画成行内块、读音在基底上方居中，排版与原生的注音相近。已知限制：注音的基底很长（整句）时，整个注音块掉到下一行，不再跟着折行；注音通常只给词。只读显示不受影响。
28. **加批注与改意见的入口**：选区菜单的“批注”按钮；正文右键菜单的“添加批注”；块菜单的“批注”（下面）；快捷键 Ctrl+Alt+M（macOS 上 ⌘⌥M，都不带 Shift）。快捷键只在焦点在正文里时处理（不在批注卡片、页边里），Windows 上 AltGr（系统报成 Ctrl+Alt）打字不触发，输入法组字中不触发；没有处理时不拦截这个按键。不进固定工具栏与斜杠菜单。可用条件：文档可写；选区里有文字（只有换行或空白不算）；不在代码块、原样块里；真的加不上时（例如选区跨了不允许批注的块）动作返回失败，卡片不关成“已保存”。点了或按了在选区下方开批注卡片的“写”状态（输出 29），卡片的左边缘对齐选区的左边（输出 30），原来的选区仍画成选中的样子（同输出 9），选区菜单不显示。**块菜单的“批注”**给这一块加批注：段落、标题、列表项（只算这一项自己的文字，不含子项）选中这一块的文字，加一条行内批注，空块置灰；代码块、引用、提示块、双语、对齐、批注块、表格、分割线、原样块、HTML 嵌入把整块包进一条块批注（选中的块画成选中的样子）；之后同选区上加批注：开“写”，保存写回，取消不改文档；点了以后焦点在卡片的输入框里，菜单关上时不把焦点还给正文。文档只读时块菜单不出现。选区在别的批注里、或盖住别的批注时照常再加一条（两条批注可以重叠，方言输出 11）。选区是空的、光标在批注里时，Ctrl+Alt+M 打开这条批注的“写”状态改意见（重叠的几条里是排在前面的一条，输出 31）；光标不在批注里不响应。
29. **批注卡片**：一张卡片，有“看”“写”两种状态，与注音卡片是同一种浮层；写意见不另起输入框。浮层与页边里是同一个组件。浮层里状态之间外框与版式不变：意见区（“看”是文字、“写”是文本框）加一个固定高度的底行，只有意见区的行数随内容变；页边里没有底行（一段可能只有一行高，放不下），按钮浮在卡片右上角，状态之间的尺寸变化见输出 33。
    - **看**：意见全文（保留换行；意见为空时是一行灰字“没有写意见”）；浮层里下面一行，左边是“第 i 条，共 n 条”与上一条、下一条按钮（输出 31），右边是编辑、删除按钮；页边里没有这一行，见输出 33。意见区最高约 12 行，再长在卡片里滚动，不把卡片拉得比屏幕高。
    - **写**：同一张卡片里，意见处原地变成可输入的多行文字，卡片的样子不变，没有输入框自己的框与灰底，字体、字号与行距和“看”一样，高度随字数增减（同样最高约 12 行再滚动）；预填原来的意见（新批注为空），光标在末尾；下面一行右边是取消、保存按钮。Ctrl+Enter（macOS 上 ⌘Enter）或点保存写回，Esc 或点取消放弃，回车是换行；输入法组字时的回车与 Esc 归输入法。意见去掉首尾空白后为空时，保存等于取消：新批注不加，已有的批注保持原样（不是删除）。保存后回到“看”（卡片留在改的那一处；页边里是页边里的当前卡片）；新加的批注保存后卡片收起、选区留着。
    - **焦点**：点卡片上的任何地方（按钮、空白）不夺走正文的焦点，进入“写”时焦点进卡片里的输入。焦点移到卡片之外的别处（点正文、点页边别的卡片、Tab 出去）时收起，没保存的字放弃；窗口失去焦点（切到别的窗口、点开发者工具）不算离开，回来时卡片与字都还在；控件宽度变化使卡片在浮层与页边之间换位置（输出 33）时，写着的字跟着过去。卡片的每个出口（保存、取消、删除、点摘要跳转）之后焦点回到正文。
    - **只读**：没有编辑、删除按钮，进不了“写”；上一条、下一条照常。文档在卡片开着时变成只读，卡片收起。
30. **浮层**：页边没有画出来（输出 33）时，批注在浮层里看。**打开**两种：点被批注文字末尾的小符号（输出 38）；按住 Ctrl（macOS 上 ⌘ 也行）把鼠标停在批注的文字上，或按住 Ctrl 点批注的文字。先把鼠标停在批注上、再按下 Ctrl 同样出。都是立刻出现，不等；不需要正文有焦点，只读文档也出。光标走进批注（点击、方向键）、没按 Ctrl 的悬停与点击、打字都不出卡片，不打扰编辑正文。**收起**：点符号或 Ctrl 点击打开的卡片（“点开的”）不因鼠标离开而收；点正文里别处、点卡片之外的别处、改了文档（输入）、选区不空（这时出选区菜单）、Esc（只读文档也一样）、再点一次同一个符号、换文档、开始写意见时收起。按住 Ctrl 悬停出来的卡片（“悬停的”）除此之外，在指针离开批注文字、又没进卡片约 0.25 秒后收起，进了卡片就不收，从卡片出来再算；它被收起之后，同一次悬停（指针没离开批注文字）不再弹，指针离开再进来才重新算；在正文里按下鼠标（没按 Ctrl）也算：点击批注文字之后指针停着不动，按 Ctrl（复制、粘贴这类快捷键）不弹。注音、双语卡片或右键菜单开着时不弹。重叠的几条在同一张卡片里上下排：点符号时是在这个符号处结束的那几条（符号上的数字就是条数），Ctrl 悬停时是指针所在位置上的几条；每条各有自己的序号、上一条下一条、编辑与删除。**位置与对齐**：卡片出现在符号（或指针）所在那一行的下面（块批注也是那一行，不是块的第一行），放不下时翻到上面，随滚动跟着；左边缘对齐这条批注的文字在这一行的起点（重叠的几条取最左的），不是居中于指针；靠近窗口边时夹进窗口。点上一条、下一条：光标与卡片都移到目标批注开头那一行，卡片留着。“写”的卡片同样对齐：改已有批注的在光标所在那一行下面、左边缘对齐这条批注在这一行的起点，新批注的在选区下面、左边缘对齐选区的左边。**键盘**：光标在批注里按 Ctrl+Alt+M 直接进“写”（输出 28）；键盘走进批注不出卡片，要读意见用 Ctrl+Alt+M 或页边。触屏没有悬停与 Ctrl，点小符号。
31. **批注的先后与上一条、下一条**：批注按起点靠前的在前（块批注的起点是块里第一个文字处，分截的批注按它的第一截），起点相同时终点靠前的在前，起点终点都相同时块批注（外层）在前，再相同时按编号（读入时编的，同一段上重叠的批注里层的编号靠前，之后新加的在后；改意见不改编号，所以不改先后）；一条分截的批注算一条。点“上一条”“下一条”：这条批注成为“当前批注”，光标放到它的开头，滚进视野，卡片（页边开着时是页边里展开的卡片）换成它；两条批注紧挨或同起点、光标位置不变时，当前批注照样换。到头不绕回，按钮置灰。“第 i 条，共 n 条”按整份文档算，序号随批注的增减当场变（不是稍后）。
32. **当前批注的标出**：浮层卡片开着时（卡片里排在前面的一条，点上一条、下一条跳到的那条），它对应的批注的文字在波浪线之外加一层批注色的淡底；批注在页边里展开时同样。只是显示，不进撤销历史，不写进文件。
33. **页边**：
    - **开关**：活动编辑组的标签条右侧（编辑区标题，[`workbench.editor`](editor.md) 输出 34）有一个批注页边的开关按钮：图标后面是这份文档里批注的条数 N（没有批注时为 0，多于 99 写 99+），提示是“显示或隐藏批注页边”。只有活动标签的控件提供批注页边（Markdown 富文本）时出现；按钮有按下态；放不下按钮时按输出 34 的规则收进“⋯”，不显示条数。点它切换这部作品的页边开关，命令 `nbook.editor.toggle-comment-margin`，命令面板里的名称是“显示或隐藏批注页边”。开关缺省关，按作品记在本机，不进作品目录，也不进设置窗口（见“副作用与数据”）。
    - **开着**：控件够宽时（约 1030px 起），稿纸往左让出页边的宽度的一半，页边画在稿纸右边，按**段**排槽位，一个槽位一张卡片。段指文字块（段落、标题、列表项、引用与提示块里的段落）；表格按行算一段（同一行几个单元格里的批注并在一起）；整块批注按它里面第一个文字块算；批注跨了几段时按它起点所在的段；批注在折叠的提示块里时，对着提示块的标题行。页边压不到正文，两侧的场景图不画（正文底下是干净的面），工具栏仍在编辑组的中轴上；页边画出来时不出浮层，也不画小符号（输出 38）。
    - **位置与高度**：槽位的顶边与这一段的顶边对齐；槽位的高度含与相邻槽位之间约 3px 的空，卡片面比槽位矮这么多，所以卡片面不小于这一段的高度减去这 3px（段落很高时最小高度封顶在约 8 行意见的高度，免得一句话拖出一张很高的空卡；一行的短段也至少放得下一行意见，所以卡片可能比这一段稍高，后面的槽位照常往下让）；不高于这一段的高度，下一段没有批注时放宽到两倍段高，但不越过下一段的底边，所以槽位不会压到别的槽位；意见比槽位放得下的行数长时在最后一行末尾省略。
    - **卡片的样子**：没有底行，没有左边框一类的侧边色条，不画“第 i 条，共 n 条”与跨整份文档的上一条、下一条（页边本身就是总览）。编辑、删除按钮在这张卡片是当前批注、指针停在上面或焦点在里面时显现在卡片右上角，其余时候不画；它们的位置（有同段切换时连同 `‹ 1/3 ›`）在意见第一行里一直留着，文字绕开，所以按钮不压到字，显现与否文字也不动（只读又只有一条时没有按钮，也不留位置）。当前批注（光标所在的、写着的）与展开的卡片是浮层，用浮层的材质（面色、描边、阴影与磨砂，与浮层里的批注卡片一样），其余的是实心的淡底、不开磨砂；两种的外框（描边宽度、圆角）一样，切换时不跳；皮肤的浮层画框（[`theme/skins.md`](../theme/skins.md) 输出 13）不画在页边卡片上。
    - **同一段几条批注**：合用一个槽位，一次只显示一条，右上角常显 `‹ 1/3 ›`（意见在第一行为它让位），点两侧箭头切换，顺序是输出 31 的先后；切到的那条成为当前批注、光标移到它开头、正文里标出（输出 32）；光标走进另一条批注的文字时槽位自动切到那一条；光标离开后槽位仍显示上次看的那一条。
    - **展开**：点卡片的空白，或点编辑进“写”，这张卡片在原地向下长到意见全文（最多约 12 行再滚动），浮在别的槽位上面；**槽位的位置与占位不变，别的卡片不动**。光标走进批注的文字时卡片只是成为当前批注（底色、阴影、按钮），不展开；展开之后光标走动、打字、点正文别处、Esc 时收回。“写”的卡片下面一行右边是取消、保存。
    - **滚动与更新**：页边随正文一起滚动；正文换行、改动使段落位置或高度变了时，槽位滑到新位置（过渡，不是一跳）；换文档时按新文档重排，不从顶上滑下来。点卡片或点批注的文字，那条批注成为当前批注、光标移过去。
    - **动画**：开、关页边（点开关、控件宽度跨过阈值）时稿纸平移到新位置、卡片跟着稿纸走并淡入淡出；槽位首次出现时淡入并从右向左滑入约 8px；槽位位置或高度变化时滑到新位置；当前批注换一条时底色、阴影与按钮渐变；展开与收回时卡片的高度过渡，收回时意见保持全文被卡片面裁着、等卡片面收完才截成几行加省略号（不是文字先跳成几行、框再慢慢缩），展开时立刻放开（已显示的槽位里限的行数因窗口缩放重新折行、打字使段高变而变时，限行同样晚一个过渡才生效，不处理）；同一段里切换条目时直接换文字，没有动画。时长与缓动取布局动效令牌（[`ui-development-spec.md`](../../../packages/nb-ui/docs/ui-development-spec.md) 第 3 节第 8 条）；减少动态效果时没有动画。首次排好位置之前不显示。
    - **待写的新批注**：加批注的“写”卡片在页边画出来时也在页边里，作为一张还不在文档里的卡片，顶边对着选区起点所在的段，浮着，不占位（这一段已有批注时盖在它上面），取消时消失、保存时成为一条批注（并进这一段的槽位）；页边没画出来时是选区下方的浮层（输出 28、30）。
    - **放不下**：控件窄到页边画不下（出现约 1030px，已画出的在窄于约 1000px 时收起，避免在临界宽度闪）时不画页边，退回浮层（输出 30）；开关与按钮的按下态不变，宽度够了再画页边。拆成两栏、开着侧栏时就是这种情形，每组各自判断。
34. **删除批注**：点卡片的删除，这条批注的标记（块批注是它的容器）连同所有截一起去掉，只去这一条，盖在同一段上的别的批注留着；被批注的文字留着；一个撤销步，Ctrl+Z 恢复；不询问。删后光标留在原处，卡片收起。
35. **改意见**：保存后这条批注（它的所有截）的意见换成新的，一个撤销步，编辑器里别的批注与这条的先后不变；保存之后紧接着打的字不并进这个撤销步；写回文件时意见写在第一截（方言输出 11），意见里的换行写成 `&#10;`。已知行为：列表里的块批注改了意见，写回时这个列表整块重写，项之间可能多一个空行。
36. **替换批注文字时批注不丢**：选中的文字全在同一条（或几条重叠的）批注里，打字（含输入法）或粘贴一段行内文字把它整个或一部分替换掉时，新文字仍在这些批注里，意见不丢，一次替换是一个撤销步。选中整句再一个字一个字打新句子时，第一个字替换选区，接着打的字（光标没有离开、没有在别处改文档、没有撤销）也在批注里，整句新话都在；光标被挪走（点击、方向键）、在别处改了文档、撤销之后，批注末尾照常是批注外。不适用：只在批注两端打字（新字在批注外，同以前）；选区跨出了批注（盖住了批注以外的字）；删除（Backspace、Delete、剪切）：删光批注的文字，批注就没了，Ctrl+Z 回来。
37. **批注的显示**：被批注的文字带批注色的波浪线，行内、分截与块批注一样，块批注没有边框、缩进之类另外的标记，里面的块之间的间隔与顶层的一样。同一段文字上叠着几条批注时，嵌套的第 2、3 层把线依次往下错开，看得出有几层。只读显示与编辑器一样。
38. **批注的小符号**：页边没有画出来时，每条批注（行内、分截、块批注）的文字末尾（块批注是块里最后一个文字之后）有一个小符号：对话气泡图标，批注色，比正文字小，占一个字的宽；点它在浮层里看（输出 30）。几条批注结束在同一处时合成一个，图标旁带条数。符号只是显示：不进文件、不进撤销历史、复制不带；点它不移动光标、不夺走正文焦点；只读文档也画。页边画出来时不画（页边就是总览），所以开关页边时正文会按有无符号重新折行。
39. **属性面板**：文档有 frontmatter 时，正文第一块上方是属性面板：一张淡底、没有边线的卡片，与版心同宽，随正文滚动，用界面字号；没有 frontmatter 时不画。面板不在正文里：全选、复制、块按钮、块菜单与拖动都碰不到它，写不出（[`workbench.editor`](editor.md) 输出 61）时给出的“第几块”不算它。
40. **收起与展开**：面板顶上一行是折叠箭头、“属性”与右端的源码切换按钮（输出 44）。收起时这一行后面是摘要：每个属性写成“名字 值”，以“·”隔开；列表的项以“、”连接，勾选写“是”“否”，空值与表示不了的属性（输出 43）只写名字；放不下时在末尾省略；没有属性时没有摘要。点这一行（切换按钮之外）展开或收起。展开时每个属性一行：类型图标、属性名、值，按 frontmatter 里的先后；最后一行是“添加属性”。
41. **记住展开**：打开文件时面板缺省收起。在一个文件上展开或收起之后，这部作品里再打开它（关掉标签、重开应用之后也一样）照这次的样子显示，别的文件不受影响；同一个文件在几个组里打开时共用这一份。frontmatter 写错（输出 45）时打开就展开，不看记着的样子。经输出 48 新建 frontmatter 时面板展开。
42. **改值**：点值就地改，输入按类型：文字是单行的文字框；数字是数字框，不是数的输入不写回；勾选是复选框，点了就写回；日期按年月日分段输入，也能点开日历选一天，周首日随界面语言；列表是一个个小块，改的时候每块带 ×，末尾接着打，回车或逗号（`,`、`，`、`、`）加一项，空着按退格删掉最后一项，重复的项与首尾的空白去掉。文字与数字在回车或焦点离开时写回；日期填满年月日或在日历里选了一天、列表每加或删一项时立即写回，年份不到 1000 的日期当作还没打完、不写回（1000 年以前的日期在源码里写）；清空写回空值（`名字:`）。悬停的一行与正在改的一行有底色，悬停的一行右边出“移除”。
43. **表示不了的属性**：值是映射、含映射或列表的列表、项上带注释的列表、多行文字、带锚点或标签的值，或者键不是普通的文字（`? …` 写出的键、合并键 `<<`）时，这一行的类型图标是“{ }”，值的位置是它的源码（一行，放不下时省略），只读；右端的按钮打开源码（输出 44）并把光标放到这一项的第一行。
44. **源码**：顶上一行的切换按钮把属性换成等宽的文字框，内容是开栏与闭栏两条 `---` 之间的 YAML，就地改；按钮的按下态表示正在看源码，再点回到按属性显示。焦点离开或按 Ctrl+Enter（macOS 上 ⌘Enter）时写回，开栏、闭栏两行原样保留。改出独占一行的 `---`（会让 frontmatter 提前结束）时不写回，留在源码里并标出原因；这时切回按属性显示，这次的修改放弃。YAML 本身写错照样写回，按输出 45 显示。
45. **写错**：frontmatter 读不成属性时（YAML 语法错、重复的键、顶层不是“名字: 值”的一项项而是列表、一段文字或写在一行里的 `{…}`、几个 YAML 文档、文档标记或指令 `...`、`%YAML`、`--- 内容`），面板显示源码，出错的那一行带波浪线，下面写出行号与原因，并说明改好之前按源码显示；这时没有“添加属性”，不能切回按属性显示。收起时摘要换成一句出错的提示。改好写回后回到按属性显示。
46. **改类型**：点一行的类型图标出菜单：文字、数字、勾选、日期、列表，当前的打勾。只能换成不丢信息的类型，其余置灰：空值能换成任何类型（列表为空、勾选为不勾）；文字换数字（文字是一个数）、换勾选（文字是 `true` 或 `false`）、换列表（整段文字成为一项）；数字、勾选换文字；不多于一项的列表换文字。有值的日期不能换（写成文字后仍会读成日期）。换了以后值按新类型写出（数字换文字后带引号）。空值换成文字、数字或日期后，这一行在这次打开期间按选的类型输入；文件里仍是空值，下次打开按文字显示。
47. **添加、改名与移除**：点“添加属性”在末尾多出一行，焦点在它的名字上；打完名字按回车或焦点离开时写回 `名字:`（空值），按回车写回的焦点移到它的值；名字为空时不加，与已有的属性同名时不加并提示已有。点属性名就地改名，回车或焦点离开时写回；为空或与别的属性同名时恢复原名；表示不了的键不能改名。点“移除”删掉这一行，连同它的行尾注释，上方的注释留着。
48. **新建 frontmatter**：命令 `nbook.edit.properties`（“添加属性”：命令面板、斜杠菜单“块”组的末尾、工具栏的“⋯”）：没有 frontmatter 时在文件开头建一个空的（开栏、闭栏两行，换行符同文档；只用单独回车换行的文档用 `\n`），面板展开，焦点在新属性的名字上；已有时展开面板，焦点在新属性的名字上。在没有 frontmatter 的文档里，第一块的光标前只有刚打出的 `---`（或被自动替换成的 `—-`）时，这三个字符不留在正文里，同样建一个空的 frontmatter，光标后原有的文字仍在第一块。新建之后、还没有属性时，在空着的新属性名上按退格：用 `---` 新建的撤回这次新建，正文里还原成 `---` 文字；用命令新建的只把焦点交回正文。已有 frontmatter、或不在第一块里时，`---` 照旧是分割线；要在文件开头放分割线，用 `***`。
49. **撤销与外部修改**：面板的每次写回（改值、改名、添加、移除、改类型、源码）与新建 frontmatter 各是一个撤销步，和正文的编辑在同一条历史里：焦点在正文里时 Ctrl+Z、Ctrl+Y（工具栏的撤销、重做）撤销与重做，撤销新建时面板消失。焦点在面板的输入框里时 Ctrl+Z 是输入框自己的撤销，只撤还没写回的输入。面板里还没写回的输入算作这个编辑器还没交出的输入（[`workbench.editor`](editor.md) 输出 63）：保存、换文档与结算之前先写回。别处改了 frontmatter（磁盘、另一组）时面板跟着换，这次替换不进撤销历史。
50. **键盘**：在正文第一块的开头按上方向键，焦点进面板的最后一个输入（展开时是“添加属性”，收起时是顶上一行）；面板里 Tab、Shift+Tab 在各个输入之间走，上下方向键在属性之间走（日历、列表的输入在用这两个键时归它们）；在最后一个输入按下方向键、或按 Esc，焦点回到正文刚才的位置，正在改的输入照常写回。输入法组字时的回车与 Esc 归输入法。
51. **只读与写不出**：文档只读时面板照常显示、收起与展开，值不能改，没有“添加属性”、“移除”与类型菜单，源码只能看；在改的时候文档变成只读，还没写回的输入放弃。写不出（[`workbench.editor`](editor.md) 输出 61）期间面板照常能改，它的修改与正文一起等写得出时交出。
52. **链接卡片**：入口是选区菜单与工具栏的链接按钮、快捷键 Ctrl+K（macOS 上 ⌘K，焦点在正文里时；输入法组字中不响应）。在选区下方开一张与注音卡片同样子的一行卡片（宽到放得下一个网址，窄屏夹在窗口内），只填地址：回车或点确定写回，Esc 取消，焦点离开时收起，清空再确认等于取消，输入法组字时的回车与 Esc 归输入法；卡片开着时原来的选区仍画成选中的样子（没有选区时在光标处画一条竖线），选区菜单不显示。**加链接**：选着文字时，选中的字成为链接文字；没选字（光标处）时插入一段链接，文字取这个地址指向的作品里文件的名字（去掉扩展名），外部网址取网址本身。**改链接**：光标在链接里、或选区碰到链接时，卡片预填这条链接的地址，确认时改所有碰到的链接的**整条**地址（选区只盖住链接的一部分也一样，不把链接切成几段；链接里夹着图片、或只含一张图片的链接，图片也在这一条里）；确定按钮左边多一个“去掉链接”（`nbook.edit.link-remove`），去掉碰到的整条链接、文字留着；碰到的几条链接地址不同时不预填、不能确认，只能去掉链接。地址原样写下，只有 `project://` 开头的作品地址改写成相对当前文件的写法（输出 57）。像域名的输入（`www.example.com`）不自动补方案，会按相对文件地址写，这是已知限制。
53. **打开链接**：按住 Ctrl（macOS 上 ⌘）点链接才打开；单击照旧：点在链接上选中被点的整条链接（Shift、Alt 加点不接手），接着按 Ctrl+K 改地址、或直接打字替换链接文字；浏览器自己不跟随编辑器里的链接（只读文档里单击也不被带走）。地址指向作品里的文件或用户资产的（相对地址、`/` 开头的地址、`project://` 与 `user://` 开头的，分类同 [`workspace.markdown-dialect`](../workspace/markdown-dialect.md) 输出 27）在编辑器区打开那个文件（文件不在时与别处打开不存在的文件一样：开一个标签，编辑区显示读取失败，不另给通知）；外部网址（`http:`、`https:`、`mailto:`）在新标签页打开；别的方案不动作。一段文字同时是链接与批注时，Ctrl 点只打开链接（批注用小符号或按住 Ctrl 悬停看，输出 30）。只读文档同样能打开。
54. **插图卡片**：入口是工具栏的图片按钮与斜杠菜单“块”组里的“图片”（`nbook.edit.image`）。在光标下方开一张卡片，光标处画一条竖线标出图会插在哪里：顶上一行输入，下面是图片列表，右边是“上传”按钮。输入为空时列出存放目录（输出 56）里的图片，名字倒序（粘贴的图按时间命名，所以大致是新的在前），至多 12 张；输入文字时按名字在整部作品里找图片，至多 12 张；输入的是 `http://` 或 `https://` 开头的网址时列表只有一行“插入网址的图片”。列的“图片”是扩展名为 png、jpg、jpeg、gif、webp、svg、avif、bmp 的文件（不分大小写）。每一行是缩略图（懒加载，加载失败时是占位图标）、名字与所在目录（名字过长截中间、目录过长截开头）；上下键移动、回车或点击插入，图片插在光标处，说明取文件名（去掉扩展名），写成相对当前文件的地址（输出 57）。列表在读取中显示“正在读取”，没有结果显示“没有匹配的图片”，读不了显示原因；查到的比显示的多（`truncated`）时末尾有一行“还有更多，请输入更多字”；回车时没有选中项什么也不做。“上传”打开系统的选文件框（只列 PNG、JPEG、GIF、WebP），选了就复制进存放目录（保留原名，输出 56）再插入；传的过程中“上传”置灰，Esc 取消这次上传。系统的选文件框开着时不算焦点离开，卡片不收。Esc 取消，焦点离开时收起；输入法组字时的回车与 Esc 归输入法。
55. **粘贴图片**：在正文里按 Ctrl+V（macOS 上 ⌘V；Ctrl+Shift+V 是纯文字粘贴、不处理图片；Shift+Insert 是普通粘贴，同 Ctrl+V）时，剪贴板里有图片文件、而文字部分没有实质内容的，每张图片存进存放目录（输出 56）并插入。“文字部分没有实质内容”指：纯文字去掉空白后为空，或每一行都只是某个文件的名字、路径或 `file://` 地址（从文件管理器复制文件）；HTML 去掉标签后没有文字（从网页、Word 里复制一张图）。从网页复制的图也存进作品，不留外链。剪贴板里另有实质的文字（表格软件复制的单元格、图文混排）时仍照原来的粘贴。**插入的位置**：光标在不在表格里的空段落时，几张图各占一段；其余位置（有字的段落、标题、列表项、表格单元格）依次插在光标处、图之间不加字符；代码块、原样块里（以及选区跨块、选在节点上）不能放图片：不上传，这次粘贴被吞掉（文件管理器复制文件时的文件名也不粘进去），给一条“这里不能插入图片”的通知。**时序**：图片一张接一张地传（所以同一秒粘贴的几张，序号与剪贴板里的先后一致）；开始粘贴时在光标处出现占位（“正在上传 N 张图片”，弱色斜体、选不中，随文字改动移动），每张传完就把它换成图片，全部传完占位消失；传的过程中可以继续打字；切到别的文件、文档被关闭、变成只读、控件被卸载时没传的不再传（换回来也不接着传，占位不再显示）、已传完而没来得及插入的保留在作品里并给出通知。图片的类型在传之前按浏览器给的类型判定，不是 PNG、JPEG、GIF、WebP 的不上传。一张失败（过大、格式不支持、名字不合规、作品里这个目录写不了、结果未知、没有连上服务）不影响别的：成功的照常插入，失败的各给一条通知，写明是哪一张与原因；“结果未知”的通知说明这张图可能已经写进存放目录。只读文档不处理，照原来的粘贴。
56. **图片存放与命名**：按设置 `nbook.editor/imageLocation` 决定存进哪个目录：`folder` 是作品根下的 `imageFolder`（缺省 `插图`，没有就建出来）；`root` 是作品根；`same` 是当前文件所在的目录；`sibling` 是当前文件所在目录下的 `imageFolder` 子目录。`imageFolder` 可以是几级目录（`资源/插图`），不能以 `/` 开头、不能含 `..`、不能在控制目录 `.nbook` 下，不合规时按缺省 `插图`（设置窗口里也能存下不合规的值，这是用到时才判断的）。选的本机文件保留原来的名字（JPEG 的扩展名不是 `.jpg`、`.jpeg` 时改成 `.jpg`，例如 `.jfif`）；粘贴的图叫“粘贴的图片 年月日-时分秒”加按类型定的扩展名（PNG 是 `.png`，JPEG 是 `.jpg`，本机时间，例如 `粘贴的图片 20261117-140533.png`），不随界面语言变；本机文件的名字不合规（含不允许的字符、过长）时这一张失败并给出通知。目标已有同名文件时不覆盖，名字后加序号（`名字 2.png`、`名字 3.png`），图片格式、大小与不覆盖的规则同 [`workspace.files`](../workspace/files.md) 的“写入图片”。图片存成普通图片文件。已知限制：当前文件在内容文件夹里时，`same` 与 `sibling` 存下的图是内容树里的未列入项，`sibling` 建出的子目录是没有正文的节点（见 `workspace.files`）；缺省的 `folder` 不受影响。
57. **地址的写法**：在富文本里新建指向作品里文件的链接或图片，写相对当前文件的地址（`插图/a.png`、`../设定/林雪.md`），规则见 [`workspace.markdown-dialect`](../workspace/markdown-dialect.md) 输出 18；文件名里的 `%`、`#`、`?` 与空格、括号按方言读取一侧的规则编码，第一段含 `:` 的地址写成 `./` 开头，使写下的地址读回来指向同一个文件。当前文件挪动或改名后，相对地址不跟着改（链接按新位置读）。当前文件在 `user://` 下时没有作品，不改写 `project://` 地址，图片的上传与按名字找图也不可用（输出 58）。
58. **只读与不可用**：文档只读时链接卡片与插图卡片都不出现，工具栏的链接与图片按钮置灰，Ctrl+K 不响应，粘贴图片不处理。插图的能力有三种状态：宿主没有提供（Lab、不带编辑器区的场景）时，插图卡片仍能打开、只能插入网址的图片，“上传”置灰，粘贴截图时照原来的粘贴；宿主提供了、但没有绑定作品时，列表为空、“上传”置灰，粘贴截图给出通知；绑定了作品时按输出 54 到 56。
59. **属性的图标、显示名与类型的贡献**：贡献点 `markdown.properties`（`nbook.markdown` 拥有，只有声明，写在贡献方插件描述的顶层 `contributions` 里，浏览器与项目两个位置都登记；贡献 id 以贡献方的插件 id 加 `.` 开头）。声明 `{name, icon?, label?, kind?}`：`name` 是属性名，精确、区分大小写地等于 frontmatter 里键的文字，非空、不含控制字符，对整部作品里的所有 Markdown 文件生效，不分文件夹类型；`icon` 是 Iconify 类名（形如 `i-lucide-user`）；`label` 是文字（字符串、文字引用或按语言的表，同其它贡献的文字），按当前界面语言取出来是空的（空串、没有当前语言的条目、只有空白）按没给；`kind` 是 `text`、`number`、`checkbox`、`date`、`list` 之一（不含表示不了的“{ }”）；三项至少给一项，别的字段不收（以后只追加）。几个声明给同一个名字时，贡献 id 码元顺序最小的那一条整条生效，其余忽略。
60. **属性面板怎样用它**：声明的 `icon` 换掉这一行的类型图标（表示不了的属性的“{ }”不换：它说的是这一行只读），它仍是改类型的按钮，点了出同一个类型菜单（菜单里每种类型的图标不变，当前类型照旧打勾），按钮的提示与可访问名称写出当前类型；声明的 `label`（按当前界面语言取文字，语言切换时跟着变）显示在属性名一列、收起时的摘要与各输入的可访问名称里，名称的提示与名字按钮的名称带真名（“显示名（真名）”），点名字改名时输入框里是真名、写回的是真键；没有声明的属性与没给的字段照旧（输出 40、47）。声明的 `kind` 只管值为空（`名字:`）的行：这一行按它输入（日期输入、数字框、勾选框、列表输入），不改文件；这次打开期间用户在类型菜单里选过的类型盖过声明，声明盖过缺省的文字。有值的行仍按值推断，声明不改它；值与声明的类型不符时（声明日期、值是一段文字）照值显示，不报错也不改写；类型菜单的规则（输出 46）不变，声明不让别的项置灰。声明的 `kind` 为 `checkbox` 时，空值的行显示成不勾选，点了才写回。
61. **不合格与冲突**：声明不合格（`name` 为空或含控制字符、三项都没给、`kind` 不在五种之内、`icon` 不是类名、贡献 id 不带插件前缀、有别的字段）被贡献点拒绝（`invalid-declaration`，原因可向插件宿主查询，见 [`runtime.plugins`](../runtime/plugins.md) 输出 15），不生效，也没有诊断（运行时的校验与查询不产生诊断）；同名冲突（输出 59）时被忽略的声明各记一条诊断（`markdown.properties.conflict`，同一对不重复记）。摘要与各行用同一份声明，属性列表或界面语言变化时重查；插件装卸之后，面板下一次重查时生效，面板正显示着时插件增减不即时重画（已知限制）。冲突诊断在面板第一次用到这个名字时记，每个窗口同一对只记一次，没有文件用到它就不记；显示名与别的属性的名字或显示名相同时不处理，名字一列写同一个词，悬停提示带真名（已知限制）。贡献的图标类名要在构建里有对应的样式（同菜单贡献的 `icon`，静态扫描源码里的类名），没有构建进应用的第三方插件的图标可能不显示。
62. **表情**：工具栏与斜杠菜单的“表情”打开表情选择器，打 `:` 弹出表情补全，行为见 [`agent/stickers.md`](../agent/stickers.md) 输出 39 到 43；选定的表情插在光标处（有选区时替换），是一个表情节点（`agent/stickers.md` 输出 21）；菜单层直接用编辑动作 `sticker`，与命令 `nbook.edit.sticker` 同一个实现，参数不是一个完整写法时不插。选择器锚在光标（同插图卡片）；从斜杠菜单打开时先删掉 `/查询`。只读文档、代码块与行内代码里不出补全，按钮置灰。
63. **可嵌入的编辑组件**（planned）：`nbook.markdown` 的服务另交出一个不绑定文件的富文本编辑组件，给别的插件的页面用（条目的主文字，[`canon/author-ui.md`](../canon/author-ui.md) 输出 39）。输入是一段 Markdown 源文字与调用方加的语法：语言是核心语法加这些语法，不带项目方言。停止输入 150 毫秒后与失焦时把写出的源文字交给调用方，往返照 [`workspace/markdown-dialect.md`](../workspace/markdown-dialect.md) 输出 1 到 4；写不出时不交，把原因交给调用方。调用方换了源文字、与编辑器现在写得出的不同时按新的重载，这次替换不进撤销历史。工具栏、选区菜单、斜杠菜单与章节的相同，动作作用在这个组件自己的编辑器上，语言里没有的动作（批注、注音、双语、表情）不显示；Ctrl+S 交给调用方。只读时不能输入，不显示工具栏与菜单。调用方可以让它在光标处插入一段源文字。

## 状态与转换

菜单状态都按控件实例算，没有持久化（工具栏显隐与颜色按钮记住的颜色除外）。

时序与寿命：

- 换文档、切标签：所有浮动菜单与块按钮收起，查询作废；批注卡片（含“写”里没保存的字）同样收起。页边按新文档重排。属性面板里还没写回的输入先写回，再换成新文档的面板。
- 编辑组的布局变化让控件重挂：菜单状态清空，编辑器实例与撤销历史不变，重挂后各菜单照常工作。
- 编辑器插件停止：命令与菜单项撤回；打开着的菜单关闭。
- 命令经活动控件执行；点工具栏按钮时这一组先成为活动组（[`workbench.editor`](editor.md)），所以目标就是被点的组。

## 副作用与数据

动作的副作用就是编辑（进撤销历史，第 15 条的除外），写回规则见 [`workspace.markdown-dialect`](../workspace/markdown-dialect.md)。设置 `nbook.editor/markdownToolbar` 随设置保存。卡片开着时画出的选区不是编辑，不进撤销历史，不写进文件；输出 32 的标出同样。批注的加、改、删是编辑，进撤销历史。

页边开关（输出 33）存在项目分区的本机记录 `editor.comment-margin`（`nbook.editor` 拥有，第 1 版，`{on: boolean}`，缺省关），按作品记，不进作品目录、不跟用户层。记录读不出或已损坏时按关，这时切换不记；保存失败或结果未知时只改这次运行里的显示，不重试也不提示；没有绑定作品时只在这次运行里记住。

颜色按钮记住的颜色（输出 1）存在用户级、只在本机的记录 `markdown.colors`（`nbook.markdown` 拥有，第 1 版，`{text?: string, highlight?: string}`，值是 `#rrggbb`），不进作品目录。记录读不出或已损坏时按缺省颜色，这时选了颜色也不记（存储不覆盖读不出的记录）；保存失败或结果未知时只改这次运行里的显示，不重试也不提示（这是偏好，不是要用户处理的数据）；应用没装存储服务时只在这次运行里记住。

属性面板的修改是编辑，写进文件的 frontmatter（写回规则见 [`workspace.markdown-dialect`](../workspace/markdown-dialect.md) 输出 28），进撤销历史。展开状态（输出 41）存在项目分区的本机记录 `markdown.properties-open`（`nbook.markdown` 拥有，第 1 版，`{open: string[]}`：展开着的文件的地址，至多 200 个、不重复，最近展开的在前，再多时去掉最旧的；收起即去掉），按作品记，不进作品目录；几个窗口同时改不同的文件时都记得住。记录读不出或已损坏时按收起，这时切换不记；保存失败或结果未知时只改这次运行里的显示，不重试也不提示；没有绑定作品时只在这次运行里记住。

## 失败与恢复

| 情形 | 结果 |
|---|---|
| 命令执行时活动控件没有 `editing`，或动作此刻不可用 | `unavailable`，原因是文字值 |
| 右键粘贴读不到剪贴板 | 输出 23 的通知，文档不变 |
| 拼音库加载失败 | 记诊断，继续只按名称筛选 |
| 卡片的“保存”“删除”时，在最新的文档里找不到这条批注（序号处的批注指纹对得上就是它；对不上时在整份文档里找指纹相同的，只有唯一一条才算；意见或开头文字变了、或有几条指纹相同都找不到） | 不执行，文档不变，卡片收起，“写”里没保存的字放弃 |
| 块菜单的“批注”保存时，这一块已经包不进批注块（例如被别处改成了不允许的结构） | 动作返回失败，卡片留在“写”里，字还在，不关成“已保存”（同输出 28 的失败行为） |
| 贡献的命令不在目录里 | 不显示（[`workbench.menus`](menus.md) 输出 1） |
| 属性声明不合格（输出 61） | 被贡献点拒绝，原因可查询、不记诊断；面板按没有这条声明显示 |
| 属性声明同名冲突被忽略（输出 61） | 记诊断 `markdown.properties.conflict`；id 最小的那条照常生效 |

## 边界与兼容

- 公开接口：命令 id、公开键、五个菜单位置、`EditorEditing`、控件句柄的 `comments`（输出 33）。字段只追加。
- 信任边界：菜单项只能引用命令；位置只给 `{address}`，不给选区内容。
- 命令表以外的 Tiptap 快捷键不是这份合同的一部分。

12. Given 两条批注，When 按住 Ctrl 把鼠标停在第一条上、点卡片的编辑、把意见改成新的并保存，Then 文件里第一条的意见变了、第二条不变；When 再点编辑、清空后保存，Then 意见保持；When 点删除，Then 文件里这句没有批注标记、字还在；When 鼠标移出批注与卡片，Then 卡片收起。

Given 三条批注，When 按住 Ctrl 把鼠标停在第二条上，Then 卡片立刻出现、写着“第 2 条，共 3 条”，左边缘对齐这条批注在这一行的起点、贴在这一行下面；When 点“下一条”，Then 光标到第三条开头、卡片换成第三条，下一条按钮置灰；When 不按 Ctrl 把鼠标停在批注上、用鼠标点或方向键走进一条批注、在批注中间连打几个字、在末尾继续打字，Then 卡片都不出现；When 点批注末尾的小符号，Then 卡片出现、鼠标移开后仍在、光标位置与正文焦点不变，点正文别处、点卡片之外或按 Esc 时收起，再点一次同一个符号也收起；When 按 Ctrl 悬停出来的卡片被点正文或打字收起，Then 指针不动卡片也不回来；When 按 Esc 收起卡片后指针没动，Then 卡片不回来，移开再回到批注上才重新算；When 鼠标从批注移向卡片途中经过空白，Then 卡片不收；Given 两条紧挨的批注，When 点前一条卡片的“下一条”，Then 卡片换成后一条。

- 不变量：动作目录不引 Tiptap，插件入口静态引用它，首屏不含编辑内核；目录里的每个动作都有实现（`MarkdownControl.dom.test.ts`）。

- 不变量：注音整体（输出 26）在注音语法自己的 ProseMirror 插件里补，按加标记、去标记的步认，不在各个命令上补：格式的入口有编辑动作、编辑内核自带的快捷键与输入规则，最后都落成这两种步（`nb-markdown/src/language/syntax/ruby/whole-ruby.ts`，`whole-ruby.dom.test.ts`）。

- 不变量：批注的数据操作（列出、按序号与指纹找、改意见、去掉、跳到上一条下一条、光标处的批注）在 `nb-markdown/src/editor/comments.ts`，按文档里的标记与块批注节点算，不依赖界面；每个事务同步重算，不缓存、不防抖（五万字、两百条批注的全文扫描约 0.1 毫秒）。一条批注的各截是同一个 `key`（读入时按文件先后编号，排序比较其中的数），块批注没有 `key`，所以对外用序号加指纹找（序号只在一个事务内有效，指纹是意见与被批注的开头文字），指纹对不上就不执行（输出 29 的失败行为），因为控件拿不到“正文是不是被程序重载过”的可靠信号（重载与写回回填走同一条不进历史的事务）。改意见只动目标标记实例并保持别的批注标记的先后，去标记只去目标实例，不按标记类型删（盖住同一段的别的批注会一起没）；`comments.dom.test.ts` 含分截、块、重叠、列表与引用里的块批注。改意见、去标记、加批注各是一个事务。
- 不变量：批注卡片是一个组件，浮层与页边共用（`MarkdownCommentCard.vue`）；两处的区别只在摆在哪里：浮层用 `AnchoredPopover`（`align="start"`）锚在被批注文字所在的那一行，页边是稿纸右边按段排的一列槽位，与稿纸同在滚动容器里，所以随正文滚动、不另算滚动偏移。按下不夺焦、焦点离开的判断（含窗口失焦不算离开）写在卡片里，浮层与页边一样；快捷键只处理来自编辑器 DOM 的事件。页边画不画由 `MarkdownControl` 量 `.markdown-control-root` 的容器宽度（不含滚动条，带迟滞）算出一份，下传给版心让位、页边、浮层与场景图，不各自量；拆分后每组各自判断，不读窗口宽度。折叠的提示块里的批注取提示块的标题行定位（折叠内容没有盒子，`coordsAtPos` 取不到）。
