# 世界引擎：故事时间

## 目标与非目标

作者能精确记时间（“王历 612 年霜月 5 日清晨”），也能粗略地记（“十五岁那年”“三天后”“三百年前”），还能查（这件事大约什么时候、第 8 章写到的是哪几天、她当时几岁、这几件事打不打架）。本能力定义历法、时间说法、由说法算出时间范围与矛盾的规则，以及查询。历法、说法、计算与查询在无依赖的包 `nb-time` 里，nb-canon 用它给剧情变更算时间。取舍见 ADR 0043（`docs/adr/0043-world-engine-placement-and-telling-orders.md`）。

时间不决定折叠：状态仍按安放折叠（[`canon.model`](model.md) 输出 2），安放的先后也不进时间的计算。

不承诺：

- 按故事时间读状态（“那天她有多少钱”）。
- 同一部作品几套历法并存。
- 中文时间说法的自动解析：说法由写入者（作者或记账）写成结构化的形状。
- 天文历法（按月相、节气算的月份）：月的天数只能由规则给出。

## 术语与参与者

- **历法**：作品设置里的数据：时间单位、各月、闰年规则、纪年、时段，带版本（输入）。
- **说法**：剧情变更上关于时间的一句话的结构化形状，带原话与依据；一件事可以有几条，同时成立。
- **绝对时间**：从历法的元年起的整数个最小单位（缺省是分钟）；只在计算时用，不存。
- **范围**：一件事最早、最晚可能在什么时候，带依据（是哪几条说法定下的）。
- **打架**：几条说法不可能同时成立。
- **模糊词表**：作品设置里“几天”“不久”“多年”“约”这类词对应的范围。

## 输入与前置条件

**历法**（宿主从作品设置给出；没设置时用内置的公历）：

| 项 | 规则 |
|---|---|
| `version` | 正整数，作者每次改历法加一 |
| `unit` | 最小单位：`minute`（缺省）、`hour`、`day` |
| `hoursPerDay`、`minutesPerHour` | 一天几小时、一小时几分钟，正整数 |
| `months` | 月的列表，每项 `{id, name, days}`；`id` 稳定，改名不改 id |
| `leap` | 闰年规则的列表，每项 `{every, offset?, months: {月 id: 天数}}`，按顺序检查，后面的覆盖前面的（公历：每 4 年二月 29 天，每 100 年回到 28 天，每 400 年又是 29 天） |
| `eras` | 纪年的列表，每项 `{id, name, start}`：这一纪的元年是绝对年份 `start`；绝对年份可以为负 |
| `periods` | 时段的列表，每项 `{id, name, from, to}`（时，`to` 可以小于 `from` 表示跨夜） |

**模糊词表**：`{词: 间隔}`，另有“约”按精度给出的放宽量（`approx: {year, month, day, hour}`，各是一个数，单位就是那一级）。

**间隔**：`{min?, max?, unit}` 或 `{word}`。`unit` 是 `minute`、`hour`、`day`、`month`、`year`；`min` 缺省 0，`max` 缺省无穷，`min` 不大于 `max`，都是非负整数；`{word}` 按模糊词表换成前一种，词不在表里时这条说法按输出 3 不成立。说法里的 `gap`、`lasts`，分叉的 `back`（[`canon.worldlines`](worldlines.md)）都用这个形状。

**说法**（剧情变更的 `when`，列表，每项带 `quote?`（原话）与 `basis`（`told` 里的讲述 id、作者给的、或推断）：

| `kind` | 其余字段 | 约束（这件事记作 E，起点 E.s，终点 E.e） |
|---|---|---|
| `date` | `{era?, year?, month?, day?, period?, hour?, minute?}`、`approx?`、`uncertain?` | E.s 落在这个日期单位里（给到哪一级，精度就到哪一级）；`approx` 按模糊词表放宽；`uncertain` 只标记，不改范围 |
| `after`、`before` | `of`（剧情变更 id）、`edge?`（`start` 缺省或 `end`，指 `of` 的哪一端）、`gap?`（间隔） | E.s 减（或被减）`of` 那一端落在间隔里；没有 `gap` 时间隔是零到无穷 |
| `lasts` | 间隔 | E.e 减 E.s 落在里面；没有这条说法时 E.e = E.s |
| `age` | `who`（条目引用）、`years: {min, max}` | E.s 减 `who` 的出生落在 `[L_min(min), L_max(max + 1))`（输出 12） |
| `birth` | `who` | 这件事是 `who` 的出生 |

- 月、年的长度随历法变：n 个连续的年（月）的总长度，在历法里有最短的 `L_min(n)` 与最长的 `L_max(n)`（由闰年规则决定）；以年（月）为单位的间隔 `{min, max}` 取 `[L_min(min), L_max(max)]`。
- 日期说法给的最细一级不能比历法的最小单位更细：`unit` 为 `hour` 时不能给 `minute`，为 `day` 时不能给 `hour`、`minute`、`period`（写入时拒收，`invalid-time`）。
- 说法存的是作者按历法写的形状（纪、年、月 id……），不存绝对时间。

## 输出与可观察行为

1. **网络。** 每条世界线（[`canon.worldlines`](worldlines.md)）各算一份：这条线视图里生效、不是叙述的剧情变更是事件，每条说法是事件之间（或事件与元年之间）相差的一个范围；按实际模式只用已写的，按计划模式再加上计划。由此算出每件事起点与终点的范围与依据（定下最早、最晚的那几条说法）。没有任何说法连到元年的事件，范围是相对的：只能回答与别的事件相差多久。
2. **打架与局部降级。** 按连通分量算：一个分量里的说法不可能同时成立时，环上的说法标“打架”，各成一条待处理 `time-conflict`（同一个环合成一条，列出环上的说法、原话与所在的变更）；这个分量里的事件范围都是“不可确定”，带原因；别的分量照常。
3. **历法里不成立。** 说法在当前历法里不成立（月 id 不在、日子超出这个月的天数、时段 id 不在、纪 id 不在）时，单独标出、不进网络，各成一条待处理 `time-invalid`。
4. **改历法与词表。** 历法或模糊词表变了，所有范围、打架与依据按新的重算；存下来的说法不改。
5. **安放与时间对不上。** 同一条线上，按安放 A 在 B 之前，而按时间 B 一定早于 A（B 的最晚早于 A 的最早），成一条待处理 `time-placement-mismatch`，列出两件事、各自的范围与依据。时间不改变折叠。
6. **世界线上的时间。** 回溯分叉有 `back` 时，子线的网络里多一个点 R（回溯到的那一刻）：R 减触发处那件事的起点落在 `[-back.max, -back.min]`；子线自己的事件都不早于 R；子线上的事件只和它视图里的事件（切口之前的共同过去）比先后，兄弟线之间不比。切口那件事一定晚于这一刻时，成一条待处理 `fork-time-mismatch`。
7. **前史的先后。** 写入一条前史变更、没给前史里的先后时，按它的时间范围的最早时间排进已有的前史（最早时间相同的排在后面；排不出的放在前史最后），写入时算好存下（[`canon.revisions`](revisions.md) 输出 18 的同一处）。
8. **查询。** 在给定的线与模式上：
   - 一件事、一章（安放在这一章的事件合起来）的范围与依据；
   - 一段时间（按历法写的两端）里一定发生、可能发生的事件；
   - 两件事相差多久（范围）；
   - 某人在某件事时几岁（范围，从他的 `birth` 事件算；没有出生事件时答“不知道”）；
   - 按纪、年、月、日逐级列出这一级里一定、可能发生的事件的数目与列表。
   结果的时间按历法的写法给出，精度到依据能确定的那一级（“王历 612 年霜月”“约 15 岁到 16 岁”）。
9. **校验。** 写入时，说法的 `of`、`who` 指向这条线视图里存在的剧情变更与条目，`years`、间隔的 `min` 不大于 `max`，同一件事最多一条 `birth`、一个人最多一件出生事件；不过整次拒收（`validation-failed` 的详情 `invalid-time`）。说法打架与历法里不成立不拒收，按输出 2、3 成待处理。叙述（[`canon.model`](model.md) 输出 30）不能有说法。
10. **确定。** 同一份世界版本、同一历法与词表，算出的范围、打架与依据逐字相同。
11. **速度。** 在 [`canon.project`](project.md) 输出 14 的参考机器与模拟世界上（三成的剧情变更有一到两条说法），发布之后第一次时间查询 1 秒以内；同一版本上之后的查询 20 毫秒以内。时间在第一次用到时才算，不挡发布。
12. **年龄。** 问某人在某件事时几岁：这件事有关于他的 `age` 说法时，答说法里的岁数；否则取这件事起点减他出生的范围 D，答所有“D 里有一个值满足 `L_min(k)` ≤ 值 < `L_max(k + 1)`”的整数 k：只有一个就答“k 岁”，几个就答“k 到 k′ 岁”。不按周年、生日算。
13. **历法的校验。** 历法合法当且仅当：`hoursPerDay`、`minutesPerHour` 是正整数；月、纪、时段的 `id` 各自不重复；每个月的天数是正整数；闰年规则的 `every` 是正整数、`offset` 是 0 到 `every - 1` 的整数，指到的月都在、天数是正整数；纪的 `start` 是整数、按 `start` 严格递增；时段的 `from`、`to` 是 0 到 `hoursPerDay - 1` 的整数。不合法时用上一个合法的历法，写诊断 `calendar-invalid` 指出哪一项；从来没有合法的历法时用内置的公历。

## 状态与转换

- 范围、打架、依据都在读取时算出，按世界版本、历法版本与词表缓存；没有自己的状态。
- 说法随它所在的剧情变更由修订写入与还原。

## 副作用与数据

- 说法存在剧情变更的 `when` 里，随修订写进世界日志。历法与模糊词表在作品设置里（位置随项目布局定），不进世界日志。
- 绝对时间只在内存里用 JS 的数表示；跨度极长的世界把最小单位设成时或天。

## 失败与恢复

| 码 | 含义 | 调用方怎么办 |
|---|---|---|
| `invalid-time` | 说法的引用、范围或出生事件不合规则（`validation-failed` 的详情） | 按详情改 |
| `time-conflict` | 待处理：几条说法不可能同时成立 | 改其中一条说法，或把一件事挪到别的线 |
| `time-invalid` | 待处理：说法在当前历法里不成立 | 改说法，或改历法 |
| `time-placement-mismatch` | 待处理：安放的先后与时间的先后对不上 | 挪安放、标平行或改前史的先后 |
| `fork-time-mismatch` | 待处理：回溯的切口晚于回溯到的那一刻 | 改切口或往回多久 |
| `calendar-invalid` | 诊断：作品设置里的历法不合规则（月的天数不是正整数、闰年规则指向不存在的月），继续用上一个合法的历法 | 改作品设置 |

## 边界与兼容

- 公开接口：说法的形状（存进世界日志）、历法与模糊词表的形状（作品设置）、查询的结果、`nb-time` 的导出（历法的校验、说法的校验、网络的计算与查询、按历法格式化），nb-story 用同一个包。
- `nb-time` 没有运行时依赖，前后端共用。

## 验收与 Smoke

1. **自定义历法。** 一天 48 小时、12 个月各有名字、每 3 年第 12 月多 1 天的历法：“王历 612 年霜月 5 日清晨”算出的范围是那一天清晨的那几个小时；“5 日之后三天”落在 8 日；把霜月改名，说法照常；删掉霜月，这条说法成 `time-invalid`，别的照常。
2. **粗略与年龄。** 星瑕出生是前史里的一件事（公历 1997 年 3 月 1 日），“十五岁那年”的事算出的范围从 2012 年 2 月底起、到 2013 年 3 月初止（不含）；问这件事时星瑕几岁，答 15 岁（取说法里的岁数）。另一件没有年龄说法、定在 2012 年 6 月的事，答 15 岁。没有出生事件的人答“不知道”。
3. **打架与局部降级。** A 在 B 之后三天、B 在 C 之后两天、A 在 C 之前：这三件事都“不可确定”，一条 `time-conflict` 列出三条说法；同一时刻另一组没连在一起的事件照常给范围。
4. **安放与时间。** 第 3 章的事在第 5 章的事之后“十年”：成 `time-placement-mismatch`；把第 3 章那件挪进前史后消失。
5. **回溯。** 第 8 章末尾回溯“往回半天”：子线上第一件事不早于触发处减半天；切口安放在第 8 章早上但时间说法定在第 8 章傍晚：`fork-time-mismatch`。

Smoke：不适用——由 `nb-time` 的包测试与 [`canon.project`](project.md) 的 Smoke 覆盖。
