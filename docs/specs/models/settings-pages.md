# 模型服务的设置页

## 目标与非目标

设置窗口 AI 分组下的两页：“服务商与模型”添加服务商、填密钥、管理模型并检测，“模型角色”给角色绑模型。两页的数据与写入全部经远程合同 `nbook.models/settings`（[`models/service.md`](service.md) 输出 12），改了就写，没有“未保存”状态。

不承诺：

- OAuth 登录、发现方式、兼容选项、扩展窗口、用命令取密钥（同 [`models/service.md`](service.md) 的非目标）。
- 本作品标签下编辑：两个设置项只允许用户层，本作品标签下两页停用（[`settings/settings-window.md`](../settings/settings-window.md) 输出 8 的 page 分区规则）。
- 价格以外的用量统计。

## 术语与参与者

- **数据模块**：两页共用的非组件模块，持有快照、密钥状态与检测、发现结果，所有写都经它调远程方法。
- **选用数据**：`nbook.models/shared` 里的纯 TS 工厂，按服务商分页读模型行（[`models/service.md`](service.md) 输出 23）并缓存；设置页的数据模块与 Agent 插件（模型选择器、Profile 页）各建一份。
- **被角色用着的模型**：某个角色绑定的模型；判断用 `nbook.models` 的共享纯函数，服务端解析与页面同一份。

## 输入与前置条件

- 两页是 `nbook.models` 浏览器入口贡献的 page 分区（贡献点 `settings.pages`），分区 id `nbook.models.providers`、`nbook.models.roles`，分类 `ai`，`layout: "fill"`，`layers: ["user"]`；`nbook.models/providers`、`nbook.models/roles` 两个设置项指向它们。
- 远程合同不可用（服务端入口没激活或已停止）时两页只读。

## 输出与可观察行为

### 服务商与模型

1. **版式**：左边服务商列表、右边所选服务商的详情（这一页自己分栏，见 [`settings/settings-window.md`](../settings/settings-window.md) 输出 3）。列表只列用户添加过的服务商，每项一行，高度同窗口左栏：服务商图标（输出 19）、名称，行尾一格写启用了几个模型；密钥没有设、环境变量没有值、有模型检测失败时这一格换成图标，悬停条目写原因。列表顶上“全部模型”一项、底下“添加服务商”。列表的选择照窗口左栏：当前项 `aria-current`、上下键与 Home、End 移动。页面宽不到 600px 时列表收成顶上的下拉加“添加”。
2. **开箱**：没有服务商时列表为空，右边是引导（为什么要添加、中转站与本机端点用空白模板）与“添加服务商”。
3. **添加服务商**：对话框列模板（[`models/service.md`](service.md) 输出 19），顶上搜索框按名称、id、地区名匹配；按“国际、国内、聚合与网关、其他、自定义”分组，组内多列（窄时一列），每行是图标、名称与模型数，有地区的写出地区。同一模板可以添加多份：已添加的不停用，标“已添加”与小字“再添加一份”，可访问名称里带“已添加”；不要密钥的标“不要密钥”；不能添加的（要登录、暂不支持、要自己填地址）列在同一张表里、停用并写原因。普通模板点了即添加；空白模板（OpenAI 兼容、Anthropic 兼容、Gemini 兼容）进第二步填名称、接口地址与接口格式，有地区的模板进第二步选地区，“返回”回到第一步、焦点回到点过的模板。键盘：模板按 DOM 顺序 Tab，搜索框里回车选第一个命中且能添加的。添加成功后对话框关闭、新服务商成为当前项，要密钥的焦点放在 API 密钥框上；失败时原因写在对话框里。
4. **连接**：标签在上的紧凑表单，说明收进标题旁的提示。
   - **API 密钥**：密码框，已设置时不回显值、显示“已设置”与“清除”；失焦或回车时写（`setKey`）；值以 `env:` 开头时存成环境变量引用，之后显示变量名与“环境里没有这个变量”的提示（变量没值时）。第一次拿到密钥状态之前显示“读取中”，不显示“未设置”。不要认证的服务商不显示密钥框。
   - **接口地址**：每家都可以改；要以 `http://` 或 `https://` 开头、能解析，否则原位写原因、不写；提示里写实际请求地址；改过模板的地址时出现“恢复模板地址”，并说明改了以后按通用协议发送。有地区的模板另有**地区**下拉。
   - **接口格式**：每家都有下拉（OpenAI Chat Completions、OpenAI Responses、Anthropic、Google Gemini）；改了模板的协议时旁边写“已改，模板是 …”与按通用协议发送的说明，选回模板的协议即恢复跟随。
   - **高级**（默认收起）：认证方式（按接口格式、`Authorization: Bearer`、不要认证）与服务商级请求头。
5. **请求头编辑**：一行一个名称与值，可加可删；名称非空、是合法的请求头名称、不重复（不分大小写）且值非空、不换行的行才写出，不合法的行原位标原因、不写；值可写 `env:<变量名>`；名称像凭据（例如含 `key`、`token`、`authorization`）而值不是 `env:` 时提示改用环境变量。名称与值的输入框有可访问名称。
6. **模型列表**：读的是这家的模型行（经选用数据分页读完）。列表头下一行是模型列表的来源与“重新拉取”（输出 20），再下面是“服务商新出的模型自动加入”开关（`followSource`，[`models/service.md`](service.md) 输出 22；空白模板也有）；超过 8 个模型时有搜索框（按名称与 id，在页面里过滤）。模型按系列分组（没写系列时由 id 推出）：模型不多于 30 个时系列默认展开，更多时默认收起、收起的组不渲染；搜索时展开命中的组、至多画 200 行，多出的写“还有 N 条，缩小搜索词”。改过来源值的模型标“已改”，手加的标“手动添加”。读行失败时原位写原因与“重试”。每行：启用开关、名称、能力图标（看图、推理、工具调用；图标有文字说明）、淡色的上下文窗口与单价、检测按钮、编辑按钮。被角色用着的模型行标角色名的小标。单价未知显示“未知”，为 0 显示“免费”。列表头有“检测全部”“管理模型”“手动添加”（每家都有）。
7. **启用与停用**：开关立即写（`upsertModel`）。有效上下文窗口不明的模型（来源没给、用户也没填）不启用，开关停用并说明“要补上下文窗口”。停用或移出被角色用着的模型时行内先确认，列出会受影响的角色。
8. **检测**：单个检测与“检测全部”（`check`、`checkAll`）进行中可取消（点行上的转圈取消这个模型，详情头的“取消检测”取消这家全部）；结果显示在行上（通过与失败，悬停或点开看时间），失败时红色图标可点开看归类后的原因、服务商原文与“重新检测”。没检成（远程调用本身失败：服务停了、服务商不在了）不算模型的检测失败，原因写在模型列表头上。检测按钮的可访问名称带模型名。结果按服务商与模型记在数据模块里，换页面、关开设置窗口都不丢，刷新页面后才没有。
9. **编辑模型**：对话框（叠在设置窗口上，二级面），分“基本”（模型 id 只读、显示名称、系列）、“能力与限制”（上下文窗口、最大输出、能看图、支持推理）、“单价”、“压缩”（触发点：跟随全局设置、留预留量、窗口的百分比、固定的 token 数，见 [`service.md`](service.md) 输出 17）、默认收起的“高级”（模型级请求头，同名盖过服务商的）。来源模型（模板目录里的）各字段显示来源值，可以覆盖；覆盖过的字段（名称、上下文窗口、最大输出、能看图、支持推理、单价）旁有“恢复来源值”，点了表单换回来源值；只写与来源值不同的字段。手加的模型整条写。“保存”才写（`upsertModel`），关闭不写；校验不过时不关、原位标原因。
10. **管理模型**：对话框列这家来源里的全部模型（[`models/service.md`](service.md) 输出 25：服务商的列表，没有时是目录），在列表里的与不在的（移出过的、关着自动加入时没加过的、类型不明不自动加入的）；空白模板与目录模板一样。按系列分组，类型不明的单独一组放在最后，组头下写“服务商没说明这些是不是对话模型，确认是再加入”；可搜索，至多画 200 行。每项“加入列表”或“从列表移出”（移出的来源模型可以再加回来），缺字段的标“要补字段”、加入后不启用；“完成”一次写（`setModels`）。读候选失败时原位写原因；对话框关闭后迟到的结果丢弃。重新拉取在模型区，不在对话框里。
11. **全部模型**：每家服务商一节（图标、名称、启用数），默认收起、收起的不渲染，展开时才读这家的行；节里是启用的模型（模型、能力、上下文窗口、检测状态、编辑按钮）。搜索时读全部服务商，命中的节展开，至多画 200 行。没有启用的模型时显示“没有启用的模型”。
12. **删除服务商**：在列表的条目上：悬停或聚焦的条目行尾出删除图标，右键条目弹菜单“删除服务商…”，键盘在条目上按 Delete（Shift+F10 或菜单键开同一个菜单）；页面窄、列表收成下拉时，下拉旁边一个删除按钮，删当前选中的那家；标题区不放按钮。确认框写明去掉几个模型、密钥一起删、哪些角色会变成未绑定；确认后 `removeProvider`。删的是当前选中的那家时，选中并聚焦下一个服务商，没有时到“添加服务商”；删的是别的一家时选中不变，焦点回到当前项；取消时焦点回到那家的条目。

### 模型角色

13. **角色表**：每行角色图标、角色名、说明、绑定的模型（可搜索的下拉，只列启用且可用的模型；在页面里按名称与 id 过滤，一次至多列 100 项，当前绑定的名字按引用取，不在前 100 项里也显示）、默认思考档（分档下拉，选项取自绑定模型的推理能力：可跟随模型、能关闭时有“关闭”；模型不能调档或未绑定时置灰并写原因；已存的档位不在选项里时说明实际用哪一档，规则见 [`models/service.md`](service.md) 输出 18）；未绑定的标红写“未绑定”，绑定的模型不可用时写原因（目录里没有了、没启用、没有密钥）。表上方一句说明解析规则（对话里没选、Profile 没指定时用“主力”；未绑定时报错并指向这一页，不换用别的模型）。选择立即写（`setRole`）。
14. **专精角色**：表下“添加专精角色”（`addRole`），自建的可改名与说明（`updateRole`）、可删（`removeRole`）；内置的不可删。

### 两页共有

15. **写入失败**：远程方法失败时经页面上下文的 `reportWriteFailure` 交给窗口通知（[`settings/settings-window.md`](../settings/settings-window.md) 输出 14），控件回到快照里的实际值；`unknown-outcome` 为“可能没有保存”，之后重取快照；`partially-applied` 按返回的实际密钥状态显示。
16. **跟随变化**：快照的 `changed` 事件到达时两页刷新（别的窗口、设置文件视图的改动即时可见）；正在编辑的输入框不被打断，失焦时以快照为准。
17. **只读**：远程合同不可用时写控件停用并在标题区说明；本作品标签下两页按分区规则停用。
18. **打开到指定位置**：两页读页面上下文的 `focus`（[`settings/settings-window.md`](../settings/settings-window.md) 输出 15），等第一份快照到了再取走（`takeFocus`）并定位。角色页：值是角色 id，滚到这个角色那一行，焦点放在它的模型下拉上（不是思考档下拉）。服务商页：值是已添加的服务商 id 时选中这家、焦点放在 API 密钥框上（不要认证的服务商没有密钥框，只选中）；值是 `add` 时打开“添加服务商”对话框。认不出的值取走后什么都不做。窗口已开在这一页时再来一次照样定位。
19. **服务商的标题区与图标**：详情顶上左边是图标按钮，中间是名称（`h3`），右边“复制一份”；删除仍在列表条目上（输出 12）。
    - **图标**：点图标开面板，三个页签：“内置”（搜索框加网格，只列模板用到的、图标表里有的）、“上传”（选一张图片，在页面里缩成边长不超过 128 像素的 PNG 再经 `setIcon` 上传；不收 SVG）、“首字母”。服务商有自己的图标时底部有“恢复模板的图标”。失败原因（不是图片、读取失败、不收 SVG、缩后仍过大、服务端拒收）写在面板里一行 `role="alert"`；上传与写入期间面板的控件停用。
    - **名称**：点名称或铅笔就地改，回车或失焦提交，Esc 取消；空名或没改时回退，不报错；与别家重名时输入框下写“已有同名服务商”、留在编辑状态。
    - **复制一份**：`duplicateProvider`；成功后选中副本、焦点放在名称上；`partially-applied` 时同样选中副本，并经窗口通知说密钥没复制成功。
    - 服务商的图标同样画在列表条目、添加对话框与“全部模型”的节头：上传的取读取路由，内置与模板的取应用的图标表，空白模板、选了首字母或认不出的画首字母块。Agent 的模型选择器按同一规则取实例的图标（[`ui/agent-conversation-view.md`](../ui/agent-conversation-view.md)）。
20. **模型列表的来源**：模型区头下一行按快照的列表状态（[`models/service.md`](service.md) 输出 25）写来源，`aria-live="polite"`：正在拉取；拉取失败与原因（有旧列表时加“沿用某时的列表”，红字）；地址、协议或凭据改过、要重新拉取；服务商的列表、更新于某时；还没有列表时，目录模板写“用内置的模型目录”，空白模板写“还没有拉到服务商的模型列表”。旁边“重新拉取”（`refreshSource`，受理即回，进度与结果随快照来）：没有可用的密钥时停用、旁边写“先填密钥才能拉取”，只读时停用；拉取进行中不停用（再点与在途的合并）。没受理（没有可用的密钥、设置读不到、服务商不在了）的原因写在这一行下面，不走写入失败的通知。时间按界面语言写。

## 状态与转换

- 数据模块随 `nbook.models` 的浏览器入口建立与释放：第一次显示任一页时订阅 `changed`（订阅先推一次快照），之后一直订阅到入口停用；订阅结束时两页只读，下次显示页面时重新订阅。检测结果同寿命。
- 时序与寿命：
  - 写入返回之前，控件显示这次的值；返回失败时回到快照的值（输出 15）。
  - 同一输入框连着改两次：后一次的值最终生效，前一次的失败通知照发。
  - 对话框里的读候选、检测进行中关闭对话框：请求取消或结果丢弃，不写入。
  - 重新拉取进行中离开页面：拉取在服务端照样走完，回来时按快照显示结果。

## 副作用与数据

无本地存储；全部状态在服务端（[`models/service.md`](service.md)）。

## 失败与恢复

页面不定义新的失败码，按远程合同的业务码显示原因（[`models/service.md`](service.md) 的失败表）。

## 边界与兼容

- 组件只经数据模块读写；两页组件是数据模块的消费者，不是两个宿主。
- 密钥与请求头的值不进浏览器的任何状态：密钥框写完即清空，只显示状态。

## 验收与 Smoke

1. 空白模板的服务商（本机假的 OpenAI 兼容端点）：添加（第二步填名称与地址）、设密钥与 `env:`、设好密钥后自动拉到服务商的列表（缺上下文窗口的不启用）、重新拉取、补上下文窗口后启用、检测失败看原因、在角色页绑定 `main`；停用被角色用着的模型先确认；删除服务商后焦点到“添加服务商”、角色变成未绑定。
2. 两个窗口同开“服务商与模型”：一处添加服务商、改地址、删除，另一处即时跟上。
3. 窄窗口（600px 以下）列表变下拉；本作品标签下两页停用；写失败时出现窗口通知。
4. 模板服务商：同一模板添加两份，名称自动区分；改名、复制一份、换内置图标与上传图标；模型区搜索与系列收起；关掉自动加入、移出一个来源模型、在管理模型里加回来。

Smoke：`e2e/models.e2e.ts`。

## 实现合同

- **公开入口**：无新的公开符号。两页经 `settings.pages` 贡献（`nbook/ui/settings/settings-page` 的 `settingsPage`），调用 [`models.service`](service.md) 的远程合同。
- **owner 与依赖方向**：`nbook.models` 的浏览器入口持有数据模块（`web/models-store.ts`）并贡献两页；页面组件只经数据模块读写，不各自订阅、不各自调用远程合同。依赖 `nbook.settings` 的设置窗口（页面上下文、写失败的窗口通知）与 nb-ui。
- **关键不变量**：
  - 快照只来自数据模块的订阅：别的窗口改了即时跟上；释放后不再跟着变、不再可用（输出 16、17，`models-store.test.ts`“数据模块”）。
  - 检测状态归数据模块：单独检测与检测全部同时进行时各自结算、不会留下一直转圈的；取消回到开始之前；服务商或模型离开快照时它的结果清掉（输出 8，`models-store.test.ts`）。
  - 模型行只经选用数据读：先比快照里各家的 `modelsRevision`，只重读变了的那家；分页中途换代整家重读、重试有上限；新的一份到齐前交出旧的，到齐后一次换引用（`selection.test.ts`）。快照里没有模型行，页面不从快照拼行。
  - 写失败交回码与详情、不抛；页面经窗口通知告诉用户，控件回到实际值（输出 15，`models-store.test.ts`，`models.e2e.ts` 验收 3）。
