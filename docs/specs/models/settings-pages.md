# 模型服务的设置页

## 目标与非目标

设置窗口 AI 分组下的两页：“服务商与模型”添加服务商、填密钥、管理模型并检测，“模型角色”给角色绑模型。两页的数据与写入全部经远程合同 `nbook.models/settings`（[`models/service.md`](service.md) 输出 12），改了就写，没有“未保存”状态。

不承诺：

- OAuth 登录、发现方式、兼容选项、扩展窗口、用命令取密钥（同 [`models/service.md`](service.md) 的非目标）。
- 本作品标签下编辑：两个设置项只允许用户层，本作品标签下两页停用（[`settings/settings-window.md`](../settings/settings-window.md) 输出 8 的 page 分区规则）。
- 价格以外的用量统计。

## 术语与参与者

- **数据模块**：两页共用的非组件模块，持有快照、密钥状态与检测、发现结果，所有写都经它调远程方法。
- **被角色用着的模型**：某个角色绑定的模型；判断用 `nbook.models` 的共享纯函数，服务端解析与页面同一份。

## 输入与前置条件

- 两页是 `nbook.models` 浏览器入口贡献的 page 分区（贡献点 `settings.pages`），分区 id `nbook.models.providers`、`nbook.models.roles`，分类 `ai`，`layout: "fill"`，`layers: ["user"]`；`nbook.models/providers`、`nbook.models/roles` 两个设置项指向它们。
- 远程合同不可用（服务端入口没激活或已停止）时两页只读。

## 输出与可观察行为

### 服务商与模型

1. **版式**：左边服务商列表、右边所选服务商的详情（这一页自己分栏，见 [`settings/settings-window.md`](../settings/settings-window.md) 输出 3）。列表只列用户添加过的服务商，每项写名称、密钥有没有设、启用了几个模型；列表顶上“全部模型”一项、底下“添加服务商”。列表的选择照窗口左栏：当前项 `aria-current`、上下键与 Home、End 移动。页面宽不到 600px 时列表收成顶上的下拉加“添加”。
2. **开箱**：没有服务商时列表为空，右边是引导（为什么要添加、本机端点也在目录里、中转站选自定义）与“添加服务商”。
3. **添加服务商**：可搜索的对话框，列 OMP 目录里的服务商；已添加的停用并标“已添加”；不要密钥的本机端点标“不要密钥”；只能登录的停用并写“要登录，第一版不支持”；最后一项是“自定义 OpenAI 兼容服务商”。选中即添加（`addProvider`）、对话框关闭、新服务商成为当前项。
4. **连接**：标签在上的紧凑表单，说明收进标题旁的提示。
   - **API 密钥**：密码框，已设置时不回显值、显示“已设置”与“清除”；失焦或回车时写（`setKey`）；值以 `env:` 开头时存成环境变量引用，之后显示变量名与“环境里没有这个变量”的提示（变量没值时）。第一次拿到密钥状态之前显示“读取中”，不显示“未设置”。不要认证的服务商不显示密钥框。
   - **接口地址**：可以改，目录服务商也可以；提示里写实际请求地址；目录服务商改过地址时出现“恢复目录地址”。自定义服务商另有**接口格式**下拉。
   - **高级**（默认收起）：认证方式（按接口格式、`Authorization: Bearer`、不要认证）与服务商级请求头。
5. **请求头编辑**：一行一个名称与值，可加可删；名称非空、不重复（不分大小写）且值非空的行才写出，不合法的行原位标原因、不写；值可写 `env:<变量名>`；名称像凭据（例如含 `key`、`token`、`authorization`）而值不是 `env:` 时提示改用环境变量。名称与值的输入框有可访问名称。
6. **模型列表**：启用的与列表里的模型按系列分组（没写系列时由 id 推出），每行：启用开关、名称、能力图标（看图、推理、工具调用；图标有文字说明）、淡色的上下文窗口与单价、检测按钮、编辑按钮。被角色用着的模型行标角色名的小标。单价未知显示“未知”，为 0 显示“免费”。列表头有“检测全部”“管理模型”“手动添加”（自定义服务商）。
7. **启用与停用**：开关立即写（`upsertModel`）。自定义模型缺上下文窗口时开关停用并说明“要补上下文窗口”。停用或移出被角色用着的模型时行内先确认，列出会受影响的角色。
8. **检测**：单个检测与“检测全部”（`check`、`checkAll`）进行中可取消；结果显示在行上（通过、失败与时间），失败时红色图标可点开看归类后的原因、服务商原文与“重新检测”。检测按钮的可访问名称带模型名。结果按服务商与模型记在数据模块里，换页面、关开设置窗口都不丢，刷新页面后才没有。
9. **编辑模型**：对话框（叠在设置窗口上，二级面），分“基本”（模型 id 只读、显示名称、系列）、“能力与限制”（上下文窗口、最大输出、能看图、支持推理）、“单价”、“压缩”（触发点）、默认收起的“高级”（模型级请求头，同名盖过服务商的）。目录模型的能力与单价来自目录、不能改，只写用户改过的字段。“保存”才写（`upsertModel`），关闭不写；校验不过时不关、原位标原因。
10. **管理模型**：对话框列目录模型（目录服务商）或 `/models` 发现的结果（自定义服务商，可“重新拉取”），可搜索；每项“加入列表”或“从列表移出”，缺字段的标“要补字段”；“完成”一次写（`setModels`）。发现失败按码显示原因（没有密钥、不支持、鉴权失败、连不上）。对话框关闭后迟到的发现结果丢弃。
11. **全部模型**：所有服务商启用的模型一张表（服务商、模型、能力、检测状态），可从这里打开编辑对话框；没有时显示“没有启用的模型”。
12. **删除服务商**：标题区的“删除”（`SettingsPageActions`），确认框写明去掉几个模型、密钥一起删、哪些角色会变成未绑定；确认后 `removeProvider`，焦点到下一个服务商，没有时到“添加服务商”。

### 模型角色

13. **角色表**：每行角色名、说明、绑定的模型（可搜索的下拉，只列启用且可用的模型）；未绑定的标红写“未绑定”，绑定的模型不可用时写原因（目录里没有了、没启用、没有密钥）。表上方一句说明解析规则（对话里没选、Profile 没指定时用“主力”；未绑定时报错并指向这一页，不换用别的模型）。选择立即写（`setRole`）。
14. **专精角色**：表下“添加专精角色”（`addRole`），自建的可改名与说明（`updateRole`）、可删（`removeRole`）；内置的不可删。

### 两页共有

15. **写入失败**：远程方法失败时经页面上下文的 `reportWriteFailure` 交给窗口通知（[`settings/settings-window.md`](../settings/settings-window.md) 输出 14），控件回到快照里的实际值；`unknown-outcome` 为“可能没有保存”，之后重取快照；`partially-applied` 按返回的实际密钥状态显示。
16. **跟随变化**：快照的 `changed` 事件到达时两页刷新（别的窗口、设置文件视图的改动即时可见）；正在编辑的输入框不被打断，失焦时以快照为准。
17. **只读**：远程合同不可用时写控件停用并在标题区说明；本作品标签下两页按分区规则停用。

## 状态与转换

- 数据模块随 `nbook.models` 的浏览器入口建立与释放：第一次显示任一页时订阅 `changed`（订阅先推一次快照），之后一直订阅到入口停用；订阅结束时两页只读，下次显示页面时重新订阅。检测结果同寿命。
- 时序与寿命：
  - 写入返回之前，控件显示这次的值；返回失败时回到快照的值（输出 15）。
  - 同一输入框连着改两次：后一次的值最终生效，前一次的失败通知照发。
  - 对话框里的发现、检测进行中关闭对话框：请求取消或结果丢弃，不写入。

## 副作用与数据

无本地存储；全部状态在服务端（[`models/service.md`](service.md)）。

## 失败与恢复

页面不定义新的失败码，按远程合同的业务码显示原因（[`models/service.md`](service.md) 的失败表）。

## 边界与兼容

- 组件只经数据模块读写；两页组件是数据模块的消费者，不是两个宿主。
- 密钥与请求头的值不进浏览器的任何状态：密钥框写完即清空，只显示状态。

## 验收与 Smoke

1. 自定义服务商（本机假的 OpenAI 兼容端点）：添加、设密钥与 `env:`、管理模型里拉取并加入、补上下文窗口后启用、检测失败看原因、在角色页绑定 `main`；停用被角色用着的模型先确认；删除服务商后焦点到“添加服务商”、角色变成未绑定。
2. 两个窗口同开“服务商与模型”：一处添加服务商、改地址、删除，另一处即时跟上。
3. 窄窗口（600px 以下）列表变下拉；本作品标签下两页停用；写失败时出现窗口通知。

Smoke：`e2e/models.e2e.ts`。
