# TypeScript 与 JavaScript

适用：`*.ts`、`*.tsx`、`*.js`、`*.mjs`、`*.cjs`。本文件只定义语言级合同；架构和框架规则由领域文件定义。

- 遵循仓库 ESM 与 `strict` 配置；4 空格缩进、双引号、分号。Node 内置模块使用 `node:` 前缀。
- 跨根目录导入使用 `nbook/*` 或所属包的公开入口；相对导入只用于同一局部模块，不穿越项目或包边界。
- 领域概念用命名类型表达，联合类型穷尽处理。`unknown` 只用于尚未验证的边界值并立即收窄；类型断言必须由运行期不变量支持。
- JSON、YAML、环境变量、HTTP、IPC、文件和 Provider 返回值使用现有 schema、解析器或类型守卫校验；类型声明不能代替运行期验证。
- 异步工作必须被 `await`、返回或由明确的生命周期 owner 持有；并发任务定义取消、超时和清理。保留底层错误的 `cause`、状态码或现有错误类型。
- 从长寿命的 `AbortSignal`（插件、连接、应用的停止信号）派生单次调用或订阅的信号时，操作结束就撤掉挂在长寿命信号上的监听；`AbortSignal.any` 派生的信号挂了监听又一直不触发时同样不会释放（2026-10 实测 Bun）。不在一个信号派发 abort 的过程中移除它的其它监听：被移除的监听这一轮不再被调用。
- 数据集合优先单次遍历和稳定 key；避免无必要的 spread、深拷贝、JSON 往返和循环内重复构建 `Map`、正则或 formatter。
- 结构化日志示例：`logger.debug({kind: message.kind}, "已处理 Agent 消息")`。字段名稳定，秘密和大正文只记录尺寸、摘要或脱敏标识。

完成标准：`strict` 类型检查通过，所有边界值已验证，所有异步任务都有 owner，导入没有穿越所属模块的公开边界。
