# 调研资料

`docs/research/` 保存第三方资料、实验、方案比较和尚未验证的结论，不是当前产品或工程行为依据。每份调研应写明日期、问题、证据来源、验证边界和当前状态。

调研只写可核查的事实：来源与版本、机制、实测输出、对照差异、未验证边界。主观评价、价值排序、推荐与取舍结论不进入调研文档；需要判断时只给出事实与证据位置，由 ADR、Proposal 或 Spec 承载。逐条标注证据等级（实测、源码、官方文档、检索），区分一手证据与未验证内容。

调研结论被采用时，把有效行为写入 [`../specs/`](../specs/) 或 [`../standards/`](../standards/)，长期取舍写入 [`../adr/`](../adr/)；调研原文保留证据身份，不继续作为操作说明。
