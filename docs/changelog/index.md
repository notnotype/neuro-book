## 版本号怎么读

所有版本目前都带 `-canary` 后缀，意思是「早期验证版」：功能可用，但可能还没经过完整的人工验收。完整版本号长这样：

```
0.8.19-canary.20260720.112718Z.1b4c9685
└─┬──┘ └─┬──┘ └──────┬───────┘ └───┬──┘
 版本   通道      发布时间(UTC)   代码快照
```

中间的数字是发布时刻，末尾是对应的代码版本。安装管理器（NeuroBook Manager）有自己独立的版本号，形如 `0.1.0-canary.30`，和应用版本不是一回事。

## 找不到某个版本？

0.5.4、0.5.5、0.6.x、0.7.3 – 0.7.8、0.8.1、0.8.7、0.8.8 这些号段没有对外发布记录：它们要么在构建阶段就失败了、要么只是内部候选。跳号是正常的，不是文档漏了。
