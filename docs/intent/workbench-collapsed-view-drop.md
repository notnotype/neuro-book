# 收起 View 后的内容落点

- **结果：** 面板里的 View 收成细条后，drop 落在细条右侧没被占用的内容区，不再贴着 32px 细条画一条蓝线。
- **谁用：** 在 `WorkbenchShellLayout` 里拖 View 或整容器的人。
- **为什么现在改：** 细条没有吃掉剩余宽度，反馈和「并入 1 个视图」都落在空白里，看起来像投进了空区。
- **成功：** 反馈铺满细条右侧那块区域；松手后拖进来的 View 在这块区域展开，原来收起的 View 仍是细条。那两行「剩余未被吸收」诊断不再出现。
- **约束：** 不把细条拉宽去填满剩余宽度。已经展开的窗格仍按前后各 50% 接收。3001 不重启。
- **不做：** 不改 Editor 的四边命中，不改 Switcher 插入线，也不为了消掉诊断去改宽度分配算法。
