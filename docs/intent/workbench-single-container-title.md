# 左栏单 View 容器标题

- **结果：** 主侧栏只剩一个可见 View 时，32px 标题行左侧显示当前容器名，拖这一行就能搬走整个容器。
- **谁用：** 在 `WorkbenchShellLayout` 里整理只剩一个 View 的主侧栏容器的人。
- **为什么现在改：** 容器名被收成 1×1 隐藏拖动源，标题行只剩右侧 `...`，既看不见名字，也拖不到容器。
- **成功：** 标题行左侧出现容器名；从标题拖起能移动容器；View 内容区不出现第二行标题。
- **约束：** 右侧动作区保持不动，`...` 和按钮不作为拖动起点。多个 View 时隐藏整条外层标题行，只保留各自的 View 标题。Panel 和右栏继续用标签。
